**Notes on judgment calls:**

- **Extension markers:** The function searches for the earliest occurrence of `ext`, `x`, or `#`, so `555-123-4567 ext. 89` and `5551234567x89` both cut correctly.
- **ZIP+4:** It accepts both `02139-4307` and the Excel-mangled `2139-4307`. The second becomes `02139`.
- **Digits:** Only ASCII `0-9` count as digits, so odd Unicode digits can't slip through.
- **Gmail rules:** These apply only when the address has exactly one `@`. Addresses with more than one `@` are invalid anyway.
- **Bad dates:** An unparseable `updated` value raises a `ValueError` that names the value. Since `updated` is required, I chose to fail loudly instead of silently guessing.
- **Opt-outs:** If any row in a merged group has opted out, the whole person is marked `opted_out = "Y"`. Remember to filter those people out before sending. This function flags them but doesn't remove them.
- **Dropped rows:** Rows without a valid email are kept if they have a valid phone, so the output can include people you can't email. Filter on `email != ""` for the send list.
