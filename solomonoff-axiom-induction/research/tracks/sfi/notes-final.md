## 1. Setting and dictionary (T1)

### 1.1 Objects

Throughout, $\mathcal L$ is a countable first-order language with computable syntax, $B\subseteq\Sent_{\mathcal L}$ a decidable consistent background, $V$ the universal prefix machine, $\Omega_V:=\sum_{p\in\dom V}2^{-|p|}<1$. A data set $D$ is a finite partial function $\Sent_{\mathcal L}\rightharpoonup\{0,1\}$; $D^\pm$, $\psi_D$ as in NOTATION §3.2. $\Unif$ is the fair-coin measure on tapes.

* **Theory machines** (NOTATION §4.1). A c.e. set $G\subseteq\{0,1\}^*\times\Sent_{\mathcal L}$; $A^G_\omega$; $\nu_G(D):=\Unif\{\omega:B\cup A^G_\omega\text{ consistent and}\vdash\psi_D\}$; $G_U:=\{(pw,\chi):p\in\dom V,(w,\chi)\in G_{V(p)}\}$; $M_A:=\nu_{G_U}$, $A_\omega:=A^{G_U}_\omega$.
* **Function machines** (P1 Def 3.6, letter $F$ here). A c.e. consistent set $F\subseteq\Sent_{\mathcal L}\times\{0,1\}^*\times Y$; $f^F_\omega$; $\nu_F(D):=\Unif\{\omega:f^F_\omega\supseteq D\}$; $F_U$ the universal one (P1 Thm 3.8), $M_F:=\nu_{F_U}$, $f_\omega:=f^{F_U}_\omega$. Here $Y=\{0,1\}$ unless three-valued labels are stated.
* **Definition 1.1 (consistent and closed labellers; scout S Def 2.1).** For a partial $f:\Sent_{\mathcal L}\rightharpoonup\{0,1\}$, $\Gamma_f:=\{\varphi^{f(\varphi)}:\varphi\in\dom f\}$. $f$ is *consistent* if $B\cup\Gamma_f$ is consistent, and *closed* if moreover $f(\varphi)=b\iff B\cup\Gamma_f\vdash\varphi^b$ for all $\varphi,b$.
* **Consistent and closed one-tape SOI.** $\nu^{\rm cons}_F(D):=\Unif\{\omega:f^F_\omega\supseteq D,\ f^F_\omega\text{ consistent}\}$, $\nu^{\rm cl}_F$ likewise with "closed and consistent"; $M_F^{\rm cons}:=\nu^{\rm cons}_{F_U}$, $M_F^{\rm cl}:=\nu^{\rm cl}_{F_U}$.
* **Random deciders.** Function machines $F$ with outputs in $\{0,1\}$ such that $f^F_\omega$ is total for every $\omega$; $A^{\rm dec}_F(\omega):=\{\chi:f^F_\omega(\chi)=1\}$; $\mu^{\rm dec}_F(D):=\Unif\{\omega:B\cup A^{\rm dec}_F(\omega)\text{ consistent},\vdash\psi_D\}$; $M_A^{\rm dec}(D):=\sum_{p\in\dom V,\ F_{V(p)}\text{ a random decider}}2^{-|p|}\mu^{\rm dec}_{F_{V(p)}}(D)$.
* **Coin-free and Kolmogorov versions.** $W_A$, $K_A$ over enumerators (indices of r.e. sets $\mathsf W_{V(p)}$), $W_A^{\rm dec}$, $K_A^{\rm dec}$ over deciders; $W^{\rm cons}$, $W^{\rm cl}$, $K_F^{\rm cons}$, $K_F^{\rm cl}$ over the partial computable labellers $\{V(p)\}$ (Kleene bracket, NOTATION §2) that are consistent, resp. closed and consistent. *Plain* SOI on sentences is P1's $M_F$, $K_F$ and coin-free $W$ with $X=\Sent_{\mathcal L}$; following NOTATION §4.4 the coin-free one is written $W^{\rm all}$ when its inputs are sentences (the AI-paper's FIall), and $W$ is kept for P1's object on strings (§5).
* **Background and consequence.** "$\Gamma$ proves $\varphi$" means $B\cup\Gamma\vdash\varphi$, and $\Cn(\Gamma)$ includes $B$ (NOTATION §3.1). A sentence is *$B$-independent* if $B$ decides neither it nor its negation.

*Measurability.* $\{\omega:f_\omega\supseteq D\}$ is open. "$f_\omega$ inconsistent" is open: an inconsistency uses finitely many labels, each certified under a prefix of $\omega$, and these prefixes are comparable. "$f_\omega$ closed" is a countable intersection of Borel conditions. For theory machines $\{\omega:B\cup A_\omega\vdash\psi\}$ is open and consistency is closed (F1(a)). All events below are Borel.

### 1.2 The decompositions

**Lemma 1.2 (mixture decompositions) [proved].** For every finite $D\neq\emptyset$,
$$M_F^{\rm cons}(D)=\sum_{p\in\dom V}2^{-|p|}\nu^{\rm cons}_{F_{V(p)}}(D),\tag{1.1}$$
and the same for $\nu^{\rm cl}$ and for $\nu$ (P1 eq. (setting:mixture)); for $D=\emptyset$ add $1-\Omega_V$ on the right for $\nu^{\rm cons}$ and $\nu$, and nothing for $\nu^{\rm cl}$: the empty labeller is never closed, because $B$ proves every tautology and the empty labeller labels none (development round: "add $(1-\Omega_V)[\text{the empty labeller is closed}]$", a bracket that is always $0$; referees A m11, B 7). For every finite $D$, the empty one included,
$$M_A(D)=\sum_{p\in\dom V}2^{-|p|}\nu_{G_{V(p)}}(D)+(1-\Omega_V)\,[B\vdash\psi_D].\tag{1.2}$$

*Proof.* $\dom V$ is prefix-free, so every tape has at most one prefix $p\in\dom V$. On a tape $p\omega'$, $f^{F_U}_{p\omega'}=f^{F_{V(p)}}_{\omega'}$ and $A^{G_U}_{p\omega'}=A^{G_{V(p)}}_{\omega'}$, with $\omega'$ uniform given $p$. On the tapes with no prefix in $\dom V$ (measure $1-\Omega_V$), $f_\omega$ is nowhere defined, so it extends $D$ only if $D=\emptyset$ (and it is consistent, $B$ being consistent); and $A_\omega=\emptyset$, so the theory is $B$, consistent, and proves $\psi_D$ iff $B\vdash\psi_D$. $\square$

The weight on index $i$ is $\mm(i)=\sum_{V(p)=i}2^{-|p|}$, so (1.1) reads $M_F^{\rm cons}=\sum_i\mm(i)\nu^{\rm cons}_{F_i}$ on nonempty $D$.

### 1.3 The four maps

Every proof of an equivalence below uses one or more of four constructions. For a computable map $h$ on indices, universality of $V$ gives a string $r_h$ with $V(r_hs)=h(V(s))$ for all $s\in\dom V$ (the prefix machine $s\mapsto h(V(s))$ is simulated with prefix $r_h$). So $p\mapsto r_hp$ is injective, maps $\dom V$ into $\dom V$, and adds $|r_h|$ to the length. "Tape by tape" means: the stated relation holds for every tape $\omega$.

**Lemma 1.3 (the maps) [proved].**
* **(PS) Proof search.** For a theory machine $G$ let $F_G$ answer a query $\varphi$ as follows: in stages $s=1,2,\dots$ read the tape up to bit $s$, run $s$ steps of the enumeration of $G$ restricted to pairs $(w,\chi)$ with $w$ a prefix of the bits read, and test all derivations of size $\le s$ from $B$ together with the sentences emitted so far; halt with $1$ at the first derivation of $\varphi$, with $0$ at the first derivation of $\neg\varphi$ (within a stage $\varphi$ is tested first). Then $F_G$ is a function machine, and on every tape $\omega$ with $B\cup A^G_\omega$ consistent, $f^{F_G}_\omega$ is consistent and closed and decides every sentence exactly as the theory $B\cup A^G_\omega$ does. In particular $\{\omega:G\text{ compatible with }D\}\subseteq\{\omega:f^{F_G}_\omega\supseteq D,\ f^{F_G}_\omega\text{ closed and consistent}\}$.
* **(EM) Emission.** For a function machine $F$ let $G_F:=\{(w,\varphi):(\varphi,w,1)\in F\}\cup\{(w,\neg\varphi):(\varphi,w,0)\in F\}$. Then $A^{G_F}_\omega=\Gamma_{f^F_\omega}$ for every $\omega$. So if $f^F_\omega$ is consistent and extends $D$, then $G_F$ is compatible with $D$ on $\omega$; if $f^F_\omega$ is closed and consistent, the theory $B\cup A^{G_F}_\omega$ decides every sentence exactly as $f^F_\omega$ does.
* **(CR) Craig.** For a function machine $F$ (presented as a machine that reads the tape one-way) let $C_F$ answer a query $\chi$: find the at most two decompositions $\chi=\psi^{\wedge m}$ (right-nested $m$-fold conjunction; $m=1$, or $\psi$ the left conjunct of $\chi$ and $m$ fixed by $|\chi|$); for each, test **both readings**: (i) run $F$ on $\psi$ for exactly $m-1$ steps, reading the tape as $F$ does, and accept if $F$ halts at step $m-1$ with label $1$; (ii) if $\psi=\neg\varphi'$, run $F$ on $\varphi'$ for exactly $m-1$ steps and accept if it halts at step $m-1$ with label $0$. Answer $1$ iff some test accepts, $0$ otherwise. (The development round's wording, "if $\psi=\varphi$ (or $\psi=\neg\varphi$) … label $1$ (label $0$)", could be read as testing only (ii) for a negated $\psi$; that reading loses the members $(\neg\varphi')^{\wedge(k+1)}$ that come from $f(\neg\varphi')=1$ and does not preserve $\Cn$: referee A m12; `checks/c5_revision.out` (B): $\Cn$ changes in 26 of 82 random labellers under the one-reading decoder and in none under the two-reading decoder.) Then $C_F$ is a random decider and $A^{\rm dec}_{C_F}(\omega)$ is Craig's set of $f^F_\omega$, with $\Cn(A^{\rm dec}_{C_F}(\omega))=\Cn(\Gamma_{f^F_\omega})$.
* **(CL) Closure.** For a partial computable labeller $f$ let $\bar f$ be "search for proofs of $\varphi$ and of $\neg\varphi$ from $B\cup\Gamma_f$ (dovetailing the enumeration of $\Gamma_f$)". If $f$ is consistent, $\bar f$ extends $f$, is consistent and closed, and $\Cn(\Gamma_{\bar f})=\Cn(\Gamma_f)$.

*Proof.* (PS) The run on query $\varphi$ is a deterministic function of the bits read, and a halting run that has read $w$ runs identically on every tape extending $w$; so the triples $(\varphi,w,y)$ of halting runs are consistent, and the set is c.e. Let $B\cup A^G_\omega$ be consistent. If it proves $\varphi^b$, a derivation uses finitely many axioms, each emitted under a prefix of $\omega$; at a late enough stage they have all been enumerated and the derivation has size $\le s$, so the run halts; it cannot find a derivation of $\varphi^{1-b}$ first, because none exists. If the theory decides neither, no derivation is ever found and $f(\varphi)=\bot$. So $f^{F_G}_\omega(\varphi)=b$ iff $B\cup A^G_\omega\vdash\varphi^b$. Then $\Gamma_f\subseteq\Cn(A^G_\omega)$ is consistent with $B$, and $f$ is closed: $B\cup\Gamma_f\vdash\varphi^b$ implies $B\cup A^G_\omega\vdash\varphi^b$ (as $\Gamma_f\subseteq\Cn(A^G_\omega)$), which implies $f(\varphi)=b$; the converse holds as $\varphi^b\in\Gamma_f$.
(EM) $G_F$ is c.e. and emits $\varphi^y$ exactly under the prefixes that certify $f(\varphi)=y$; so $A^{G_F}_\omega=\Gamma_{f^F_\omega}$. If $f$ is closed, $B\cup\Gamma_f\vdash\varphi^b$ iff $f(\varphi)=b$.
(CR) Every run is bounded by $m-1$ simulated steps, so $C_F$ halts on every query and every tape: a random decider. Its answer depends only on the tape bits read by the simulated run, so its triples are consistent. Its accepted set on $\omega$ is $\{\varphi^{\wedge(k+1)}:F\text{ halts on }\varphi\text{ with }1\text{ in exactly }k\text{ steps}\}\cup\{(\neg\varphi)^{\wedge(k+1)}:\dots\text{ with }0\dots\}$: reading (i) gives the first set (also for $\varphi$ itself a negation), reading (ii) the second. Each member is equivalent to a member of $\Gamma_{f_\omega}$, and each member of $\Gamma_{f_\omega}$ has one. (This is AI-paper Thm 6.3's construction with the tape added; re-checked against `app-time.tex`, proof of Thm 6.3, and TF Lemma 2.1(b) for the "at most two decompositions".)
(CL) As (PS), with the r.e. set $\Gamma_f$ in place of $A^G_\omega$; $f(\varphi)=b$ puts $\varphi^b\in\Gamma_f$, so $\bar f(\varphi)=b$. $\square$

**Remark 1.4 (only inclusions are claimed).** The (PS) inclusion can be strict: on a tape on which the theory is inconsistent the labeller may still have committed to a consistent set of labels before the inconsistency appeared. In the finite propositional analogue this happens often (`checks/c1_onetape_finite.out`, item (1): $F_G$ strictly larger in 40635 and 50267 machine–data–tape triples; item (5a): 135 and 167 tapes with an inconsistent theory but a closed consistent $F_G$). Scout S's toy reported equality in its item (1); nothing below needs equality.

## 2. The coin-free equivalence (T2)

**Theorem 2.1 (coin-free equivalence) [proved; Craig 1953 known].** There is $c$, depending only on $V$, the coding of syntax and $B$, such that for every finite $D$:
(a) $2^{-c}W_A(D)\le W^{\rm cons}(D)\le2^cW_A(D)$, $\;2^{-c}W_A(D)\le W_A^{\rm dec}(D)\le2^cW_A(D)$, and $2^{-c}W^{\rm cons}(D)\le W^{\rm cl}(D)\le W^{\rm cons}(D)$;
(b) $K_A$, $K_A^{\rm dec}$, $K_F^{\rm cons}$ and $K_F^{\rm cl}$ agree up to $\pm c$, and all are finite iff $B\cup D^\pm$ is consistent;
(c) for every $\varphi\notin\dom D$ and each outcome $o\in\{1,0,\bot\}$, with $W_A(D;\varphi\mapsto o)$ the weight of the compatible enumerators whose theory proves $\varphi$ ($o=1$), proves $\neg\varphi$ ($o=0$), or decides neither ($o=\bot$), and $W^{\rm cl}(D;\varphi\mapsto o)$ the weight of the closed consistent labellers extending $D$ with $f(\varphi)=o$:
$2^{-c}W_A(D;\varphi\mapsto o)\le W^{\rm cl}(D;\varphi\mapsto o)\le2^cW_A(D;\varphi\mapsto o)$.
Hence the semimeasure losses of all four coin-free inducers agree within $2c$ on every $D$ in every order.

*Proof.* Coin-free versions of the maps of Lemma 1.3 (deterministic machines ignore the tape).
* *Enumerators to labellers* (PS): $p\mapsto r_{\rm ps}p$; if $p$ is compatible, the proof-search labeller is closed and consistent, extends $D$, and decides each $\varphi$ as the theory does.
* *Labellers to enumerators* (EM): $p\mapsto r_{\rm em}p$, the enumerator of $\Gamma_{\{V(p)\}}$; if the labeller is consistent and extends $D$, the theory is consistent and proves $D^\pm$; if it is closed, it decides as the labeller does.
* *Labellers to deciders* (CR without tape): the decider of Craig's set; it halts on every input even when the labeller is partial, since every run is bounded by the exponent of the candidate power.
* *Deciders to enumerators*: enumerate the decided set (same theory).
* *Consistent to closed* (CL).
All maps are injective on programs and add a constant to the length, so summing $2^{-|p|}$ over compatible programs gives (a) and (c), and taking shortest programs gives (b). (c) uses (PS) and (EM) restricted to closed labellers, which preserve the decision of every sentence. Finiteness in (b): if $B\cup D^\pm$ is consistent, the lookup table of $D$ is a consistent labeller and the decider of the finite set $D^\pm$ is compatible; if not, no consistent theory proves $D^\pm$ and no consistent labeller extends $D$. Losses: each of the two terms of $\ell(D)=-\log W(D)+\log W(\emptyset)$ changes by at most $c$. $\square$

*What was re-checked in the source* (AI-paper Thm 6.3 and its proof in `app-time.tex`): the decider of $A^C_f$ halts on all inputs (bounded runs); each member is equivalent to its literal and each literal has a member, so $\Cn$ is preserved; both maps are a fixed wrapper followed by the program, hence injective with constant overhead; $W(D)$ depends on $D$ only as a set. ## 3. The one-tape equivalence (T3)

**Theorem 3.1 (one-tape equivalence; scout S Thm 2.5, scout F's F8) [proved; computed: `checks/c1_onetape_finite.out`, items (1)–(3)].** There is $c$, depending only on $V$, the coding and $B$, such that for every finite $D$, the empty one included:
(a) $2^{-c}M_A(D)\le M_F^{\rm cons}(D)\le2^cM_A(D)$;
(b) $2^{-c}M_A(D)\le M_A^{\rm dec}(D)\le2^cM_A(D)$;
(c) tape by tape: $\{\omega:G\text{ compatible with }D\}\subseteq\{\omega:f^{F_G}_\omega\supseteq D,\ f^{F_G}_\omega\text{ consistent}\}$ for every theory machine $G$; $\{\omega:f^F_\omega\supseteq D,\text{ consistent}\}\subseteq\{\omega:G_F\text{ compatible with }D\}$ and $\subseteq\{\omega:C_F\text{ compatible with }D\}$ for every function machine $F$.

*Proof.* (c) is Lemma 1.3 (PS), (EM), (CR). (a) for $D\neq\emptyset$: by (1.2), (c) and (1.1), with the maps $p\mapsto r_{\rm ps}p$ (an index of $F_{G_{V(p)}}$) and $p\mapsto r_{\rm em}p$ (an index of $G_{F_{V(p)}}$),
$$\sum_p2^{-|p|}\nu_{G_{V(p)}}(D)\le\sum_p2^{-|p|}\nu^{\rm cons}_{F_{V(r_{\rm ps}p)}}(D)\le2^{|r_{\rm ps}|}M_F^{\rm cons}(D),\qquad M_F^{\rm cons}(D)\le2^{|r_{\rm em}|}\sum_p2^{-|p|}\nu_{G_{V(p)}}(D)\le2^{|r_{\rm em}|}M_A(D).$$
The remaining term $(1-\Omega_V)[B\vdash\psi_D]$ of (1.2) is at most $[B\vdash\psi_D]$; if $B\vdash\psi_D$, the deterministic proof-search labeller of $B$ is closed and consistent and extends $D$ on every tape, so $M_F^{\rm cons}(D)\ge2^{-c_B}$. Hence $M_A\le(2^{|r_{\rm ps}|}+2^{c_B})M_F^{\rm cons}$. For $D=\emptyset$ both $M_A(\emptyset)$ and $M_F^{\rm cons}(\emptyset)$ lie in $[1-\Omega_V,1]$ (tapes without a program give the consistent theory $B$ and the empty labeller), so their ratio is at most $1/(1-\Omega_V)$.
(b) A random decider is a theory machine (emit $\chi$ under the prefix that certifies the answer $1$), so $M_A^{\rm dec}\le2^cM_A$; and $C_{F_{V(p)}}$ with (CR) gives $M_A^{\rm dec}\ge2^{-c}M_F^{\rm cons}\ge2^{-2c}M_A$ on $D\neq\emptyset$; for $D=\emptyset$ the decider of $\emptyset$ gives $M_A^{\rm dec}(\emptyset)\ge2^{-c}$. $\square$

*Overhead.* Three wrappers (proof search over emitted axioms; emission; Craig) and the proof search of $B$. Nothing uses lower semicomputability. *Re-check of scout S's proof:* its $T_G$ tests "derivations of size $\le s$ from $B$ together with the sentences emitted so far", which needs $B$ decidable (assumed); its argument for (a) handles the $(1-\Omega_V)$ term exactly as above. Correct. The extension to $D=\emptyset$ is new and trivial.

**Corollary 3.2 (closed one-tape labellers and the trichotomy) [proved; computed: c1 items (5a), (5b)].** For every finite $D$, $\varphi\notin\dom D$ and $o\in\{1,0,\bot\}$, let $M_A(D;\varphi\mapsto o)$ be the measure of the tapes on which the theory is consistent, proves $\psi_D$, and proves $\varphi$ ($o=1$), proves $\neg\varphi$ ($o=0$) or decides neither ($o=\bot$), and $M_F^{\rm cl}(D;\varphi\mapsto o)$ the measure of the tapes on which $f_\omega$ is closed, consistent, extends $D$ and has $f_\omega(\varphi)=o$. Then $2^{-c}M_A(D;\varphi\mapsto o)\le M_F^{\rm cl}(D;\varphi\mapsto o)\le2^cM_A(D;\varphi\mapsto o)$, and $2^{-c}M_A\le M_F^{\rm cl}\le M_F^{\rm cons}$.

*Proof.* (PS) maps tapes with a consistent theory to tapes on which $F_G$ is closed and decides as the theory; (EM) maps tapes with a closed consistent labeller to tapes on which the theory decides as the labeller. The program-less tapes (theory $B$) are covered by the closed deterministic labeller "proof search from $B$", of weight $2^{-c_B}$, which decides as $B$ does. Sum as in Thm 3.1. $\square$
So the trichotomy of SAI (true / false / independent of the sampled theory) is the three-way split of SOI over *closed* labellers; over all consistent labellers it is not (Prop 6.1).

### 3.3 Penalised one-tape versions

The AI-paper's axiom-side penalties (TF Def 1.1) bound the time to check or to generate axioms. For the one-tape version the natural objects are random deciders and random enumerators that meet the bound on every tape. We use U-program format, as TF does: programs of the universal prefix machine $U$, read to their end before the input, now with access to a one-way read-only random tape.

**Assumption (S$_{\rm tape}$).** There are constants $\alpha,a\ge1$ with the properties of TF's (S) (`app-time.tex`, paragraph "Machines"), where the dovetailing schedule is run on a tape-reading program $q$: at stage $s$ it starts $q$ on the $s$-th sentence and advances every unfinished run by one simulated step, all runs reading the same tape $\omega$ one-way from its start; the work counter $T$ counts the simulated steps (tape reads included), the lengths of the sentences started, and $|q|$; up to work $T$ the schedule costs at most $\alpha(T+1)^a$ steps and reads at most $T$ tape bits. [assumed, like (S); *justification sketch:* keep the bits read so far on a work tape and one pointer per run; a simulated read copies a stored bit or reads the next tape bit, at cost $O(T)$; so the exponent of (S) grows by at most $1$. Not written out for a concrete $U$.] Put $a':=\max(a,2)$, $a^*:=\max(a,3)$.

**Definition 3.3 (penalised one-tape SAI).** A *random decider program* $q$ halts on every $(\chi,\omega)$ with yes or no; $A^q_\omega$ is its yes-set on $\omega$. A *random enumerator program* $e$ (no input) writes $a_1(\omega),a_2(\omega),\dots$, completing $a_i$ at step $e_i(\omega)$. For time-constructible $t$:
* $M_A^{{\rm chk},t}(D):=\sum_q2^{-|q|}\mu^{\rm dec}_q(D)$ over random decider programs with $\sup_{\chi,\omega}{\rm time}_q(\chi,\omega)/t(|\chi|)<\infty$;
* $M_A^{{\rm gen},t}(D):=\sum_e2^{-|e|}\Unif\{\omega:B\cup\{a_i(\omega)\}_i\text{ consistent},\vdash\psi_D\}$ over random enumerator programs meeting the delay form $\sup_{\omega,i}(e_i-e_{i-1})/t(|a_i|)<\infty$ (strict form: $e_i/t(|a_i|)$; cumulative form: $e_i/t(|a_1|+\dots+|a_i|)$).

In U-program format, the unpenalised one-tape laws $M_A^U:=\sum_q2^{-|q|}\nu_{G_q}$ (all tape-reading programs read as theory machines) and $M_F^{{\rm cons},U}$ agree with $M_A$ and $M_F^{\rm cons}$ within constant factors (each universal mixture contains the other's universal machine with a constant prefix; F5, P1 "The choice of universal machine"). [proved]

**Theorem 3.4 (axiom-side penalties are vacuous for the one-tape version) [proved, under (S$_{\rm tape}$)].** Let $t(m)\ge m^{a^*}$ be time-constructible. There is $c$ such that for every finite $D$, the empty one included,
$$2^{-c}M_F^{\rm cons}(D)\le M_A^{{\rm chk},t}(D)\le2^cM_A(D),\qquad2^{-c}M_F^{\rm cons}(D)\le M_A^{{\rm gen},t}(D)\le2^cM_A(D)$$
(strict, delay and cumulative forms). With Thm 3.1, all of $M_A^{{\rm chk},t}$, $M_A^{{\rm gen},t}$, $M_A$, $M_F^{\rm cons}$ agree within constant factors on every finite data set, and their semimeasure losses within a constant. (The development round stated this for $D\neq\emptyset$; the empty case is added on referee B's issue 8.)

*Proof.* *Lower bounds.* Let $p$ be a tape-reading program for a function machine $F$. Let $q_F$ say yes on $\chi$ if $F$ labels $\chi$ with $1$, or if $\chi=\neg\varphi$ and $F$ labels $\varphi$ with $0$ (dovetailing the two runs, on the same tape). On every tape its yes-set is $\Gamma_{f^F_\omega}$, and $|q_F|\le|p|+c$. The padded random decider $d:=W_{\rm dec}{}^\frown q_F$ answers $\chi$ as TF Lemma 2.1(b) prescribes: at most two candidates $\chi=\psi^{\wedge m}$; reject if $m-1<|q_F|$; otherwise run the schedule of $q_F$ on the tape, without writing, until the counter exceeds $m-1$, and accept iff $q_F$ is first detected saying yes on $\psi$ exactly at counter $m-1$. Under (S$_{\rm tape}$) this takes at most $\alpha(|q_F|+1)+3\alpha(|\chi|+1)^{a'}$ steps on *every* tape (TF Lemma 2.1(b), verbatim with the tape), and the bound is uniform in $\omega$. The answer depends only on the tape bits read by the schedule, so $d$ is a random decider. On each tape its yes-set is $\mathrm{Pad}_\omega:=\{\psi^{\wedge(T+1)}:q_F\text{ first detected saying yes on }\psi\text{ at counter }T\text{ on }\omega\}$; distinct detections have distinct counters, so each $\psi\in\Gamma_{f^F_\omega}$ has exactly one padded copy and $\Cn(\mathrm{Pad}_\omega)=\Cn(\Gamma_{f^F_\omega})$ (TF Lemma 2.1(a) per tape). So on every tape where $f^F_\omega$ is consistent and extends $D$, $d$ is compatible with $D$. The padded enumerator $e:=W_{\rm enum}{}^\frown q_F$ writes $\psi^{\wedge(T+1)}$ at each detection; TF Lemma 2.1(c) gives, per tape, delay $\le2\alpha|a_i|^a$, strict completion $\le5\alpha|a_i|^{a^*}$ and cumulative completion $\le2\alpha(|a_1|+\dots+|a_i|)^a$, uniformly in $\omega$. Both maps are injective and add a constant to the length. Summing over $p$ (with $M_F^{{\rm cons},U}\asymp M_F^{\rm cons}$) gives the lower bounds for $D\neq\emptyset$. For $D=\emptyset$: the decider that rejects every sentence runs in linear time and its theory $B$ is consistent, and the enumerator that writes nothing meets every delay condition vacuously, so $M_A^{{\rm chk},t}(\emptyset),M_A^{{\rm gen},t}(\emptyset)\ge2^{-c}\ge2^{-c}M_F^{\rm cons}(\emptyset)$.
*Upper bounds.* A random decider program $q$ (input $\chi$, answer yes or no) and a random enumerator program $e$ (no input, writes sentences) are read as theory machines in two different ways: $G^{\rm dec}_q$ emits $\chi$ under the tape prefix read by a run of $q$ on $\chi$ that answers yes, and $G^{\rm enum}_e$ emits the $i$-th written sentence under the prefix read when it is completed. Each reading is a fixed computable map on programs, realised by a constant-size wrapper, which is injective and keeps the theory on every tape (referee A m6). So $M_A^{{\rm chk},t},M_A^{{\rm gen},t}\le2^{c}M_A^U\le2^{c'}M_A$, for every $D$. $\square$

**Proposition 3.5 (class posteriors, one tape; the one-tape form of TF Prop 5.1) [proved, under (S$_{\rm tape}$)].** Let $X$ be $M_A^{{\rm chk},t}$ or $M_A^{{\rm gen},t}$ (any form), $t\ge m^{a^*}$. For a class $\mathcal C$ of deductively closed theories let $X(\mathcal C,D)$ be the measure, under $X$'s mixture, of the tapes on which the hypothesis is compatible with $D$ and $\Cn(\text{its axioms})\in\mathcal C$. Then $2^{-c}M_A(\mathcal C,D)\le X(\mathcal C,D)\le2^cM_A(\mathcal C,D)$ for all $\mathcal C$ and $D$. So posterior odds between any two classes of theories ("genuine" axiom systems and "disguised" assigners alike) differ between $X$ and $M_A$ by a factor at most $2^{2c}$.

*Proof.* Lower bound: for a theory machine $G$ (program $p$), let $q_G$ say yes on $\chi$ iff $G$ emits $\chi$ on the tape; pad as in Thm 3.4. The padded hypothesis has, on every tape, the same $\Cn$ as $B\cup A^G_\omega$, so it lies in $\mathcal C$ and is compatible with $D$ exactly when $G$'s theory is. The program-less tapes of $M_A$ (theory $B$) are matched by the decider of $\emptyset$. Upper bound: a penalised hypothesis is its own theory machine, with the same theory. Divide by $X(\text{all},D)$ and $M_A(\text{all},D)$. $\square$

## 5. SAI is SOI on positive literals (T5)

**Theorem 5.1 (transfer principle; scout S Thm 2.7, scout F's F9) [proved].** Let $X\subseteq\{0,1\}^*$ be P1's (infinite, decidable) input set and $x\mapsto t_x$ a computable injective map from $X$ to closed $\mathcal L$-terms with decidable range and computable inverse. Let $R$ be a unary relation symbol not occurring in $B$, and suppose some model of $B$ interprets the terms $t_x$ as pairwise distinct elements (e.g. $B=\emptyset$ with the word terms $t_w$ of NOTATION §3.4, or $B=\Q$ with binary numerals of $1w$). For a data set $D$ with $\dom D\subseteq\{R(t_x):x\in X\}$ put $D^{\rm str}:=\{(x,b):(R(t_x),b)\in D\}$. Then there is $c$ with
$$|K_A(D)-K_F(D^{\rm str})|\le c,\qquad W_A(D)\asymp W(D^{\rm str}),\qquad M_A(D)\asymp M_F(D^{\rm str})\ (D\neq\emptyset),$$
where $K_F,W,M_F$ are P1's objects over $X$ with labels $\{0,1\}$; the same for $K_A^{\rm dec}$, $W_A^{\rm dec}$, $M_A^{\rm dec}$, and for the three-way weights on a literal query $R(t_y)$ (prove / refute / neither on the SAI side, $1$ / $0$ / undefined at $y$ on P1's side).

*Proof.* By Thms 2.1 and 3.1 it suffices to compare consistent SOI on sentences with plain SOI on $X$. *Strings to sentences:* for a partial computable $g$ on $X$ let $g^P(R(t_x)):=g(x)$, undefined off the literals; for a function machine on $X$ likewise (decode $x$ from $t_x$). $\Gamma_{g^P}$ is a set of literals $\pm R(t_x)$, at most one per $x$; it is consistent with $B$, because in a model of $B$ with distinct $t_x$ the symbol $R$, which $B$ does not mention, can be interpreted as $\{t_x:g(x)=1\}$. So $g^P$ (and the machine version, on every tape) is consistent, extends $D$ iff $g$ extends $D^{\rm str}$, and costs a constant. *Sentences to strings:* $f^{\rm str}(x):=f(R(t_x))$, at a constant cost; $f\supseteq D$ implies $f^{\rm str}\supseteq D^{\rm str}$; consistency is not needed. Sum over the injective maps and take shortest programs. For the three-way weights on $R(t_y)$: by (Lit) below, the theory $\Cn(\Gamma_{g^P})$ decides $R(t_y)$ iff $g(y)$ is defined, with the same value; and the proof-search labeller of a theory, restricted to literals, labels $y$ exactly as the theory decides $R(t_y)$. $\square$

The hypothesis implies scout F's condition (Lit) (a consistent set of such literals proves exactly its members): for $R(t_y)^b$ not in the set, reinterpret $R$ at $t_y$. Without distinct terms the transfer can fail: if $B\vdash t_x=t_y$, the data $(R(t_x),1),(R(t_y),0)$ are inconsistent for SAI while $D^{\rm str}$ is fine for SOI (scout S self-check 6).

### 6.1 Logical closure and the trichotomy

**Proposition 6.1 (logical closure; scout S Prop 2.11, extended by (c)) [proved; (a), (b) computed: c1 item (4), rb1 (5); (c) construction check: c1 item (4)].** Let $B\cup D^\pm$ be consistent and $\chi\notin\dom D$.
(a) If $B\cup D^\pm\vdash\chi$, every SAI hypothesis compatible with $D$ proves $\chi$: $M_A(1\mid D,\chi)=1$, $M_A(0\mid D,\chi)=0$, $\Indep_D(\chi)=0$; the same for $W_A$.
(b) If $B\cup D^\pm\vdash\chi$, no consistent labeller extending $D$ labels $\chi$ false, so $W^{\rm cons}(0\mid D,\chi)=0$; and $W^{\rm cons}(1\mid D,\chi)\ge2^{-2c}$. The same for $M_F^{\rm cons}$.
(c) *(new)* For **every** $\chi\notin\dom D$ (entailed or not), the posterior probability that the sampled labeller is undefined at $\chi$ is at least $2^{-K(\chi)-c}$: $W^{\rm cons}(D;\chi\mapsto\bot)\ge2^{-K(\chi)-c}W^{\rm cons}(D)$ and $M_F^{\rm cons}(D;\chi\mapsto\bot)\ge2^{-K(\chi)-c}M_F^{\rm cons}(D)$, uniformly in $D$.
(d) Over closed labellers all three predictive probabilities agree with SAI's within $2^{\pm2c}$ (Thm 2.1(c), Cor 3.2).

*Proof.* (a) A consistent theory proving $\psi_D$ proves $\chi$; F1(c). (b) $f\supseteq D$ with $f(\chi)=0$ puts $D^\pm\cup\{\neg\chi\}\subseteq\Gamma_f$, inconsistent with $B$. By Thm 2.1, $W^{\rm cons}(D+(\chi,1))\ge2^{-c}W_A(D+(\chi,1))=2^{-c}W_A(D)\ge2^{-2c}W^{\rm cons}(D)$; for one tape use Thm 3.1. (c) Let $q_\chi$ be a shortest $V$-program for $\chi$. The prefix machine that reads $q_\chi$, then $s\in\dom V$, and outputs an index of "$\{V(s)\}$, made undefined at $V(q_\chi)$" is simulated by $V$ with a prefix $r$. The map $s\mapsto rq_\chi s$ is injective; removing one label preserves consistency, and the restricted labeller still extends $D$ because $\chi\notin\dom D$. So the consistent labellers extending $D$ and undefined at $\chi$ have weight at least $2^{-|r|-K(\chi)}W^{\rm cons}(D)$. For one tape, apply the same map to function machines and use (1.1); on the program-less tapes the empty labeller is undefined at $\chi$ already. $\square$
So consistent SOI never becomes certain of a logical consequence in the semimeasure convention: for a fixed simple $\chi$ the undefined mass stays above $2^{-K(\chi)-c}$ whatever the data. In the normalised convention its prediction on an entailed $\chi$ is $1$ (by (b)). The equivalence of Thms 2.1 and 3.1 controls the semimeasure *losses* (each entailed datum costs consistent SOI at most $2c$ bits and SAI nothing), not the size of the $\bot$ mass: SOI's $\bot$ mixes logical independence with laziness. Scout S's version of (b) used the lookup table of $D$ for the $\bot$ mass, $2^{-K(D)-c}$, which degrades with the data; (c) does not.
*Computed* (c1 item (4)): on 412 and 476 (data set, entailed sentence) cases, SAI gives $(1,0,0)$ every time, and consistent SOI gives $P(0)=0$ and $P(1)>0$; this checks (a) and (b), as does referee B's independent `rb1` item (5). The status of (c) is "proved".

**Remark 6.2 (the three outcomes are a measure for SAI) [proved; computed: c1 item (6)].** $M_A(D+(\varphi,1))+M_A(D+(\varphi,0))+M_A^3(D+(\varphi,\iota))=M_A(D)$ for $\varphi\notin\dom D$ (F1(b), (f)); likewise for $W_A$. ### 6.2 An observed "independent" label

Three-valued data map sentences to $\{1,0,\iota\}$. A partial three-valued labeller $f$ is *consistent* if $B\cup\Gamma_f$ is consistent ($\Gamma_f$ from the $1/0$ labels) and $B\cup\Gamma_f$ decides none of the sentences $f$ labels $\iota$. $W_A^3$: enumerators whose theory is consistent, proves the $1/0$ data and decides no $\iota$-labelled sentence; $W^{3,\rm cons}$: consistent three-valued labellers extending $D$; one-tape: $M_A^3=\nu^3_{G_U}$ (NOTATION §4.1) and $M_F^{3,\rm cons}(D):=\Unif\{\omega:f_\omega\supseteq D,\ f_\omega\text{ consistent}\}$ for P1's universal function machine with $Y=\{1,0,\iota\}$. $\mathrm{Ind}_B$ is the set of sentences that $B$ decides neither way. $B$ is *$\Sigma_1$-sound* if it proves no false $\Sigma_1$ sentence (then it is consistent).

**Lemma 6.3′ (productivity of the independent sentences) [known: classical (effective inseparability of the provable and the refutable sentences of every consistent r.e. extension of $\Q$; Smullyan, *Theory of Formal Systems*, 1961), verified at secondary-source level (§14); proved here, given the textbook facts (R), (O), (Diag) below; the development round's proof, under the stronger hypothesis that $B$ is $\Sigma_1$-sound, is kept as (ii)].** Let $\mathcal L\supseteq\mathcal L_{\rm ar}$, $B$ decidable and **consistent**, $\Q\subseteq\Cn(B)$. From an index of an r.e. set $\mathsf W\subseteq\mathrm{Ind}_B$ one computes an $\mathcal L_{\rm ar}$-sentence $\rho\in\mathrm{Ind}_B\setminus\mathsf W$. In particular $\mathrm{Ind}_B$ is productive, hence not r.e., and the set $\mathrm{Ref}_B$ of $B$-refutable sentences is r.e. and not decidable.

*Textbook facts used* [known: standard, e.g. Boolos–Burgess–Jeffrey, *Computability and Logic*, chs. 16–17; not re-checked against a particular edition]: (R) every decidable relation on numbers is strongly represented in $\Q$: there is a formula $\alpha(\bar x)$ with $\Q\vdash\alpha(\bar{\underline n})$ when the relation holds of $\bar n$ and $\Q\vdash\neg\alpha(\bar{\underline n})$ when it does not; (O) for every $n$, $\Q\vdash\forall z\,(z\le\underline n\to z=\underline0\vee\dots\vee z=\underline n)$ and $\Q\vdash\forall y\,(y\le\underline n\vee\underline n\le y)$, with $\le$ the usual abbreviation; (Diag) for every formula $\Theta(x)$ there is a sentence $\rho$ with $\Q\vdash\rho\leftrightarrow\Theta(\ulcorner\rho\urcorner)$, computable from $\Theta$.

*Proof (i), Rosser's argument relative to $\mathsf W$.* Let $A(y,x)$ be the decidable relation "$y$ codes a $B$-derivation of the negation of the sentence coded by $x$, or $x$ is enumerated into $\mathsf W$ within $y$ steps", and $C(y,x)$ the decidable relation "$y$ codes a $B$-derivation of the sentence coded by $x$" ($B$ is decidable). Let $\alpha,\gamma$ strongly represent them (R), and let $\rho$ satisfy $\Q\vdash\rho\leftrightarrow\exists y\,(\alpha(y,\ulcorner\rho\urcorner)\wedge\forall z\le y\ \neg\gamma(z,\ulcorner\rho\urcorner))$ (Diag); $\rho$ is computed uniformly from the index of $\mathsf W$.
* *$B\nvdash\rho$.* Suppose $p$ codes a $B$-derivation of $\rho$. Then $\rho\notin\mathrm{Ind}_B\supseteq\mathsf W$, and $B\nvdash\neg\rho$ by consistency, so $A(n,\ulcorner\rho\urcorner)$ fails for every $n$ and $\Q\vdash\neg\alpha(\underline n,\ulcorner\rho\urcorner)$ for every $n$ (R); also $\Q\vdash\gamma(\underline p,\ulcorner\rho\urcorner)$. Argue in $\Q$: given $y$ with $\alpha(y,\ulcorner\rho\urcorner)\wedge\forall z\le y\,\neg\gamma(z,\ulcorner\rho\urcorner)$, by (O) either $\underline p\le y$, which contradicts $\gamma(\underline p,\ulcorner\rho\urcorner)$, or $y\le\underline p$, so $y$ is one of $\underline0,\dots,\underline p$, which contradicts $\neg\alpha(\underline n,\ulcorner\rho\urcorner)$. So $\Q\vdash\neg\rho$, hence $B\vdash\neg\rho$ and $B$ is inconsistent: a contradiction.
* *$B\nvdash\neg\rho$ and $\rho\notin\mathsf W$.* Otherwise $A(n,\ulcorner\rho\urcorner)$ holds for some $n$, and $C(m,\ulcorner\rho\urcorner)$ fails for every $m$ (previous step). By (R) and (O), $\Q\vdash\alpha(\underline n,\ulcorner\rho\urcorner)\wedge\forall z\le\underline n\,\neg\gamma(z,\ulcorner\rho\urcorner)$, so $\Q\vdash\rho$ and $B\vdash\rho$, contradicting the previous step.

So $\rho\in\mathrm{Ind}_B\setminus\mathsf W$. A productive set is not r.e. (take $\mathsf W$ to be the set itself). If $\mathrm{Ref}_B$ were decidable, so would be $\mathrm{Thm}_B=\{\varphi:\neg\varphi\in\mathrm{Ref}_B\}$ up to the decidable map $\varphi\mapsto\neg\varphi$ and double negation ($B\vdash\varphi$ iff $B\vdash\neg\neg\varphi$), hence $\mathrm{Ind}_B$, which is not even r.e. $\square$

*Proof (ii), the development round's proof under $\Sigma_1$-soundness* (scout S's construction, re-checked line by line; $\mathcal L=\mathcal L_{\rm ar}$; it uses MRDP (known; AI-paper Lemma E.14(a)) and Kleene's recursion theorem (known)). $\Out(e,x,y)$ is the $\Sigma_1$ formula $\exists\bar c\,(E(e,x,y,\bar c)=E'(e,x,y,\bar c))$ of AI-paper Lemma E.14(a). By the recursion theorem (in the parametrised form, uniformly in the index of $\mathsf W$) take a program $e$ that on input $0$ searches simultaneously for $\sigma_e:=\Out(\num e,\num0,S0)$ in $\mathsf W$ and for a $B$-proof of $\neg\sigma_e$ ($B$ is decidable, so its proofs are r.e.), and halts with output $1$ when either search succeeds; on other inputs it loops. Suppose a search succeeds. Then $e$ outputs $1$ on $0$, so $\sigma_e$ is a true sentence of the form $\exists\bar y(s=s')$ and $\Q\vdash\sigma_e$ (Lemma E.14(c)), hence $B\vdash\sigma_e$. Then $\sigma_e\in\mathsf W\subseteq\mathrm{Ind}_B$ is impossible, and $B\vdash\neg\sigma_e$ would make $B$ inconsistent. So no search succeeds: $e$ does not output $1$ on $0$, $\sigma_e$ is a false $\Sigma_1$ sentence, $B\nvdash\sigma_e$ ($\Sigma_1$-soundness), $B\nvdash\neg\sigma_e$ (search (ii) fails), and $\sigma_e\notin\mathsf W$ (search (i) fails). $\square$ This route needs $\Sigma_1$-soundness only for $B\nvdash\sigma_e$; proof (i) removes it, as referee A (m3) pointed out.

*Status of the lemma in the paper.* It is classical and should be cited, not presented as part of what is new; what is new is its use in Props 6.3–6.5.

*Proof.* (a) Map (EM): on a tape where $f^F_\omega$ is consistent and extends $D$, the emitted theory $\Cn(\Gamma_{f_\omega})$ proves the $1/0$ data and decides no sentence that $f_\omega$ labels $\iota$, in particular none of $D$'s. Sum with (1.1).

If $\Unif(C_p)=0$, $p$ contributes nothing. Otherwise, by the Lebesgue density theorem almost every $\omega\in C_p$ has a prefix $w$ with $\Unif(C_p\cap[w])>(1-\varepsilon)2^{-|w|}$. $$J_w:=\{\sigma:\Unif([w]\cap\{\omega:f^{F_p}_\omega(\sigma)=\iota\})>\varepsilon2^{-|w|}\}.$$
*$J_w$ is r.e.*, uniformly in $(p,w)$ and the rational $\varepsilon$: the measure of the open set $[w]\cap\{f(\sigma)=\iota\}$ is lower semicomputable. *$J_w\subseteq\mathrm{Ind}_B$:* if $\sigma\in J_w$, the set $[w]\cap\{f(\sigma)=\iota\}$ has measure larger than $\varepsilon2^{-|w|}>\Unif([w]\setminus C_p)$, so it meets $C_p$: some tape on which $f_\omega$ is consistent labels $\sigma$ with $\iota$, hence $B\cup\Gamma_{f_\omega}$, and so $B$, decides neither $\sigma$ nor $\neg\sigma$. Let $I_n:=\bigcup_{|p|\le n}\bigcup_{w\in\mathcal W'_p}J_w$, a finite union of r.e. subsets of $\mathrm{Ind}_B$, and $\sigma_n\in\mathrm{Ind}_B\setminus I_n$ (Lemma 6.3′). For $|p|\le n$,
$$\nu^{3,\rm cons}_{F_p}(\{(\sigma_n,\iota)\})\le\sum_{w\in\mathcal W'_p}\Unif([w]\cap\{f(\sigma_n)=\iota\})+\sum_{w\in\mathcal W_p\setminus\mathcal W'_p}2^{-|w|}+\Unif\Big(C_p\setminus\bigcup_{\mathcal W_p}[w]\Big)\le\sum_{w\in\mathcal W'_p}\varepsilon2^{-|w|}+\varepsilon\le2\varepsilon,$$
since $\sigma_n\notin J_w$. By (1.1), $M_F^{3,\rm cons}(\{(\sigma_n,\iota)\})\le\sum_{|p|\le n}2^{-|p|}2\varepsilon+\Omtail{n+1}\le2^{1-n}+\Omtail{n+1}$. The deterministic theory machine that emits nothing (theory $B$) is compatible with $\{(\sigma_n,\iota)\}$ on every tape.
(c) Deterministic labellers are function machines that ignore the tape. $\square$
The coin-free Prop 6.3 is the special case of machines that ignore the tape ($J_w$ is then the labeller's $\iota$-set and no density argument is needed). Scout S had not treated the one-tape case; the obstacle is that the set of sentences a random machine labels $\iota$ on *consistent* tapes is not r.e. in general (positivity of the measure of a $\Pi_1$ class), and the density point restores an r.e. subset of $\mathrm{Ind}_B$ that carries almost all of the consistent $\iota$-mass. Thresholding the measure of a labelling event at a density point to obtain an r.e. (or computable) object is the technique of de Leeuw, Moore, Shannon and Shapiro (1956) (credit added on referee A m14); the same device is used in Cor 4.2(c) (through `logic` Prop 2.3(b)) and in Props 9.2, 9.3.
*Computed.* (c2, development round) The finite analogue of the lemma ($J_w\subseteq\mathrm{Ind}$, and consistent $\iota$-mass $\le\varepsilon$ in $[w]$ off $J_w$) holds in all 4174 dense prefixes of 20 random three-valued machines ($\varepsilon=0.25,0.1$); the coin-free diagonal of Prop 6.3 (finite analogue: $\sigma_n$ the first independent sentence outside $I_n$) satisfies (b) and (c) at every length until the finite set of independent sentences is exhausted. *This density check is weakly informative* (referee B, issue 6, instrumented in `rb6`): c2's machines are consistent on a median 5% of tapes, 2380 of the 4174 dense prefixes are single tapes, only 42 of 261,542 tested pairs could have failed, and the summed bound of the proof was never tested. (c5 (A), revision) A family of 30 *mostly consistent* machines (consistent on 73% to 96% of tapes, median 88%), 48 sentences of which 12 are decided by $B$, noise that labels $B$-decided sentences $\iota$ on 1/8 or 1/16 of the tapes, $\varepsilon\in\{1/4,1/8,1/16\}$: $J_w\subseteq\mathrm{Ind}_B$ in all 5875 dense prefixes (1464 single tapes), although 106 pairs $(w,\sigma)$ with $w\in\mathcal W'$ and $\sigma$ decided by $B$ carry positive $\iota$-mass in $[w]$ (so the threshold, not the absence of such labels, keeps them out); the summed bound $\nu^{3,\rm cons}(\{(\sigma,\iota)\})\le\sum_{\mathcal W'}\Unif([w]\cap\{f(\sigma)=\iota\})+\sum_{\mathcal W\setminus\mathcal W'}2^{-|w|}+\Unif(C\setminus\bigcup_{\mathcal W}[w])\le2\varepsilon$ holds for every $\sigma$ outside $I$, 226 of which carry positive consistent $\iota$-mass, with largest $\nu^{3,\rm cons}/\varepsilon=1.000$; the finite diagonal over machines of lengths $2,\dots,7$ satisfies the mixture bound until $\mathrm{Ind}_B$ is exhausted. Referee B's independent `rb2` (not read before c5 was written) found the same: 0 violations in 117 cases, 119 non-vacuous instances, largest ratio $1.0$.

### 6.3 Shared versus private randomness

**Remark 6.6 (scout S Rem 2.13) [proved].** If a product law (private coins per input, P1 Prop 3.9(a)) gives positive probability to labelling $\varphi$ true and $\psi$ true, with $B\cup\{\varphi,\psi\}$ inconsistent, the sampled labeller is inconsistent with probability at least their product. The consistent part of a product law is not a product law: for a $B$-independent $\varphi$ (referee A m16: if $B$ decides $\varphi$, one of the two outcomes below is inconsistent too), on the two inputs $\varphi,\neg\varphi$ with fair independent labels, the consistent outcomes are $(1,0)$ and $(0,1)$, each of mass $\frac14$, and a product would need $P(1,1)P(0,0)=P(1,0)P(0,1)\neq0$. The shared tape is what makes a random labeller a random *theory*; private randomness is harmless on logically independent inputs such as positive literals (Thm 5.1). Product laws are machine laws, so $M_F^{\rm cons}$ dominates their consistent parts.

### 6.4 Computability

**Proposition 6.7 (computability of the versions) [(a), (b), (c), (c′) proved; $\emptyset'$-computability of the closed and decider versions not claimed].**
(a) Suppose the set of finite data sets $D$ with $B\cup D^\pm$ consistent is not r.e. (b) In every setting, $M_A(\emptyset)$ and $M_F^{\rm cons}(\emptyset)$ are not left-c.e., so $M_A$ and $M_F^{\rm cons}$ are not lsc (`fundamentals` Thm 3.2(a), scout F's F3(b), for $M_A$; the same construction for $M_F^{\rm cons}$).
(c) $W_A$, $W^{\rm cons}$, $M_A$ and $M_F^{\rm cons}$ are computable relative to $\emptyset'$, uniformly in $D$.
(c′) $W_A^{\rm dec}$, $M_A^{\rm dec}$, $W^{\rm cl}$ and $M_F^{\rm cl}$ are computable relative to $\emptyset''$, uniformly in $D$. Whether they are $\emptyset'$-computable is not settled here (referee A expects not, in general).
(The development round claimed (c) for all eight objects, with a proof that covers only the four whose defining conditions are $\Delta_2$; referee A M2, referee B issue 4. Being closed, and being a (random) decider, are $\Pi_2$ conditions; for closedness the condition is even $\Pi_2$-complete, by referee B's reduction: with $\chi_0,\chi_1,\dots$ an injective enumeration of the $B$-decided sentences, the labeller that labels $\chi_n$ with $B$'s decision once program $e$ halts on $n$ is consistent, and it is closed iff $e$ is total.)
*Proof.* (a) For a function $\nu$ that is lsc uniformly in $D$, the support $\{D:\nu(D)>0\}$ is r.e. Each object listed has support exactly the consistent data sets: positive weight needs a consistent hypothesis proving or extending $D$; conversely, for a consistent $D$ the lookup table of $D$ (as a labeller, a finite theory, a decider, or a machine ignoring the tape) has positive weight in $W_A$, $W_A^{\rm dec}$, $W^{\rm cons}$, $M_A$, $M_A^{\rm dec}$, $M_F^{\rm cons}$, and for the closed versions $W^{\rm cl}$, $M_F^{\rm cl}$ its closure under the map (CL), "proof search from $B\cup D^\pm$", which is closed, consistent and extends $D$, has positive weight (the lookup table itself is never closed; referee A m10, referee B issue 4). (b) For $M_F^{\rm cons}$: for a left-c.e. $\alpha$ with approximations $\alpha_s\uparrow\alpha$, the function machine $F_\alpha$ labels the sentence $\exists x\,x\neq x$ with $1$ under a prefix $w$ as soon as some stage $s$ has $0.w+2^{-|w|}\le\alpha_s$, and is undefined elsewhere; its labelling is inconsistent with probability $\Unif\{\omega:0.\omega<\alpha\}=\alpha$. With $p_\alpha$ a $V$-program for $F_\alpha$, the inconsistency probability of $F_U$ is $2^{-|p_\alpha|}\alpha+\gamma$ with $\gamma$ left-c.e.; if $M_F^{\rm cons}(\emptyset)=1-(\text{that})$ were left-c.e., the inconsistency probability would be computable and $\alpha$ right-c.e.; take $\alpha=\Omega_V$. (c) $W_A$ and $W^{\rm cons}$ are sums $\sum_p2^{-|p|}\ind[\cdot]$ of $\Delta_2$ indicators ("proves $\psi_D$" and "extends $D$" are $\Sigma_1$, consistency is $\Pi_1$), and the tails $\Omtail{\ell}$ are $\emptyset'$-computable; so $\emptyset'$ computes each value to any precision. For one tape, $M_A(D)=\Unif(O_{\psi_D})-\Unif(O_\bot)$ (`fundamentals` Prop 3.1, 3.4) and $M_F^{\rm cons}(D)=\Unif(O\cap C)=\Unif(O)-\Unif(O\setminus C)$ with $O=\{\omega:f_\omega\supseteq D\}$ effectively open and $C=\{\omega:f_\omega\text{ consistent}\}$ effectively closed: differences of left-c.e. reals, uniformly in $D$.
(c′) *Coin-free.* "$V(p)$ is a total $\{0,1\}$-valued program" and "$\{V(p)\}$ is closed" ($\forall\varphi,b:B\cup\Gamma\vdash\varphi^b\to\{V(p)\}(\varphi)=b$) are $\Pi_2$, so $\emptyset''$ decides each indicator and computes the sums. *One tape, deciders.* "$F_{V(p)}$ halts on every query and every tape" is $\Pi_2$: for each query, halting on all tapes is, by compactness of Cantor space, equivalent to "some $n$ and $s$ make every tape prefix of length $n$ halt within $s$ steps", a $\Sigma_1$ condition. For a random decider $\mu^{\rm dec}_{F}(D)$ is a difference of left-c.e. reals uniformly in an index (as in (c)). So $\emptyset''$ computes $M_A^{\rm dec}(D)=\sum_p2^{-|p|}[\cdot]\mu^{\rm dec}_{F_{V(p)}}(D)$. *One tape, closed.* "$f_\omega$ closed" is the countable intersection over $(\varphi,b)$ of the sets $\{\omega:B\cup\Gamma_{f_\omega}\nvdash\varphi^b\}\cup\{\omega:f_\omega(\varphi)=b\}$, each the union of an effectively closed and an effectively open set, hence an effective $G_\delta$; so the event in $M_F^{\rm cl}(D)$ is an effective $\Pi^0_2$ class $\bigcap_kU_k$ with $U_k$ uniformly effectively open and decreasing, whose measure is $\inf_k\Unif(U_k)$, an infimum of uniformly left-c.e. (so uniformly $\emptyset'$-computable) reals, hence right-c.e. relative to $\emptyset'$ and computable from $\emptyset''$. $\square$

### 6.5 Pathwise versus machine-wise consistency (scout S Rem 2.14)

$M_F^{\rm cons}$ conditions on the event that the *sampled* labeller is consistent. The machine-wise alternative is $M_F^{C}(D):=\sum_{p\in\dom V}2^{-|p|}[F_{V(p)}\text{ consistent on every tape}]\,\nu_{F_{V(p)}}(D)$ (and $M_A^C$ likewise over theory machines consistent on every tape).

**Proposition 6.8 [(a)–(c) proved; computed: c1 item (7); (d) open].**
(a) $W^{\rm cons}\le2^cM_F^C\le2^cM_F^{\rm cons}$ on nonempty $D$, and $M_F^C\asymp M_A^C$.
(b) $M_F^{\rm cons}(D)\le2^{\min\{\Kpad(L^{\rm cons}_{1/2}(D)),\,K(\dom D)\}+c}\,M_F^C(D)$.
(c) If consistency of finite sets with $B$ is decidable (uniformly: an algorithm decides, for finite $\Lambda\subseteq\Sent_{\mathcal L}$, whether $B\cup\Lambda$ is consistent; e.g. $\Cn(B)$ decidable, as for a decidable complete $B$ such as Presburger arithmetic, or propositional languages, and monadic predicate languages without function symbols, with $B=\emptyset$: monadic first-order logic is decidable (Löwenheim–Behmann; known, standard); with two unary function symbols consistency of finite sets is not decidable, so "monadic" must exclude function symbols: referee A m17), then $M_F^{\rm cons}\asymp M_F^C$ and $M_A\asymp M_A^C$.
(d) In general (e.g. $B=\Q$, or $B=\emptyset$ with a binary relation symbol) whether $M_F^{\rm cons}/M_F^C$ is bounded is **open**.

*Proof.* (a) A deterministic consistent labeller is consistent on every tape; a machine consistent on every tape has $\nu=\nu^{\rm cons}$. The maps (PS) and (EM) preserve "consistent on every tape" (on each tape, PS of a consistent theory is consistent; EM of a consistent labelling is consistent). (b) Prop 4.1 with (a). (c) *The global-schedule filter.* For a function machine $F$ (as a machine reading the tape one-way), let $F'$ answer a query $\varphi$ by running the *global schedule* of $F$: stage $s$ reads tape bit $s$, starts $F$ on the $s$-th sentence and advances every started run by one step; certification events (a run halting with a label) are ordered by stage, ties by sentence index. When $\varphi$'s event occurs, $F'$ checks whether the set of labels certified up to and including it is consistent with $B$ (decidable by hypothesis); if so it outputs $\varphi$'s label, otherwise it diverges. The answer is a deterministic function of the bits read, so $F'$ is a function machine, and $K(F')\le K(F)+c$. On a tape $\omega$ let $\lambda_1,\lambda_2,\dots$ be the labels in event order. $F'$ outputs $\lambda_i$ iff $\{\lambda_1,\dots,\lambda_i\}$ is consistent; consistency of these prefixes is monotone, so the outputs are an initial segment all of whose finite subsets are consistent, hence consistent by compactness. So $F'$ is consistent on every tape, and on every tape on which $F$ is consistent, $F'=F$. Hence $\nu_{F'}(D)\ge\nu^{\rm cons}_F(D)$ for every $D$, and summing over $p$ with (1.1) gives $M_F^C\ge2^{-c}M_F^{\rm cons}$. The theory-machine version filters emissions the same way. $\square$
*Computed* (c1 item (7)): in the propositional analogue (where consistency is decidable) the filter is consistent on every tape, equals $F$ on $F$'s consistent tapes, and has $\nu_{F'}\ge\nu^{\rm cons}_F$ on all 28825 machine–data pairs, for 25 random machines each inconsistent on some tape.
*Why (d) is hard.* An always-consistent machine must avoid inconsistency, which is only semi-decidable; its support $\{D:\nu_F(D)>0\}$ is an r.e. family of consistent data sets. A pathwise-conditioned machine can exploit the $\Pi_1$ event "nothing inconsistent ever happens". Every attempt at a separation made here was absorbed by machine-wise consistent machines that are told a small finite amount of information (an edge count or a window index), at a cost that a simple random machine pays as well. The lottery (Cor 4.2) does not separate them: $G_{\rm lot}$ is consistent on every tape.

**Remark 7.9 (what the time results say).** Penalising the axiom side (checking or generating axioms) does not change which theories win: the equivalence survives, also class by class (Thm 7.1, Props 7.7, 3.5). So the time-bounded separations do not show that axioms are better hypotheses than programs; they show that free deduction is a free computation.

## 8. Charged deduction (T8)

**Setting** (AI-paper Def E.18; SD Defs 1.2, 1.3, 1.6; TF Def 1.3). $\mathcal L$ finite, $B$ decidable in polynomial time, Mendelson-style calculus $\mathsf K$ with sizes counting nodes. ## 9. A natural separation: Presburger arithmetic (T9)

$\mathcal L_{\rm Pr}:=\{0,1,+,=\}$ (finite), $B=\emptyset$, $D^{\rm Pres}$ lists all $\mathcal L_{\rm Pr}$-sentences in length-lexicographic order, labelled by truth in $(\mathbb N,0,1,+)$; $\mathrm{PrA}:=\Th(\mathbb N,0,1,+)$.

**Remark 9.0 (lengths) [proved, given the proviso on Fischer and Rabin's syntax stated in (iii)].** This remark is new in the revision (referee A m1).
(i) *Our length.* $|\varphi|$ is the **symbol count** of $\varphi$: every occurrence of a connective, quantifier, nonlogical symbol, parenthesis or variable counts $1$, whatever the variable's index. This is the size measure of the AI-paper's calculus $\mathsf K$, in which a variable or parameter counts one symbol (AI-paper Lemma E.28). Machines read $\varphi$ as a bit string of length $b(\varphi)\le\kappa_0|\varphi|\log_2(|\varphi|+2)$ (a sentence with $m$ symbols has at most $m$ distinct variables, which can be renamed $x_1,\dots,x_m$ and written in binary). In this section clocks $\tau$, derivation budgets $d,g,h$ and the length $m$ in the lower bounds are functions of $|\varphi|$.
(ii) *Why the symbol count.* If a clock were a function of the bit length $b$, which can exceed the symbol count by a factor $\log m$, a clock $2^{2^{c'b}}$ could be $2^{2^{c'\kappa_0m\log m}}$, above every $2^{2^{cm}}$, and the contradictions below would fail. For clocks in bit length the results hold with $\tau(b)\le2^{2^{c'b/\log_2(b+2)}}$ in place of $\tau(m)\le2^{2^{c'm}}$ (and likewise for the singly exponential clocks), since $b/\log_2(b+2)\le\kappa_0|\varphi|$.
(iii) *Fischer and Rabin's length.* Their syntax was not seen. *Proviso:* their length counts every symbol occurrence, variables included, at least once, and their nonlogical symbols are among $0,1,+,=,<$. Under the proviso every sentence of their length $n$ has an equivalent $\mathcal L_{\rm Pr}$-sentence with at most $\kappa n$ symbols, computable in polynomial time (rewrite $x<y$ as $\exists z\,(x+z+1=y)$ with $z$ fresh; every other symbol is copied). *Padding:* every $\mathcal L_{\rm Pr}$-sentence $\psi$ has an equivalent sentence with **exactly** $m$ symbols for every $m\ge|\psi|+c_0$, computable in polynomial time, because two equivalence-preserving paddings with coprime increments exist (in the node count of $\mathsf K$: $\psi\wedge0=0$ adds $4$ nodes and $\psi\wedge\neg\,0=1$ adds $5$; every standard syntax has such a pair). *Consequence.* Let $Q$ be a decision procedure for $\mathrm{PrA}$ in our syntax, deterministic or nondeterministic. For $j=0,\dots,\kappa-1$ let $P_j$ decide their sentences of length $n$ by translating, padding to exactly $\kappa n+c_0+j$ symbols and running $Q$. Each $P_j$ is a decision procedure in their syntax, with the same reading of nondeterministic time as $Q$, so by their theorem, for all large $n$, $Q$ takes more than $2^{2^{c_{\rm FR}n}}-\mathrm{poly}(n)$ steps on some sentence with exactly $\kappa n+c_0+j$ symbols. As $j$ runs through all residues, **for all large $m$, $Q$ takes more than $2^{2^{cm}}$ steps on some sentence with exactly $m$ symbols**, for every $c<c_{\rm FR}/\kappa$. Below, $c$ denotes such a constant. (The exact-length form is what the "for all large $m$" arguments of Prop 9.4 use; a form with "at most $m$ symbols" would not do, because a procedure that is slow at some lengths would then be slow at all larger ones.) (The development round wrote "lengths differ by a constant factor $\kappa$" without checking the direction that matters; with symbol counts on our side only the direction above is needed, and it holds under the proviso.)

**Facts used.**
* (F$_{\rm P}$) *Presburger 1929* [known; standard, not re-checked]: the axioms for successor and addition with the induction schema for $\mathcal L_{\rm Pr}$-formulas form a decidable, consistent and complete axiomatisation of $\mathrm{PrA}$, with membership decidable in polynomial time.
* (F$_{\rm FR}$) *Fischer and Rabin 1974*, "Super-exponential complexity of Presburger arithmetic", *Complexity of Computation*, SIAM-AMS Proceedings 7, 27–41; MIT LCS TM-43 [known; **statement verified against the abstract** as reported by search results (HUJI CRIS listing, MIT DSpace TM-43, Semantic Scholar and Google Books records) by referee A and again in this revision; full text not seen]: there is a constant $c_{\rm FR}>0$ such that for every decision procedure for $\mathrm{PrA}$, deterministic or nondeterministic, and every sufficiently large $n$, some sentence of length $n$ requires more than $2^{2^{c_{\rm FR}n}}$ steps; the same bounds hold for the minimum lengths of proofs in complete axiomatisations whose axioms are easily recognised. In our lengths (Rem 9.0(iii)): for every such procedure and all large $m$, some sentence with exactly $m$ symbols takes it more than $2^{2^{cm}}$ steps.
  *Two readings of nondeterministic time.* (max) the time of a nondeterministic procedure is the maximum over its computation paths, all of which halt, every output being correct and some path giving an output; (short) the time on a sentence is the length of the shortest computation that outputs the correct answer. The abstract does not say which is meant. (short) implies (max). The proof-length clause is a statement of the (short) kind. Where only (max) is needed, nothing is assumed; Prop 9.4's "for all large $m$" for arbitrary (not time-constructible) budgets uses (short) and says so.

**Proposition 9.1 (coin-free; scout S Prop 2.10) [proved, given F$_{\rm P}$, F$_{\rm FR}$ and Rem 9.0].** (a) $W_A$, $W_A^{\rm dec}$, $M_A$, and the penalised $W_A^{{\rm chk},t}$, $W_A^{{\rm gen},t}$, $M_A^{{\rm chk},t}$ ($t$ a large enough polynomial) have bounded loss on $D^{\rm Pres}$. (b) For time-constructible $\tau$ with $\tau(m)\le2^{2^{c'm}}$ for large $m$ and $c'<c$: $\ell_{W^{{\rm cons},\tau}}(D^{\rm Pres}_n)\to\infty$ and $\ell_{W^{{\rm all},\tau}}(D^{\rm Pres}_n)\to\infty$.
*Proof.* (a) The decider of Presburger's axioms is compatible with every prefix (complete and consistent), runs in polynomial time, and is a deterministic theory machine; the losses are at most $-\log$ of its weight. (b) The clocked mixtures are mixtures in the sense of AI-paper Lemma E.11 (compatibility inherited by prefixes), so a bounded loss would give one $\tau$-clocked $f$ labelling every sentence correctly. By TF's overhead (i) it yields a multitape decision procedure in time $q(C_f\tau(m)+b)$ with $b\le\kappa_0m\log_2(m+2)$ the input's bit length, which is at most $2^{2^{cm}}$ for large $m$ when $c'<c$ (c3, table (A), gives the thresholds for illustrative constants): this contradicts F$_{\rm FR}$ (deterministic case). $\square$

**Proposition 9.2 (one tape, exponential clocks; scout S Prop 2.10′) [proved, given F$_{\rm P}$, F$_{\rm FR}$, Rem 9.0 and the Lebesgue density theorem].** If $\tau(m)\le2^{c'm}$ for large $m$, $c'<c$, then $\ell_{M_F^{{\rm cons},\tau}}(D^{\rm Pres}_n)\to\infty$ and $\ell_{M_F^{{\rm all},\tau}}(D^{\rm Pres}_n)\to\infty$, while $M_A$ has bounded loss.
*Proof* (re-checked). Write $M:=\sum_fw(f)\nu_f$, each $\nu_f(D^{\rm Pres}_n)$ non-increasing in $n$. Bounded loss gives $\inf_nM(D_n)>0$; by dominated convergence some $f$ has $\lim_n\nu_f(D_n)>0$, which by continuity from above is $\Unif(G)$ for $G:=\{\omega:F^\tau_f\text{ labels every sentence correctly on }\omega\}$ (and consistently). By Lebesgue density there is $u$ with $\Unif(G\cap[u])>\frac34\,2^{-|u|}$, so for every sentence the tapes in $[u]$ on which $F^\tau_f$ answers correctly have conditional measure $>\frac34$. A query of length $m$ reads at most $\tau(m)$ tape bits, so the procedure "for every $v$ of length $\max(0,\tau(m)-|u|)$ run $F^\tau_f$ with tape $uv$ and output the majority answer" ($u$ hard-coded) decides $\mathrm{PrA}$ deterministically within $2^{\tau(m)}q(C_f\tau(m)+b)\le2^{2^{cm}}$ steps for large $m$ (c3, table (B)): a contradiction. $\square$ The majority vote over the tape completions at a density point is the technique of de Leeuw, Moore, Shannon and Shapiro (1956). The argument applies to every mixture of machines whose tape use per query is bounded by $\tau$.

**Proposition 9.3 (one tape, doubly exponential clocks) [conditional: proved, given (B*) and (SGL); (B*) known only in a recalled form confirmed by secondary sources, (SGL) standard].** Assume
* (B*) there is $c_B>0$ such that no alternating machine with at most two alternations ($\Sigma_2$) decides $\mathrm{PrA}$ within $2^{2^{c_Bm}}$ steps on all sentences with $m$ symbols, for all large $m$. *Source:* L. Secondary sources (Haase's survey of Presburger arithmetic, arXiv 1401.5266 / the Oxford copy; Klaedtke, arXiv cs/0506008) state Berman's result as completeness of $\mathrm{PrA}$ for the class $\mathrm{STA}(*,2^{2^{n^{O(1)}}},O(n))$ of alternating machines with doubly exponential time and linearly many alternations. (B*) would follow from the hardness part if the reductions used are of linear size (then every $\Sigma_2$-time-$2^{2^{n}}$ set reduces to $\mathrm{PrA}$, and the $\Sigma_2$ time hierarchy gives (B*)). *Caveat* (referee A m2): if the hardness holds only under reductions of polynomial size, only a bound $2^{2^{c_Bm^\varepsilon}}$ follows for some $\varepsilon\in(0,1]$, and the clock condition below must be weakened to $\tau(m)\le2^{2^{c'm^\varepsilon}}$. * (SGL) for time-constructible $T(m)\ge m$, $\mathsf{BPTIME}(T)\subseteq\Sigma_2\text{-}\mathsf{TIME}(T^{3})$ for large $T$ [known: Sipser 1983, Gács (in Sipser 1983), Lautemann 1983, in the standard form $\mathsf{BPP}\subseteq\Sigma_2^p$; the time bound is derived here from Lautemann's proof: amplify by $O(\log T)$ repetitions to $R=O(T\log T)$ random bits and error $<1/(2R)$; the $\Sigma_2$ machine guesses $R$ shifts of $R$ bits, universally chooses $R$ bits, and runs the amplified machine $R$ times, in time $O(R\cdot T\log T)=O(T^2\log^2T)$].

**Proposition 9.4 (charged derivation size or material: doubly exponential budgets on Presburger data) [proved, given F$_{\rm FR}$, Rem 9.0, AI-paper Lemma E.28 and the proof of AI-paper Thm 6.9 (both re-read); the "all large $m$" form given F$_{\rm FR}$ and F$_{\rm P}$, for time-constructible budgets, and given F$_{\rm FR}$ in reading (short) for arbitrary budgets].** Let a hypothesis $p$ of the charged readings (AI-paper Def E.18: $\mathcal L_{\rm Pr}$ is finite, $B=\emptyset$, $A_p$ decided in time $O(m^e)$, (F1)) be compatible with every prefix of $D^{\rm Pres}$.

The constant $c''$ does not depend on $e$; only the threshold does, through $m\ge\log_2(c_e)/(c-c'')$.
(b) *Material reading* (b), $W_A^{\rm b}[t,g]$: the same with $g$ in place of $d$.
*Proof.* (a) *Infinitely often.* Fix $c''<c$ and suppose $d(m)\le\ell(m):=2^{2^{c''m}}$ for all $m\ge m_1$; $\ell$ is time-constructible, so AI-paper Thm 6.9's hypothesis "$\ell(m)\ge m$ time-constructible" is met by the clock $\ell$ even if $d$ itself is not time-constructible (referee A M1). The nondeterministic procedure $N$: on a sentence $\varphi$ with $m<m_1$ symbols, look $\varphi$ up in a table; otherwise compute $\ell(m)$, guess a derivation of $\varphi$ or of $\neg\varphi$ of size at most $\ell(m)$ whose parameter numbers have at most $K+1+\lceil\log_2(\ell(m)+1)\rceil$ bits, $K=O(\ell(m)^e)$ (if a derivation of size $\le\ell(m)$ exists, such a one exists: AI-paper Lemma E.28), check it as in the proof of AI-paper Thm 6.9 (each line a logical axiom by matching, a member of $A_p$ in time $O(\ell^e)$, or MP or Gen), and output the label it proves; a path whose guess is not a valid derivation outputs nothing. Every output is correct: $B\cup A_p$ is consistent and proves every true sentence (compatibility with all of $D^{\rm Pres}$), so it proves exactly $\mathrm{PrA}$. Every sentence has a path with an output, by the assumption on $d$. Every path halts within $\ell(m)^{c_e}$ steps, $c_e$ depending only on $e$ and $\mathsf K$'s checking overhead. (ii) *Arbitrary $d$, reading (short).* Let $N'$ be $N$ without the table, where a path whose guess is not a valid derivation runs the deterministic procedure and outputs its answer. **Proposition 9.4′ (reading (a1) on Presburger data: at least exponential instance sizes) [proved, given F$_{\rm FR}$ (deterministic case), Rem 9.0 and AI-paper Prop E.23(a) (re-read; its proof applies to sentence data)].** Let $p$ be a hypothesis of $W_A^{\rm a1}[t,h]$ (Def E.18; (F1)) with $t(m)\le(m+2)^e$ and $h$ nondecreasing and time-constructible, compatible with every prefix of $D^{\rm Pres}$. *Proof.* AI-paper Prop E.23(a) gives the assigner $g_p$: with $H(\varphi):=\max(h(|\varphi|),|\varphi|+1)$, accept $\varphi$ if $\varphi\in D_{H(\varphi)}$ (the formulas with a derivation from $B\cup A_p$ all of whose lines have size $\le H(\varphi)$), reject it if $\neg\varphi\in D_{H(\varphi)}$ and $\varphi\notin D_{H(\varphi)}$, abstain otherwise. It runs in time $2^{O(H\log H)}(1+t(H))^{O(1)}$ (canonical formulas of size $\le H$, at most $2^{O(H\log H)}$ of them, closed under the rules, using (F1)), and it labels correctly every datum of every $D$ with which $p$ is (a1)-compatible: a normal (a1)-derivation of $\varphi^b$ has every line of size $\le\max(h(|\varphi|),|\varphi^b|)\le H(\varphi)$ (subformula lemma, AI-paper Lemma E.19(a), (b)), and $B\cup A_p$ is consistent. Nothing in this argument uses the form of $\varphi$; referee A checked the same. On $D^{\rm Pres}$, $g_p$ therefore decides $\mathrm{PrA}$ deterministically (it never abstains, since every sentence is a datum) in time $T(m)\le2^{C_aH\log_2H}$ with $H=\max(h(m),m+1)$, $C_a$ depending on $e$ (computing $h(m)$ costs $O(h(m))$). So $C_aH\log_2H>2^{cm}$, hence $H>2^{cm}/(C_acm)>2^{c''m}$ for all large $m$; as $m+1<2^{c''m}$ for large $m$, $H=h(m)$. $\square$

(iii) Under the nonlogical-only readings (a2), (b2) logical instances are free, so neither the guess-and-check route of Prop 9.4 nor the enumeration route of Prop 9.4′ gives a bound, and Cor 8.2(c) (every decidable set is fitted) concerns literal data in the literal language, not $D^{\rm Pres}$ in $\mathcal L_{\rm Pr}$: nothing is settled for (a2), (b2) on Presburger data, in either direction [**open**].

**Remark 9.5 (each charged reading of SAI matches one version of SOI on Presburger data) [summary of Props 9.1–9.4′ and Thm 8.1; the (a1) correspondence is a theorem of SD for literal data only, so for sentence data it is a reading].** With free deduction SAI has bounded loss on $D^{\rm Pres}$ (Prop 9.1(a)), while coin-free clocked consistent SOI with $\tau\le2^{2^{c'm}}$ and one-tape clocked SOI with $\tau\le2^{c'm}$ have unbounded loss (Props 9.1(b), 9.2; doubly exponential one-tape clocks conditionally, Prop 9.3). Once deduction is charged, the budget SAI needs is the budget of the matching SOI version: under the size and material readings SAI is certificate SOI (Thm 8.1), a nondeterministic notion, and Fischer and Rabin's nondeterministic bound forces doubly exponential budgets on both (Prop 9.4); under (a1) SAI behaves like deterministic SOI with an exponential clock (SD Cor 4.4(v)), and their deterministic bound forces exponential instance sizes, the exponential clock turning them into doubly exponential time (Prop 9.4′). ## 10. The circuit analogue of the sandwich (T10)

Fix $d\ge1$. Data are the literals $\varphi_x:=R(t_x)$, $x\in\{0,1\}^d$, labelled by a partial $f:\{0,1\}^d\rightharpoonup\{0,1\}$.

**Definition 10.0.**
* A *verifier circuit* $V$ of size $s$ is a list of $s$ two-input gates (any of the 16 Boolean functions) over the inputs $x_1,\dots,x_d$, certificate bits $z_1,\dots,z_k$ ($k\le2s$ without loss of generality), the constants and earlier gates; its last two gates are the outputs $\mathsf a,\mathsf r$. It is *consistent* if no $x$ has certificates $c,c'$ with $\mathsf a(x,c)=1$ and $\mathsf r(x,c')=1$. It defines $f_V(x):=1$ if some $c$ has $\mathsf a(x,c)=1$, $0$ if some $c$ has $\mathsf r(x,c)=1$, undefined otherwise. $s_N(f)$ is the least size of a consistent verifier circuit with $f_V\supseteq f$. (These are $\mathsf{NP}\cap\mathsf{coNP}$-type circuits; $s_N(f)\le\csize(f)+O(1)$, P1 Def 9.7.)
* *The fixed language* $\mathcal L_{\rm circ}:=\{\mathtt e,\mathtt s_0,\mathtt s_1,\mathrm{Bit},\mathrm{Gate},R\}$ with $\mathrm{Bit}$ binary, $\mathrm{Gate}$ ternary. Index terms $n_i$ and gate terms $g_j$ are word terms $t_{\beta(i)}$, $\beta(i)$ the binary expansion of $i+1$ without its leading $1$; so $|n_i|=O(\log i)$ and the language does not grow with the circuit.
* $a_\ell(f)$ is the least total size of a finite set $T$ of $\mathcal L_{\rm circ}$-sentences (or of sentences of any fixed finite language $\supseteq\{\mathtt e,\mathtt s_0,\mathtt s_1,R\}$) with $T\cup\Gamma_f$ consistent such that every datum $\varphi_x^{f(x)}$, $x\in\dom f$, has a $\mathsf K$-derivation from $T$ of size $\le\ell$.

**The translation $T_V$.** All sentences universally closed; $\leftrightarrow$ abbreviates $\neg((A\to B)\to\neg(B\to A))$.
* Bit: $\forall y\,\mathrm{Bit}(n_0,\mathtt s_1y)$, $\forall y\,\neg\mathrm{Bit}(n_0,\mathtt s_0y)$, and $\forall y\,(\mathrm{Bit}(n_{i+1},\mathtt s_ay)\leftrightarrow\mathrm{Bit}(n_i,y))$ for $i<\max(d,k)-1$, $a\in\{0,1\}$. (So $\mathrm{Bit}(n_i,t_w)$ holds iff the $(i+1)$-st symbol of $w$ is $1$.)
* Gates: for an input gate $j$ reading $x_i$ (resp. $z_i$): $\forall x\forall z\,(\mathrm{Gate}(g_j,x,z)\leftrightarrow\mathrm{Bit}(n_{i-1},x))$ (resp. $z$); for an internal gate $j$ with operation $\mathrm{op}$ on gates $a,b$: $\forall x\forall z\,(\mathrm{Gate}(g_j,x,z)\leftrightarrow\mathrm{op}(\mathrm{Gate}(g_a,x,z),\mathrm{Gate}(g_b,x,z)))$.
* Outputs: $\forall x\forall z\,(\mathrm{Gate}(g_{\mathsf a},x,z)\to R(x))$, $\forall x\forall z\,(\mathrm{Gate}(g_{\mathsf r},x,z)\to\neg R(x))$.

**Theorem 10.1 (circuit sandwich; the routine circuit form of the AI-paper's sandwich, Thm 8.1, not a separate novelty: scout L's verdict "near-definitional once the sandwich is proved", credited on referee A m14).**
(i) [proved; computed: `checks/c4_circuit_axioms.out`] For every consistent verifier circuit $V$ of size $s$ with $k$ certificate bits, $T_V$ has total size at most $C_1(s+d+k)\log_2(s+d+k+2)$, $T_V\cup\Gamma_{f_V}$ is consistent, and every $x\in\dom f_V$ has a derivation of $\varphi_x^{f_V(x)}$ from $T_V$ of size at most $\ell_V:=C_2\big(s\,(\log_2(s+2)+d+k)+(d+k)^3\big)$, with absolute constants $C_1,C_2$. Hence $a_{\ell}(f)\le C_1'(s_N(f)+d)\log_2(s_N(f)+d+2)$ for $\ell=C_2'(s_N(f)\,(\log s_N(f)+d)+(d+s_N(f))^3)$, using $k\le2s$.
(ii) [proved, given the standard simulation of a time-$T$ Turing machine on inputs of a fixed length by Boolean circuits of size $O(T^2)$ (known)] Conversely $s_N(f)\le P(a_\ell(f),\ell,d)$ for a fixed polynomial $P$ depending only on the language and $\mathsf K$.

*Proof.* (i) *Size.* There are $O(d+k)$ Bit axioms of size $O(\log(d+k))$, and one axiom of size $O(\log(s+d+k))$ per gate (two or three gate terms and at most two index terms), plus two output axioms.
*Consistency.* Take the free term algebra on $\mathtt e,\mathtt s_0,\mathtt s_1$ with equality the identity. Read off the bits of any element $y$ (the symbols of the word it spells, $0$ beyond its length; a term is a word); let $\mathrm{Bit}(t,y)$ hold iff $t=n_i$ for some $i<\max(d,k)$ and bit $i$ of $y$ is $1$; let $\mathrm{Gate}(t,x,z)$ hold iff $t=g_j$ and gate $j$ of $V$ outputs $1$ on the first $d$ bits of $x$ and the first $k$ bits of $z$; let $R(x)$ hold iff some $c$ has $\mathsf a(\text{bits}_d(x),c)=1$. The Bit and gate axioms hold by construction (the $n_i$ and $g_j$ are pairwise distinct). The first output axiom holds by the definition of $R$; the second holds because $V$ is consistent: $\mathsf r(\text{bits}_d(x),z)=1$ excludes $\mathsf a(\text{bits}_d(x),c)=1$ for every $c$. On word terms of length $d$, $R(t_x)$ iff $f_V(x)=1$, and $f_V(x)=0$ forces $\neg R(t_x)$; so the structure satisfies $T_V\cup\Gamma_{f_V}$.
*Derivations.* For $x\in\dom f_V$ take a certificate $c$ for its label. Instantiate every gate axiom with $x:=t_x$, $z:=t_c$ (two A4 instances and two MP steps per axiom, each line of size $O(\log s+d+k)$). Derive each needed bit: $\mathrm{Bit}(n_i,t_w)$ or its negation from a Bit0 instance and $i$ BitS instances (each $O(d+k)$ in size), with a fixed propositional derivation for biconditional elimination substituted at each step: $O((d+k)^2)$ per bit, $O((d+k)^3)$ in all. Then, gate by gate in order, derive $\mathrm{Gate}(g_j,t_x,t_c)$ or its negation from the ground biconditional and the literals of its inputs, by a substitution instance of a fixed propositional derivation (the propositional fragment of $\mathsf K$ is complete; substitution instances of derivations are derivations, of size linear in the substituted formulas: TF Thm 4.2(b), referee script r3 Part D). Finish with the output instance and MP. The total is $O(s(\log s+d+k)+(d+k)^3)$.
(ii) A certificate is the code of a derivation of size $\le\ell$; since $T$ is a set of sentences, (F1) holds and parameters can be renamed to $p_0,\dots,p_{\ell-1}$, so the code has $O(\ell\log\ell)$ bits (AI-paper Prop E.21(b)). The checker (with $T$ hard-wired) verifies each line (logical axioms by matching, A4 by first-order matching, members of $T$ by comparison, MP, Gen) and the last line against $\varphi_x$ or $\neg\varphi_x$, in time polynomial in $\ell+|T|+d$; accept if it is a derivation of $\varphi_x$, reject if of $\neg\varphi_x$. Simulating it by circuits gives a verifier circuit of size $P(|T|,\ell,d)$. It is consistent because $T$ is ($T\cup\Gamma_f$ is), and $f_V\supseteq f$ because every datum has a derivation within $\ell$ and $T$ proves no wrong label. $\square$

*Computed* (c4): for 24 random consistent verifier circuits with $d\in\{2,3\}$, $k\in\{1,2\}$, every axiom of $T_V$ is true in the intended structure on a finite fragment (all words of length $\le\max(d,k)+2$ and all index and gate terms), $R$ agrees with $f_V$, and forward propagation through the ground instances derives the right label for every $x\in\dom f_V$ (nonlogical material $\le1682$ symbols); as a negative control, every corruption of one gate operation that changes $f_V$ makes the translated theory derive a wrong label or change its domain (95 of 95; corruptions that leave $f_V$ unchanged are skipped). Sizes: $|T_V|/((s+d)\log_2(s+d))$ stays between $7.9$ and $9.0$ for $s$ from 33 to 1099 gates.

**Corollary 10.2 (P1's circuit-Bayes theorem for verifier circuits) [proved, by the proof of P1 Thm 9.8 with the changes stated].** Let $W_N$ be the mixture over consistent verifier circuits with prior $w(V):=2^{-s}\cdot\frac1{2s+1}\cdot N_{s,k}^{-1}$ (size $s$, $k\le2s$ uniform, $N_{s,k}=\prod_{j=1}^s16(d+k+1+j)^2$ gate lists), and for a nonempty $B'\subseteq\{0,1\}^d$, an ordering of $B'$ and the labels of $f$, let $L:=-\log W_N(f|_{B'})$, $\ell_\emptyset:=-\log W_N(\emptyset)$, and $\mathcal E:=\sum_iP_i$ with $P_i$ the posterior mass at step $i$ that is wrong **or undefined** at $x_i$. Then:
(a) some consistent verifier circuit of size $\le\lceil L\rceil$ agrees with $f$ on $B'$, and $L\le s_N+\log(2s_N+1)+\log N_{s_N,2s_N}=O(s_N\log(s_N+d))$ with $s_N:=s_N(f|_{B'})$;
(b) $\mathcal E\le(\ln2)(L-\ell_\emptyset)$ and $L-\ell_\emptyset\le2\mathcal E(\Gamma_N(\lceil L\rceil)+3)$ with $\Gamma_N(s):=\gamma(5+2\log_2(d+3s+\gamma+1))+\log_2(\gamma+1)$, $\gamma:=2d+2$.
*Proof.* (a) The prior has an exponential tail in $s$ (total weight of sizes $>S$ is $\le2^{-S}$), and the verifier with no active output disagrees with $f$ at every size, so P1's argument applies. (b) The first inequality is $P_i\le-\ln(1-P_i)$ and telescoping (now $W_N(\emptyset)<1$, hence $\ell_\emptyset$). For the second, the *exception gadget* for verifiers: given $V$, a point $a$ and a label $b$, append $\mathrm{eq}_a(x)=[x=a]$ ($\le2d-1$ gates), its negation, and new outputs $\mathsf a':=\mathsf a\vee\mathrm{eq}_a$, $\mathsf r':=\mathsf r\wedge\neg\mathrm{eq}_a$ if $b=1$ (symmetrically if $b=0$): $\gamma\le2d+2$ gates. $V'$ is consistent (at $a$ only the $b$-output can fire; elsewhere as $V$), defined at $a$ with label $b$, agrees with $V$ off $a$, and $V\mapsto V'$ is injective; $w(V')/w(V)\ge2^{-\Gamma_N(s)}$. It maps the hypotheses of size $\le S$ that are wrong *or undefined* at $x_i$ injectively to hypotheses that are right at $x_i$ and still compatible with $D_{i-1}$ (earlier inputs differ from $x_i$). The rest of P1's proof is unchanged. $\square$
So Bayes over nondeterministic verifier circuits makes few posterior mistakes on $f$ exactly when $f$ has a small consistent verifier circuit, and, by Thm 10.1, exactly when $f$ has a small finite axiomatisation in a fixed language whose data have polynomially short derivations, up to polynomial changes.

**Remark 10.3 (the axiom-set prior itself) [proof sketch].** For a mixture over finite axiom sets with a derivation budget, the upper bound $L=O(a\log a)$ and $\mathcal E\le(\ln2)L$ hold directly (Thm 10.1(i); telescoping). The converse needs an exception gadget for *every* hypothesis $T$: replace $R$ by a fresh unary predicate $R'$ in $T$ and add $\forall x\,(x\neq t_a\to(R(x)\leftrightarrow R'(x)))$ and $R(t_a)^b$. This works if the language supplies fresh predicate symbols (so $\mathcal L$ is not fixed finite; the symbol index costs $O(\log)$ bits), if $B$ contains the free-algebra axioms needed to derive $t_x\neq t_a$ (size $O(d^2)$), and if the budget is charged in the prior so that the gadget's extra $O(d^2)$ derivation size moves a hypothesis to a nearby budget at $O(\log)$ bits. Not written out.
