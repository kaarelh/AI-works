\section{Universal axioms from their instances}\label{sec:univ}

Question~1 asks whether the method developed for PA induction (a cautious verifier over a class of templates, sound at all times and exact once the data contain an anchor; \cref{lem:setting:closed}) also learns an axiom $\forall x\varphi(x)$ from sentences $\varphi(x)$. We read the data as instances $\varphi(t)$ at terms $t$; a datum $\varphi(x)$ with $x$ free is, in closure-normal form, already the axiom (\cref{prop:univ:gen}). The answer has four parts; proofs are in \cref{app:univ}.
\begin{enumerate}[label=(\arabic*)]
\item \emph{The instance schema $\varphi(z)$ is learned, easily.} It is a first-order pattern. First-order anti-unification and the $\DT$ learner both learn it, with Plotkin's events \evR\ and \evD\ as the anchor condition; for one variable, two instances such as $\varphi(0)$, $\varphi(S0)$ suffice (\cref{thm:univ:anchor,prop:univ:dt}). In $\SO$ these events do not suffice. Failure rates have exact formulas for one and two variables and an exponential bound in general (\cref{thm:univ:rates}).
\item \emph{The instance schema is not the sentence.} The $\omega$-step ``all closed instances are true in $M$, hence so is $\forall\bar x\varphi$'' is \emph{truth-safe} in $M$ (never leads from true closed instances to a false universal) for every $\varphi$ iff the closed-term substructure of $M$ is elementary (\cref{prop:univ:tv}): in $\N$ and in every model of true arithmetic, but not in $\R$, in $V$, or in a model of $\PA+\neg\Con(\PA)$ (\cref{ex:univ:fail}). In general it is not derivable: $\Q\vdash0+\num n=\num n$ for each $n$, but $\Q\nvdash\forall x\,(0+x=x)$ (\cref{ex:univ:q}).
\item \emph{A cautious learner takes this step silently} when parameters are admissible values (\cref{prop:univ:open}); a closedness guard prevents it, and data with a parameter at every variable license it as ordinary generalization (\cref{prop:univ:gen}). In a first-order encoding, \emph{capture} instances, possibly false in every structure, must be excluded by a guard (\cref{prop:univ:capture}). Evaluating closed instances never refutes a false universal whose closed instances are true (\cref{prop:univ:refute}).
\item \emph{Without labels}, $\forall x\varphi$ is learned by a sound merge of instances (\cref{prop:many:forall}).
\end{enumerate}

% ---------------------------------------------------------------------
\subsection{The target}\label{sec:univ:target}

Fix a first-order language $L$ with at least one constant. Let $\varphi(x_1,\dots,x_k)$, $k\ge1$, be a parameter-free $L$-formula in which each $x_i$ occurs free. A term is \emph{closed} if it has neither variables nor parameters.

\begin{definition}[Instance schema; witness events]\src{cases \S1.1}\label{def:univ:target}
The \emph{instance schema} $\sigma_\varphi:=\varphi[z_1/x_1,\allowbreak\dots,\allowbreak z_k/x_k]$ has a $0$-ary term metavariable $z_i$ at each \emph{free} occurrence of $x_i$. Its \emph{closed instances} are $\instc(\varphi)=\{\varphi(\bar t):\bar t\text{ closed}\}$, its \emph{open instances} $\insto(\varphi)=\{\varphi(\bar t):\bar t\text{ terms over }L\cup\mathrm{Par}\}$, $\mathrm{Par}$ the parameters. For data $D=\{\varphi(\bar t_1),\dots,\varphi(\bar t_N)\}$, $\bar t_j=(t_{j,1},\dots,t_{j,k})$, Plotkin's events (\cref{lem:setting:recover}) read: \univR{i}: the roots of $t_{1,i},\dots,t_{N,i}$ are not all equal; \univD{ii'} ($i<i'$): some $j$ has $t_{j,i}\neq t_{j,i'}$. \evR\ and \evD\ are their conjunctions.
\end{definition}

Under the $\lambda$ convention (\cref{sec:setting:templates}), the default, $\inst(\sigma_\varphi)$ is $\insto(\varphi)$ if parameters are admissible values and $\instc(\varphi)$ if not. In the first-order encodings (Nm) and (dB) (\cref{sec:setting:fo}) a metavariable may also take a bound-variable name or index, which adds \emph{capture instances} (\cref{sec:univ:capture}). The question has content for languages with closed terms, such as $L_A$; in $L_\in$ every instance is at parameters, and a datum $\varphi(\bar p)$ with distinct parameters already is the axiom. Several results assume \univRich: \emph{for every $k$ there are pairwise distinct closed $t_1,\dots,t_k$ and pairwise distinct closed $t'_1,\dots,t'_k$ with $\univroot(t_i)\neq\univroot(t'_i)$ for all $i$} (in $L_A$: $t_i=S^i0$, $t'_i=0+S^i0$). \univRich\ concerns closed terms only and differs from \Rich\ of \cref{def:single:events}.

\subsection{Anchors}\label{sec:univ:anchor}

We use \cref{lem:setting:recover}; every first-order schema covering $D$ is $\gen\lgg(D)$. $\Hk1(\FO)$ denotes the single first-order schemas of the syntax at hand ($\lambda$, Nm or dB). Under \univRich\ instance sets determine schemas: for a first-order $\sigma$ with $0$-ary term metavariables and any first-order $\tau$, $\inst(\sigma)\subseteq\inst(\tau)$ iff $\inst(\tau)$ contains the closed instances of $\sigma$ iff $\tau\gen\sigma$, in each syntax (\cref{prop:univ:determine} in \cref{app:univ:anchor}).

\begin{theorem}[Anchors for the instance schema]\label{thm:univ:anchor}\status{proved; computed}\src{cases Thm A2}
Assume \univRich, and let $D=\{\varphi(\bar t_1),\dots,\varphi(\bar t_N)\}\subseteq\instc(\varphi)$, $N\ge1$. In each syntax the following are equivalent:
\textup{(i)} $D$ is an anchor for $\instc(\varphi)$ in $\Hk1(\FO)$, i.e.\ every first-order schema covering $D$ contains $\instc(\varphi)$;
\textup{(ii)} $\lgg(D)\equiv\sigma_\varphi$;
\textup{(iii)} \evR\ and \evD\ hold.
Without \univRich, (iii)$\Leftrightarrow$(ii)$\Rightarrow$(i).
\end{theorem}

\noindent Proof in \cref{app:univ:anchor}. One datum is never an anchor; two with componentwise different roots and pairwise distinct components are. From numeral data every anchor of $z+0=z$ contains $0+0=0$, which slows the rates and matters for unlabelled mixtures (\cref{rem:many:numerals}). Further corner cases and the computational checks: \cref{app:univ:anchor,app:univ:comp}.

The much larger class $\DT$ of the induction method needs no more data for first-order targets; without determinacy it does.

\begin{proposition}[Anchors in $\DT$ and in $\SO$]\label{prop:univ:dt}\status{proved; computed}\src{cases A2$'$; single D.1; untagged 5.5}
Work under the $\lambda$ convention.
\begin{enumerate}[label=(\alph*)]
\item Let $\sigma\in\FO$ (0-ary metavariables of term or formula sort, possibly under binders) and $D=\{\sigma\theta_1,\dots,\sigma\theta_N\}$ with values that have no free bound variables (parameters allowed; a formula value may contain its own binders). If \evR\ and \evD\ hold, every $T\in\DT$ covering $D$ satisfies $T\gen\sigma$. In particular, data $D\subseteq\insto(\varphi)$ with \evR\ and \evD\ are an anchor for $\inst(\sigma_\varphi)$ in $\Hk1(\DT)$, and $\Min(D)=\{\sigma_\varphi\}$.
\item Under \univRich, if $D\subseteq\instc(\varphi)$ violates \evR\ or \evD, then $\lgg(D)\in\FO\subseteq\DT$ covers $D$ and misses a closed instance. So the anchors for $\instc(\varphi)$ in $\Hk1(\DT)$ are exactly those of \cref{thm:univ:anchor}.
\item In $\SO$ this fails, e.g.\ for $x+0=x$ and the data $0+0=0$, $S0+0=S0$ (\cref{ex:setting:classes}(4)): a metavariable without a pattern occurrence can use different arguments on different data.
\end{enumerate}
\end{proposition}

\noindent Proof in \cref{app:univ:anchor}, with binder analogues of (c); the key to (a) is an identity lemma (\cref{lem:univ:identity}). For one variable, (a) is the two-point lemma (\cref{lem:many:twopoint}); in general it is the ``if'' half of \cref{cor:single:special}(a), proved directly.

\subsection{Rates}\label{sec:univ:rates}

Let $\bar t\sim\Lambda$ i.i.d., $p_{i,f}:=\Lambda(\univroot(t_i)=f)$, $c_{ii'}:=\Lambda(t_i=t_{i'})$, and let $P_N$ be the probability that $N$ instances violate \evR\ or \evD, i.e.\ (under \univRich) are not an anchor in $\Hk1(\FO)$ or $\Hk1(\DT)$.

\begin{theorem}[Failure probabilities]\label{thm:univ:rates}\status{proved; computed}\src{cases Thm A3}
\textup{(a)} For $k=1$, $P_N=\sum_fp_f^N$.
\textup{(b)} For $k=2$, an exact inclusion--exclusion formula in the root and coincidence probabilities of $(t_1,t_2)$ holds (\cref{app:univ:rates}).
\textup{(c)} In general $P_N\le\sum_{i,f}p_{i,f}^N+\sum_{i<i'}c_{ii'}^N\le(2k+\binom k2)(1-\rho)^N\le(2k+\binom k2)e^{-N\rho}$, where $\rho=\min(\min_i\rho_i,\min_{i<i'}\Lambda(t_i\neq t_{i'}))$ and $\rho_i=\max_G\min(\Lambda(\univroot(t_i)\in G),\Lambda(\univroot(t_i)\notin G))$ is the best split of the roots, as in the coupon-collector bound of \citet{claude2026whatfollows}.
\end{theorem}

\noindent Proof (inclusion--exclusion, union bound) in \cref{app:univ:rates}. For a Galton--Watson term law ($\rho=0.5$) the exact failure probability is below $0.01$ from $N=6$ ($k=1,2$), while (c) needs $N=11$ and $13$ in its exponential form, $8$ and $9$ in its $(1-\rho)^N$ form \src{cases q1\_lgg (4); referee r1 (5)}. \emph{Experiment E1} (\cref{sec:exp:results}, \cref{fig:exp:e1}) confirms (a): the implemented $\DTF$ verifier and the first-order $\lgg$ became exact at the same $N$ in every run, with mean close to the prediction of (a) \src{experiments E1, Prop E7}.

\subsection{Parameters, guards and capture}\label{sec:univ:capture}

Once the data contain an anchor, the cautious verifier over $\mathcal H$ accepts exactly the closure $\univcl_{\mathcal H}(h^*)=\bigcap\{h\in\mathcal H:h\supseteq h^*\}$ of the target, so it is sound iff the target is $\mathcal H$-closed (\cref{lem:setting:closed}).

\begin{proposition}[Open instances and the hidden $\omega$-step]\label{prop:univ:open}\status{proved; computed}\src{cases Prop A4}
\textup{(a)} For distinct parameters $\bar p$, $\varphi(\bar p)\in\insto(\varphi)$ has universal closure $\forall\bar x\varphi$, and $\insto(\varphi)$ and $\forall\bar x\varphi$ are interderivable in first-order logic.
\textup{(b)} Assume \univRich\ and the $\lambda$ convention with parameters admissible. In $\Hk1(\FO)$ and in $\Hk1(\DT)$, $\univcl(\instc(\varphi))=\inst(\sigma_\varphi)=\insto(\varphi)\supsetneq\instc(\varphi)$. So once closed data contain an anchor, the cautious verifier accepts $\varphi(\bar p)$: it takes the $\omega$-rule step ``all closed instances, hence $\forall\bar x\varphi$'', which no datum licenses.
\textup{(c)} With the guard $\mathrm{closed}(z_i)$ (``the value contains no variable and no parameter''), $\instc(\varphi)$ is realizable in every syntax. By the most-specific-guard rule (\cref{sec:setting:fo}), closed data teach the guard, and the learner accepts neither $\varphi(\bar p)$ nor any capture instance; one datum with a parameter at $z_i$ deletes $\mathrm{closed}(z_i)$.
\end{proposition}

\noindent Proof in \cref{app:univ:capture}. The class $\DT$ has no guards, so the $\DT$ learner on closed data takes the $\omega$-step after the first anchor whenever parameters are admissible: in E1, from $0+0=0$ and $1+0=1$ it accepts $w_0+0=w_0$, the axiom in parameter form.

In a first-order encoding the step can be worse \src{cases referee F1}. A value $\theta(z_i)$ is \emph{captured} if it contains a variable bound at some free occurrence of $x_i$ (in (Nm), a name in the scope of a binder of that name; in (dB), an index that refers to an enclosing binder). $\Cap(\varphi)$ is the set of instances $\sigma_\varphi\theta$ with a captured value.

\begin{proposition}[Capture]\label{prop:univ:capture}\status{proved; computed}\src{cases Prop A4$'$}
Work in syntax (Nm) or (dB).
\begin{enumerate}[label=(\alph*)]
\item $\inst(\sigma_\varphi)=\instc(\varphi)\cup\insto(\varphi)\cup\Cap(\varphi)$ (the middle term if parameters are admissible), and $\Cap(\varphi)\cap\insto(\varphi)=\emptyset$.
\item \Cref{lem:univ:capcrit} says for each syntax exactly when $\Cap(\varphi)\neq\emptyset$; in (dB), iff every free occurrence of some $x_i$ lies under a binder.
\item Capture instances can be false in every structure while all genuine instances hold in every structure with two elements ($\exists y\,\neg(y=x)$ gives $\exists y\,\neg(y=y)$), or false in $\N$ while $\forall x\varphi$ is logically valid ($\exists y\,(y=Sx)$ gives $\exists y\,(y=Sy)$).
\item Hence, if $\Cap(\varphi)\neq\emptyset$, the unguarded cautious verifier accepts after an anchor sentences outside $\insto(\varphi)$, for suitable $\varphi$ some false in every structure: it is unsound outright, not merely $\omega$-incomplete.
\item With guards $\mathrm{closed}(z_i)$ and $\mathrm{nocap}(z_i)$ (no captured value: the free-for condition, i.e.\ the $\lambda$ convention as a guard), closed data teach both, and after an anchor the accepted set is $\instc(\varphi)$. A datum whose value at $z_i$ contains a parameter deletes $\mathrm{closed}(z_i)$ but not $\mathrm{nocap}(z_i)$; once this has happened for every $i$ (for $k=1$, after one such datum), the accepted set after an anchor is $\insto(\varphi)$. Capture instances are never accepted.
\end{enumerate}
\end{proposition}

\noindent Proof and computed checks in \cref{app:univ:capture}. Under the $\lambda$ convention $\Cap(\varphi)$ does not arise.

\subsection{The \texorpdfstring{$\omega$}{omega}-gap}\label{sec:univ:omega}

For an $L$-structure $M$ let $M_0:=\{t^M:t\text{ closed}\}$ be its \emph{closed-term substructure}. The criterion of \citet{tarski1957arithmetical} gives (proof in \cref{app:univ:omega}):

\begin{proposition}[When closed instances decide universals]\label{prop:univ:tv}\status{proved; known}\src{cases Prop A5}
For an $L$-structure $M$ the following are equivalent: \textup{(i)} for every $L$-formula $\varphi(\bar x)$, $M\models\forall\bar x\varphi$ iff $M\models\varphi(\bar t)$ for all closed $\bar t$; \textup{(ii)} $M_0\preceq M$. In particular (i) holds for term-generated $M$ ($M_0=M$), e.g.\ $\N$, and for every model of true arithmetic.
\end{proposition}

\begin{example}[Where the step fails]\label{ex:univ:fail}\status{proved}\src{cases Ex.~A6, A7, A7$'$}
\textup{(a)} In $\R$ as an ordered field ($0$, $1$, $+$, $-$, $\cdot$, $<$) closed terms denote integers, so every closed instance of $\neg(x\cdot x=1+1)$ is true, but $\forall x\,\neg(x\cdot x=1+1)$ is false. The theory $\mathrm{RCF}$ of real closed fields refutes it; the ordered-field axioms $\mathrm{OF}$ do not ($\mathbb Q$).
\textup{(b)} In $V$ with $\emptyset$, $p(a,b)=\{a,b\}$, $u(a,b)=a\cup b$, closed terms denote the hereditarily finite sets, so every closed instance of $\neg\mathrm{Ind}(x)$, $\mathrm{Ind}(x):=\emptyset\in x\wedge\forall y{\in}x\ u(y,p(y,y))\in x$ ($\Delta_0$), is true; Infinity refutes $\forall x\,\neg\mathrm{Ind}(x)$.
\textup{(c)} In a model $M$ of $\PA+\neg\Con(\PA)$ (one exists if $\PA$ is consistent), every closed instance of $\neg\mathrm{Prf}(x,\ulcorner\bot\urcorner)$, $\mathrm{Prf}$ a $\Delta_0$ proof predicate, is a true $\Delta_0$ sentence and holds in $M$, but $M\models\exists x\,\mathrm{Prf}(x,\ulcorner\bot\urcorner)$.
\end{example}

\begin{example}[Not derivable]\label{ex:univ:q}\status{proved; computed}\src{cases Ex.~A8; q1\_qmodel; referee r1 (4)}
$\Q\vdash0+\num n=\num n$ for every $n$ (Q4, then Q5 and induction on $n$ outside $\Q$). But $\Q$ plus all closed instances of $0+x=x$ does not prove $\forall x\,(0+x=x)$: there is a model of $\Q$ on $\N\cup\{a,b\}$, standard on $\N$, with $Sa=a$, $Sb=b$ and $0+a=b$ (\cref{app:univ:omega}).
\end{example}

\begin{proposition}[Parameters and generalization]\label{prop:univ:gen}\status{proved}\src{cases Prop A9}
With data at parameters the gap disappears. In closure-normal form a datum $\varphi(\bar p)$ with distinct parameters (none occurs in $\varphi$) \emph{is} the sentence $\forall\bar x\varphi$, its universal closure; with trusted generalization $\forall\bar x\varphi$ is derived from it in one step.
\end{proposition}

\subsection{Consequences for a learner}\label{sec:univ:learner}

\Cref{tab:univ:learner} collects what the cautious verifier accepts, and \cref{prop:univ:learner} in \cref{app:univ:learner} what is soundly learnable. Beyond the table: in (Nm) and (dB) a learner sound for $\instc(\varphi)$ must exclude capture instances whenever $\Cap(\varphi)\neq\emptyset$, even without parameters.

Refutation by the world (\cref{sec:setting:refutation}) helps only partly (\cref{prop:univ:refute} in \cref{app:univ:learner}). A false $\forall\bar x\varphi$ whose closed instances are true is condemned by no evaluation of closed instances, and by a coherence refutation from designated true premises $\Gamma$ iff $\Gamma\cup\{\forall\bar x\varphi\}$ is inconsistent ($\mathrm{RCF}$ refutes \cref{ex:univ:fail}(a), $\mathrm{OF}$ does not; $\ZF$ refutes (b)); where the $\omega$-step is truth-safe, e.g.\ in $\N$, every false universal has a false closed instance instead. Capture instances false only in $M$ need a designated theory that refutes them ($\PA$ refutes $\exists y\,(y=Sy)$, $\Q$ does not): against capture the world channel alone does not protect a first-order learner.

\paragraph{Without labels.}\label{sec:univ:merge}
In the untagged setting (\cref{sec:many}), learning $\forall x\varphi$ means merging instances read as separate ground targets. Two closed instances of a one-variable $\varphi$ with different heads have the single minimal template $\sigma_\varphi$ (\cref{prop:univ:dt}(a)), so \DTRC{} merges them into a cluster accepting $\varphi(a)$ for a fresh parameter $a$, i.e.\ $\forall x\varphi$, unless an instance of $\sigma_\varphi$ is refuted (\cref{prop:many:forall}, with its caveats). With R-$\Delta_0$, ``never refuted'' means ``true'' for quantifier-free $\varphi$ (\cref{prop:many:qf}), but not in general.

\subsection{Summary}\label{sec:univ:summary}

The answer to Question~1 is yes for the instance schema, which first-order anti-unification and the $\DT$ learner alike learn from two instances with different roots (plus \evD\ for several variables), and ``only where $M_0\preceq M$'' for the axiom: the passage to $\forall\bar x\varphi$ is an $\omega$-rule step, which a cautious learner takes silently when parameters are admissible, a closedness guard stops, and data with a parameter at every variable license; first-order encodings also need a guard against capture (\cref{tab:univ:learner}). Without labels, $\forall x\varphi$ is a sound merge (\cref{sec:many:forall}). Open problems: \cref{sec:disc:open}.
