\begin{abstract}
\noindent Proofs show axiom instances, not axioms. We ask when a checker can learn from positive instances which axioms
and schemas a community uses, soundly against adversarial provers. As in an earlier report, the checker is cautious: it
accepts what every covering template of a fixed class accepts. We answer three questions.
(1)~From instances $\varphi(t)$ one learns the instance schema $\varphi(z)$, a first-order pattern; two instances with
different head symbols suffice. Passing to $\forall x\varphi$ is an $\omega$-rule step: truth-safe for all $\varphi$
exactly when the closed-term substructure is elementary (in $\mathbb N$, not in $\mathbb R$), and not derivable in
general.
(2)~Every ZF schema, in each formulation considered, is a higher-order pattern; from pattern to rigid second-order
templates, instances form an anchor iff their bodies' main symbols vary and every argument place is used. First-order
anti-unification works only for some formulations and encodings; elsewhere no finite union of first-order schemas is
sound. PA induction is not a pattern: first-order and pattern anti-unification fail on it, determinate templates learn
it.
(3)~For many unlabelled schemas we propose \DTRC{}: cluster the data by refuting merged templates, then check each cluster
cautiously. Under refutation separation it recovers the labels and needs no more data than a learner given them;
otherwise it is sound relative to a residue of unrefuted merges, and dependence on the refutation depth is unavoidable.
We give complexity bounds, show separation for PA, ZF and ZFC, and report experiments; in one, injected mistakes led
to a false sentence being accepted.
\end{abstract}
