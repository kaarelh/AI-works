ALGORITHM: LEARN-IND, applied per rule tag (the community cites "induction"). Data: motive-annotated induction records, encoded as ground first-order step terms. Default encoding (E1, the paper's Sub encoding): ind(phi,v) = st( Sub(phi,v,0,phi[0/v]), Sub(phi,v,Sv,phi[Sv/v]), (phi[0/v] & forall v(phi -> phi[Sv/v])) -> forall v phi ). Sub(phi,x,t,psi) is W-decidable and true iff phi is a well-formed formula, x is an object variable, t is a term free for x, and psi = phi[t/x]. The target pattern is sigma_x = the same term with metavariables P, A, B and x fixed; with X as a fourth metavariable if the induction variable is not normalized.

Steps:
(1) Canonicalize each record. Put the two Sub premises in a fixed order (0 before Sx) and the base-case conjunct first. Optionally alpha-normalize the induction variable to x; this is sound under trusted FOL.
(2) W-filter: drop records with a W-false Sub premise. They are useless as steps, and dropping data never harms soundness.
(3) Generalize. Noise-free: L = lgg(D), Plotkin/Reynolds anti-unification (T1 lgg_list). With per-tag noise budget e: use the trimmed version space, the intersection over |E| = e of inst(lgg(D\E)).
(4) Verify a query q. Accept iff q matches L (first-order matching, linear time) and all Sub premises of q are W-true. Reject if a Sub premise is W-false. Otherwise escalate. This is the cautious verifier of the guarded single-schema class with guard psi_Sub ("all Sub premises are W-true"), via the paper's lem:setting:guard.
(5) In the two-tier learner, every tag's learned schema goes through the audit, including latent fallacy tags such as step-by-2.

Identification diagnostic: L equals the pattern iff the data contain an anchor. An anchor is two motives with different main symbols, at least one with x free, plus two distinct induction variables if not alpha-normalized.

Equivalent encodings, also analysed:
- (E2) Lean-style. Motive recorded as M = lam(x,phi). The premise-free conclusion keeps the beta-redexes: (M 0 & forall n(M n -> M(Sn))) -> forall n M n. Beta is a trusted step. One metavariable. Anchor: two motives with different main symbols; vacuity is irrelevant.
- (E3) Metamath-style, after set.mm finds/nnind. Premises |- x=0->(ph<->ps), |- x=y->(ph<->ch), |- x=Sy->(ph<->th), |- ps, |- ch->th; conclusion |- ph. Needs freshness guards: either learned as "strongest guards true on all data", or recorded as W-decidable NF premises.

   S: (a) A first-order pattern in phi, psi, chi, theta (plus X, Y if the variables vary), whose premises are |- judgments. ALGORITHM: SOCL, a second-order cautious learner. The hypothesis class is DT, the determinate second-order templates.

**Class DT.**
- A template is a formula of first-order arithmetic in which function metavariables F(t1..tn) (type iota^n->iota) and predicate metavariables M(t1..tn) (type iota^n->o) may occur.
- In Church encoding it is a beta-normal eta-long lambda-term with free metavariables, of type o, with no free object variables.
- An instance is T theta beta-normalized, where theta assigns closed lambda-terms lambda z.beta with beta first-order and metavariable-free. Since bodies are first-order, beta-reduction is one-step plugging.
- T is *determinate* if every metavariable has a pattern occurrence: an occurrence M(y1..yn) at a rigid position (not inside another metavariable's arguments), applied to pairwise distinct variables bound above it. A 0-ary metavariable needs only a rigid occurrence.
- Example: T_ind = P(0) & Ax(P(x) -> P(Sx)) -> Ax P(x) is determinate. Its pattern occurrence is P(x) under the conclusion's Ax; P(0) and P(Sx) are *derived* occurrences.

**Learning and verifying (input: finite multiset D of sentences).**
1. *Common prefix.* Compute C(D): the positions on which all data agree, top-down, using de Bruijn trees. This is Plotkin–Reynolds anti-unification with the disagreement positions kept as slots sigma, each with a content column c_i(sigma).
2. *Own pattern filler.* Each slot can take its own pattern metavariable M_sigma(ybar_sigma), where ybar_sigma are the bound variables occurring in the column. Then theta_i(M_sigma) = lambda ybar. c_i(sigma) (Miller pattern).
3. *Derived fillers.* For each ordered pair of slots (sigma, pi), find ubar with c_i(sigma) = c_i(pi)[ubar/ybar_pi] for all i. The components of ubar are forced: substitution into a formula with a free occurrence of the variable is injective. Each solution gives a derived filler M_pi(ubar) at sigma.
4. *Minimal templates.* The covering templates are the prefixes of C(D) with fillers in {fresh 0-ary metavariable (for closed columns), own pattern, derived occurrence}. This is complete by the rigid-prefix lemma. Keep the minimal ones Min(D) under subsumption, tested by freezing metavariables and matching. With a size bound s ≥ 12, enumerate within the bound.
5. *Verification.* Accept a step q iff q is in inst(T) for every T in Min(D). Each test is a determinate match: read every metavariable off one pattern occurrence, then check the remaining occurrences by lazy evaluation, in O(|T|·|q|).

**On raw induction data.** Once D contains two motives with different main symbols, at least one with x free (conditions (R) and (N)), Min(D) = {T_ind}. The verifier then reduces to:
- read P := lambda x.phi off the conclusion Ax phi;
- check that the antecedent is phi[0/x] & Ax(phi -> phi[Sx/x]).

This is linear time.

**Before an anchor.** The verifier is still sound, because T_ind is in DT. It accepts only a specialization, e.g. the induction instances with motives of the form t(x)=x.

**Noise.** Use the trimmed version, accepting the intersection over {T in DT : |D \ inst T| ≤ e}. It is sound with at most e mistakes, and exact once the clean data are e-robustly diverse.

**What not to use.**
- First-order lgg: unsound (Track B).
- Pattern-restricted higher-order anti-unification (Pfenning 1991; Baumgartner–Kutsia–Levy–Villaret 2017): its lgg here is A & Ax(P(x)->Q(x)) -> Ax P(x), which is unsound.
- Non-determinate second-order templates (SO°): they need the stronger anchor condition (B), and matching can have exponentially many matchers.
