# Editor decisions for cross-cutting review issues (binding)

1. **Q-axiom numbering**: use §2's (setting.tex) numbering everywhere: Q1 Sx≠0, Q2 Sx=Sy→x=y, Q3 x≠0→∃y x=Sy, Q4 x+0=x, Q5 x+Sy=S(x+y), Q6 x·0=0, Q7 x·Sy=x·y+x. many.tex and app-many.tex must convert every Q-number (the untagged record uses another order; check each statement, table and example, e.g. cor:many:paslots, tab:many:pacross, "descent through Q3" → the recursion axiom Q5). When in doubt write the formula instead of the number.
2. **The three questions** are "Question 1/2/3" (never "Q1/Q2/Q3", which are Robinson's axioms).
3. **Duplicated results** (∀xφ as a sound merge: prop:univ:merge = prop:many:forall; two-point lemma; lem:univ:qf = prop:many:qf): the canonical statements and proofs live in §6 (many.tex / app-many.tex). §4 (universal.tex) keeps one short paragraph summarizing the consequence for Question 1 with \cref to §6's labels, and app-universal drops the duplicated proofs (keep lem:univ:identity if it is used for §4's own DT° anchor result). The universal editor must not delete labels that other files reference without replacing those references (grep all sections for each label you remove; you may edit the referencing line in other files only to update the \cref target).
4. **E1 figure** (figures/e1_anchor_cdf.png): included once, in §7 (experiments.tex) as fig:exp:e1; §4 refers to it with \cref{fig:exp:e1}. The universal editor removes any claim that §7 "plots" something without a \cref; the experiments editor adds the figure.
5. **prop:setting:align (fatal)**: restrict (b) and (c) to templates all of whose parameters occur in their skeleton (in particular parameter-free targets), fix the proofs, fix the false sentence "If some datum has no parameter there is one alignment, and Min^al = Min", add the counterexample as a remark; setting.tex's sentence in sec:setting:params must match. The experiments editor fixes prop:exp:oracle(b) and any other statement inheriting the old claim, with the same restriction (all experiment targets are parameter-free, so no number changes).
6. **prop:exp:share (fatal)**: restate with the missing hypothesis (every target labels a phase-1 cluster, or whatever the reviewer's counterexample shows is needed) or weaken; include the reviewer's counterexample as an example of failure; adjust experiments claims and the intro/discussion later (the final editor handles intro/discussion).
7. **Status markers on definitions**: Definitions carry \src only, no \status. Remove \status{definition}/\status{known} from definition environments.
8. **Glossary**: setting.tex gets a compact table of named conditions/hypotheses (witness events (R),(R*),(N),(D),(U),(Rich); (W) finiteness; refutation separation RS_d; (H-ref); (S); closure; anchor; target-sound/truth-sound), each with a one-line meaning and the label where it is defined. Rename clashing symbols where reviewers flag clashes (e.g. §7's hypotheses printed like witness events; "(N)" for the named encoding vs non-vacuity: use \mathrm{nm} / "named" for the encoding).
9. **\DTRC inside \emph**: write \textup{\DTRC} or avoid \emph around it.
10. **Length**: apply the readability reviewer's cuts for your section (move secondary results/proofs/details to your appendix with a one-line pointer; delete duplicated recalls; tighten). Target main-text lengths: setting ≤ 5.5 pp, single ≤ 7 pp, universal ≤ 4.5 pp, zfc ≤ 7 pp, many ≤ 8.5 pp, experiments ≤ 6.5 pp. Never drop a result statement: either keep it or leave a one-line pointer to its new place in your appendix. Never drop caveats.
11. **Labels**: do not rename existing labels. If you delete or move a labelled item, grep all of ../../paper/sections/*.tex for references and keep them valid (moving within the document keeps the label valid).
12. **Shared files**: preamble.tex may be edited only to add a macro you need (prefix it with your section key); do not change existing macros. Build with ./build.sh only when no other build is running: use `flock /tmp/claude-0/paper-build.lock ./build.sh` (the lock prevents concurrent builds corrupting main.aux). For isolated checks use ./test-section.sh <section> <appendix> (it builds in its own directory).
