# Orchestration scripts

The research, verification, writing and review behind *What Follows from What* were done by many separate Claude instances. These scripts started them; each one fans out agents with a written brief and collects their reports.

* **Top-level files.** The runs as executed, named by phase:
  * literature sweep;
  * theory exploration;
  * the second theory wave;
  * recovery and repair rounds;
  * experiments;
  * final checks.
* **`templates/`.** Parameterised scripts that were filled in for individual verification, writing, review and editing rounds.

The prompts in these scripts show what each agent was asked to do and which checks it was told to run. They refer to absolute paths in the original working environment.
