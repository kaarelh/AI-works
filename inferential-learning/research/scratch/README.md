# Working scripts (unreviewed)

These are the working files from the theory and verification rounds behind *What Follows from What*, kept as they were.

* **What is here:**
  * small Python scripts that check lemmas numerically, by brute force or by searching for counterexamples;
  * their saved outputs (`.out`);
  * Lean scratch files (`lean/`);
  * referee scripts and reports from individual rounds (`t1ref/`, `t2s2/`, `t3fix/`, `t4rep/`, `l3re/`, `r2/`, `review/`, `t7runs/`);
  * physics checks (`L9/`, `leg*.py`, `lip.py`);
  * raw workflow summaries (`logs/`).
* **Why they are kept.** Several verification records in `../verification/` and `../theory/` cite these scripts by file name, for example `conjsearch.py`, `lem12_13.py`, `rank43.py`, `prop32.py` and `thm34d.py`.
* **The maintained versions.** The checks that matter were consolidated into `../../code/` (see `code/README.md` and `run_all_quick.sh`).
* **No review.** Nothing here was reviewed, scripts may depend on files that no longer exist, and some were superseded within minutes.
