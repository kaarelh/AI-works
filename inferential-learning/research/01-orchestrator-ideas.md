# Orchestrator ideas (second-round input for design agents)

These ideas are in addition to the hypotheses in `00-brief.md`. Treat them as proposals to scrutinize, not as conclusions.

## 1. Bilateral coherence dissolves most of the context problem

* Make coherence a property of **positions** (what is asserted and what is denied), not of sentences, following Restall's reading of multiple-conclusion sequents.
* Supposing is not asserting. Inside a hypothetical context `[suppose A]`, deriving P and ¬P is not an incoherent position; it is a reductio of A.
* An idealized physics context ("air pressure = 0") is a supposition. The physicist never asserts it. What they assert is the exported claim "the answer is ≈ v (to the relevant precision)".
* So coherence penalties attach only to asserted and denied claims:
  * the actual background,
  * observations,
  * exported conclusions.
* The context problem then reduces to one question: **what licenses moving from a supposition-internal result to an assertion?** Call this the export rule.
* In mathematics the export rule is purely logical (→-introduction or discharge), and it is exact.
* In physics the export rule is not logical. It is an approximation claim, and it needs its own justification.

## 2. Justification beyond proof = proof inside a context + certified bridges, organized as a refinement tower

* An exported physical claim is justified relative to a **tower of models** M₀ ⊂ M₁ ⊂ … ⊂ M_k, where M_{i+1} is less idealized than M_i.
* Each bridge M_i → M_{i+1} carries an error bound. The bound is proved *inside* M_{i+1}: a stability or sensitivity estimate, an asymptotic expansion, or a numerical simulation that is itself a computation inside M_{i+1}.
* The top model M_k is related to the world by calibration, i.e. world feedback on a class of observables.
* A conclusion is then justified to within ε when two things hold:
  * the sum of the bridge errors is ≤ ε;
  * the top model is calibrated on the relevant observable class.
* The candidate thesis is that the following can all be cast this way:
  * Laymon's monotonicity condition;
  * McMullin's de-idealization;
  * Norton's distinction between idealization and approximation.
* "Principled justification beyond proof" would then be: a **proof modulo a stable refinement tower whose top is empirically calibrated**.
* Coherence acts on the exported claims, which are all in the same, actual context. Inconsistency between idealized contexts is harmless because nothing inconsistent is ever asserted.

## 3. Algebra / equational reasoning as the experimental workhorse

* Steps are rewrite instances `s = t ⟹ C[σl] = C[σr]`.
* Rules (rewrite schemas, e.g. ring axioms) are learnable from positive examples by anti-unification.
* World feedback is **random numerical evaluation**. By Schwartz–Zippel this is an essentially perfect truth oracle for polynomial identities. So it is a principled stand-in for "occasional truth values from the world", and it is cheap.
* Systematic human errors come for free:
  * the "freshman's dream" (a+b)² = a²+b²;
  * √(a²) = a;
  * cancelling x/x = 1 without the guard x ≠ 0;
  * (a+b)/(c+d) = a/c + b/d.
* Coherence or evaluation refutes each of these.
* Rules with **guards (side conditions)** are learned by Lakatosian monster-barring or lemma-incorporation:
  * a rule "x/x → 1" leads to a contradiction via 0/0;
  * the minimal repair is the guarded rule "x/x → 1 if x ≠ 0".
* Learning guards from negative bags (contradictions) is a precise toy version of "proof-generated concepts".

## 4. Candidate package theorem ("CIL theorem")

**Setting.**
* (i) Human steps are generated by an unknown schematic calculus R*. Rules are schemas with guards from a finite guard language. Sporadic noise has rate η, and systematic fallacies are allowed.
* (ii) A coherence oracle detects contradictions among asserted claims, or derivations of ⊥ from accepted premises.
* (iii) A truth oracle answers on a decidable fragment (world feedback).

**Learner.** An MDL-ranked version space, with:
* conservative acceptance (accept a step only if every surviving hypothesis above a weight threshold accepts it);
* coherence pruning, where each contradiction is a negative bag.

**Desired conclusions.**
* (a) **Soundness against any adaptive prover**, with probability ≥ 1−δ.
* (b) **Completeness after enough human data.** After Õ(Σ_r 1/p_r) human steps, the accepted step set equals the valid step set, which gives systematic OOD generalization.
* (c) **Bounded contradictions.** The number of contradictions encountered is ≤ log₂ of the size of the relevant hypothesis class.
* (d) **Exact characterization of residual errors.** A systematic fallacy F survives forever iff R* ∪ {F} is coherent and agrees with the world oracle. In that case F is an alternative meaning that is empirically equivalent on the oracle fragment (a Kripkenstein-type lower bound).

**Open issue.** It is unclear what the right notion of "coherent" is when the target itself is incomplete (arithmetic). The candidate answer is conservativity: prefer hypotheses whose new consequences in the old vocabulary are already target consequences. But that cannot be checked; it can only be approached in the limit.

## 5. The informal-math story in this frame

Informal proofs are chains of steps where each step is valid "in the obvious formalization". The learner must find a calculus and a reading such that:
* accepted steps are short derivations;
* known paradoxes are not derivable;
* computational spot checks agree.

Pre-1900 analysis already had a de-facto refinement tower:
* Leibnizian infinitesimals were used as an idealization;
* bridges were justified by the agreement of results with exact computations;
* Cauchy and Weierstrass later supplied the "next model up" in which the bridges are theorems (ε-δ).

Robinson's non-standard analysis shows the infinitesimal context can itself be made consistent. So this is chunk-and-permeate becoming a single consistent context after the fact.

## 6. What would make the result "great" rather than "fine"

* One clean end-to-end theorem for formal mathematics: learning a calculus from positive human proofs plus coherence yields a reasoner that is sound against search and complete in the limit, with explicit sample complexity.
* One for informal mathematics: learning a latent formalization (R, ρ). Its toy Frege→Russell→Zermelo instance should be fully proved.
* One for physics: a checker for refinement towers, proved sound under stated bridge-certification assumptions and with learned bridge validity regions, demonstrated on real olympiad problems.
* Sharp impossibility results showing that each ingredient (positive data, conservativeness, coherence, world feedback, contexts) is necessary.
* Working code that exhibits all of this, including a prover exploiting a merely-average-case-accurate learned verifier.
