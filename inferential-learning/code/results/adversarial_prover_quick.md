# Experiment C: adversarial proof search against learned verifiers

_Auto-generated by `experiments/exp_adversarial_prover.py` --quick; seeds [0]; mean ± sd over seeds. Raw data: `results/adversarial_prover_quick.json`. Total wall time 36 s._

## Setup

* **Domain and corpus.** Partial field algebra (`cil.domains.algebra`). Every learned verifier is trained on N = 150 simulated human derivations with sporadic noise (5%) and systematic fallacies (rate 0.3). The only exception is `lgg_ms_clean`, trained on a clean corpus of the same size.
* **(a) Statistical baselines (PRM-like).** These are `cil.baselines.StatisticalVerifier` models: logistic regression, histogram gradient boosting and a random forest. Features are hashed bags of subterm-shape n-grams of the rewrite core (lhs, rhs and their difference), root-shape pairs, an abstract rule signature, and numeric tree-edit features. The training data are oracle-labelled:
  * positives: valid human steps;
  * negatives: refuted human steps, perturbations of human steps (anywhere, and inside the rewritten core), and instances of the five known fallacies.
  So the baselines get *more* supervision than the positive-only rule learner. Thresholds are calibrated on an in-distribution calibration set to balanced precision TPR/(TPR+FPR) ∈ {0.95, 0.99, 0.999, 1.0}; `t0.5` is the default 0.5 threshold. In-distribution numbers below are on a separate test split of fresh human derivations (N = 100, split by derivation).
* **(b) Conservative LGG / version-space verifiers, positive examples only** (`cil.learners.LGGLearner`, tagged, support m = 2):
  * `lgg_pos`: unguarded schemas;
  * `lgg_ms`: most-specific guards;
  * `lgg_ms_clean`: most-specific guards learned from a clean corpus (the realizable, noise-free case).
* **(c) LGG + coherence / world feedback** (`cil.learners.CoherenceRepairer`, default budget): `lgg_coherence` is pure coherence with no world; `lgg_world_bag` gets world feedback on derivation endpoints; `lgg_world_step` gets it on single steps.
* **(d) `target`**: the ground-truth calculus (41 guarded schemas).
* **The adversarial prover** (`cil.provers.prove`) is black-box: it sees only accept/reject. It runs a bidirectional best-first search, and a proof is a path whose every edge is accepted in some orientation. Candidate steps come from:
  * target rules, fallacies and near-miss schemas applied forward and backward with guards ignored;
  * arithmetic, forward and backward;
  * random mutations;
  * goal-directed leaps and grafts.
  The budget is verifier queries: 1000 per false goal and 800 per true goal. The goals are 23 FALSE equations and 33 TRUE identities, listed at the end. Truth is checked by exact evaluation at random and boundary points with Kleene equality; 'x/x = 1' is false because the lhs is undefined at x = 0.
* **Metrics.**
  * *Derived false equations*: every term u reached from a root r gives a derived equation r = u. It is counted as false when exact evaluation at 8 fixed points refutes it.
  * *Certainly invalid accepted steps*: accepted edges from a node with r = u unrefuted to a node with r = v refuted (a lower bound on the invalid steps accepted).
  * *Search precision*: 1 minus the fraction of accepted edges that are certainly invalid. This is an upper bound on the precision on the steps the prover actually used.
  * *Proofs*: every edge of every found proof is checked by a 60-point oracle.

## Interpretation

1. **In-distribution accuracy does not transfer to the search distribution.** 4 of the 4 statistical configurations derive false equations under search.
   * The configurations with in-distribution balanced precision ≥ 0.99 are `gboost@p1.0`, `logreg@p0.99`.
   * They still prove 3.0–8.0 of the 23 false goals.
   * On the steps the search actually took, their precision is at most 0.969 (`gboost@p1.0`).
   * The 82 invalid proof edges (all statistical configurations and seeds; section 3b) split by proposal as follows:
     * goal-directed leap / graft: 70%
     * random mutation: 22%
     * target rule outside its guard: 4%
     * near-miss schema: 4%
     * fallacy schema: 1%
     These steps look like human steps and are not. The classifier scores surface similarity to valid steps, and nothing ties its acceptance region to validity off the training distribution.
   * No statistical configuration avoided false proofs within the budget.
2. **Rule-learned verifiers fail only through identifiable schemas, and world feedback removes them.**
   * After step-level world feedback, the learned calculus proves 0.0 false goals and derives 0.0 false equations.
   * It proves 26.0/33 true identities, against 29.0/33 for the ground-truth calculus. Soundness costs 3.0 identities: the true goals it misses use target rules the learned calculus lacks or holds only in specialised form (section 4).
   * Every false proof of a rule-learned verifier runs through a named schema. 23/23 of their invalid proof edges are licensed by a schema that the random soundness test flags as unsound (section 3b).
   * A counterexample to such a schema deletes it or guards it, and that removes the whole family of exploits at once. A statistical verifier has no such unit of repair.

**Caveats.**
* *The prover is a heuristic black-box search with a modest budget.* 'Not proved' is not 'unprovable'.
  * The zeros of the rule-based verifiers `target`, `lgg_world_step` are not search luck. Together they derive no false equation at all in 58,723 verifier queries.
  * The false proofs of the statistical verifiers are certified by exact evaluation.
* *Truth is measured, not proved.* False derived equations are refuted at exact rational points, so these counts are certain lower bounds. Proof edges are checked by a 60-point oracle. Schema soundness of the rule-based verifiers is random-tested (`schema_sound`).
* *The baselines are small models on hand-built features, trained on a few thousand steps.* More capacity and data would push in-distribution error down. They would not by themselves close the gap, because the acceptance region of a classifier is not closed under the substitution instances a prover can construct. Theory T1 Thm 2.1 shows that for every step distribution there are verifiers with arbitrarily small average error that accept a trivialising step. The experiment does not test whether larger learned verifiers are exploitable at the same rate.
* *World feedback is cheap here.* Random evaluation is an almost perfect oracle for these identities. The soundness of the conservative calculus rests on that oracle having been used during learning (section 5 lists the oracle queries).
* *Seeds.* 1 seed(s); ± is the sd over seeds.

## Goals

False goals: `1 = 2`; `0 = 1`; `x = x + 1`; `x = 2*x`; `x = -x`; `x*y = x + y`; `(x + y)^2 = x^2 + y^2`; `-(x + y) = -x + y`; `(x + y)/(z + 1) = x/z + y/1`; `x - y = y - x`; `sqrt(x + y) = sqrt(x) + sqrt(y)`; `x/(y + z) = x/y + x/z`; `x/x = 1`; `sqrt(x^2) = x`; `x*(1/x) = 1`; `0/x = 0`; `x^2/(x*x) = 1`; `x/(1/y) = x*y`; `sqrt(x*y) = sqrt(x)*sqrt(y)`; `(1/x)^0 = 1`; `0*(1/x) = 0`; `(x - x)/y = 0`; `x/y*(y/x) = 1`.

True goals: `(x + y)^2 = x^2 + 2*x*y + y^2`; `(x + 1)*(x - 1) = x^2 - 1`; `x*(y + z) = x*z + x*y`; `x + 0*y = x`; `x/x = 1  [nonzero(x)]`; `sqrt(x^2) = x  [nonneg(x)]`; `x*(1/x) = 1  [nonzero(x)]`; `x + y - (x + y) = 0`; `2*x + 3*x = 5*x`; `--(x*y) = y*x`; `(x*y)^2 = x^2*y^2`; `(x - y)*(x + y) = x^2 - y^2`; `(x + y)/z = x/z + y/z`; `x*y + x*z = x*(z + y)`; `x^2/(x*x) = 1  [nonzero(x)]`; `0/x + y = y  [nonzero(x)]`; `x/(1/y) = x*y  [nonzero(y)]`; `sqrt(x*y) = sqrt(x)*sqrt(y)  [nonneg(x), nonneg(y)]`; `(1/x)^0 = 1  [nonzero(x)]`; `0*(1/x) = 0  [nonzero(x)]`; `(x - x)/y = 0  [nonzero(y)]`; `x/y*(y/x) = 1  [nonzero(x), nonzero(y)]`; `(x + y)*(x + y) = x^2 + 2*x*y + y^2`; `x*x - y*y = (x + y)*(x - y)`; `x*(y*z) = z*(y*x)`; `-(x - y) = y - x`; `2*(x + 1) = 2*x + 2`; `2*x/(2*y) = x/y`; `(x + 0)*(1*y) = y*x`; `(x + y)^2 - (x^2 + 2*x*y + y^2) = 0`; `x*(y + 1) - x = x*y`; `(x + y)*z - y*z = x*z`; `x/(x*y) = 1/y  [nonzero(x)]`.
