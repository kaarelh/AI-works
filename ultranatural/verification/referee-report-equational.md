### 1.3 Minor (gaps and small errors; each with its fix)

**m1. Corollary 4, "checked for n ≤ 3000" is not a proof, and the check is not in the repository** (`prior_tail.py` prints seven values of n).
*Fix (complete proof):* the generating function T(z) of the number T_s of binary terms satisfies T = 4z + zT + zT², has radius 1/5, and T(1/5) = 2. So the weight of the terms of more than m symbols is Σ_{s>m} T_s 7^(−s) ≤ (5/7)^(m+1) Σ T_s 5^(−s) = 2·(5/7)^(m+1). With q_m ≤ q, ε(m) ≤ 2q(q − q_m)/(7(1 − q²)²) = 1.2588·(q − q_m), so ε(n+1) ≤ 1.2845·(5/7)^n for every n. This gives 7^13·ε(n+1) ≤ 2^(36.5 − 0.485n) for n ≥ 836; for n ≤ 3000 I verified it with exact arithmetic (`eq_prior.py`; worst case n = 1, with 2.9 bits to spare). For successor the closed form gives ε(n) ≤ (48/49)·3^(−n) for all n, hence 6^5·ε(n) ≤ 2^(12.9 − 1.585n).

**m2. Proposition 7(2), "SOI's stays below K(g) + c" needs g computable.** C_E(g) = ∞ for every non-computable g too. *Fix:* insert "for computable g".

**m3. Proposition 8(2): the citation does not give the statement.**
* The Herbrand–Gödel–Kleene theorem says: some system E derives, **by Kleene's rules R1 and R2**, exactly the true equations f(x̲) = y̲. The note needs a system that is **consistent under full equational logic**. These differ: E = {f(x) = 0, g(x) = 0, g(x) = S(0)} defines f ≡ 0 recursively in Kleene's sense and proves 0 = S(0) equationally.
* What is needed is a system true in a standard model with total auxiliary functions. It exists: recursion equations for primitive recursive t, u (Kleene's T-predicate and U), the conditional c, a search letter with σ(x,y) = c(t(x,y), y, σ(x,S(y))), and f(x) = u(σ(x,0)). Read σ(x,y) as the least witness y′ ≥ y if there is one and 0 otherwise; this is total and satisfies the equation.
* The statement should say **total** computable function. Kleene §54–55 is the formalism and the definition; the equivalence with machine computability is in his Chapter XIII (§§67–69).

**m7. Section 1, "Neither proof nor consistency is decidable": true, but no proof or reference.** A reduction (checked by me): take a finitely presented semigroup ⟨a₁…a_k | u_r = v_r⟩ with unsolvable word problem and non-empty relators, code a_i as the word c_i = f S^i f, and for words p, q let T_{p,q} consist of ĉ(u_r)(x) = ĉ(v_r)(x) for all r, S^(k+1)(ĉ(p)(f(0))) = 0 and S^(k+1)(ĉ(q)(f(0))) = S(0). If p = q in the semigroup, T_{p,q} proves 0 = S(0). If not, there is a model with distinct numerals (elements: ℕ, the semigroup with a unit, two kinds of chains, and a sink; a code word acts as left multiplication on the semigroup and sends everything else to the sink). So consistency is Π⁰₁-complete already for unary f. The literature on undecidable properties of finite sets of equations (Perkins 1967, McNulty 1976; references from memory, not checked) covers statements of this kind.

### 3.1 Reading the code

* **`eqlib.py`.** `forward_chain` is sound. It derives h(a̲) = v̲ only from an instance one of whose sides evaluates to v from values already derived and whose other side is h applied to terms that evaluate; that is substitution, replacement and transitivity. It never cancels S. It cannot overwrite a derived value with a different one, because an instance both of whose sides evaluate goes to the conflict test first.
* **`theories.py`.** Checks truth on a range and derivation on a box, as the note says. Truth for all arguments is by inspection of the schemata; I did that inspection for `quus_theory`, `patch_theory` (all a, b), `quus_aux_theory` and `doubling_patch_theory`. Stale header strings (m6).
* **`test_radius.py`.** Correct. Caveats: the search range (immaterial for linear targets: a refuting assignment of least need can be taken with values 0 and 1), and the overflow (m11).
* **`prior_tail.py`.** Correct. It does not contain the check "for n ≤ 3000" (m1).
* **`eq_unary.c`.**
  * *Translation.* The four kinds are translated correctly: u(x) = v(x) gives p·u·w ~ p·v·w; u(x) = v(y) gives p·u·w ~ p·v·w′; u(x) = v(0) gives p·u·w ~ p·v; u(0) = v(0) gives p·u ~ p·v; for all prefixes p. This is the ground congruence of the identities, because for unary symbols a context is a prefix and an instance is a suffix.
  * *Unions.* Every union is a valid consequence. Some go through an over-length term (m10).
  * *Multiplicities.* 4 or 2 strings for u(x) = v(x) and u(x) = v(y), 4 for u(x) = v(0), 2 or 1 for u(0) = v(0); the check against 9(s−1)2^(s−2) is right. The number of orderings of a multiset is built up correctly as (depth+1)/run.
  * *Profile.* Correct (the word f·S^x against the numerals of at most L letters).
  * *Pruning.* Sound: the bounded closure is monotone in the set, and every prefix of a sorted multiset is a sub-multiset. The counters count search nodes (M2).
* **`eq_unary_analyze.py`.** Correct.
* **`eq_unary_recheck.py`.** Does what it says; see m9 for what it leaves out.

### 4.4 Open question 2 has a positive answer: doubling is pinned only polylogarithmically

For unary f and n = 2^j let Q_j be

    f(0) = 0,
    f(fⁱ(S(f(z)))) = S(S(f((S∘f)ⁱ(f(z)))))     for i = 0, …, j−1,
    f(fʲ(S(0))) = 0.

* **Size:** 1.5j² + 8.5j + 7 symbols (30 for n = 4, 140 for n = 128, against 37 and 24,899 for the ground-identity sets the note mentions).
* **Reading.** Under doubling the argument fⁱ(S(f(z))) is p = 2ⁱ(2z+1), the term (S∘f)ⁱ(f(z)) is p − 1, and the identity says f(p) = 2 + f(p − 1). So every middle identity is true of doubling; only the last is false, and it is refuted only by data that reach 2^j.
* **It proves doubling below 2^j and a wrong value at 2^j.** By strong induction on p < 2^j: in the instance for p = 2ⁱ(2z+1), f is applied inside the left argument only at z and at 2^t(2z+1) for t < i, and on the right only at numbers at most p − 1. Then fʲ(S(0)) is the numeral of 2^j, and the last identity gives f(2^j) = 0.
* **It is consistent:** g(x) = 2·(x mod 2^j) is a standard model. (Both sides of the middle identity are 2·(2ⁱ(2r+1) mod 2^j) with r = z mod 2^j, because 2ⁱ(2r+1) is not divisible by 2^j for i < j.)
* **Checked by machine** for j ≤ 7 (`eq_doubling_patch.py`): sizes, the model for z < 8n, the derivations. `eq_unary … check` at L = 16 finds Q_2 consistent with profile 0, 2, 4, 6, 0, 2, 4, 6.

Consequences for the note:
* Open question 2 ("about n² symbols; is there one with far fewer?"): yes, about 1.5·log₂²n. Theorem 2's limit for doubling (sides of at least about log₂ n symbols) is reached up to a square, as in the other rows of the naming table.
* After doubling on [0, n), the belief in the wrong value 0 at 2^⌈log₂ n⌉ is at least 6^(−(1.5j² + 8.5j + 8)) / M_E(D): quasi-polynomially small, not exponentially small. From the other side, Theorem 2 with τ(m) = 2^(m−2) + 1 and the 10-symbol set for doubling gives a wrong belief of at most 6^11·ε(⌊log₂(n−1)⌋ + 2), about 2^(28 − 1.585·log₂ n). So the pinning of doubling at that input is between about 1.58·log₂ n − 28 and 3.9·log₂² n + 22·log₂ n + 20 bits: logarithmic up to a square, like SOI's and unlike that of addition. The strong pinning of Section 3 is specific to targets that cannot name large numbers with their own values. Section 7's "we do not know the truth" can be replaced by this.
* The naming principle extends: with a fast-growing target, f itself is the cheap name.

### 4.5 A remark on what the theorems leave open for addition itself

Nothing in the note bounds from below the belief in the **right** sum at a far input. Theorem 2 bounds wrong beliefs; the complement is split between "right" and "undetermined", and no statement controls the split. Short sides do not force determination: for n ≥ 4 the set U_n = {f(x, Sʲ(0)) = Sʲ(x), f(Sʲ(0), y) = Sʲ(y) for j ≤ n − 2; f(S(x), S(x)) = S(S(f(x,x)))} has all sides of at most n + 1 symbols, is true of plus, proves the whole square, and is also true of the function that is 0 where both arguments are at least n − 1 and differ; so it leaves f(n−1, n) undetermined (`eq_remarks.out`). It has 2(n−1)(n+2) + 10 symbols, so the undetermined share it contributes is negligible. Whether every fitting set of o(n) symbols determines all sums is open; a proof would make "confident" in Section 4 a theorem.
