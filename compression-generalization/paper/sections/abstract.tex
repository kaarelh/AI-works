If a trained network $f$ agrees on most inputs with a network $g$ that has a short description, then an Occam bound on $g$ plus the disagreement $\Pr[f\ne g]$ bounds the test error of $f$, with no validation data. We study when the disagreement term can be certified. When the input distribution is known, as for Boolean tasks with uniform inputs, it is free. A 289{,}281-parameter MLP then compresses into a 28--100-bit truth table, threshold function or small quantized network, and the bound tracks the test error of $f$ along the whole learning curve. This includes networks that have only partly learned a parity and networks that interpolate 10\% label noise, where parameter-counting and VC bounds are vacuous. On 20-bit inputs, once $f$ has learned the target, the compressed networks agree with it on all but at most a few of the $2^{20}$ inputs, which gives bounds valid for every input distribution. With only the training set, we prove a dithered transfer theorem. Compressing $f$ by subtractive dithered quantization with public randomness makes $g-f$ independent noise. A certificate computed from $g$ alone at each training point then transfers through the same Occam bound, giving a deterministic bound on $f$ itself. This removes the $\sqrt{d}$ loss of worst-case perturbation sets. On MNIST it is non-vacuous for narrow ReLU networks and for networks with sparse updates, and vacuous for wide dense ones, because it needs the weights described to the precision the margins require. The random initialization costs nothing, since codes may depend on data-independent randomness. We measure how coding relative to the initialization, the initialization scale and a deterministic initialization change the description length, and give an init-kernel codec whose cost reproduces the $n^k$ sample complexity of kernel methods.
