With $n=20$ the whole input space has $2^{20}\approx10^6$ points, so the disagreement between $f$ and $g$ can be computed exactly, and \cref{cor:anyD} turns compression into a bound that holds for \emph{every} input distribution. \Cref{tab:boolean_n20} uses the same architecture and training protocol as before, with widths $(20,512,512,1)$. Once a network has learned its target, its compressed description typically agrees with it on all $2^{20}$ inputs: the exception set $E$ is empty and the distribution-free bound costs only the extra flag bit and the bits for $|E|=0$ over the uniform-distribution bound. Where $f$ has not learned the target, $E$ is large, appending it is expensive, and the distribution-free bound is vacuous. That is correct here, since such an $f$ could be wrong on most of the support of some distribution.
