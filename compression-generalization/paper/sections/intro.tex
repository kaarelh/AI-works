\section{Introduction}\label{sec:intro}

A standard way to certify that a trained network generalizes is to hold out labelled data. Without held-out data, the classical tools (VC dimension, parameter counting, norm-based bounds) are vacuous for networks with more parameters than training examples. They bound every network in a huge class, not the one that was trained.

This paper studies a reduction that targets the trained network itself. Suppose that some network $g$ with a \emph{short description} (a code of $L$ bits fixed before seeing the data) agrees with the trained network $f$ on most inputs. Then
\[
\err(f)\ \le\ \err(g)+\Pr_x[f(x)\ne g(x)],
\]
and since $g$ ranges over at most $2^L$ descriptions, a Chernoff--Occam union bound over all of them bounds $\err(g)$ by its training error plus about $L\ln2/m$. Bounding generalization reduces to compressing the network, provided one can certify the closeness term $\Pr[f\ne g]$. That term concerns the input distribution, which is exactly what the training data does not reveal without depending on $f$.

We consider three regimes, in decreasing order of what is known about the input distribution, and ask three questions. Has this been done? Can a compression scheme give interesting bounds on real networks, beating parameter counting? Does the random initialization have to be described, which would make the description long?

\paragraph{Answers in brief.}
\begin{itemize}
\item \emph{Prior work.} Compression bounds for the compressed network $g$ are well developed \cite{arora2018stronger,zhou2019nonvacuous,lotfi2022pac}. The reduction to the original $f$ with the closeness term estimated on \emph{unlabeled} data goes back to \citet{kaariainen2005generalization} and was recently carried out for modern networks by \citet{bazinet2026bound}, with non-vacuous bounds on MNIST and CIFAR-10. With no extra data, the deterministic derandomization bounds of \citet{neyshabur2018pacbayes} and \citet{nagarajan2019deterministic} bound the original network but are vacuous. The exception we know of is \citet{biggs2022nonvacuous}, who obtain non-vacuous training-data-only bounds for one-hidden-layer networks with erf or GELU activations, via an exact identity between such a network and a stochastic majority vote.
\item \emph{Known input distribution} (\cref{sec:exp-bool,sec:exp-anyD}). On Boolean tasks with uniform inputs, $\Pr[f\ne g]$ is free. A 289{,}281-parameter MLP trained on $n=50$ bits compresses into a 28--100-bit truth table, linear threshold function or small quantized network. The resulting bound on $f$ tracks its test error along the whole learning curve: within $0.005$ at $m=16000$, $0.30$ against $0.29$ for a partially trained parity network, and $0.17$ against $0.14$ for a network that interpolates 10\% label noise. Parameter-counting and VC bounds are 1.0 throughout. For $n=20$ the compressed networks agree with $f$ on all $2^{20}$ inputs, giving bounds that hold for \emph{every} input distribution.
\item \emph{Training data only} (\cref{sec:transfer,sec:exp-t3}). We prove a \emph{dithered transfer theorem}. Compress $f$ by subtractive dithered quantization with public randomness, so that $g-f$ is independent uniform noise; compute from $g$ alone a per-input certificate that $f$ and $g$ classify alike; and transfer the fraction of certified training points to the population with the same Occam bound. The result is a deterministic bound on the original $f$ with no validation or unlabeled data. It is non-vacuous for narrow one-hidden-layer MNIST networks (0.44 for 8 hidden units) and for networks whose first-layer update is sparse in a DCT basis (\cref{tab:t3sparse}), and it becomes vacuous for wide dense networks. The certificate needs $f$'s weights described to the precision its margins require, and that costs bits in proportion to the width. Worst-case versions of the same idea fail by a factor $\sqrt d$ (\cref{thm:certified}).
\item \emph{Initialization} (\cref{sec:init-theory,sec:exp-init}). The initialization costs nothing: any data-independent randomness may be used by the code (\cref{lem:init}). Function-space codecs never refer to it, and weight-space codecs code the update relative to it. We measure how coding relative to the initialization or to zero, the initialization scale and a deterministic initialization affect the description length. We give an init-kernel codec (\cref{prop:kernel}) whose cost reproduces the $n^k$ sample complexity of kernel methods. In that picture, feature learning is what makes trained networks short to describe.
\end{itemize}

\paragraph{Scope.} Everything here is a theorem or a reproducible measurement on small networks: MLPs on 20--50-bit Boolean tasks, MNIST and Fashion-MNIST, on a 4-core CPU. Every bound is computed with explicit code lengths, confidence parameters and a charge for the design choices we made on the same data (\cref{sec:experiments}). The code, the result files and an AI referee record are in the repository.
