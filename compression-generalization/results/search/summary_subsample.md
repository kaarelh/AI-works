# Searching for a short surrogate g of a trained Boolean network f

n = 50, m = 16000 uniform training inputs, one network per row. Each search family's best candidate (chosen on a 30k selection pool) is certified on 2x10^5 fresh inputs; `bound` is Theorem 2 with the design charge of accounting.py, a 4-bit prefix naming one of up to 16 search families, and the disagreement term at delta_2/16 for the same 16 slots (so the best of the families certified on a network is also a valid bound). `A` is the D_X path norm sum_i ||a_i|| ||phi_i||, `A_upd` the same for the update relative to the initialization, `N_eff` = A^2 / sum_i s_i^2 the effective number of units, `|f| med` the median |logit|. Families: `codec` = influence codec; `scratch` = distill from scratch; `sub_refit` = subsample+refit; `sub_refit_init` = subsample+refit (init-rel.); `greedy_refit` = greedy+refit; `greedy_refit_init` = greedy+refit (init-rel.); `update_refit` = subsample update; `sub_distill` = subsample+distill; `greedy_distill` = greedy+distill; `mixed_scratch` = distill on fresh+training inputs; `mixed_greedy` = greedy, then distill on fresh+training inputs; `restarts_k4` = best of 32 restarts, 4 units; `restarts_k8` = best of 32 restarts, 8 units.
