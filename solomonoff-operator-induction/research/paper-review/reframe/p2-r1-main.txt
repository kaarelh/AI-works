       Steeper Simplicity Priors in Solomonoff Function Induction:
            Absorption, the Teacher’s Mistakes and the Model–Randomness Split

                                                Kaarel Hänni∗

                                                October 2026



                                                   Abstract
           Solomonoff function induction (SFI) predicts labels from inputs with a universal prior over
       random functions. We study the proposal to penalise program length more steeply than log-
       likelihood, by a factor λ > 1, for hypotheses with private randomness at each input, so that
       learning selects a simple model plus noise rather than a model of a teacher’s systematic errors.
       A standard objection is that a universal mixture, taken as one hypothesis, absorbs all structure.
       We prove that it does in every class containing its own mixture, such as Solomonoff induction
       and SFI with shared randomness, while no private-randomness hypothesis is universal. For a
       random parity on uniform inputs whose labels are flipped, at a rate below 0.056, on an error
       set of product form that is incompressible relative to the parity, we prove that for λ = cn
       (n samples) and c in an explicit window, every near-optimal hypothesis of the population
       objective knows the parity and, when the error rule is large, gives the erroneous labels far
       less probability than a memoriser does. The window needs λ proportional to n; density and
       description length of the error rule do not suffice. At λ = 1 a computable sampler and the
       programs that fill in its sampled bits get similar posterior weight; for fixed λ > 1, private
       randomness selects samplers over fill-ins, while with shared randomness a universal mixture
       beats every sufficiently long sampler. For a random parity on {0, 1}d whose labels are flipped
       on a random set of inputs of fixed density below 1/4, the sophistication defined with product
       models exceeds the set sophistication of algorithmic statistics by d − O(log d) bits, for a range
       of sufficiency slacks.

1    Introduction
Solomonoff function induction (SFI) is Bayesian prediction of a label y from an input x with
a universal prior over random partial functions (Hänni, 2026a). It is the supervised-learning
counterpart of Solomonoff induction (SI), and like SI it learns every computable regularity of the
labels, including a labeller’s systematic mistakes. A human learner, by contrast, can grasp what
a teacher means by a word without learning to predict what the teacher would say, mistakes
included. We study the following proposal for this purpose, a stronger simplicity prior: when the
mistakes are explainable deviations from a simple model, select the simple model with noise, by
penalising the length of a hypothesis more than its likelihood term.1 In the form studied here, a
hypothesis is a program π of length ℓ(π) with likelihood Pπ , and one minimises

                                Jλ (π; D) = λ ℓ(π) − log Pπ (D),          λ > 1,

or uses the power prior 2−λℓ(π) (Definition 3.5). We consider it for function induction with private
randomness at each input: a hypothesis is a probabilistic program that uses fresh coins at every
input.
    A standard objection, which we call the absorption objection, is that under a steeper penalty
a hypothesis that is itself a universal mixture is short, penalises complexity inside itself only in
the usual way, and therefore absorbs all the structure of the data, errors included. In sequence
prediction the objection holds (Section 4). In function induction one may hope that it fails if
each input samples its own random bits, so that a hypothesis pays its likelihood term separately
at every input. A three-hypothesis calculation supports this hope. Take a 100-bit simple model
and systematic errors on a 2−10 fraction of the inputs, whose set takes 10,000 bits to specify; of

2    Related work
This section describes the closest work informally; the objects are defined in Section 3, and the
basic theory of SFI is in the companion paper (Hänni, 2026a).

Steeper penalties and generalised posteriors. The proposal studied here weights the de-
scription length of a hypothesis by a factor λ > 1 against its log-likelihood, either in a two-part
code or through the prior 2−λℓ (Definition 3.5). The tempered posterior Π1/λ , which raises the
likelihood to the power 1/λ instead, is a generalised (Gibbs, fractional or safe) posterior with
learning rate 1/λ (Zhang, 2006; Bissiri et al., 2016; Bhattacharya et al., 2019; Grünwald, 2012;
Grünwald and van Ommen, 2017), and the λ-MAP, its maximiser, is a two-part code with com-
plexity weight λ. The power-prior posterior Πλ has the same maximiser but is Bayes’ rule with the
prior 2−λℓ ; it is proportional to (Π1/λ )λ . Our posterior results concern Πλ unless stated. Unlike
in these works, the target here deliberately differs from the data distribution (Remark 6.2).

λ-weighted two-part MDL in noisy classification. The closest prior work studies two-part
codes in noisy binary classification, where a hypothesis is a classifier together with a code for the
label noise, essentially a product hypothesis. Grünwald and Langford (2007) show that Bayes and
MDL classifiers can behave suboptimally under misspecification. Zhu and Srebro (2025) quantify
overfitting along the regularisation path of two-part-code MDL in supervised classification, and

4     The absorption objection, and why private randomness blocks
      it
Under a steeper penalty, a hypothesis that is itself a universal mixture, and so penalises complexity
only in the usual way inside itself, can absorb all the structure of the data. This is a standard
point, familiar from algorithmic statistics, where the model classes are restricted, for example to
finite sets (Gács et al., 2001; Vereshchagin and Shen, 2017). In sequence prediction it means that
it is better to drop bits of the hypothesis and pay for them in likelihood. In function induction
there is a natural way out: if the randomness is not shared between inputs, each input sampling
its own random bits, a hypothesis pays its likelihood term separately at every input, and the
pathology may be absent.2 We call the point the absorption objection. Theorem 4.2 makes it

4.3    Why private randomness, and what it costs
Remark 4.6 (Why private randomness is what matters). At λ = 1 the decomposition into hy-
potheses does not change the predictor (ξ× = Mprod is one shared hypothesis); at λ > 1 it does.
Over the class HF of all machine laws, MF would be a short member and absorption would return,
so steeper SFI is defined over H× , whose λ → 1 limit is Mprod , not MF . At λ = 1 this costs at
most K(dom D) + O(1) bits against MF , but not a constant: MF /Mprod is unbounded already
against the law νlen of F (x) = ω|x|+1 , one shared fair coin per input length, although on inputs of
length at most k the gap to νlen is at most K pad (k + 1) + O(1) bits, K pad (N ) := minL≥N K(L)
(Hänni, 2026a, Theorem 4.4, Proposition 4.7 and Remark 4.8). At λ > 1 the cost is a constant
factor on shared latent causes (Proposition 4.7).

4.4     Answer to the absorption objection
Remark 4.8 (Answer to the absorption objection). (i) The objection is correct wherever a uni-
    versal hypothesis is one member of the class: in SI, in SFI with shared randomness, in the
    weak class and in history-aware SFI. There every λ-MAP has length at most ℓ∗λ and fits al-
    most as well as U ; for fixed λ it reproduces a deterministic teacher’s errors (Theorem 4.2(c)),
    and samplers longer than ℓ∗λ = ℓU + (ℓU + κ0 )/(λ − 1) are never selected (Theorem 7.6);
    with λ = cn this threshold tends to ℓU .
 (ii) The construction is unavailable in the product class H× . No product hypothesis is universal
      (Corollary 4.5); the universal conditional semimeasure never learns (Remark B.1); seeing
      earlier inputs does not help while the randomness stays private (Proposition B.3).
 (iii) The restriction has a price and a boundary. The product class cannot represent latent
       randomness shared across inputs, which costs up to K(dom D) + O(1) bits against MF at
       λ = 1, unboundedly in the worst case (Remark 4.6), and a factor min(λ, 2) on shared coins
       at λ > 1 (Proposition 4.7); and the protection ends where hypotheses see labelled history
       (Proposition B.2). So restricting to private randomness is not free at λ = 1 when compared
       with MF .
 (iv) The algorithmic-statistics reading. For set models, which share their randomness, the d-bit
      parameter of a noisy random parity is noise; for product models it is model (Proposition 8.3
      and Remark 8.4).
    The restriction is a modelling choice. Two reasons support it: the product hypotheses are
exactly the computably samplable predictors that use different random bits on different inputs,
the natural class to compare SFI with, and SFI dominates them (Hänni, 2026a, Theorem 5.1(a));
and in supervised learning the model is naturally the part of the description that is reused across
inputs.

Question 4.9 (shared hypotheses). Is every lower-semicomputable law of a random partial func-
tion dominated by MF up to a constant factor? This open question of the companion paper
(Hänni, 2026a, Question 3.14) decides which laws with shared randomness the class HF covers;
Theorem 4.2 holds for Hw and for HF either way.

5.1     The three-hypothesis calculation
Remark 5.1 (The three-hypothesis calculation). The example has two versions.
  (1) Version 1 (total bits): a simple model of 100 bits that predicts 100 bits of labels per bit of
      description, and on top of it a systematic error model of 100 bits that predicts 10 bits per
      bit. Coin, simple model, and simple model plus errors lie on a hull with slopes 100 and 10,
      so the simple model alone is selected exactly for λ ∈ (10, 100).
  (2) Version 2 (per sample): a 100-bit simple model with systematic human error on a 2−10
      fraction of the inputs, whose set takes 10,000 bits to specify. Of the good model (the simple
      model with flip probability p = 2−10 , 10 more bits), the model that learns the errors (10,100
      bits, loss 0) and the fair coin, the good model is selected if and only if c lies between the rate
      H(p)/9990 = 1.1185 · 10−6 of the errors and the rate (1 − H(p))/110 = 8.989 · 10−3 of the
      model, a ratio of about 8000; plain MDL (λ = 1) switches to the memoriser at n ≈ 8.94·105 .
A direct computation (code in the accompanying repository) gives these numbers, with the exact
H(2−10 ) = 0.0112 rather than p log(1/p) ≈ 1/100. The calculation compares three hypotheses
only; it does not exclude partial models, partial memorisers, mixtures or some universal hypoth-
esis, so it leaves open whether another hypothesis does better.

near-optimal hypotheses reproduce the errors. For such rules this settles the question left open
by the three-hypothesis calculation of Remark 5.1.

6.3   Other pathologies
Proposition 6.6 (Separable components). Let the inputs split into regions X1 , . . . , Xk and the
hypotheses be products of per-region choices with additive code lengths. Each region selects a vertex
of its own hull for slope c (Lemma A.1). If region j offers a default or a component j of extra
length kj and population risk reduction rj , component j is selected if and only if rj /kj > c (ties
arbitrary). So a valid component whose rate is at most an error component’s rate cannot be kept
without the error, except at a common tie value. Two worlds with the same teacher channel and
input law, one where a component is an error and one where it is a rare valid rule, get the same
selection at every c.

    The steeper penalty sorts components by rate, risk reduction per bit, not by validity. Three
consequences follow (proofs in Appendix D.3). A guard that restricts a rule to its proper contexts
is dropped when its rate is below the rule’s: on an interval of c the unguarded rule is the unique
selection and applies the rule where the teacher never did (Proposition D.1; in a numerical instance
the interval spans a factor of 67 in c). The selection depends on the input law (Proposition D.3);
Theorem 5.7’s window depends on it by the same mechanism, which is proved here only in the
separable case. And λ cannot be chosen from imitation data: every strictly proper scoring rule
prefers the teacher’s channel, errors included (Gneiting and Raftery, 2007); log-loss validation
along the selection path picks the smallest, error-memorising, value of c; and in the twin worlds
of Proposition 6.6 every rule that chooses c from imitation data alone is wrong in one of them
(Proposition D.2).

and by programs that fill in the sampled bits. At λ = 1, Solomonoff induction has no preference

8       Relation to algorithmic statistics
Besides a steeper penalty, one can look for the split between model and noise by plotting the
entropy left given the hypothesis against the hypothesis length and looking for a change of slope.
With shared randomness, as in the sequence case, one expects none, because each bit of hypothesis
pays for about one bit of data (Remark 8.5).4 For set models this graph is Kolmogorov’s structure
function. We define a product version and show, for a noisy random parity, that the two place
the split about d bits apart. Proofs are in Appendix F.

8.1     Set models and steeper two-part codes
Definition 8.1 (Set models). For a string z, a set model is a finite set A ∋ z, with two-part
length K(A) + log |A|. The structure function is hz (α) := min{log |A| : A ∋ z, K(A) ≤ α}. The
sufficiency line is the bound K(A) + log |A| ≥ K(z) − κ, valid for every A ∋ z since K(z | A) ≤
log |A| + κ. A is b-sufficient if K(A) + log |A| ≤ K(z) + b; a minimal sufficient statistic minimises
K(A) among b-sufficient models; and the set sophistication is sophset   b (z) := min{K(A) : A ∋
z, K(A) + log |A| ≤ K(z) + b}. Conditional versions given a string w (for example a domain)
replace K by K(· | w).

    These notions are standard (Gács et al., 2001; Vereshchagin and Vitányi, 2004; Vereshchagin
and Shen, 2017); we use them as stated. Sophistication goes back to Koppel (1987); Koppel and
Atlan (1991), with total programs as models; see also Vitányi (2006) and Antunes and Fortnow
(2009). We do not use the equivalences between the versions.
    Steeper two-part codes over sets select an approximately minimal sufficient statistic only in a
limited sense: a minimiser Aλ of λK(A) + log |A| has K(Aλ ) ≤ sophsetb (z) + (b + κ)/(λ − 1) and is
(b+(λ−1) sophsetb (z))-sufficient, and as λ → 1 the length bound becomes vacuous (Proposition F.1
and Remark F.2 in Appendix F.1).

Remark 8.5 (Reading: one bit for one bit). With shared randomness (a set model, or any shared
model) a uniformly random d-bit parameter costs the same in the model as in the data-to-model
code, one bit for one bit. So the minimal sufficient statistic treats the parity’s parameter as
noise. With private randomness, not knowing the parameter costs about one bit per input, so
the product split keeps it in the model, and the slope of ρ× D changes at α ≈ d. For supervised
learning the product split is the relevant one, because the model is the part of the description
reused across inputs. This is also why steeper simplicity is useless over set models in the parity
example (Proposition 8.3(i)) and decisive over product models (Theorem 5.7 and Corollary 5.10).

Proposition 9.1 (Computable product classes). Let H′ be a hypothesis class of product hypotheses
(Definition 3.4). (a) Lemmas 5.3 to 5.6 and the lower-bound parts of Theorem 5.7 ((o), the bound

Remark 9.2 (Examples). Examples are probabilistic programs clocked at t(|x|) steps, as in time-
bounded SFI (Hänni, 2026a, Section 9.1), where generous time bounds change κg , κb by logarith-
mic terms, and circuits with private output noise, where a parity costs about d log d bits, so κg
is of order d log d and chi shrinks by a factor of order log d. Theorem 4.2 does not transfer, since
a mixture of all time-t programs is not a time-t program; so the contrast between product and
shared classes is established only for unbounded classes.
Proposition 9.3 (Computability of the steeper predictor). Let λ ≥ 1 be computable, the class
H× or HF , X infinite and {0, 1} ⊆ Y . (a) ξλ (D) is lower semicomputable uniformly in D. (b)
Neither the raw conditional ξλ (D + (x, y))/ξλ (D) nor its normalised version is computable. (c)
Both are limit-computable.
    Part (b) is the diagonal argument for MF (Hänni, 2026a, Proposition A.10(c)): a computable
conditional yields a computable labelling on which the predictor loses a constant per input, against
the weight 2−λ(K(f )+κ) of a program for it.
Remark 9.4 (Neural-network Bayes). With labels independent given the parameters θ, a network’s

power prior p(θ)λ , λ > 1, deterministic parameter settings that reproduce the noisy labels get
posterior mass exponentially small in the sampled randomness, if the noise model is in the family.
Whether a parameter prior behaves like a description-length prior, as Theorem 5.7 needs, is the
bridge question of the companion paper (Hänni, 2026a, Question 10.9 and Remark H.2), which
the slides of Vaintrob and Hänni (2026) motivate; nothing here settles it.
Question 9.5 (resource bounds and computability). (a) Does some time-bounded shared class
contain a short member that absorbs everything at λ > 1, as in Theorem 4.2? If not, steeper
simplicity could also work in time-bounded Solomonoff induction. (b) For computable λ ≥ 1 and
the class H× , is there a computable map from data sets to λ-MAPs?

10     Discussion
What counts as one hypothesis. Whether a steeper simplicity prior can separate a model
from its noise depends on what counts as one hypothesis. When a universal mixture is a member
of the class, as in SI and in SFI with shared randomness, it cannot for any model longer than ℓ∗λ ,
a bound that does not depend on the data, and for fixed λ a computable teacher’s labels, errors
included, are eventually predicted (Theorem 4.2). With private randomness at each input no
member is universal, and steeper selection can work; as in algorithmic statistics (Proposition 8.3),
the product view counts as model what is reused across inputs and as noise what is private
to each input. This is a modelling choice with a price on shared latent causes (Remark 4.6
and Proposition 4.7), and the protection ends when inputs carry labelled history (Proposition B.2).

The window and its price. For error rules incompressible relative to the model, near-optimal
product hypotheses are, up to explicit slack, the simple model with noise for 2−m < c < chi
(Theorem 5.7). The lower end is sharp because a bit of information about the error rule costs c
per sample in length and saves about 2−m per sample in risk. So λ must grow linearly with n, and
the learner is then deliberately inconsistent for the teacher’s labels: it discards every component
whose rate is below c, valid or not, and its guaranteed code length exceeds a program’s own loss
by c ℓ(π) bits per sample (Remark 6.2). Imitation data cannot justify this price, because strictly
proper scores prefer the teacher’s channel, errors included (Proposition D.2).

The gap to realistic errors. Human labelling errors are often cheap, frequent patterns rather
than incompressible sets. In the parity instance steeper selection provably fails for such errors in
two ways: a fixed cheap rule defeats every c once the simple model is long enough (Proposition 6.4
and Lemma 6.5), and a rule made of a cheap region plus random points, with the original density
and description length, makes the good model non-optimal on about a third of the window
(Proposition 6.3). Whether any window survives for structured errors in general is open. Steeper
simplicity sorts components by rate, not by validity (Proposition 6.6), so by itself it does not tell
errors from rare valid rules. We do not expect steeper penalisation alone to solve the general
problem of learning a norm from imperfect imitation; it works in one toy case and fails in others.

The model–randomness split. At λ = 1 a Bayes mixture is indifferent, up to factors that
grow at most triply logarithmically in the amount of data, between a sampler and the programs
that fill in its sampled bits (Theorem 7.3). For fixed λ > 1 a steeper prior over product hypotheses
breaks the tie in favour of samplers, in the limited sense of Remark 7.5; in SI’s representation by
deterministic programs no form of steepness does (Remark E.5).

Relation to other work. The λ-MAP is a two-part code with complexity weight λ, as in
λ-weighted MDL in noisy classification, and maximises the tempered posterior, a generalised
posterior with learning rate 1/λ; the power-prior posterior has the same maximiser but is Bayes’
rule with the prior 2−λℓ . Those works aim at the data distribution; our target differs from it
by design (Section 2). A neural network whose labels are independent given its parameters has
a Bayes posterior that mixes product laws, so Theorem 7.4 applies to countable discretisations;
whether a parameter prior behaves like a description-length prior, as Theorem 5.7 would need,
is the bridge question of the companion paper (Hänni, 2026a, Question 10.9), which the slides of
Vaintrob and Hänni (2026) motivate (Remark 9.4).

10.1    Open problems
 (1) Structured error rules. For envelopes whose cheap region has error density below one, only
     part (i) of Proposition 6.3 carries over; whether near-optimal hypotheses memorise the
     random part, and what is selected above cenv , are open (Question 6.8).
 (2) Other model classes and flip rates. Which simple-model classes give a window? Parities do;
     we expect that majority-like functions do not give a window. Is there a window for flip rates
     up to 1/4, where the kink exists (Questions 5.12 and 6.8)?
 (3) Non-uniform inputs and finite samples. A version of Theorem 5.7 for non-uniform input laws
     (only the separable case is proved, Proposition D.3); near-population constants at realistic
     sample sizes: they need about 1011 samples, and coarser guarantees hold from about 109
     (Corollary 5.11 and Question 5.12).
 (4) Choosing c. A principled choice of c that does not use the imitation data, and the extra
     information that would tell errors from rare valid rules (Question 6.8).
 (5) Shared hypotheses. Is every lower-semicomputable law of a random partial function domi-
     nated by MF up to a constant (Question 4.9)?
 (6) Resource bounds and computability. Does a time-bounded shared class contain a short
     member that absorbs everything at λ > 1? Is there a computable map from data sets to
     λ-MAPs (Question 9.5)?
 (7) Lower-semicomputable product models. Does Proposition F.4 hold for them (Question F.5)?

A     Proofs for Section 3 (setting)
A.1    Standard facts
The following facts are standard (Li and Vitányi, 2008); κ is as in Section 3.2.
(F1) K(π) ≤ ℓ(π) + κ for every program π of a class H. The identity map on the c.e. prefix-free
     set H is a prefix machine, which the universal machine simulates with a fixed prefix; for
     canonical classes, H = dom V and the fact is immediate.
(F2) Conditional coding theorem. If a fixed program lower-semicomputes from z a semimeasure
     Qz on a countable set, then K(w | z) ≤ − log Qz (w) + κ.
(F3) K(x) ≤ K(y) + K(x | y) + κ, and K(x, y | z) ≤ K(x | z) + K(y | x, z) + κ.
(F4) Symmetry of information. K(x, y) = K(x) + K(y | x, K(x)) + O(1).
(F5) K(j) ≤ 2 log(j + 1) + κ for every integer j ≥ 0, by a doubling code.

A.2    The hull lemma
Lemma A.1 (Hull lemma). Let A := {(ℓ(π), R(π))} with R ∈ [0, ∞] and finitely many points
below each ℓ-level, let C := conv(A ∩ {R < ∞}) + R2≥0 , and call the extreme points of C its
vertices.
  (i) For c > 0, every minimiser of c ℓ + R lies on the boundary of C, on a supporting line with
      normal (c, 1).
 (ii) If c < c′ and h, h′ minimise Jc , Jc′ , then ℓ(h) ≥ ℓ(h′ ) and R(h) ≤ R(h′ ).
(iii) A point of A is the unique minimising point of c ℓ + R for every c in some nonempty open
      interval if and only if it is a vertex of C; the least-ℓ vertex and the least-R vertex, if it exists,
      count. A hypothesis is then the unique minimiser if and only if no other hypothesis has the
      same point.



                                                   31
 (iv) (Absolute length bound.) Every minimiser hc of c ℓ + R (c > 0) solves min{R(h) : ℓ(h) ≤
      ℓ(hc )}. Conversely, a solution of min{R(h) : ℓ(h) ≤ L} minimises c ℓ + R for some c > 0
      if and only if its point lies on the boundary of C and not on the open horizontal ray to the
      right of the least-R vertex.
Remark A.2 (The converse in (iv)). The converse in (iv) cannot be weakened to “on the bound-
ary of C”: in A = {(0, 1), (10, 0), (20, 0)} the point (20, 0) lies on the boundary and solves the
constrained problem for L ≥ 20, but (10, 0) is strictly better for every c > 0.
    Examples. In {(0, 1), (10, 0.5), (20, 0)} the middle point lies on the segment between the other
two, so it is never the unique minimiser; the end points are the unique minimisers on (0.05, ∞)
and on (0, 0.05). In {(0, 1), (5, 0.9), (10, 0)} the point (5, 0.9) lies above the boundary of C; it
solves the constrained problem for L ∈ [5, 10) and minimises no penalised objective.
    We prove Lemma A.1. Write A′ := A ∩ {R < ∞} and ⟨(c, 1), (ℓ, R)⟩ = c ℓ + R.
    (i). Since (c, 1) ≥ 0, the infimum of c ℓ + R over C = conv(A′ ) + R2≥0 equals its infimum over
A′ . A minimiser a over A therefore minimises a nonzero linear functional over C. So the line
{c ℓ + R = c ℓ(a) + R(a)} supports C at a, and a lies on the boundary of C.
    Structure of the boundary. Fix a ∈ A′ and s > 0. A point b ∈ A′ with ℓ(b) > ℓ(a) and
R(b) ≤ R(a) − s(ℓ(b) − ℓ(a)) has ℓ(b) ≤ ℓ(a) + R(a)/s, because R(b) ≥ 0; only finitely many points
satisfy this. So from each point the steepest descending direction to the right is attained, and
the lower-left boundary of C is a polygonal line. It consists of a vertical ray above the least-ℓ
vertex, segments between consecutive vertices with slopes −s, s ∈ (0, ∞), strictly increasing from
left to right, and, if a point of least R exists, a horizontal ray to the right of the least-R vertex.
Its corners are extreme points of C, and every extreme point of C lies in A′ , because the extreme
points of a convex hull belong to the generating set and adding the orthant creates none.
    (iii). Let a be a vertex. Its two incident boundary pieces have slopes −s− < −s+ ≤ 0, with
s− = ∞ at the least-ℓ vertex and s+ = 0 at the least-R vertex. For c ∈ (s+ , s− ) the line with
normal (c, 1) through a meets C only at a, so a is the unique minimising point. Conversely, if
a is the unique minimising point for every c in an open interval, then a is an exposed point of
C, hence an extreme point, hence a vertex. A boundary point that is not a vertex lies in the
relative interior of a segment between two vertices, or on one of the two rays. In the first case,
whenever it minimises c ℓ + R, so do both endpoints of its segment. A point on the vertical ray
is beaten by the vertex below it (smaller R), and a point on the horizontal ray by the least-R
vertex (smaller ℓ, same R). So no such point is ever the unique minimising point. The statement
about hypotheses is immediate: a hypothesis is the unique minimiser exactly when its point is
the unique minimising point and no other hypothesis has that point.
    (ii). Add c ℓ(h)+R(h) ≤ c ℓ(h′ )+R(h′ ) and c′ ℓ(h′ )+R(h′ ) ≤ c′ ℓ(h)+R(h) to get (c′ −c)(ℓ(h′ )−
ℓ(h)) ≤ 0, so ℓ(h′ ) ≤ ℓ(h). Then the first inequality gives R(h) ≤ R(h′ ) + c(ℓ(h′ ) − ℓ(h)) ≤ R(h′ ).
    (iv). If ℓ(h) ≤ ℓ(hc ), then R(h) ≥ R(hc ) + c(ℓ(hc ) − ℓ(h)) ≥ R(hc ), so hc solves the constrained
problem with L = ℓ(hc ). For the converse, by the description of the boundary: a vertex minimises
c ℓ + R for every c in its interval (s+ , s− ), which contains positive values; a point on a segment
between two vertices, of slope −s with s > 0, lies on the supporting line with normal (s, 1) and so
minimises s ℓ + R. A point on the open horizontal ray is beaten, for every c > 0, by the least-R
vertex. A point on the vertical ray above the least-ℓ vertex is never a constrained solution, since
that vertex is feasible whenever the point is and has smaller R. A point not on the boundary
minimises no linear functional with normal (c, 1) over A, by (i).
    Remark A.2. In A = {(0, 1), (10, 0), (20, 0)} the point (20, 0) lies on the open horizontal ray
to the right of the least-R vertex (10, 0). It solves min{R : ℓ ≤ L} for L ≥ 20, since it ties with
(10, 0) there, but 20c > 10c for every c > 0.

Proof of Proposition 6.6. The objective c ℓ + R is a sum over regions of (extra length times c)

Proposition D.1 (Guard erosion). In a region of contexts a schema σ is one of nst possible steps,
and a guard G splits the region into G-contexts (input mass µ(G)), where the teacher plays σ with
probability 1 − ϵG + ϵG /nst and every other step with probability ϵG /nst , and ¬G-contexts (mass
µ(¬G)), where it plays one fixed step other than σ. Over a common base, “none” is uniform
(length 0), “unguarded σ” predicts the G-context law everywhere (length kσ ), and “guarded σ”
does so in G-contexts and is uniform over the other nst − 1 steps elsewhere (length kσ + kG ). With
