# An explicit sufficient width for mean-field Bayesian circuit learning

**Status:** Earlier complete result; width requirement superseded by meanfield-all-width

Quantifies a double-exponential-in-d sufficient width while retaining polynomial sample complexity. Its open all-width target is subsequently resolved by the main meanfield-all-width paper.

[Paper (PDF)](paper.pdf) · [LaTeX source](source/meanfield-quantified-width.tex) · [Collection index](../../README.md)

## Build

Run `bash build.sh` in this directory with a standard TeX Live installation. The script runs two LaTeX passes, stores temporary output in `build/`, and refreshes `paper.pdf`. No network access is required.

The PDF is the existing manuscript copied into this collection; its mathematical text has not been rewritten for publication here. Later results and current scope are summarized in the collection index.
