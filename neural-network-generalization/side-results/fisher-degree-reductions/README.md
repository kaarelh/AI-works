# Degree and square-root energy on the Boolean cube: equivalent positive estimates and a signed obstruction

**Status:** Proved side result

Proves equivalence of weak positive Fisher-energy control, a linear degree bound, and relative-L1 sum-of-squares approximation; disproves the analogous unrestricted signed statement. The positive inequality itself and the natural-scale posterior bound remain open; the signed examples have no bounded-source-cost guarantee.

## Build

Run `bash build.sh` in this directory with a standard TeX Live installation. The script runs two LaTeX passes, stores temporary output in `build/`, and refreshes `paper.pdf`. No network access is required.
