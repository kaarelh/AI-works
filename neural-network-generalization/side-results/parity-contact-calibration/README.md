# Parity, polynomial degree, and contact-weighted error costs

**Status:** Proved side result

Proves a quantitative parity degree obstruction under an explicit contact-weighted amplitude-cost hypothesis, including exponent 0.719367 at beta=1/2, stability, transport, and analytic refinements. Establishing the contact-cost hypothesis for a learner is a separate step.

[Paper (PDF)](paper.pdf) · [LaTeX source](source/parity-contact-calibration.tex) · [Collection index](../../README.md)

## Build

Run `bash build.sh` in this directory with a standard TeX Live installation. The script runs two LaTeX passes, stores temporary output in `build/`, and refreshes `paper.pdf`. No network access is required.

The PDF is the existing manuscript copied into this collection; its mathematical text has not been rewritten for publication here. Later results and current scope are summarized in the collection index.
