# Homogeneous parity approximants have a strict local repair cost

**Status:** Proved side result

Complete strict repair-cost theorem for low-degree homogeneous Walsh heads with arbitrary amplitudes in a fixed-background cusp-cell model. This newest seven-page version also includes weighted homogeneous, affine, and two-level extensions. It is not a general adaptive-posterior sample theorem.

[Paper (PDF)](paper.pdf) · [LaTeX source](source/homogeneous-cell-calibration.tex) · [Collection index](../../README.md)

## Build

Run `bash build.sh` in this directory with a standard TeX Live installation. The script runs two LaTeX passes, stores temporary output in `build/`, and refreshes `paper.pdf`. No network access is required.

The PDF is the existing manuscript copied into this collection; its mathematical text has not been rewritten for publication here. Later results and current scope are summarized in the collection index.
