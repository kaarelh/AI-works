# Exponential sample lower bounds for sparse parity under a globally separated neural prior

**Status:** Proved side result

For 0 < gamma < 1, proves confidence failure at every specified n <= exp(c max{k,sqrt(k) log(e(d+1)/sqrt(k))}) for growing sparse parity. Gives an exp(Omega(k)) obstruction and a matching-scale upper-bound comparison, but not the full natural sparse lower bound.
