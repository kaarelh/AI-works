For an exact approximate state hq and quantized weight Wq,
    h W-hq Wq=(h-hq)W+hq(W-Wq).
Thus the inherited exact spectral bound for W and the exact Frobenius
residual give the stated L2 recurrence, since ||hq||<=sqrt(N).
For the first layer, input quantization is not assumed exact: the script
explicitly computes the integer residual product (x-xq)Wq, and bounds
x(W-Wq) by column L1 norms using |x_i|<=1. All original float32 inputs
are interpreted as exact dyadic real numbers. The bias coordinate is
included and is exactly one. The final readout uses the analogous
operator/state term plus an exact L1 coefficient-residual term.

Every tanh table proposal is checked against an outward interval value.
Linear interpolation has error <=grid_step^2/8 because |tanh''|<=1.
Endpoint errors combine convexly; nearest fixed-point interpolation
adds at most 1/(2 QH). Beyond |x|>=12, replacing tanh by its sign has
error at most 2 exp(-24). The implementation evaluates interpolation
as left+(right-left)*fraction, with a direct overflow guard.

The exact matrix-product guard bounds every absolute partial sum by
max_abs_input times the maximum column L1 norm. It therefore excludes
overflow in products and arbitrary accumulation orders, not merely in
the final sum. The table shift and interpolation intermediate products
have separate guards. Integer outputs are converted to Fractions
without a floating approximation.

The global raw-noise recursion q_1=1, q_s=1+||W_s||op^2 q_{s-1} gives
the simultaneous hidden/output bound r sqrt(1+Ev q_H). The clipped
comparison is conservative for the full clean-output interval, so
every passing row establishes its pointwise support condition.

All inherited operator bounds are tied to the saved model hash. The
source and input archive hashes are recorded. The scope is the exact
declared held-out input set, not a population statement or full image
domain. This uses trusted integer/rational and outward-interval
implementations and is not a Lean formalization.

PASS: exact_heldout_105_local.py, mathematical method and source code.
The exact clean forward and reverse-adjoint recurrences use outward
dyadic interval arithmetic. At each internal layer, the prior prefix
gain q bounds every preactivation displacement by the column norm
times r sqrt(N q). The derivative caps are valid on this full tube;
||W diag(cap)|| bounds every coordinatewise secant matrix. Thus the
updated q=1+ell q is a finite-radius bound for simultaneous noise.

The separate clean-Jacobian expansion is exact: output displacement
equals its linear response to every injection plus the sum of each
layer's nonlinear Taylor remainder against its clean suffix adjoint.
The script encloses the scalar remainders at both tube endpoints and
all possible stationary points, propagates adjoints with intervals,
and bounds each signed product. The linear gain uses the joint
hidden/output Euclidean noise norm. Intersecting this enclosure with
the independent reachable-tube output bound is valid. There is no
first-layer Taylor remainder because its injection occurs after the
activation at a fixed input.
