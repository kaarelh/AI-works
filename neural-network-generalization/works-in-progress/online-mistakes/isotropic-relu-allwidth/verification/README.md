The theorem concerns every fixed learner width `N≥N₀=2^(m+d+1)`, followed by the limit of the prior scale to zero. The input order is fixed before width and scale. The count is `exp(Ω(√C))` in the displayed bounded-weight shallow teacher width, and `exp(Ω(d))` in input dimension. The calibration history can be exponentially large. This is an arbitrary-order cumulative-mistake lower bound, not an IID sample-complexity lower bound or a claim for every width above teacher complexity.
