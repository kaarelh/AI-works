# GD numerics: results tables

Generated by `make_tables.py` from the files in this folder. Do not edit by hand.

**Status: numerical.** Single runs, mostly one seed each, at $`19\le d\le 50`$. These dimensions cannot distinguish polynomial from exponential growth in $`d`$.

## Targets

- `mix`: staircase-or-parity target: sign(x_1 + x_1x_2 + ... + x_1...x_d) if z=+1, x_1...x_d if z=-1.
- `ctrl`: control: x_1 if z=+1, x_1...x_d if z=-1.
- `mixw`: weighted variant: sign(x_1 + ... + x_1...x_{d-1} + 5 x_1...x_d) if z=+1, x_1...x_d if z=-1 (d=31).
- `par`: full parity x_1...x_d.
- `stair`: sign-staircase sign(x_1 + x_1x_2 + ... + x_1...x_d).

The input is $`(x,z)`$ with $`x\in\lbrace -1,1\rbrace ^d`$ and one selector bit $`z`$ for the two-half targets, so $`D=d+1`$ input bits; $`D=d`$ for `par` and `stair`. Inputs are uniform.

## Architectures and initializations

- **two-head trunk** depth×width: a ReLU MLP on $`x`$ only, with output $`a\cdot h(x)+z\,b\cdot h(x)`$; $`z`$ only selects the readout. For `par` and `stair`, which have no $`z`$, the same trunk has the single readout $`a\cdot h(x)`$ (**one-head trunk**).
- **MLP** depth×width: a plain ReLU MLP on all $`D`$ input bits, so $`z`$ is an ordinary input.
- All layers are `torch.nn.Linear`, with biases. Initializations:
  - `gaussian`: every weight N(0, 1/fan_in), every bias 0.
  - `gaussianU`: weights N(0, 1/fan_in), biases PyTorch default U(-1/sqrt(fan_in), 1/sqrt(fan_in)).
  - `gaussian3`: weights N(0, 1/(3 fan_in)) (the variance of PyTorch's default), biases 0.
  - `gaussian3U`: weights N(0, 1/(3 fan_in)), biases PyTorch default.
  - `default0`: PyTorch default weights U(-1/sqrt(fan_in), 1/sqrt(fan_in)), biases 0.
  - `default`: PyTorch default (weights and biases U(-1/sqrt(fan_in), 1/sqrt(fan_in))).
  - `rademacher`: first-layer weights +-1/sqrt(fan_in), other layers PyTorch default.

## Gaussian-initialization runs (`gd_train2.py`)

Common settings: square loss on $`\pm1`$ labels, batch 512, fresh uniform samples at every step (online training, so samples = steps × 512). The test set has 20000 points drawn once from a separate seeded generator (10000 in each $`z`$-half for two-half targets). Any training point that coincides with a test point is resampled, so the test points are never trained on. Errors are sign errors on the test set. Evaluation every 100 steps up to step 2000 and every 500 steps after. "Samples to 0.05" is the first evaluation at which that error is less than 0.05 (errors are computed in single precision, so an error of exactly 0.05 does not count). A run stops early ("early") once every tracked error (both halves, or the single error) has been less than 0.05 at 3 consecutive evaluations; otherwise it runs to its budget ("cap"). "Final" is the last evaluation. Optimizer: Adam, learning rate 1e-3, unless stated.
