# First-round exploratory code and selected summaries

These are the computational experiments from the first research round. They include trial models and approaches that were not retained as theorem claims. The papers and their stated assumptions determine the mathematical claims.

The Python programs use this directory as their workspace and write to `results`. C++ programs should be compiled into `tools` with a C++17 compiler. Some campaign and analysis programs require regenerating large trajectories; those trajectories are not bundled. Selected summaries and the independent critical-covariance integration records are included. Monte Carlo error bars and agreement between chains do not certify mixing or prove the posterior limits.

The exact checkers and their complete inputs are supplied separately at the collection root. Use that verification inventory for certificate checks. Here, the observed-margin generation scripts resolve the existing repository through the published folder structure or the `NNBAYES_REPO` environment variable where supported.

`source-provenance.json` records source and published hashes. The only source portability edits replace the original machine's repository path. No archived manuscript or human author roster is changed.
