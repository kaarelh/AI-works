\section{Function semimeasures, function machines and SFI}\label{sec:setting}

H\"anni's definition of Solomonoff function induction (SFI) reads, in full: ``you have a bunch of input-output pairs. you have the usual prior on all programs. solomonoff function induction := you think of the input-output pairs as being generated by picking a random program from this prior and generating using it, and so you update on seen pairs as you should'' \citep{hanni2026notes}. This section makes the definition precise. A ``random program'' can be a deterministic program drawn at random, or a program that also reads random bits; the random bits can be private to each input or shared by all inputs. We take the most general reading that still yields a random function: one random tape, read by all inputs (\cref{def:setting:machine}). \Cref{sec:versions} compares the other readings. The notion is H\"anni's, and so are several of the claims checked below (dominance over samplers that see only the input, invariance under encodings, the equivalence question of \cref{sec:versions}); the definitions and proofs follow the foundations track of this project.

\subsection{Data and conventions}\label{sec:setting:data}

\begin{definition}[Data]\src{foundations \S1}\label{def:setting:data}
Inputs come from a set $X$ and labels from a set $Y$; by default $X=Y=\{0,1\}^*$, and all results hold for any infinite decidable $X$ and countable $Y$ with $|Y|\ge2$ unless stated. $\bot$ means ``undefined'' and $\Ybot:=Y\cup\{\bot\}$. A \emph{data set} is a finite partial function $D:X\rightharpoonup Y$, written as a finite set of pairs with distinct first coordinates; $\dom D$ is its domain, $D+(x,y):=D\cup\{(x,y)\}$ for $x\notin\dom D$, and $D|_T$ is the restriction to $T\subseteq\dom D$. A partial function $f$ \emph{extends} $D$, $f\supseteq D$, if $f(x)=y$ for all $(x,y)\in D$. A sequence $(x_t,y_t)_{t\le n}$ is \emph{consistent} if $D_n:=\{(x_t,y_t):t\le n\}$ is a partial function (repeated inputs carry equal labels); $h_t:=(x_1,y_1,\dots,x_t,y_t)$ is the history. For a map $\nu$ from data sets to $[0,1]$ the \emph{one-step conditional} is
\begin{equation}\label{eq:setting:conditional}
\nu(y\mid D,x):=\frac{\nu(D+(x,y))}{\nu(D)}\quad(x\notin\dom D;\ 0\text{ if }\nu(D)=0),\qquad \nu(y\mid D,x):=\ind[y=D(x)]\quad(x\in\dom D).
\end{equation}
The second clause is the \emph{repeated-input convention}.
\end{definition}

\paragraph{Complexity.} $V$ is a fixed universal prefix machine: $\dom V$ is prefix-free, and for every prefix machine $V'$ there is a string $r$ with $V(rs)=V'(s)$ for all $s$. $K(a)$ and $K(a\mid b)$ are prefix complexity and conditional prefix complexity; finite sets and data sets are coded canonically. $\varphi_e$ is the $e$-th partial computable function $X\rightharpoonup Y$, and $\mm(i):=\sum_{p:V(p)=i}2^{-|p|}\ge2^{-K(i)}$. For a class with an effective enumeration $(\nu_i)$, $K(\nu):=\min\{K(i):\nu_i=\nu\}$. ``Lsc'' abbreviates lower semicomputable. We use two standard facts \citep{levin1974laws,gacs1974symmetry,chaitin1975theory}, \citep[\S4.3]{li2008introduction}, not re-checked against these sources: $\mm$ dominates every lsc discrete semimeasure up to a constant factor; and the conditional coding theorem: if $P(a\mid z)\ge0$ is lsc uniformly in $(a,z)$ and $\sum_aP(a\mid z)\le1$ for every $z$, then $K(a\mid z)\le-\log P(a\mid z)+K(P)+c$. Both relativise to oracles. $\log=\log_2$; losses are in bits; $c,c',c''$ and $O(1)$ are constants that depend only on the fixed machines and codings. $\Unif$ is the fair-coin measure on tapes $\omega\in\{0,1\}^\infty$, $[w]$ the cylinder of a string $w$, and $\omega_{1:L}$ the first $L$ tape bits.

\paragraph{Two loss conventions.} The predictors below issue sub-probabilities: the missing mass is the probability that the label is undefined. In the \emph{semimeasure convention} the raw conditionals \eqref{eq:setting:conditional} are scored; the cumulative loss on a consistent sequence is then $-\log\nu(D_n)+\log\nu(\emptyset)$ in every order (\cref{prop:setting:order}). In the \emph{normalised convention} each conditional is divided by its sum before scoring. Every statement about losses says which convention it uses. Upper bounds proved in the semimeasure convention hold in both; lower bounds do not transfer automatically (\cref{prop:setting:normalise,rem:setting:conventions}).

\subsection{Three notions of function semimeasure}\label{sec:setting:weak}

\begin{definition}[Weak function semimeasure]\src{foundations Def 2.1}\label{def:setting:weak}
A map $\nu$ from data sets to $[0,1]$ with $\nu(\emptyset)\le1$ and, for every data set $D$ and every $x\notin\dom D$,
\begin{equation}\label{eq:setting:weak}
\nu(D)\ \ge\ \textstyle\sum_{y\in Y}\nu(D+(x,y)).
\end{equation}
\end{definition}

Two consequences are immediate: $\nu$ is monotone, $\nu(D+(x,y))\le\nu(D)$; and $\sum_{D:\dom D=S}\nu(D)\le\nu(\emptyset)$ for every finite $S\subseteq X$ (sum out the labels one input at a time). Call a predictor $q$ (sub-probabilities $q(\cdot\mid D,x)$ on $Y$, with the repeated-input convention) \emph{order-independent} if for every $D$ the product of its conditionals along a reveal order of $D$ is the same for all orders, and write $\nu_q(D)$ for that product.

\begin{proposition}[Predictor reading]\status{proved}\src{foundations Prop 2.1a (= context Prop 5.1(a))}\label{prop:setting:predictor}
(a) If $\nu$ is weak with $\nu(\emptyset)=1$, its conditionals form an order-independent predictor $q_\nu$ with $\nu_{q_\nu}=\nu$. (b) If $q$ is order-independent, $\nu_q$ is weak with $\nu_q(\emptyset)=1$, and $q(y\mid D,x)=\nu_q(D+(x,y))/\nu_q(D)$ whenever $\nu_q(D)>0$. So weak semimeasures with $\nu(\emptyset)=1$ correspond one-to-one to order-independent predictors, two predictors being identified when they agree wherever $\nu(D)>0$.
\end{proposition}

\begin{proof}
(a) Along any order the conditionals telescope to $\nu(D)/\nu(\emptyset)=\nu(D)$; if an intermediate value vanishes, so does $\nu(D)$, by monotonicity. They sum to at most $1$ by \eqref{eq:setting:weak}. (b) The empty product is $1$. Revealing $D$ first and $x$ last gives $\nu_q(D+(x,y))=\nu_q(D)\,q(y\mid D,x)$; summing over $y$ gives \eqref{eq:setting:weak}.
\end{proof}

\begin{definition}[Random partial function]\src{foundations Def 2.2}\label{def:setting:rpf}
A \emph{random partial function} is a random element $F$ of $\Ybot^X$ (product $\sigma$-algebra, $\Ybot$ discrete) with law $P$. Its \emph{containment functional} is $\nu_P(D):=P(F\supseteq D)$.
\end{definition}

Every containment functional is weak: the events $\{F\supseteq D+(x,y)\}$, $y\in Y$, are disjoint subsets of $\{F\supseteq D\}$. The converse fails (\cref{ex:setting:weaknotrpf}). For finite $T\subseteq X\setminus\dom D$ the \emph{Möbius sum} is $\Mob_T\nu(D):=\sum_{E:\,\dom E\subseteq T}(-1)^{|E|}\nu(D\cup E)$.

\begin{proposition}[Normalised predictors are random total functions]\status{proved}\src{context Prop 5.1(b)}\label{prop:setting:normtotal}
If, in \cref{prop:setting:predictor}(b), every conditional of $q$ sums to $1$, then $\nu_q$ is the containment functional of a unique law of a random \emph{total} function $F\in Y^X$.
\end{proposition}

\begin{proof}
Now $\sum_y\nu_q(D+(x,y))=\nu_q(D)$ for all $D$ and $x\notin\dom D$ (also where $\nu_q(D)=0$, by monotonicity). By induction, for each finite $A\subseteq X$ the map $l\mapsto\nu_q(l)$ on labellings $l\in Y^A$ is a probability distribution, and these distributions are consistent under marginalisation. Kolmogorov's extension theorem gives a law on $Y^X$; it is unique because its cylinder probabilities are determined.
\end{proof}

\begin{proposition}[Möbius characterisation]\status{proved}\src{foundations Prop 2.3 (= context Prop 5.1(c)); checks c6, r4}\label{prop:setting:mobius}
A weak $\nu$ with $\nu(\emptyset)=1$ is the containment functional of a random partial function if and only if $\Mob_T\nu(D)\ge0$ for every $D$ and every finite $T\subseteq X\setminus\dom D$. The law $P$ is then unique, and $\Mob_T\nu(D)=P(F\supseteq D,\ F(t)=\bot\text{ for all }t\in T)$.
\end{proposition}

Necessity is inclusion--exclusion over the events $\{F(t)\ne\bot\}$; sufficiency takes the Möbius sums as cylinder probabilities and applies Kolmogorov's extension theorem (\cref{app:setting:mobius}). The weak inequality \eqref{eq:setting:weak} is the case $|T|=1$. The statement is the function-space analogue of the correspondence between completely monotone set functions and random sets \citep{choquet1954theory,matheron1975random}, or belief functions in finite form \citep{shafer1976mathematical}; we state the analogy without having checked it against these sources.

\begin{example}[Weak but not a random function]\status{proved; computed}\src{foundations Ex 2.4; checks c1, c6, c9(b), r1, r4}\label{ex:setting:weaknotrpf}
(a) Inputs $a,b$: $\nu(\emptyset)=\nu(\{(a,0)\})=\nu(\{(b,0)\})=1$, all other values $0$. Every one-point inequality holds, but $\Mob_{\{a,b\}}\nu(\emptyset)=1-1-1+0=-1$: ``$F(a)=0$ surely and $F(b)=0$ surely, but never both''.
(b) Inputs $a,b,c$, labels $\{0,1\}$: $\nutri(\emptyset)=1$; $\nutri=\tfrac12$ on the six one-point data sets and on $E_1=\{(a,0),(b,1)\}$, $E_2=\{(b,0),(c,1)\}$, $E_3=\{(c,0),(a,1)\}$; $\nutri=0$ elsewhere. $\nutri$ is weak (all 27 one-point inequalities hold, c1). $E_1,E_2,E_3$ are pairwise inconsistent, yet carry total mass $\tfrac32$. For a random partial function the events $\{F\supseteq E_i\}$ are disjoint, so no law $P$ satisfies $P(F\supseteq D)\ge c\,\nutri(D)$ for all $D$ with $c>\tfrac23$. The value $\tfrac23$ is attained by the uniform law on the three total functions $(F(a),F(b),F(c))\in\{(0,1,0),(1,0,1),(1,0,0)\}$, which gives probability $\tfrac13$ to each $E_i$ and to $(a,0),(b,1),(c,1)$, and $\tfrac23$ to the other three one-point data sets.
\end{example}

\subsection{Function machines and universality}\label{sec:setting:machines}

\begin{definition}[Function machine]\src{foundations Def 2.5}\label{def:setting:machine}
A \emph{function machine} is a computably enumerable set $T\subseteq X\times\{0,1\}^*\times Y$ of triples that is \emph{consistent}: if $(x,w,y),(x,w',y')\in T$ and $w,w'$ are comparable (one is a prefix of the other), then $y=y'$. For a tape $\omega\in\{0,1\}^\infty$ put $f^T_\omega(x):=y$ if some prefix $w$ of $\omega$ has $(x,w,y)\in T$, and $f^T_\omega(x):=\bot$ otherwise. The \emph{machine law} of $T$ is
\[
\nu_T(D):=\Unif\{\omega:\ f^T_\omega\supseteq D\}.
\]
\end{definition}

The value at $x$ is fixed by a finite prefix of one random tape, and all inputs read the same tape. Equivalently, $T$ is a Turing machine with a one-way read-only random tape which, on query $x$, reads finitely many tape bits and halts with a label or diverges; every query reads the same tape. A machine law is the law of the random partial function $f^T_\omega$, $\omega\sim\Unif$.

\begin{proposition}[Machine laws]\status{proved}\src{foundations Prop 2.6 and the enumeration remark}\label{prop:setting:machinelaw}
Every machine law is the containment functional of a random partial function, with $\nu_T(\emptyset)=1$, and $\nu_T(D)$ is lsc uniformly in $D$ and in an index of $T$. Function machines have an effective enumeration $(T_i)$; $K(\nu)$ for machine laws refers to it.
\end{proposition}

The event $\{f_\omega\supseteq D\}$ is a finite intersection of effectively open sets; the enumeration discards each enumerated triple that conflicts with one already accepted (\cref{app:setting:machines}).

\begin{theorem}[Universal function machine]\status{proved}\src{foundations Thm 3.2}\label{thm:setting:universal}
$T_U:=\{(x,\,pw,\,y):\ p\in\dom V,\ (x,w,y)\in T_{V(p)}\}$ is a function machine. Its law $\MF:=\nu_{T_U}$ satisfies $\MF(\emptyset)=1$ and, for every data set $D\ne\emptyset$,
\begin{equation}\label{eq:setting:mixture}
\MF(D)=\sum_i\mm(i)\,\nu_{T_i}(D),\qquad\text{hence}\qquad \MF(D)\ \ge\ 2^{-K(\nu)}\,\nu(D)\ \text{ for every machine law }\nu .
\end{equation}
\end{theorem}

\begin{proof}
$T_U$ is c.e. If $(x,pw,y),(x,p'w',y')\in T_U$ with $pw,p'w'$ comparable, then $p,p'$ are comparable elements of the prefix-free set $\dom V$, so $p=p'$, and $(x,w,y),(x,w',y')$ are triples of the consistent $T_{V(p)}$ with $w,w'$ comparable; so $y=y'$. For $\omega=p\omega'$ with $p\in\dom V$, $f^{T_U}_\omega=f^{T_{V(p)}}_{\omega'}$, and $\omega'$ is uniform and independent of $p$. A tape with no prefix in $\dom V$ gives the empty function, which extends only $\emptyset$. Sum over $p$, and use $\mm(i)\ge2^{-K(i)}$.
\end{proof}

The formula is a Bayes mixture: pick a machine $i$ with probability $\mm(i)$, then a random tape. After $D$ the posterior weight of $i$ is $\mm(i)\nu_{T_i}(D)/\MF(D)$.

\begin{proposition}[What machine laws include]\status{proved}\src{foundations Prop 3.3}\label{prop:setting:includes}
\begin{enumerate}[label=(\alph*)]
\item \emph{Product laws (H\"anni's samplers that see only the input).} If $P(y\mid x)$ is lsc with $\sum_yP(y\mid x)\le1$ for every $x$ (a \emph{conditional semimeasure}), then $\nu_P(D):=\prod_{(x,y)\in D}P(y\mid x)$ is a machine law with $K(\nu_P)\le K(P)+O(1)$. Probabilistic machines that read $x$ and output $y$ (halting or not) define exactly the lsc conditional semimeasures.
\item \emph{Deterministic programs.} For partial computable $\varphi$, $D\mapsto\ind[\varphi\supseteq D]$ is a machine law of complexity at most $K(\varphi)+O(1)$.
\item \emph{Computable laws.} If the cylinder probabilities $P(F|_S=v)$, $v\in\Ybot^S$, of a random partial function are computable uniformly in $(S,v)$, its containment functional is a machine law. If $Y$ is finite, or the function is total, it suffices that $\nu_P$ is computable.
\item \emph{Mixtures.} If $(\nu_i)$ are machine laws with computable indices and $w$ is an lsc discrete semimeasure, then $D\mapsto\sum_iw_i\nu_i(D)$ ($D\ne\emptyset$) is a machine law.
\end{enumerate}
\end{proposition}

In (a) each input $x$ gets a private stream of tape bits, $\omega_{\langle j(x),1\rangle},\omega_{\langle j(x),2\rangle},\dots$ ($j$ the length-lexicographic index, $\langle\cdot,\cdot\rangle$ a computable pairing), from which $P(\cdot\mid x)$ is sampled through nested dyadic sets (\cref{lem:setting:realise}). This is H\"anni's remark that ``one should use different bits of randomness from the universal semimeasure's infinite read tape for sampling on different inputs; one can do this using dovetailing'' \citep{hanni2026notes}. (c) samples the labels of $x_1,x_2,\dots$ in turn by nested intervals; (d) first reads a label $i$ from the tape, as $T_U$ does (\cref{app:setting:includes}). With \cref{thm:setting:universal}, (a) gives H\"anni's dominance theorem for such samplers, stated with its hypotheses in \cref{thm:learn:dominance}.

\begin{remark}[Per input, not per query]\src{foundations remark after Prop 3.3}\label{rem:setting:perinput}
In (a) each \emph{input} has its own stream, so a repeated query of the same input returns the same label. A sampler run afresh at each \emph{query} would draw new randomness each time. The per-input reading is a choice. It is the right one for data from a function, which is H\"anni's setting (``input-output pairs from a function f: X-{}>Y revealed''), and it is what makes $\nu_P$ the law of a random function. The per-query reading gives a different object, $\Mpq$ (\cref{def:versions:variants,prop:learn:perquery}).
\end{remark}

\begin{lemma}[Laws of random total functions]\status{proved}\src{foundations Lemma 6.5a}\label{lem:setting:total}
Let $Y$ be countable and $\nu$ an lsc law of a random total function ($\nu(\emptyset)=1$ and $\nu(D)=\sum_y\nu(D+(x,y))$ for $x\notin\dom D$). Then $\nu$ is computable, uniformly in an index. So the machine laws of random total functions are exactly the computable laws of random total functions.
\end{lemma}

\begin{proof}
Induction on $|D|$: if $\nu(D)$ is computable, then $\nu(D+(x,y))=\nu(D)-\sum_{y'\ne y}\nu(D+(x,y'))$ is upper semicomputable as well as lsc. The converse is \cref{prop:setting:includes}(c).
\end{proof}

\begin{theorem}[Universal weak semimeasure]\status{proved; trimming computed}\src{foundations Thm 3.4; check r3}\label{thm:setting:weakuniversal}
There is an lsc weak semimeasure $\Mw$ with $\Mw\ge2^{-K(\nu)}\nu$ for every lsc weak semimeasure $\nu$.
\end{theorem}

Every lsc map from data sets to $[0,1]$ is trimmed, stage by stage, into a weak semimeasure, without changing those that already are; $\Mw$ mixes the results with weights $\mm(i)$ (\cref{app:setting:weak}).

\begin{theorem}[Weak versus machine universality]\status{proved; computed}\src{foundations Thm 3.5 and the remark after it; checks c1, c6, c9, r1}\label{thm:setting:weakvsmachine}
\begin{enumerate}[label=(\roman*)]
\item $\MF\le2^{O(1)}\Mw$.
\item For every lsc weak $\nu$ and every $D$: $\MF(D)\ge2^{-K(\nu)-K(\dom D)-O(1)}\nu(D)$. In particular $\Mw(D)\le2^{K(\dom D)+O(1)}\MF(D)$.
\item For every $k$ some data set $D_k$ with $|\dom D_k|=2k$ has $\log\big(\Mw(D_k)/\MF(D_k)\big)\ge k\log\tfrac32-K(k)-O(1)$.
\item The bound of (iii) holds on average over the $3^k$ explicit data sets $E_{\vec\imath}$ of its proof.
\item The constant behind (iii) is exact: every law $P$ of a random partial function has $\min_{\vec\imath}P(F\supseteq E_{\vec\imath})/\nutri^{\otimes k}(E_{\vec\imath})\le(2/3)^k$, with equality for the $k$-fold product of the law in \cref{ex:setting:weaknotrpf}(b).
\end{enumerate}
\end{theorem}

For (ii), fix $S=\dom D$. The weak inequality makes the labels of $s_1<s_2<\dots$ a semimeasure on label strings, which a monotone machine realises exactly (\cref{lem:setting:realise}); answering $s_j$ with the $j$-th output symbol gives a function machine of complexity $K(\nu)+K(S)+O(1)$. For (iii), $k$ copies of $\nutri$ on disjoint blocks give each of $3^k$ pairwise inconsistent data sets $\Mw$-mass at least $2^{-k-K(k)-O(1)}$, while $\MF$, a law of a random partial function, gives them total mass at most $1$ (\cref{app:setting:weak}). On this family $K(\dom D_k)\le k\log3+K(k)+O(1)$, so at least a fraction $\log(3/2)/\log3\approx0.37$ of the term $K(\dom D)$ in (ii) is needed there. Which member of the family realises (iii) cannot be determined by a computable rule (\cref{rem:versions:noncomputable}).

\begin{corollary}[Universality among normalised order-independent predictors]\status{proved}\src{context Cor 5.2(c), extended by foundations Lemma 6.5a}\label{cor:setting:normuniversal}
Let $Y$ be countable. If $\nu$ is lsc and weak with $\nu(\emptyset)=1$, and all its conditionals sum to $1$, then $\MF\ge2^{-K(\nu)-O(1)}\nu$.
\end{corollary}

\begin{proof}
$\nu$ is the law of a random total function (\cref{prop:setting:normtotal}), hence computable (\cref{lem:setting:total}), hence a machine law whose index is computable from that of $\nu$ (\cref{prop:setting:includes}(c)). Apply \cref{thm:setting:universal}.
\end{proof}

So requiring that total surprise not depend on the order gives the weak semimeasures, where $\Mw$ is universal; requiring in addition that each prediction be a probability vector gives the random total functions, where $\MF$ is universal.

\begin{remark}[Weak and machine universality differ]\status{refuted (weak definition); open (random-function laws)}\src{foundations \S3 ``Answer to H1(a)''; F10}\label{rem:setting:h1a}
Universal elements exist in the weak sense ($\Mw$) and in the machine sense ($\MF$); they agree up to $2^{K(\dom D)+O(1)}$ and not up to a constant (\cref{thm:setting:weakvsmachine}). A Levin-style equivalence ``lsc function semimeasures, or equivalently monotone function machines'', a working hypothesis of this project by analogy with sequences \citep{zvonkin1970complexity}, is therefore refuted for the weak definition. For laws of random partial functions only the inclusions of \cref{prop:setting:includes} and \cref{rem:setting:fillin} are known; the equivalence is open.
\end{remark}

\paragraph{Open question.}\label{q:setting:rpf} Is every lsc containment functional of a random partial function dominated by $\MF$ up to a constant factor; equivalently, are such laws, up to constants, exactly the machine laws? Yes for the classes of \cref{prop:setting:includes} and for limits of computable filling-in processes (\cref{rem:setting:fillin}); up to $2^{K(\dom D)+O(1)}$ for all of them (\cref{thm:setting:weakvsmachine}(ii)). \Cref{app:setting:rpf} reformulates the question (proof sketch): it would suffice that every such law has lower approximations, at a constant-factor loss, that increase on every up-set of the extension order and not only on the principal up-sets $\{F\supseteq D\}$; Strassen's theorem \citep{strassen1965existence} then gives couplings that fill in values.

\subsection{The definition of SFI and its conventions}\label{sec:setting:sfi}

\begin{definition}[Solomonoff function induction]\src{foundations Def 5.1}\label{def:setting:sfi}
Fix $V$ and the enumeration $(T_i)$. \emph{SFI} is the random partial function $f_\omega:=f^{T_U}_\omega$, $\omega\sim\Unif$, with law $\MF$ (\cref{thm:setting:universal}). After data $D$:
\begin{itemize}
\item the \emph{posterior} is the conditional law of $f_\omega$ given $f_\omega\supseteq D$, with containment functional $E\mapsto\MF(D\cup E)/\MF(D)$ for $E$ consistent with $D$;
\item the \emph{predictive conditional} at $x\notin\dom D$ is $\MF(y\mid D,x)=\MF(D+(x,y))/\MF(D)$, a sub-probability whose defect $1-\sum_y\MF(y\mid D,x)$ is the posterior probability that $f_\omega(x)=\bot$; at $x\in\dom D$ it is the stored label with probability $1$;
\item the \emph{normaliser} is $\Znorm(D,x):=\sum_y\MF(D+(x,y))$ and the \emph{normalised conditional} is $\MFbar(y\mid D,x):=\MF(D+(x,y))/\Znorm(D,x)$.
\end{itemize}
For a weak semimeasure $\nu$, $L_\nu(D):=-\log\nu(D)$, and SFI's loss is $\LSFI(D):=L_{\MF}(D)$.
\end{definition}

$\MF(D)>0$ for every $D$, because the lookup table of $D$ is a program with positive weight; so $\MFbar$ is well defined.

\begin{proposition}[Order independence]\status{proved; computed}\src{foundations Prop 5.2 (= context Fact A, history Prop 5.1); check c4}\label{prop:setting:order}
Semimeasure convention. For every weak $\nu$ and every consistent sequence $(x_t,y_t)_{t\le n}$,
\[
\textstyle\sum_{t\le n}-\log\nu(y_t\mid D_{t-1},x_t)=L_\nu(D_n)+\log\nu(\emptyset)\ \le\ L_\nu(D_n),
\]
which depends only on the set $D_n$, not on the order or on repetitions. For SFI the sum is $\LSFI(D_n)$. On an inconsistent sequence it is infinite.
\end{proposition}

\begin{proof}
A repeated input contributes the factor $1$ (its stored label) or $0$ (another label). The other factors telescope to $\nu(D_n)/\nu(\emptyset)$, and $\MF(\emptyset)=1$.
\end{proof}

\begin{proposition}[Normalisation]\status{proved; computed}\src{foundations Prop 5.3; checks c3, r8, r13; context c3}\label{prop:setting:normalise}
Let $\LSFIbar:=\sum_{t\le n}-\log\MFbar(y_t\mid D_{t-1},x_t)$ be SFI's normalised cumulative loss along a given consistent sequence. (a) $\LSFIbar\le\LSFI(D_n)$, so upper bounds on $\LSFI$ hold in both conventions. (b) For laws of random partial functions in general, the normalised loss can depend on the order. (c) For laws of random total functions it equals the semimeasure loss.
\end{proposition}

\begin{proof}
(a) $\Znorm(D,x)\le\MF(D)$. (b) Inputs $a,b$; $(F(a),F(b))$ equals $(0,0)$, $(0,\bot)$, $(1,1)$, $(\bot,\bot)$ with probability $\tfrac14$ each; $D=\{(a,0),(b,0)\}$. Revealing $a$ first gives normalised probability $\frac{1/2}{3/4}\cdot1=\frac23$, revealing $b$ first gives $\frac{1/4}{1/2}\cdot1=\frac12$; the semimeasure probability is $\frac14$ in both orders (c3). (c) Every normaliser equals $\nu(D)$.
\end{proof}

On a random six-point mixture of partial and product hypotheses the semimeasure loss is $10.919980315195$ bits in all $720$ orders, while the normalised loss ranges from $7.33$ to $10.64$ bits (context check c3). Whether the normalised loss of $\MF$ itself depends on the order is open (\cref{q:setting:normorder}).

\begin{proposition}[What transfers to the normalised convention]\status{proved; (b) uses the relativised coding theorem (known); computed}\src{foundations Prop 5.5; checks c10(b,c)}\label{prop:setting:transfer}
Let $Z_t:=\Znorm(D_{t-1},x_t)/\MF(D_{t-1})$, the posterior probability that $f_\omega(x_t)$ is defined ($Z_t:=1$ for a repeated input).
\begin{enumerate}[label=(\alph*)]
\item $\LSFIbar=\LSFI(D_n)-\sum_{t\le n}\log(1/Z_t)$. Since $Z_1\ge2^{-c}$, single-point bounds transfer: $-\log\MFbar(y\mid\emptyset,x)=K(y\mid x)\pm O(1)$.
\item For every input list and labels, $\LSFIbar\ge K^{\emptyset'}(y_{1:n}\mid x_{1:n})-O(1)$, where $K^{\emptyset'}$ is prefix complexity relative to the halting problem.
\item For any joint law of inputs and labels (inputs may depend on past labels), $\Ex\LSFIbar\ge\sum_t\Ex H(y_t\mid h_{t-1},x_t)$, the expected loss of the chronological Bayes predictor.
\end{enumerate}
\end{proposition}

Proofs are in \cref{app:setting:normalised}. (b) and (c) are weak exactly where it matters: in the chain, the skipped strings and the cyclic permutation (\cref{sec:hist,sec:ex}) the labels are computable from the ordered list of inputs, so both bounds are $O(1)$ there.

\begin{remark}[Which lower bounds are semimeasure-only]\status{proved (as a list); transfer open where stated}\src{foundations Rem 5.6, updated by history Prop 2.4, examples Prop 2.9, context \S1.2}\label{rem:setting:conventions}
Lower bounds proved for $\LSFI(D_n)$, or for every order-free predictor, do not transfer automatically to $\LSFIbar$, which need not be order-free (\cref{prop:setting:normalise}). In this paper:
\begin{itemize}
\item \emph{semimeasure convention only:} \cref{thm:setting:coding}(a) beyond single points; \cref{ex:setting:swap}; the $\mathrm{GF}(2^q)$ example (\cref{thm:hist:gf}); the separations of \cref{prop:hist:strict,prop:hist:strictinf}; the cyclic permutation over the full cycle (\cref{thm:ex:cycle}); Eisenstat's example (\cref{thm:ex:sandwich,thm:ex:expected});
\item \emph{proved also normalised:} the chain and the skipped strings, up to $O(n\log n)$ and $O(\ell\log\ell)$ bits (\cref{prop:hist:normchain}); the cyclic permutation at steps $t\le2^{(1-\delta)d}$, at $\delta d-O(\log d)$ bits per step (\cref{prop:ex:normalised});
\item \emph{both conventions:} the out-of-distribution lower bounds of \cref{sec:ood}, which bound the posterior mass that is defined and wrong.
\end{itemize}
\end{remark}

\paragraph{Open question.}\label{q:setting:normorder} Is the normalised loss of $\MF$ order-dependent? On two inputs the exact condition is the criterion $(\star)$ of \cref{prop:setting:twopoint}: the normaliser leaks order information exactly when whether one input is defined says something about another input's label. Since $\MF$ gives every two-point data set positive mass, its normalised loss is order-independent on $\{a,b\}$ if and only if $(\star)$ holds for $\MF$ and $(a,b)$. The foundations track expects that $(\star)$ fails for some pair, without proof. Which of the semimeasure-only lower bounds of \cref{rem:setting:conventions} hold for $\MFbar$ is also open.

\begin{remark}[Recommendation]\src{foundations \S5 ``Recommendation''}\label{rem:setting:recommend}
We call $\MF$ ``SFI''. (1) It is the object H\"anni describes: ``picking a random program from this prior and generating using it'' gives a random function, and programs may use random bits, all read from one tape. (2) It has a posterior over functions, so joint predictions for several test inputs are coherent; $\Mw$ has no such posterior (\cref{ex:setting:weaknotrpf}). (3) It dominates every machine law with constant $2^{-K(\nu)}$ (\cref{thm:setting:universal,prop:setting:includes}). (4) It is invariant (\cref{thm:setting:invariance}). (5) Its semimeasure-convention loss is order-independent (\cref{prop:setting:order}). The variants $W$, $\KF$, $\Mprod$, $\Mpq$ and $\Mw$ (\cref{sec:versions}) should be named and kept distinct: they agree with $\MF$ up to $K(\dom D)+O(1)$ bits and differ from it by unbounded amounts.
\end{remark}

\subsection{Basic properties}\label{sec:setting:basic}

\begin{theorem}[Invariance]\status{proved}\src{foundations Thm 6.2}\label{thm:setting:invariance}
\begin{enumerate}[label=(\alph*)]
\item If $\MF$ and $M'_F$ are built as in \cref{thm:setting:universal} from two universal prefix machines and two effective enumerations of function machines, then $|\log\MF(D)-\log M'_F(D)|\le c$ for all $D$.
\item Let $\alpha:X\to X'$ and $\beta:Y\to Y'$ be computable injections, $D^{\alpha\beta}:=\{(\alpha(x),\beta(y)):(x,y)\in D\}$, and $M'_F$ SFI over $X',Y'$. Then $|\log\MF(D)-\log M'_F(D^{\alpha\beta})|\le K(\alpha,\beta)+O(1)$ for all $D$. So cumulative losses on the original and on the re-encoded data differ by at most $K(\alpha,\beta)+O(1)$ bits, uniformly over data sets and reveal orders.
\item The same holds for $W$, $\Mprod$ and $\Mw$ (\cref{def:versions:variants}).
\end{enumerate}
\end{theorem}

This makes precise H\"anni's heading ``input encoding doesn't matter much'' \citep{hanni2026notes}. In (b), $\omega\mapsto\beta\circ f_\omega\circ\alpha^{-1}$ is a function machine over $X'$ whose law at $D^{\alpha\beta}$ is $\MF(D)$, with an index computable from indices of $\alpha,\beta$ (\cref{app:setting:basic}). The constant $K(\alpha,\beta)$ is not small for complex encodings: an encoding whose complexity is comparable to the data can change losses by up to that much (only the upper bound is proved). Non-computable encodings are not covered.

\begin{theorem}[Coding-theorem bounds]\status{proved}\src{foundations Thm 6.3 (= history Lemma 1.1, examples Lemma 1.1, context Prop 5.4(1))}\label{thm:setting:coding}
For every data set $D$:
\begin{enumerate}[label=(\alph*)]
\item $\LSFI(D)\ge K(D|_T\mid T)-O(1)$ for every $T\subseteq\dom D$; in particular $\MF(D)\le2^{-K(D\mid\dom D)+O(1)}$, and $\MF(D)\le2^{-K(y\mid x)+O(1)}$ for every $(x,y)\in D$;
\item $\LSFI(D)\le\min\big\{\KF(D),\ \sum_{(x,y)\in D}K(y\mid x)\big\}+O(1)\le K(\dom D)+K(D\mid\dom D)+O(1)$, with $\KF$ the shortest consistent program (\cref{def:versions:variants});
\item for single points, $\LSFI(\{(x,y)\})=K(y\mid x)\pm O(1)$.
\end{enumerate}
\end{theorem}

(a) is the conditional coding theorem for $E\mapsto\MF(E)$ on data sets with domain $T$, together with monotonicity; (b) uses one shortest program, and the product law of the conditional universal discrete semimeasure, a machine law of complexity $O(1)$ (\cref{app:setting:basic}).

\begin{example}[Swap data]\status{proved; computed}\src{foundations Ex 6.4; checks c9(c), r8}\label{ex:setting:swap}
For distinct $x_1,x_2\in\{0,1\}^d$ let $D:=\{(x_1,x_2),(x_2,x_1)\}$. Then $K(D\mid\dom D)=O(1)$, but $\LSFI(D)\ge\max\{K(x_2\mid x_1),K(x_1\mid x_2)\}-O(1)$ by \cref{thm:setting:coding}(a). Conversely $\LSFI(D)\le d+O(1)$ for every pair: the machine $F(x):=x\oplus\omega_{1:|x|}$ has complexity $O(1)$ and extends $D$ exactly when $\omega_{1:d}=x_1\oplus x_2$, which has probability $2^{-d}$ (c9(c), $d\le7$). For every $x_1$ some $x_2$ has $K(x_2\mid x_1)\ge d$; for such pairs $\LSFI(D)=d\pm O(1)$. Also $\KF(D)\le d+2\log d+O(1)$.
\end{example}

The data are trivial as a set, but each label is a random $d$-bit string given its own input. This is \emph{not} a separation between SFI and history-aware prediction: an lsc history-aware predictor shown $x_1$ first must predict the label $x_2$ from $x_1$ alone and pays at least $K(x_2\mid x_1)-O(1)$ bits on that step (in the other order, $K(x_1\mid x_2)-O(1)$). The separations are the chain and the skipped strings (\cref{thm:hist:chain,thm:hist:skipped}) and the cyclic permutation (\cref{thm:ex:cycle}). The swap data show only that $K(D\mid\dom D)$ can be a poor lower bound.

\paragraph{Open question.}\label{q:setting:twosided} Is there a two-sided characterisation of $\LSFI(D)$ up to $O(1)$ by standard complexities? The left side of \cref{thm:setting:coding} is a maximum over subsets $T$, and neither side is tight in general. The only exact form known is the tautology $\LSFI(D)=\min_\nu[K(\nu)-\log\nu(D)]\pm O(1)$ over machine laws $\nu$.

\begin{proposition}[Sequence induction is SFI on initial segments]\status{proved}\src{foundations Prop 7.1}\label{prop:setting:si}
Let $X=\mathbb N$, $\{0,1\}\subseteq Y$, and let $M$ be Solomonoff's universal monotone semimeasure on binary strings \citep{zvonkin1970complexity}, \citep[\S4.5; section number unverified]{li2008introduction}. For $x\in\{0,1\}^n$ put $D_x:=\{(i,x_{i+1}):i<n\}$. Then $2^{-O(1)}M(x)\le\MF(D_x)\le2^{O(1)}M(x)$.
\end{proposition}

\begin{proof}
($\ge$) Let $T_1$ contain $(i,w,b)$ when the universal monotone machine, run on $w$, has printed more than $i$ bits and its bit $i+1$ is $b$. Outputs on comparable strings are comparable, so $T_1$ is a function machine, and $\nu_{T_1}(D_x)=M(x)$; apply \cref{thm:setting:universal}. ($\le$) The monotone machine that prints $f_\omega(0),f_\omega(1),\dots$ in order, as long as each value is certified along $\omega$ and lies in $\{0,1\}$, prints a string extending $x$ exactly when $f_\omega\supseteq D_x$. So $x\mapsto\MF(D_x)$ is the output semimeasure of a monotone machine, and $M$ dominates it.
\end{proof}

So on binary sequences presented in order, the cumulative losses of SFI and of Solomonoff induction differ by $O(1)$. In turn SFI is dominated by universal prediction with access to the history (\cref{lem:hist:chrono,cor:hist:H4}).

\begin{proposition}[Computability]\status{proved}\src{foundations Prop 7.3}\label{prop:setting:computability}
(a) $\MF(D)$ is lsc uniformly in $D$, and positive. (b) $\MF$ is not computable. (c) Neither the raw conditional $\MF(y\mid D,x)$ nor the normalised conditional $\MFbar(y\mid D,x)$ is computable as a function of $(D,x,y)$. (d) Both are computable relative to the halting problem $\emptyset'$, hence limit-computable.
\end{proposition}

(c) is a diagonal argument: if a conditional were computable, always choosing a label with conditional below $0.6$ would define a computable $f$ with $\MF(D_n)<0.6^n$, against $\MF(D_n)\ge2^{-K(f)-O(1)}$ (\cref{app:setting:basic}). So SFI and its predictions are an ideal reference, not an algorithm; \cref{sec:comp} treats computable versions.

\paragraph{Open question.}\label{q:setting:level} What is the exact arithmetical level of the conditionals, for example are they lower or upper semicomputable? For Solomonoff's $M$ the question was studied by \citet{leike2015computability} (not checked against the source).
