\section{Discussion}\label{sec:discussion}

\paragraph{SFI as ideal supervised learning.} The positive results are what one asks of an ideal learner, and they need no assumption on how the inputs are chosen. SFI's cumulative log loss is within the complexity of any computable random labeller on every consistent data sequence (\cref{thm:learn:dominance}); when the labels come from a computable random function and the inputs do not depend on unrevealed labels, its predictions merge with the true ones (\cref{thm:learn:merging}); and with i.i.d.\ inputs the averaged predictor has risk $O(K/n)$ (\cref{thm:learn:batch}). These guarantees are relative: they compare SFI with computable labellers, in log loss, and they say nothing about which labeller the data come from. The out-of-distribution results have the same character (\cref{rem:ood:lopsided,rem:ood:answer}). On inputs that a simple property separates from the training data, SFI keeps a probability bounded below for every simple behaviour, whatever the amount of data and whatever the true labels; how large that probability is depends on the universal machine (\cref{prop:ood:hanni,prop:ood:machine}). In exchange, for a computable target $f$ the total posterior error over any sequence of distinct inputs is at most $(\ln2)(K(f)+c)$ (\cref{thm:ood:cumulative}). The limits listed in \cref{rem:learn:ideal}---log loss, averaged predictors, function semantics, computability, machine constants, distribution shift and the comparator class---are each a precise statement, not a caveat.

\paragraph{What the hypotheses may see.} The large gaps between SFI and Solomonoff induction in \cref{sec:hist,sec:ex} are properties of order-free prediction rather than of SFI. Every order-independent predictor pays them (\cref{prop:hist:orderfree,prop:ex:orderfree,prop:ex:law}), and hypotheses that see the list of previous inputs remove them (\cref{cor:hist:H4,prop:ex:cychist,thm:ex:eisensi}). Which of SFI and \SFIhist{} is the right ideal therefore depends on whether the order of the data carries information about the labels. With i.i.d.\ inputs it does not, and SFI's guarantees apply as stated. When a teacher chooses the order, it can carry almost all of the information, as in the cyclic permutation, where the labels repeat the inputs. The set of previous inputs is not enough to recover this information (\cref{prop:hist:strict,prop:ex:cycset}), and even with the list, ``as good as Solomonoff induction'' holds against SI's joint loss, not automatically against its conditional label loss (\cref{thm:hist:si,prop:hist:inputloss}).

\paragraph{Which version to call SFI.} The versions of \cref{sec:versions} agree up to $K(\dom D)+O(1)$ bits, and their gaps, although unbounded, are small on the known witnesses: about $\log d$ for the single shortest program on two points with $d$-bit inputs, and a padded tape-length cost for the program mixture (\cref{cor:versions:twopoint,prop:versions:tape}). For deterministic computable targets all of them learn at the same rate (\cref{rem:versions:prediction,prop:learn:occam}), so the choice matters mostly for random labels and for code lengths. There is no coding theorem for function programs (\cref{thm:versions:nocoding}): the single shortest consistent program, which is what minimum description length with one hypothesis selects, and the Bayes mixture are different objects for functions, unlike for strings. We call $\MF$ SFI because it is the object of \citet{hanni2026notes}, it has a posterior over functions, it dominates every machine law with constant $2^{-K(\nu)}$, it is invariant, and its semimeasure-convention loss does not depend on the order of the data (\cref{rem:setting:recommend}). Where the randomness lives also matters for noise: a random function cannot produce fresh noise on a repeated input, while a per-query mixture can (\cref{prop:learn:freshnoise,prop:learn:perquery}). The companion paper shows that it matters for steeper priors as well (\cref{sec:steep}).

\paragraph{Computable versions.} The same structure appears with bounded resources. Time-bounded mixtures keep constant regret against all predictors that see only the input and run within a time bound (\cref{prop:comp:round,cor:comp:poly}). For circuits, Bayes mistakes and circuit size are polynomially related on every ordering (\cref{thm:comp:circuitbayes}), while the simplest consistent hypothesis can fail exponentially out of distribution (\cref{thm:comp:ladder}): the selection rule matters more than the prior (\cref{rem:comp:selection}). For neural networks, the parameter--function map alone implies no simplicity bias (\cref{prop:nn:nolower}); any bridge to circuit SFI must come from the architecture and the prior, which is what the slides of \citet{vaintrobhanni2026nnbayes} claim for the strong-prior limit (\cref{rem:nn:slides}).

\paragraph{Relation to the literature.} As secondary sources describe it, Solomonoff's operator induction is the per-query mixture $\Mpq$, which equals the product mixture on distinct inputs; SFI differs from it by sharing randomness across inputs (\cref{rem:versions:operator,prop:versions:shared}). The history-aware version is, in substance, Hutter's universal chronological semimeasure (we have not checked the identification against his texts), and Hutter lists supervised learning among AIXI's problem classes (\cref{rem:learn:hutterEX}). The learning theorems are of the Occam, PAC-Bayes and online-to-batch kinds, with $K$ in place of $\log|H|$ (\cref{prop:learn:occam}). \Cref{sec:related} gives details. Our literature search reached abstracts and secondary sources only, so we claim no novelty for anything listed there as existing (\cref{rem:related:new}).

\paragraph{Open problems.} Collected from the sections.
\begin{itemize}[leftmargin=*]
\item \emph{Foundations.} Is every lower-semicomputable law of a random partial function dominated by $\MF$ (\cref{q:setting:rpf})? Is there a two-sided characterisation of $-\log\MF(D)$ by standard complexities (\cref{q:setting:twosided})? What is the arithmetical level of SFI's conditionals (\cref{q:setting:level})? Is the normalised loss of $\MF$ order-dependent, and which semimeasure-only lower bounds hold for it (\cref{q:setting:normorder})?
\item \emph{Versions.} Is $\log(\MF/W)=O(K(d,|D|))$, and what are the exact rates of the gaps of \cref{tab:versions:compare} (\cref{q:versions:open})? Does any computable family of data sets exhibit an unbounded gap (\cref{q:versions:explicit})?
\item \emph{Learning.} Does the last iterate, not only the average, have expected risk $O(K/n)$ (\cref{rem:learn:lastiterate})? Is the leave-one-out error of SFI $O(\KF(f|_B)/|B|)$ up to logarithms (\cref{conj:learn:loo})?
\item \emph{History.} Can the $K(n)+K(A)$ term of \cref{cor:hist:thm1} be removed, and does the theorem extend to defective samplers and infinite alphabets (\cref{rem:hist:thm1open})? Can $K(\Delta_f)$ be replaced by an algorithmic mutual information (\cref{conj:hist:algmi})? How does \SFIhist{} compare with normalised Solomonoff induction's label loss, and do the separations of \cref{prop:hist:strict,thm:hist:gf} hold normalised (\cref{q:hist:open})?
\item \emph{Examples.} The normalised loss over the full cyclic permutation and in Eisenstat's example (\cref{q:ex:normalised}); the depth count for weak semimeasures (\cref{q:ex:depthweak}); SI's label loss with raw undelimited blocks (\cref{conj:ex:raw}).
\item \emph{Out of distribution.} A positive statement for properties that are simple given a program fitted to the training data (\cref{q:ood:converse}); a version of ``natural machines generalise as intended'' for a fixed reference machine (\cref{conj:ood:natural}).
\item \emph{Computable versions and networks.} Efficient constant regret against time-bounded samplers (\cref{q:comp:samplers}); a circuit coding theorem for size priors with polynomial tails, and Occam failures beyond conjunctions (\cref{q:comp:open}); the upper half of the uniform-circuit bridge, a lower bound on the network log prior, and a check of the slides' main theorem (\cref{q:nn:bridges}).
\end{itemize}

\paragraph{The companion paper.} \Citet{claudeSFI2026steeper} asks what a steeper simplicity prior does in function induction with private randomness per input. In a window of $\lambda/n$ it keeps a learner from reproducing a teacher's incompressible systematic errors, and for fixed $\lambda>1$ it prefers a simple sampler to a model with filled-in random bits; with shared randomness, or in sequence prediction, a universal hypothesis absorbs everything instead (\cref{sec:steep}). Whether structured error rules leave such a window is open there.

\section*{Code and data}\addcontentsline{toc}{section}{Code and data}
Every computation reported here was done by a Python script with a fixed seed or by a deterministic one. The scripts, their saved outputs, and the research notes with full proofs are in the folder \texttt{solomonoff-function-induction/} of the repository \url{https://github.com/kaarelh/AI-works}: the scripts are in \texttt{research/tracks/*/checks/}, \texttt{research/tracks/*/referee\_code/} and \texttt{code/}. Each script saves its output next to itself, and re-running the scripts reproduces the saved outputs, apart from timing lines and one time-limited optimisation run.
