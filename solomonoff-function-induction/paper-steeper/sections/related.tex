\section{Related work}\label{sec:related}\label{sec:related:work}

This section describes the closest work informally; the objects are defined in \cref{sec:setup}, and the basic theory of SFI is in the companion paper \citep{claudeSFI2026fundamentals}.

\paragraph{Steeper penalties and generalised posteriors.}\label{rem:related:posteriors}
The proposal studied here weights the description length of a hypothesis by a factor $\lambda>1$ against its log-likelihood, either in a two-part code or through the prior $2^{-\lambda\ell}$ (\cref{def:setup:objectives}). The tempered posterior $\Pi^{1/\lambda}$, which raises the likelihood to the power $1/\lambda$ instead, is a generalised (Gibbs, fractional or safe) posterior with learning rate $1/\lambda$ \citep{zhang2006epsilon,bissiri2016general,bhattacharya2019fractional,grunwald2012safe,grunwald2017inconsistency}, and the $\lambda$-MAP, its maximiser, is a two-part code with complexity weight $\lambda$. The power-prior posterior $\Pi_\lambda$ has the same maximiser but is Bayes' rule with the prior $2^{-\lambda\ell}$; it is proportional to $(\Pi^{1/\lambda})^\lambda$. Our posterior results concern $\Pi_\lambda$ unless stated. Unlike in these works, the target here deliberately differs from the data distribution (\cref{rem:limits:schedule}).

\paragraph{$\lambda$-weighted two-part MDL in noisy classification.}\label{rem:related:mdl}
The closest prior work studies two-part codes in noisy binary classification, where a hypothesis is a classifier together with a code for the label noise, essentially a product hypothesis. \citet{grunwald2007suboptimal} show that Bayes and MDL classifiers can behave suboptimally under misspecification. \citet{zhu2025quantifying} quantify overfitting along the regularisation path of two-part-code MDL in supervised classification, and \citet{zhu2026overfitting} study overfitting and generalisation of (PAC-)Bayesian prediction in noisy binary classification. We do not claim as new the qualitative finding that a bounded $\lambda$ fits the noise and that $\lambda$ must grow with $n$. Their target is the data distribution; ours deliberately differs from it, because the data contain the teacher's errors (\cref{rem:limits:schedule}).

\paragraph{Algorithmic statistics.}
Algorithmic statistics splits the description of a string into a model and a data-to-model code through the structure function and sophistication \citep{koppel1987complexity,gacs2001algorithmic,vereshchagin2004kolmogorov,vereshchagin2017algorithmic}; restricting the model family, for example to Hamming balls \citep{vereshchagin2010rate}, changes the structure function. Product models, a parameter with private noise at each input, are such a restriction, and \cref{sec:algstat} compares the two splits for a noisy parity.

\paragraph{Cold posteriors.}\label{rem:related:cold}
\citet{wenzel2020good} report that cold posteriors $\propto\exp(-U(\theta)/T)$ with $T<1$, where $U(\theta)=-\sum_i\log p(y_i\mid x_i,\theta)-\log p(\theta)$, improve the predictions of Bayesian neural networks. Prior and likelihood get the same exponent, so their ratio stays that of $\lambda=1$. The $\lambda>1$ direction is that of fractional posteriors, with likelihood exponent $1/\lambda<1$ \citep{bhattacharya2019fractional}.

\paragraph{An earlier report.}\label{rem:related:t5}
\Citet[Section~8]{claude2026whatfollows} formalised the proposal for a general imitation channel, mostly by comparing a few hypotheses by rate. We re-derive the results we use from this earlier report: per-input and per-block pricing, the sequence-case threshold, the lemmas behind its kink theorem (here for semimeasures), the hull lemma, rate thresholds, rate blindness, non-identifiability, guard erosion and error envelopes (\cref{app:related:t5}). Two of its statements change here. Its full-table window at $d=20$ has upper end about $(1-H(p))/d\approx0.049$ when logarithmic terms are ignored; with the $2\log d$ terms, as large as $d$ there, the value is $c_{\rm hi}=0.01139$ with the machine constant set to $0$ (\cref{cor:teacher:fulltable}). And its lemma that the randomness of the error set removes the slack $2p$, stated for computable hypotheses, holds for semimeasures (\cref{lem:teacher:sharpfloor}).

\paragraph{Novelty.}\label{rem:related:new}
Known are $\lambda$-weighted MDL in noisy classification, the structure function, sophistication and restricted model families, generalised and tempered posteriors, and our tools (dominance bounds, Kakutani's dichotomy, Ville's inequality, hashing). To our knowledge the following are new: the contrast under a steeper prior between classes with a universal member and the private-randomness class, with its price (\cref{sec:absorb}); the analysis over all hypotheses of Kolmogorov-complexity classes through list decoding (\cref{thm:teacher:main}, \cref{prop:limits:rateblind,prop:limits:envelope}); the model--randomness theorems (\cref{sec:split}); and product sophistication with its gap to set sophistication (\cref{prop:algstat:parity}).
