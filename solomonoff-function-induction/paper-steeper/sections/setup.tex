\section{Setting: data, hypothesis classes and steeper objectives}\label{sec:setup}

This section fixes the data, two kinds of hypotheses, classes of programs and the steeper objectives, whose selections lie on a convex hull in the plane of length and fit (proofs in \cref{app:setup}).

\paragraph{Objects from the companion paper \citep{claudeSFI2026fundamentals}.}
A \emph{function machine} $T$ reads, on input $x$, a prefix of one random tape $\omega\sim\Unif$ shared by all inputs and outputs a label $f^T_\omega(x)$; its \emph{machine law} is $\nu_T(D)=\Unif\{\omega:f^T_\omega\supseteq D\}$. Solomonoff function induction (SFI) is the law $\MF$ of the universal function machine, $\MF(D)=\sum_i\mm(i)\,\nu_{T_i}(D)$ for $D\ne\emptyset$. $\Mprod$ mixes the product laws of lower-semicomputable (lsc) conditional semimeasures, with fresh random bits at each input; $\Mpq$ is the per-query mixture.

\subsection{Data and the two kinds of hypotheses}\label{sec:setup:hyp}

\begin{definition}[Data]\src{steeper \S1.1; split/iid Defs 1.1, 1.3; split/teacher \S1.0}\label{def:setup:data}
The input set is $X=\{0,1\}^*$; statements about a fixed input length use $\{0,1\}^d\subseteq X$. The label set $Y$ is finite, $|Y|\ge2$. We use three data objects.
\begin{itemize}[itemsep=0pt,topsep=2pt]
\item[(DS)] A \emph{data set} is a finite partial function $D:X\rightharpoonup Y$, with $\dom D=\{x_1,\dots,x_n\}$ ($n$ distinct inputs) and $y_i=D(x_i)$. No probability model is assumed.
\item[(FR)] \emph{Frozen labels.} Inputs $x_1,x_2,\dots$ are chosen by an input rule that fixes each new input before its label is revealed (for example i.i.d.\ from a law $\mu$ on $X$); each distinct input carries one label, drawn once. After $n$ queries the data are the data set $D_n$ of the distinct pairs seen.
\item[(PQ)] \emph{Per-query labels.} The pairs $(x_i,y_i)$ are i.i.d.\ from $\mu\otimes\nu$ for an input law $\mu$ and a probability kernel $\nu$: the label is drawn afresh at every query, also at a repeated input. The data are the sequence $h_n:=((x_1,y_1),\dots,(x_n,y_n))$.
\end{itemize}
On DS and FR a hypothesis is scored by its likelihood of the data set, each distinct input counting once. On PQ a product hypothesis $\nu_\pi$ (\cref{def:setup:product}) is scored by $\nu_\pi(h_n):=\prod_{i\le n}\nu_\pi(y_i\mid x_i)$.
\end{definition}

\begin{remark}[Repeated inputs]\status{remark}\src{split/iid Remark 1.4(a),(b),(d); split/teacher \S1.0}\label{rem:setup:objects}
(a) On the countable $X$ i.i.d.\ inputs repeat almost surely, so FR and PQ differ (\cref{sec:recovery}); (b) on distinct inputs they coincide. (c) Only product hypotheses are scored per query, by their terms in $\Mpq$ \citep[Proposition~5.7]{claudeSFI2026fundamentals};% P1: prop:learn:perquery
\ SFI's expected loss would be infinite \citep[Proposition~5.6]{claudeSFI2026fundamentals}.% P1: prop:learn:freshnoise
\ (d) FQ (\cref{sec:teacher}) counts a frozen table per query.
\end{remark}

\begin{definition}[Product hypothesis; private randomness]\src{steeper Def 1.1}\label{def:setup:product}
A \emph{product hypothesis} is an lsc conditional semimeasure $\nu(y\mid x)$ ($\sum_y\nu(y\mid x)\le1$): the law of a random partial function with independent values $F(x)\sim\nu(\cdot\mid x)$ at distinct $x$, as for a machine that uses fresh coins of its own at each input. Its likelihood of a data set is the \emph{product law} $\nu(D):=\prod_{x\in\dom D}\nu(D(x)\mid x)$, and its prediction at a new input $x$ is $\nu(\cdot\mid x)$, whatever $D$ is. It is \emph{deterministic} if it is a partial computable function $f$; then $\nu(D)=\ind[f\supseteq D]$. On a data set the randomness is private to each distinct input; on per-query data it is private to each query, and the likelihood $\nu(h_n)$ is the hypothesis's term in $\Mpq$. On distinct inputs the two readings coincide \citep[Proposition~5.7(a)]{claudeSFI2026fundamentals}.% P1: prop:learn:perquery
\end{definition}

\begin{definition}[Shared hypothesis]\src{steeper Def 1.2}\label{def:setup:shared}
A \emph{shared hypothesis} is an lsc weak function semimeasure $P$: $P(\emptyset)\le1$ and $\sum_yP(D+(x,y))\le P(D)$ for $x\notin\dom D$. Its prediction is $P(y\mid x,D):=P(D+(x,y))/P(D)$. Machine laws, Bayes mixtures $\sum_iw_iP_i$ with $\sum_iw_i\le1$, and product laws are shared hypotheses. By telescoping, the cumulative sequential log loss of $P$ on $D_n$ is $-\log P(D_n)+\log P(\emptyset)\le-\log P(D_n)$ in every reveal order. Hypotheses of Solomonoff induction (SI), semimeasures on an interleaved string $x_1y_1x_2y_2\cdots$, are not of this kind: they depend on the order and model the inputs.
\end{definition}

\subsection{Hypothesis classes}\label{sec:setup:classes}

A steeper penalty acts on single hypotheses, so its effect depends on what counts as one hypothesis and on its length; we make the programs explicit.

\begin{definition}[Hypothesis class]\src{steeper Def 1.3, \S1.2; split/iid Def 1.1}\label{def:setup:class}
Fix a countable set $\mathcal O$ of \emph{observations}: data sets for SFI, and per-query samples $h_n$ for product classes; binary strings for SI; input--label sequences for history-aware prediction. A \emph{hypothesis class} is a c.e.\ prefix-free set $\mathcal H\subseteq\{0,1\}^*$ of \emph{programs} $\pi$, of length $\ell(\pi):=|\pi|$, with maps $P_\pi:\mathcal O\to[0,1]$ that are lsc uniformly in $\pi$; for a product class, $P_\pi(h_n):=\nu_\pi(h_n)$. Two programs for the same law are different hypotheses. By Kraft's inequality, $\sum_\pi2^{-\ell(\pi)}\le1$.
In a \emph{canonical class}, $\mathcal H:=\dom V$ for the fixed universal prefix machine $V$, and $P_\pi$ is the member with index $V(\pi)$ of a fixed effective enumeration of a family, trimmed so that exactly the members of the family occur. The canonical classes, with their mixtures $\xi_1:=\sum_\pi2^{-\ell(\pi)}P_\pi$ in brackets, are: $\Hcl{\times}$, lsc conditional semimeasures with their product laws $\nu_\pi$ ($\xi_\times=\sum_i\mm(i)\nu_i=\Mprod$); $\Hcl{F}$, machine laws ($\MF$ on nonempty data sets); $\Hcl{w}$, lsc weak function semimeasures ($\Mw$, a universal one); $\Hcl{\mathrm{SI}}$, lsc semimeasures on strings ($M$); and $\Hcl{\mathrm{chr}}$, history-oracle function machines with their chronological semimeasures ($\MH$, the law of \SFIhist{}, SFI whose hypotheses see the earlier inputs: an lsc chronological semimeasure that dominates every one \citep[Corollary~6.17(a)]{claudeSFI2026fundamentals}; we use only this universality). % P1: cor:hist:H4
Canonical classes are \emph{closed under prefix-free simulation}: for every prefix machine $V'$ whose outputs are indices of the family there is a string $\sigma$ with $V(\sigma w)=V'(w)$ for all $w\in\dom V'$, so distinct $w$ give distinct programs $\sigma w$.
\end{definition}

Throughout, $\kappa$ is a constant that depends only on the reference machine, the class and the programs built in the proofs, and may differ between occurrences. The standard facts (F1)--(F5) are in \cref{app:setup:facts}; (F1) is $K(\pi)\le\ell(\pi)+\kappa$ in every class.

\subsection{Steeper objectives}\label{sec:setup:objectives}

\begin{definition}[Steeper objectives]\src{steeper \S1.3}\label{def:setup:objectives}
Fix a class, an observation $o$ (for a product class possibly a per-query sample $h_n$, with $P_\pi(h_n)=\nu_\pi(h_n)$) and a \emph{complexity weight} $\lambda\ge1$; we call $\lambda>1$ \emph{steeper}. The \emph{fit} of $\pi$ is $L(\pi;o):=-\log P_\pi(o)\in[0,\infty]$, and the \emph{two-part objective} is $J_\lambda(\pi;o):=\lambda\,\ell(\pi)+L(\pi;o)$; a minimiser is a \emph{$\lambda$-MAP}. The \emph{power-prior posterior} is $\Pi_\lambda(\pi\mid o):=2^{-\lambda\ell(\pi)}P_\pi(o)/\xi_\lambda(o)$, with the \emph{steeper mixture} $\xi_\lambda(o):=\sum_\pi2^{-\lambda\ell(\pi)}P_\pi(o)$: Bayes' rule with the prior $2^{-\lambda\ell}$, whose Kraft sum is at most $1$. We write $\xi^\times_\lambda$, $\xi^F_\lambda$ for $\Hcl{\times}$, $\Hcl{F}$, and $\xi_{\mathcal C}:=\sum_{\pi\in\mathcal C}2^{-\ell(\pi)}P_\pi$ for a class $\mathcal C$. The \emph{tempered posterior} with exponent $\eta\in(0,1]$ is $\Pi^\eta(\pi\mid o)\propto2^{-\ell(\pi)}P_\pi(o)^\eta$. The objective $J_\lambda$ and its minimisers are defined in the same way for every $\lambda>0$.
\end{definition}

For data-set classes $\xi_\lambda$ is a shared hypothesis. The tempered posterior $\Pi^{1/\lambda}$ is a generalised posterior with learning rate $1/\lambda$ (\cref{rem:related:posteriors}). The power-prior posterior $\Pi_\lambda$ has the same maximiser and is proportional to $(\Pi^{1/\lambda})^\lambda$. Our posterior results concern $\Pi_\lambda$ unless stated. If some program has finite $J_\lambda$, the $\lambda$-MAPs are finitely many and nonempty, they maximise both posteriors, and on deterministic hypotheses tempering changes nothing (\cref{lem:setup:basic}).

\begin{remark}[Per-sample form; $\lambda=cn$ gives batch objectives]\status{remark}\src{steeper \S1.3}\label{rem:setup:persample}
For a product class and $n$ data points put $c:=\lambda/n$; then $J_\lambda/n=\hat J_c(\pi):=c\,\ell(\pi)+\frac1n\sum_{i\le n}-\log\nu_\pi(y_i\mid x_i)$. For an input law $\mu$ and a fixed teacher $y^*:X\to Y$ the population versions are the risk $R(\pi):=\Ex_{x\sim\mu}[-\log\nu_\pi(y^*(x)\mid x)]$, $J_c(\pi):=c\,\ell(\pi)+R(\pi)$ and $\Phi(c):=\inf_\pi J_c(\pi)$. Against a teacher's systematic errors the coefficient of the length term must grow with the size of the data set (\cref{rem:limits:schedule}); $\lambda=cn$ with $c$ fixed is this choice. For fixed $\lambda$, $\xi_\lambda$ is one shared hypothesis and its sequential loss telescopes; with $\lambda=cn$ the prior changes with $n$, so statements with $\lambda=cn$ are \emph{batch} statements at a given $n$, and in $\Hcl{\times}$ no fixed prior with full support gives the $cn$-MAPs on every sample (\cref{prop:teacher:nofixedprior}).
\end{remark}

Both objectives select points on the lower boundary of a convex hull, whose kinks are where both reasons for a steeper penalty take effect (\cref{sec:kinks}).

\begin{lemma}[Hull lemma]\status{proved; computed; strengthening of (iv) refuted}\src{steeper Lemma 1.2 (T5 Lemma 3.1); split/kink Thms 2.1, 2.2, Prop 2.3; checks c5(a), c6(F), k1, rB1}\label{lem:setup:hull}
Let $(\ell(\pi),L(\pi))_\pi$ be a countable family with $\ell(\pi)\in\{0,1,\dots\}$, $L(\pi)\in[0,\infty]$, finitely many $\pi$ of each length and some $L(\pi)<\infty$; let $\mathcal A$ be the set of its finite points, $C:=\mathrm{conv}(\mathcal A)+\mathbb R^2_{\ge0}$, the \emph{vertices} the extreme points of $C$, and $J_c:=c\,\ell+L$ for $c>0$. (\emph{Data reading:} $L=L(\cdot;D)$, $c=\lambda$, and the minimisers are the $\lambda$-MAPs. \emph{Population reading:} $L=R$, $c=\lambda/n$.)
\begin{enumerate}[label=(\roman*),itemsep=0pt,topsep=2pt]
\item For $c>0$, every minimiser of $J_c$ lies on the boundary of $C$, on a supporting line with normal $(c,1)$.
\item If $c<c'$ and $\pi,\pi'$ minimise $J_c,J_{c'}$, then $\ell(\pi)\ge\ell(\pi')$ and $L(\pi)\le L(\pi')$.
\item A point of $\mathcal A$ is the unique minimising point of $J_c$ for every $c$ in some nonempty open interval if and only if it is a vertex of $C$; the least-$\ell$ vertex and the least-$L$ vertex, if it exists, count. A program is then the unique minimiser if and only if no other program has the same point.
\item (Absolute length bound.) Every minimiser $\pi_c$ of $J_c$ solves $\min\{L(\pi):\ell(\pi)\le\ell(\pi_c)\}$. Conversely, a solution of $\min\{L(\pi):\ell(\pi)\le\bar\ell\}$ minimises some $J_c$, $c>0$, if and only if its point lies on the boundary of $C$ but not on the open horizontal ray to the right of the least-$L$ vertex.
\item (Vertices and minimisers.) The vertices are points $v_i=(\alpha_i,\rho_i)$, $i=0,1,\dots$ (finitely or infinitely many), $\alpha_0<\alpha_1<\cdots$, each the point of a program of length exactly $\alpha_i$, joined by edges of slopes $-\sigma_i$, $\sigma_1>\sigma_2>\dots>0$, with $\sigma_i\to0$ if there are infinitely many; put $\sigma_0:=\infty$, and $\sigma_{q+1}:=0$ if $v_q$ is the last vertex. For $c>0$ the minimisers of $J_c$ are finitely many: for $\sigma_{i+1}<c<\sigma_i$ the programs at $v_i$; for $c=\sigma_i$ ($i\ge1$) those on the closed edge $[v_{i-1},v_i]$, interior collinear points included.
\item (Duality.) $\Phi(c):=\min_\pi J_c(\pi)=\min_i(c\,\alpha_i+\rho_i)$ is concave and piecewise linear, with derivative $\alpha_i$ on $(\sigma_{i+1},\sigma_i)$, and the lower boundary $\underline C(\alpha):=\min\{y:(\alpha,y)\in C\}$ is $\underline C(\alpha)=\sup_{c>0}(\Phi(c)-c\,\alpha)$ for $\alpha\ge\alpha_0$.
\end{enumerate}
\end{lemma}

\emph{Proof idea.} Only finitely many points lie below a line of negative slope through a point of $\mathcal A$, so the lower boundary of $C$ is a polygon built by gift wrapping; (i)--(iv) are elementary convex geometry on it, (v) follows by minimising $J_c$ along it, and (vi) is the Legendre transform (\cref{app:setup:hull}). So the $\lambda$-MAPs on a data set sit where the hull's slope crosses $-\lambda$. An absolute length bound, a natural alternative to the penalty, also selects points that no penalty selects (\cref{rem:setup:hullconverse}). The theorems on the teacher's errors (\cref{sec:teacher}) ask not whether the good model is a vertex but whether every near-optimal hypothesis knows the model and not the errors (\cref{rem:teacher:selected}).

The last lemma is the sufficiency line: one bit of description pays for at most one bit of fit.

\begin{lemma}[Coding bound]\status{proved}\src{steeper Lemma 1.6; split/kink Remark 2.5, Cor 3.3(a)}\label{lem:setup:coding}
In every data-set class (product or shared hypotheses), for every program $\pi$ and data set $D$, $\ell(\pi)+L(\pi;D)\ge K(y_D\mid\dom D)-\kappa$, where $y_D$ lists the labels of $D$ in the canonical order of $\dom D$.
\end{lemma}

\emph{Proof idea.} Given $\pi$ and $\dom D$, the labelling $y\mapsto P_\pi(\dom D\mapsto y)$ is an lsc semimeasure on $Y^{\dom D}$, uniformly in $(\pi,\dom D)$; apply (F2), (F3) and (F1) (\cref{app:setup:coding}). In the plane of \cref{lem:setup:hull} the bound is a line of slope $-1$ below all points. If $\pi_s$ is \emph{$b$-sufficient}, $\ell(\pi_s)+L(\pi_s;D)\le K(y_D\mid\dom D)+b$, then a program longer than $\pi_s$ by $x$ bits fits better by at most $x+b+\kappa$ bits: a right line of slope $1$ with offset $b+\kappa$ at $\pi_s$ (\cref{def:kink:kinks,cor:kink:split}).

What separates the two kinds of class is whether one member attains the best two-part code length $\min_\pi[\ell(\pi)+L(\pi;D)]$ up to a constant on every data set: under (Dom) $U$ does, $\ell_U-\log U(D)\le\ell(\pi)+L(\pi;D)+\ell_U+\kappa_0$ for every $\pi$ (\cref{sec:absorb}); in the product class no member does (\cref{cor:absorb:nouniversal}).
