\section{Proofs for \texorpdfstring{\cref{sec:absorb}}{Section \ref*{sec:absorb}} (absorption)}\label{app:absorb}

\subsection{Classes with an absorbing member}\label{app:absorb:examples}

We prove \cref{rem:absorb:examples}. Suppose first that the mixture $\xi_1=\sum_\pi2^{-\ell(\pi)}P_\pi$ is itself a member, $\xi_1=P_{\pi_U}$. Then $P_\pi\le2^{\ell(\pi)}\xi_1=2^{\ell(\pi)}U$ for every $\pi$, which is (Dom) with $\kappa_0=0$, and $\xi_1=U$. This covers $\Hcl{w}$ ($\Mw=\sum_i\mm(i)\nu_i$ is an lsc weak function semimeasure \citep[Theorem~3.11]{claudeSFI2026fundamentals}, hence occurs in the trimmed enumeration), $\Hcl{\mathrm{SI}}$ ($M$ is an lsc semimeasure) and $\Hcl{\mathrm{chr}}$ ($\MH$ is an lsc chronological semimeasure \citep[Corollary~6.17]{claudeSFI2026fundamentals} and, by \citet[Theorem~6.16]{claudeSFI2026fundamentals}, the law of a history-oracle function machine at every nonempty history; at the empty history both sides of (Dom) are at most $1$ and $P_{\pi_U}=1$). For $\Hcl{F}$: $\MF$ is a machine law \citep[Theorem~3.8]{claudeSFI2026fundamentals}, so it has an index; let $\pi_U$ be a shortest program for it. For $D\ne\emptyset$, $P_\pi(D)=\nu_{T_{V(\pi)}}(D)\le\MF(D)/\mm(V(\pi))\le2^{\ell(\pi)}\MF(D)$, and at $\emptyset$ both sides equal $1$. Here $\xi_1=\MF$ on nonempty data sets and $\xi_1(\emptyset)\le1=\MF(\emptyset)$, so $\xi_1\le U$. \qed% P1: thm:setting:weakuniversal, cor:hist:H4, thm:hist:representation, thm:setting:universal

\subsection{Proof of the absorption theorem}\label{app:absorb:absorption}

We prove \cref{thm:absorb:absorption}. Throughout, (Dom) holds and $\lambda>1$.

\emph{(a).} Let $\hat\pi$ be a $\lambda$-MAP for $o$. Since $U(o)>0$, $J_\lambda(\hat\pi;o)\le J_\lambda(\pi_U;o)=\lambda\ell_U-\log U(o)<\infty$, so $L(\hat\pi;o)<\infty$. By (Dom), $-\log U(o)\le\ell(\hat\pi)+\kappa_0+L(\hat\pi;o)$. Substituting, $\lambda\ell(\hat\pi)+L(\hat\pi;o)\le\lambda\ell_U+\ell(\hat\pi)+\kappa_0+L(\hat\pi;o)$, so $(\lambda-1)\ell(\hat\pi)\le\lambda\ell_U+\kappa_0$, the length bound. The fit bound is $J_\lambda(\hat\pi;o)\le J_\lambda(\pi_U;o)$ rearranged. Finally, $\ell^*_\lambda<\bar\ell$ if and only if $\lambda(\bar\ell-\ell_U)>\bar\ell+\kappa_0$.

\emph{(b).} The first inequality keeps the single term of $\pi_U$ in $\xi_\lambda(o)=\sum_\pi2^{-\lambda\ell(\pi)}P_\pi(o)$; the second holds because $2^{-\lambda\ell}\le2^{-\ell}$. If $\xi_1\le2^{\kappa_1}U$, then $-\log\xi_\lambda(o)\ge-\log\xi_1(o)\ge-\log U(o)-\kappa_1$, and the first inequality gives $-\log\xi_\lambda(o)\le\lambda\ell_U-\log U(o)$. For a data-set class, $\xi_\lambda$ is a weak function semimeasure with $\xi_\lambda(\emptyset)\le\sum_\pi2^{-\lambda\ell(\pi)}\le1$, because each $P_\pi$ is one and the weak inequalities are linear; so its sequential log loss on $D_n$ is $-\log\xi_\lambda(D_n)+\log\xi_\lambda(\emptyset)$ in every order (\cref{def:setup:shared}).

\emph{(c1).} Since $\pi_t$ is deterministic and consistent with $D_n$, $P_{\pi_t}(D_n)=1$, so $\xi_\lambda(D_n)\ge2^{-\lambda\ell_t}$. Also, by (Dom), $U(D_n)\ge2^{-\ell_t-\kappa_0}$, so $\xi_\lambda(D_n)\ge2^{-\lambda\ell_U}U(D_n)\ge2^{-\lambda\ell_U-\kappa_0-\ell_t}$. By telescoping, $\sum_{i\le n}-\log\xi_\lambda(t(x_i)\mid x_i,D_{i-1})\le-\log\xi_\lambda(D_n)$. Each conditional is at most $1$ by the one-point inequality, so each term is nonnegative, and a label with probability below $1/2$ adds more than one bit.

\emph{(c2).} Combine (a) with $-\log U(D_n)\le\ell_t+\kappa_0$.

\emph{(c3).} The set $\mathcal H_{\le}:=\{\pi:\ell(\pi)\le\ell^*_\lambda\}$ is finite, and by (a) it contains every $\lambda$-MAP for every $D_n$. For $\pi\in\mathcal H_\le$, $L(\pi;D_n)$ is nondecreasing in $n$, because weak function semimeasures are monotone; let $L(\pi;D_\infty)\in[0,\infty]$ be its limit, and $\mathcal H_{\rm fin}:=\{\pi\in\mathcal H_\le:L(\pi;D_\infty)<\infty\}$. It contains $\pi_U$, because $\ell_U\le\ell^*_\lambda$ and $L(\pi_U;D_\infty)\le\ell_t+\kappa_0$. For $\pi\in\mathcal H_\le\setminus\mathcal H_{\rm fin}$, $J_\lambda(\pi;D_n)\to\infty$, while $J_\lambda(\pi_U;D_n)\le\lambda\ell_U+\ell_t+\kappa_0$ for every $n$; as there are finitely many such $\pi$, none of them is a $\lambda$-MAP beyond some $n_0$. For $\pi\in\mathcal H_{\rm fin}$, the increments $L(\pi;D_{n+1})-L(\pi;D_n)$, the losses of $\pi$'s predictions of the next label, sum to at most $L(\pi;D_\infty)$, so $\pi$ gives the next label probability below $1/2$ fewer than $L(\pi;D_\infty)+1$ times. The union over the finite set $\mathcal H_{\rm fin}$ bounds the number of $n\ge n_0$ at which some $\lambda$-MAP does so.

\emph{(d).} By (Dom), $\xi_\lambda\ge2^{-\lambda\ell_U}U\ge2^{-\lambda\ell_U-\kappa_0-\ell(\pi_{\Prob})}\Prob$ on every string. Hence for every $\bar n$, with $\omega_{1:\bar n}$ drawn from $\Prob$, $\Ex_{\Prob}\log\big(\Prob(\omega_{1:\bar n})/\xi_\lambda(\omega_{1:\bar n})\big)\le\lambda\ell_U+\kappa_0+\ell(\pi_{\Prob})$. With $\xi_\lambda(b\mid h):=\xi_\lambda(hb)/\xi_\lambda(h)$, the chain rule over bit positions gives $\log(\Prob/\xi_\lambda)(\omega_{1:\bar n})=\sum_{j\le\bar n}\log\big(\Prob(\omega_j\mid\omega_{<j})/\xi_\lambda(\omega_j\mid\omega_{<j})\big)-\log\xi_\lambda(\epsilon)$, and $-\log\xi_\lambda(\epsilon)\ge0$. At each position the conditional expectation of the summand is $\KL\big(\Prob(\cdot\mid h)\,\|\,\xi_\lambda(\cdot\mid h)\big)\ge-\log\sum_b\xi_\lambda(b\mid h)\ge0$, since $\xi_\lambda(\cdot\mid h)$ is a sub-probability. With fixed-length blocks the label positions are fixed, and there $\Prob(\cdot\mid h)$ is a point mass, because $y_i=t(x_i)$; so the summand is $-\log\xi_\lambda(\omega_j\mid\omega_{<j})$, and these sum over one label block to $-\log\xi_\lambda(y_i\mid x_1y_1\cdots x_i)$. Dropping the nonnegative terms of the input positions gives the claim, which is Solomonoff's bound \citep{solomonoff1978complexity} restricted to the label positions. \qed

\subsection{Proof of the shared-randomness theorem}\label{app:split:shared}

We prove \cref{thm:split:shared}. (i) Since $U(o)>0$, $J_\lambda(\pi_U;o)<\infty$. By (Dom), $-\log U(o)\le k+\kappa_0+L(\pi_\nu;o)$, so $J_\lambda(\pi_U;o)\le\lambda\ell_U+\kappa_0+k+L(\pi_\nu;o)$, which is below $J_\lambda(\pi_\nu;o)=\lambda k+L(\pi_\nu;o)$ exactly when $(\lambda-1)k>\lambda\ell_U+\kappa_0$; the same condition says $\ell^*_\lambda<k$, and every $\lambda$-MAP has length at most $\ell^*_\lambda$ by \cref{thm:absorb:absorption}(a). (ii) $\sum_{\pi\in A}2^{-\lambda\ell(\pi)}P_\pi(o)\le2^{-(\lambda-1)\min_A\ell}\,\xi_1(o)\le2^{-(\lambda-1)\min_A\ell+\kappa_1}U(o)$, and the normaliser $\xi_\lambda(o)$ is at least $2^{-\lambda\ell_U}U(o)$. For SI with adaptive or non-computable inputs the sampler is not an SI hypothesis; in $\Hcl{\mathrm{chr}}$ it is a chronological semimeasure, and $\MH$ dominates every lsc chronological semimeasure on every input sequence \citep[Corollary~6.17(a)]{claudeSFI2026fundamentals}, so (Dom) holds there with $U=\MH$. \qed% P1: cor:hist:H4

The product and the shared predictor both still predict well: for fixed $\lambda$ they dominate $\nu$ ($\xi^\times_\lambda\ge2^{-\lambda k}\nu$; $\xi^F_\lambda\ge2^{-\lambda\ell_U-\kappa_0-k}\nu$), so by the argument of \citet[Theorem~5.3]{claudeSFI2026fundamentals}% P1: thm:learn:merging
\ their summed expected KL divergences to $\nu$'s predictions are at most $\lambda k$ and $\lambda\ell_U+\kappa_0+k$.

\begin{example}[Noisy parity, full table: an illustration]\status{computed; illustration}\src{steeper Ex 3.4; check c4(C); referee q1(J)}\label{ex:split:noisyparity}
Let $d=12$ and let the data be the full table ($N=4096$ inputs) of a random parity with i.i.d.\ flips at rate $1/8$ ($509$ flips). A small product class contains the coin, parity-plus-noise samplers ($\ell=24.2$ bits) and the memoriser (parity plus flip set); a ``shared class'' adds the finite Bayes mixture $U$ over all parities and a grid of noise rates, with an \emph{assigned} length $\ell_U=12$. A direct computation (code in the accompanying repository) gives: the product-class MAP is the sampler at $\lambda=1,1.1,1.5,2,3,6$, and at $\lambda=1$ the memoriser is only $8.2$ bits worse, a tie up to $O(\log N)$; the shared-class MAP is the sampler for $\lambda<1.315$ and $U$ above, the threshold being $(-\log U(D)+\log\nu(D))/(k-\ell_U)$ (the rounded values $2234.0$, $2218.0$, $24.2$, $12$ give $1.311$). Since $\ell_U=12$ is assigned and this finite class does not satisfy (Dom), the example illustrates the mechanism of \cref{thm:split:shared}; it is not an instance of it, and its numbers are not values for any reference machine.
\end{example}

\subsection{Per-input pricing}\label{app:absorb:pricing}

For a finite set $F$ of total functions $X\to Y$ and a distribution $Q$ on $F$, let $Q_x$ be the law of $f(x)$ for $f\sim Q$.

\begin{proposition}[Per-input pricing]\status{proved; computed}\src{steeper Prop 1.3 (T5 Thm 2.1, Prop 2.2); check c2(a); referee r2}\label{prop:absorb:pricing}
Let $x_1,\dots,x_n$ be distinct.
\begin{enumerate}[label=(\roman*),itemsep=0pt,topsep=2pt]
\item For every product hypothesis $\nu$ and every $Q$, $\max_{f\in F}\sum_{i\le n}-\log\nu(f(x_i)\mid x_i)\ge\sum_{i\le n}H(Q_{x_i})$; the value $\inf_\nu\max_f\sum_i-\log\nu(f(x_i)\mid x_i)$ is $\max_Q\sum_iH(Q_{x_i})$, which can be strictly below $\sum_i\log|\{f(x_i):f\in F\}|$.
\item If $F$ is the set of parities on $\{0,1\}^d$ and the $x_i$ are nonzero, every product hypothesis pays at least $n$ bits on some parity, while the Bayes mixture over parities, a shared hypothesis, pays at most $d$ bits on every parity.
\item A per-input mixture $\nu(y\mid x)=\sum_qw_q\,q(y\mid x)$ is a product hypothesis and pays up to $\log(1/w_q)$ at every input: with the two constant functions and $w=1/2$ it pays $n$ bits on $n$ ones, where the shared mixture pays $1$ bit.
\end{enumerate}
\end{proposition}

\emph{Proof.} The bound in (i) is Gibbs' inequality applied to $\Ex_{f\sim Q}$, and the value follows from Sion's minimax theorem \citep{sion1958general}.

\emph{(i), the bound.} $\max_f\ge\Ex_{f\sim Q}$, and for each $i$
\[
\Ex_{f\sim Q}\big[-\log\nu(f(x_i)\mid x_i)\big]=H(Q_{x_i})+\sum_yQ_{x_i}(y)\log\frac{Q_{x_i}(y)}{\nu(y\mid x_i)},
\]
where the last sum is at least $-\log\sum_y\nu(y\mid x_i)\ge0$, by Gibbs' inequality with a sub-probability.

\emph{(i), the value.} For $\varepsilon\in(0,1/|Y|)$ let $\Delta_\varepsilon$ be the compact convex set of conditional sub-probabilities on $\{x_1,\dots,x_n\}$ with all values at least $\varepsilon$. The loss $\mathcal L(\nu,Q):=\Ex_{f\sim Q}\sum_i-\log\nu(f(x_i)\mid x_i)$ is continuous on $\Delta_\varepsilon\times\Delta(F)$, convex in $\nu$ and linear in $Q$, so by Sion's minimax theorem \citep{sion1958general} $\min_{\Delta_\varepsilon}\max_Q\mathcal L=\max_Q\min_{\Delta_\varepsilon}\mathcal L$, and $\max_Q\mathcal L(\nu,Q)=\max_{f\in F}\sum_i-\log\nu(f(x_i)\mid x_i)$. For each $Q$, $\min_{\Delta_\varepsilon}\mathcal L(\cdot,Q)$ lies between $\sum_iH(Q_{x_i})$ and $\sum_iH(Q_{x_i})-n\log(1-|Y|\varepsilon)$, the latter attained by $\nu=(1-|Y|\varepsilon)Q_x+\varepsilon$; the error term is uniform in $Q$. Rational conditional probabilities are computable and dense in $\Delta_\varepsilon$, so the infimum over product hypotheses equals that over $\Delta_\varepsilon$. Hence $\max_Q\sum_iH(Q_{x_i})\le\inf_\nu\max_f\sum_i-\log\nu(f(x_i)\mid x_i)\le\max_Q\sum_iH(Q_{x_i})-n\log(1-|Y|\varepsilon)$; let $\varepsilon\to0$. For $F=\{(a,a),(a,b),(b,a),(c,a)\}$ a direct computation (code in the accompanying repository) gives $\max_Q\sum_iH(Q_{x_i})=2.5431$, and the same value for $\min_\nu\max_f$ by constrained optimisation over $\nu$, against $\log3+\log2=2.5850$.

\emph{(ii).} For $x\ne0$ exactly half of the parities give each label at $x$, so the uniform $Q$ has $H(Q_x)=1$, and (i) gives a parity with loss at least $n$. The Bayes mixture with weight $2^{-d}$ on each parity gives every parity's data probability at least $2^{-d}$.

\emph{(iii).} Each term of the per-input mixture assigns $1/2$ to the observed label $1$, at every input; the shared mixture gives the constant-$1$ function weight $1/2$. \qed

\begin{remark}[The universal conditional semimeasure never learns]\status{proved}\src{steeper Rem 1.5 (T5 Thm 2.4)}\label{rem:absorb:condsemi}
The universal lsc conditional semimeasure satisfies $\mm(y\mid x)\ge2^{-K(y\mid x)-\kappa}$. For $Y=\{0,1\}$ this gives a constant $\kappa_{\mm}$ with $\mm(y\mid x)\ge2^{-\kappa_{\mm}}$, hence $\mm(y\mid x)\le1-2^{-\kappa_{\mm}}$, for both labels, so it pays at least $\log\frac1{1-2^{-\kappa_{\mm}}}>0$ bits for every label on every data set. It dominates each product hypothesis input by input, $\mm\ge2^{-K(\nu)-\kappa}\nu$, but pays the factor $2^{K(\nu)}$ again at every input; its prediction does not depend on the data.
\end{remark}

\subsection{Why private randomness, and its price}\label{app:absorb:price}

\begin{remark}[Why private randomness is what matters]\status{remark; cites proved results}\src{steeper \S1.6; foundations Thm 4.2, Prop 4.5, Rem 4.5a}\label{rem:absorb:why}
At $\lambda=1$ the decomposition into hypotheses does not change the predictor ($\xi_\times=\Mprod$ is one shared hypothesis); at $\lambda>1$ it does. Over the class $\Hcl{F}$ of all machine laws, $\MF$ would be a short member and absorption would return, so steeper SFI is defined over $\Hcl{\times}$, whose $\lambda\to1$ limit is $\Mprod$, not $\MF$. At $\lambda=1$ this costs at most $K(\dom D)+O(1)$ bits against $\MF$, but not a constant: $\MF/\Mprod$ is unbounded already against the law $\nulen$ of $F(x)=\omega_{|x|+1}$, one shared fair coin per input length, although on inputs of length at most $d$ the gap to $\nulen$ is at most $\Kpad(d+1)+O(1)$ bits, $\Kpad(N):=\min_{L\ge N}K(L)$ \citep[Theorem~4.4, Proposition~4.7 and Remark~4.8]{claudeSFI2026fundamentals}.% P1: thm:versions:chain, prop:versions:shared, rem:versions:sharedsize
\ At $\lambda>1$ the cost is a constant factor on shared latent causes (\cref{prop:absorb:price}).
\end{remark}

For $s\ge1$ and $\beta\in\{0,1\}^s$ let $D_\beta:=\{(0^i,\beta_i),(1^i,\beta_i):i\le s\}$: one fair coin per pair of inputs, shown on both.

\begin{proposition}[The price of private randomness]\status{proved; computed}\src{steeper Prop 1.7; check c6(D)}\label{prop:absorb:price}
Let $Y=\{0,1\}$.
(i) For every $\lambda\ge1$ and $\beta$: $-\log\xi^\times_\lambda(D_\beta)\ge\min(\lambda,2)\,\big(K(\beta\mid s)-\kappa\big)$. (ii) Hence $J_\lambda(\pi;D_\beta)\ge\min(\lambda,2)\big(K(\beta\mid s)-\kappa\big)$ for every $\pi\in\Hcl{\times}$, and in every product class with a prefix-free code, with $\kappa$ depending on the class. (iii) $\nulen$ is a machine law of complexity $O(1)$ with $\nulen(D_\beta)=2^{-s}$, so $-\log\MF(D_\beta)\le s+\kappa$ and $-\log\xi^F_\lambda(D_\beta)\le s+\lambda\kappa$. (iv) For uniform $\beta$ and $j\ge0$, with probability at least $1-2^{-j}$ the steeper product predictor pays at least (in the semimeasure convention) $(\min(\lambda,2)-1)s-2j-(\lambda+2)\kappa$ bits more than $\MF$ and than $\xi^F_\lambda$.
\end{proposition}

\emph{Proof.} Write $a_i:=0^i$, $b_i:=1^i$ and $\bar\lambda:=\min(\lambda,2)$.

\emph{(i).} Fix $\pi\in\Hcl{\times}$ with conditional semimeasure $\nu=\nu_\pi$. Then $\nu(D_\beta)=\prod_{i\le s}\nu(\beta_i\mid a_i)\,\nu(\beta_i\mid b_i)\le Q_\pi(\beta)^2$ with $Q_\pi(\beta):=\prod_iq_i(\beta_i)$ and $q_i(y):=\frac12\big(\nu(y\mid a_i)+\nu(y\mid b_i)\big)$, by the inequality of arithmetic and geometric means. Each $q_i$ is a sub-probability on $\{0,1\}$, so $Q_\pi$ is a semimeasure on $\{0,1\}^s$, lower semicomputable uniformly in $(\pi,s)$, and so is $\bar Q(\beta):=\sum_{\pi\in\Hcl{\times}}2^{-\ell(\pi)}Q_\pi(\beta)$; by (F2), $\bar Q(\beta)\le2^{-K(\beta\mid s)+\kappa}$. If $1\le\lambda\le2$, then $2^{-\lambda\ell(\pi)}Q_\pi^2=(2^{-\ell(\pi)}Q_\pi)^\lambda Q_\pi^{2-\lambda}\le(2^{-\ell(\pi)}Q_\pi)^\lambda$; if $\lambda\ge2$, then $2^{-\lambda\ell(\pi)}Q_\pi^2\le(2^{-\ell(\pi)}Q_\pi)^2$. Since $\sum_\pi t_\pi^{\bar\lambda}\le(\sum_\pi t_\pi)^{\bar\lambda}$ for nonnegative $t_\pi$,
\[
\xi^\times_\lambda(D_\beta)=\sum_\pi2^{-\lambda\ell(\pi)}\nu_\pi(D_\beta)\le\sum_\pi2^{-\lambda\ell(\pi)}Q_\pi(\beta)^2\le\bar Q(\beta)^{\bar\lambda}\le2^{-\bar\lambda(K(\beta\mid s)-\kappa)}.
\]

\emph{(ii).} $2^{-J_\lambda(\pi;D_\beta)}$ is one term of $\xi^\times_\lambda(D_\beta)$. For a product class with a prefix-free code, define $\bar Q$ over that class; (F2) then holds with a constant for the class.

\emph{(iii).} $\nulen$ is the law of the function machine $T=\{(x,w,b):|w|=|x|+1,\ w_{|x|+1}=b\}$, which outputs the tape bit $\omega_{|x|+1}$. Inputs $a_i,b_i$ have the same length $i$, so they receive the same bit, and distinct $i$ receive independent bits; so $\nulen(D_\beta)=2^{-s}$. Universality gives $\MF\ge2^{-K(\nulen)}\nulen$ \citep[Theorem~3.8]{claudeSFI2026fundamentals}, so $-\log\MF(D_\beta)\le s+\kappa$; for $\xi^F_\lambda$ keep the single term of a shortest program for $\nulen$.% P1: thm:setting:universal

\emph{(iv).} Fewer than $2^{s-j}$ strings $\beta$ have $K(\beta\mid s)<s-j$, so $\Pr[K(\beta\mid s)<s-j]<2^{-j}$. Otherwise (i) gives $-\log\xi^\times_\lambda(D_\beta)\ge\bar\lambda(s-j-\kappa)$, while (iii) gives $-\log\MF(D_\beta)\le s+\kappa$ and $-\log\xi^F_\lambda(D_\beta)\le s+\lambda\kappa$. Subtracting, with $\bar\lambda\le2$ and $\bar\lambda\le\lambda$, the excess is at least $(\bar\lambda-1)s-2j-(\lambda+2)\kappa$ in both cases. \qed

\subsection{Hypotheses that see the history}\label{app:absorb:history}

\begin{proposition}[Labelled history restores universality]\status{proved; computed}\src{steeper Prop 4.1 (T5 Prop 2.6); check c5(d)}\label{prop:absorb:history}
Suppose a hypothesis's input at position $i$ of a block contains the block's earlier labelled pairs. Let $(\nu_\theta)_{\theta\in\Theta}$, $\Theta$ countable, be uniformly computable history-dependent conditional measures with positive values, and $w$ computable positive weights with a computable sum $\sum_\theta w_\theta\le1$. With $Z_i:=\sum_\theta w_\theta\prod_{j<i}\nu_\theta(y_j\mid\cdot)$, the in-context Bayes mixture $h_w(y_i\mid\cdot):=Z_{i+1}/Z_i$ is a single product hypothesis on the extended inputs, with a program of length at most $K(w,(\nu_\theta))+\kappa$, and on every block
\[
\textstyle\sum_i-\log h_w(y_i\mid\cdot)\ \le\ \min_\theta\big[\log(1/w_\theta)+\sum_i-\log\nu_\theta(y_i\mid\cdot)\big].
\]
So it pays $\log(1/w_\theta)$ once per block, not once per input.
\end{proposition}

\begin{proof} Each $Z_i$ is a positive real, computable uniformly in the block's history: its terms are computable and positive, and the tail $\sum_{\theta>T}w_\theta\prod_{j<i}\nu_\theta(\cdot)$ is at most $\sum_{\theta>T}w_\theta$, which is computable from $T$ because $w$ and $\sum_\theta w_\theta$ are. So $h_w=Z_{i+1}/Z_i$ is computable, and it sums to $1$ over $y_i$ because the $\nu_\theta$ are measures: a computable conditional measure on extended inputs, with a program obtained from a description of $w$ and $(\nu_\theta)$. Over a block of length $n'$ the predictive probabilities telescope to $Z_{n'+1}/Z_1$, and $Z_1=\sum_\theta w_\theta\le1$, so $-\log(Z_{n'+1}/Z_1)\le\log(1/w_\theta)+\sum_i-\log\nu_\theta(y_i\mid\cdot)$ for every $\theta$.
\end{proof}

Without the computability assumptions, $Z_{i+1}/Z_i$ is a ratio of lsc sums, which need not be lsc. A finite family with rational values and rational weights satisfies them.

\begin{proposition}[A history of inputs only]\status{proved}\src{steeper Prop 4.2}\label{prop:absorb:inputs}
A hypothesis that sees the earlier inputs but not the earlier labels, and draws fresh randomness for each extended input $(x_{<i},x_i)$, is a product hypothesis on the extended inputs, which are pairwise distinct; so \cref{prop:absorb:pricing} and \cref{cor:absorb:nouniversal} apply and per-input pricing persists. With shared randomness instead, as in \SFIhist{}, $\Hcl{\mathrm{chr}}$ has the universal member $\MH$ and \cref{thm:absorb:absorption} applies.
\end{proposition}

\begin{proof} Such a hypothesis is an lsc conditional semimeasure on extended inputs, with private randomness per extended input, and extended inputs at different positions are distinct. In \cref{prop:absorb:pricing}(ii) take the functions $(x_{<i},x_i)\mapsto\langle a,x_i\rangle\bmod2$ with nonzero $x_i$; the arguments are unchanged. The second claim is \cref{rem:absorb:examples} for $\Hcl{\mathrm{chr}}$.
\end{proof}
