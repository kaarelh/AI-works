\section{Discussion}\label{sec:discussion}

\paragraph{Two reasons, one geometry.} Both reasons select at a kink of the hull of (length, fit) and discard what lies to its right (\cref{tab:discussion:reasons}). Noise enters one likelihood term per unit, so every fixed $\lambda>1$ refuses it and per query the split is exact; an error rule enters the term of every input it governs, so $\lambda$ must exceed its reuse factor, and only the near-optimal set, not a single hull vertex, is controlled (\cref{rem:teacher:selected}). The Ville deficiency of the noise and the deficiency $\delta_S$ of the rule both offset the right side, with the same tail (\cref{rem:teacher:hypotheses}).

\paragraph{What counts as one hypothesis.} When a universal mixture is a member of the class, as in SI and in SFI with shared randomness, no model longer than $\ell^*_\lambda$, a bound that does not depend on the data, is selected, and for fixed $\lambda$ a computable teacher's labels, errors included, are eventually predicted (\cref{thm:absorb:absorption}): the universal member flattens every kink beyond its own length (\cref{prop:kink:universal}). With private randomness the model is what is reused across inputs and the noise what is private to each, as the noisy parity shows against set models (\cref{prop:parity:sets}). This choice has a price on shared latent causes, and it ends where inputs carry labelled history (\cref{prop:absorb:price,prop:absorb:history}).

\paragraph{The window and its price.} For error rules incompressible relative to the model, near-optimal product hypotheses are, up to explicit slack, the simple model with noise for $2^{-m}<c<c_{\rm hi}$ (\cref{thm:teacher:main}). The lower end is the reuse factor: a bit of information about the rule costs $c$ per sample in length and saves about $2^{-m}$ per sample in risk. So $\lambda$ must grow linearly with $n$, and the learner is then deliberately inconsistent for the teacher's labels: it discards every component whose rate is below $c$, valid or not, and its guaranteed code length exceeds a program's own loss by $c\,\ell(\pi)$ bits per sample (\cref{rem:limits:schedule}). Imitation data cannot justify this price, because strictly proper scores prefer the teacher's channel, errors included (\cref{prop:limits:noident}); for noise there is no such price.

\paragraph{The gap to realistic errors.} Human labelling errors are often cheap, frequent patterns rather than incompressible sets. In the parity instance steeper selection provably fails for such errors in two ways: a fixed cheap rule defeats every $c$ once the simple model is long enough (\cref{prop:limits:rateblind,lem:limits:robust}), and a rule made of a cheap region plus random points, with the original density and description length, makes the good model non-optimal on about a third of the window (\cref{prop:limits:envelope}). Whether any window survives for structured errors in general is open. Steeper simplicity sorts components by rate, not by validity (\cref{prop:limits:separable}), so by itself it does not tell errors from rare valid rules. We do not expect steeper penalisation alone to solve the general problem of learning a norm from imperfect imitation; it works in one toy case and fails in others.

\paragraph{Neural networks.} For a network whose labels are independent given its parameters, \cref{thm:split:private,thm:recovery:main} apply to countable discretisations; whether a parameter prior behaves like a description-length prior, as \cref{thm:teacher:main} would need, is the bridge question of the companion paper \citep[Question~10.9]{claudeSFI2026fundamentals}, which the slides of \citet{vaintrobhanni2026nnbayes} motivate (\cref{rem:related:nn}).% P1: q:nn:bridges

\subsection{Open problems}\label{sec:discussion:open}

\begin{enumerate}[label=(\arabic*),itemsep=0pt,topsep=2pt]
\item \emph{Recovery.} A computable recovery-time bound in the canonical class; local margins; the joint necessity of $1/(\min(1,\lambda-1)\gamma)$; frozen labels with repeated inputs; misspecification in countable classes (\cref{q:recovery:open}).
\item \emph{Set kinks.} Does a product kink at a model with a random parameter always come with a near-sufficient set model that omits the parameter (\cref{q:parity:open})? Does \cref{prop:algstat:coarse} hold for lower-semicomputable product models (\cref{q:algstat:lsc})?
\item \emph{The teacher's mistakes.} Other model classes (we expect none from majority-like functions); a junta window at level at most $2$ for $0.1233\le p<\frac14$; near-population constants far below $10^{11}$ samples; unequal cell multiplicities; schedules that leave the window (\cref{q:teacher:open}); non-uniform input laws (separable case only, \cref{prop:limits:inputlaw}).
\item \emph{Structured error rules.} Envelopes whose cheap region has error density below one, what is selected above $c_{\rm env}$, and a choice of $c$ that does not use the imitation data (\cref{q:limits:open}).
\item \emph{Shared hypotheses.} Is every lower-semicomputable law of a random partial function dominated by $\MF$ up to a constant (\cref{q:absorb:shared})?
\item \emph{Resource bounds.} Does a time-bounded shared class contain a short member that absorbs everything at $\lambda>1$? Is there a computable map from data sets to $\lambda$-MAPs (\cref{q:related:open})?
\end{enumerate}
