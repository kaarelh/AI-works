\section{Discussion}\label{sec:discussion}

\paragraph{Two reasons, one geometry.} Both reasons select at a kink of the hull of (length, fit) and discard what lies to its right (\cref{tab:discussion:reasons}). Noise enters one likelihood term per unit, so every fixed $\lambda>1$ refuses it and per query the split is exact; an error rule enters the term of every input it governs, so $\lambda$ must exceed its reuse factor, and only the near-optimal set, not a single hull vertex, is controlled (\cref{rem:teacher:selected}). The Ville deficiency of the noise and the deficiency $\delta_S$ of the rule both offset the right side, with the same tail (\cref{rem:teacher:hypotheses}). Imitation needs both: a person with private coins is eventually recovered at every fixed $\lambda>1$; when the environment drives the coins and the input partly reveals them, every $\lambda_n=o(n)$ eventually returns a program for the data kernel instead, and near-copies are guaranteed for $\lambda/n$ in a window (\cref{sec:imit}).

\paragraph{What counts as one hypothesis.} Which kinks exist depends on the class: a universal member flattens every kink far beyond its own length (\cref{prop:kink:universal}), and the full table of a noisy random parity can have a steep product kink at the parity (\cref{prop:parity:kink}) but has no steep set kink (\cref{prop:parity:sets}). So a steeper prior is only as good as the class's notion of one hypothesis; ours is the private-randomness class, with the price and the boundary of \cref{rem:absorb:wyeth}.

\paragraph{The window and its price.} The lower end $2^{-m}$ of the window of \cref{thm:teacher:main} is the reuse factor: a bit about the error rule costs $c$ per sample in length and saves about $2^{-m}$ per sample in risk, so $\lambda$ must grow linearly with $n$. A fixed weight-decay coefficient on an averaged loss has the same form, a Gaussian prior whose precision grows linearly in $n$, and it too can keep a cheaper, worse classifier in the limit (\cref{rem:teacher:weightdecay}). The learner with $\lambda=cn$ is deliberately inconsistent for the teacher's labels, at a price (\cref{rem:limits:schedule}) that imitation data cannot justify, because strictly proper scores prefer the teacher's channel, errors included (\cref{prop:limits:noident}).

\paragraph{The gap to realistic errors.} Human labelling errors are often cheap, frequent patterns rather than incompressible sets. In the parity instance steeper selection provably fails for such errors in two ways: a fixed cheap rule defeats every $c$ once the simple model is long enough (\cref{prop:limits:rateblind,lem:limits:robust}), and a rule made of a cheap region plus random points, with the original density and description length, makes the good model non-optimal on about a third (with the machine constant set to $0$, an illustration) to a quarter ($\kappa=30$) of the window's logarithmic width (\cref{prop:limits:envelope}). Whether any window survives for structured errors in general is open. Steeper simplicity sorts components by rate, not by validity (\cref{prop:limits:separable}), so by itself it does not tell errors from rare valid rules. We do not expect steeper penalisation alone to solve the general problem of learning a norm from imperfect imitation; it works in one toy case and fails in others.

\paragraph{What the toy cases leave open.} The results concern idealised learners in toy worlds; the problems that motivate them remain far from solved. Six gaps are concrete. (1) Data identify behaviour, not mechanism: the selected program is a shortest program in the class for the learned kernel, which may compute it unlike the person and extrapolates off the support of the inputs as that program does (\cref{sec:imit}). (2) Which structure belongs to the person and which to the environment, and with it the complexity weight, are conventions that imitation data cannot settle (\cref{prop:limits:noident}, above): worlds with one data law cannot all be copied reliably by any procedure (\cref{prop:imit:limits}(a)), and when a person's apparent randomness is its own deterministic state, returning the person with fresh coins is a modelling choice. (3) Realistic errors and realistic randomness have structure: like the cheap error rules above, cheap couplings defeat every $c$, and in a toy world no procedure reliably copies a person entangled with its coupling (\cref{prop:imit:cheap,prop:imit:limits}). (4) Exact copies need the same question answered afresh; with frozen labels no procedure recovers every sampler (\cref{prop:recovery:frozen}). (5) People have memory, and excluding hypotheses that learn in context, which absorb what they imitate, is a choice of class (\cref{thm:split:shared,prop:absorb:history,sec:imit}). (6) The steeper predictors are not computable, and whether the $\lambda$-MAPs are is open (\cref{prop:related:computability,q:related:open}); the margin form of \cref{thm:recovery:main} gives no computable sample size in $\Hcl{\times}$ (\cref{prop:recovery:necessity}); and which program counts as the shortest copy, and where every window lies, depend on the hypothesis class and the reference machine (\cref{rem:teacher:numbers}). We see the results as tools for these problems, with toy cases in which the tools work, not as solutions.

\paragraph{Neural networks.} For a network whose labels are independent given its parameters, \cref{thm:split:private,thm:recovery:main} apply to countable discretisations with integer code lengths and Kraft weights whose noise model contains the sampler; whether a parameter prior behaves like a description-length prior, as \cref{thm:teacher:main} would need, is the bridge question of the companion paper \citep[Question~10.9]{claudeSFI2026fundamentals}, which the slides of \citet{vaintrobhanni2026nnbayes} motivate (\cref{rem:related:nn}).% P1: q:nn:bridges

\subsection{Open problems}\label{sec:discussion:open}

\begin{enumerate}[label=(\arabic*),itemsep=0pt,topsep=2pt]
\item \emph{Recovery.} A computable recovery-time bound in the canonical class; local margins; the joint necessity of $1/(\min(1,\lambda-1)\gamma)$; frozen labels with repeated inputs; misspecification in countable classes (\cref{q:recovery:open}).
\item \emph{Set kinks.} Does a product kink at a model with a random parameter always come with a near-sufficient set model of about the complexity of the model without its parameter (\cref{q:parity:open})? Does \cref{prop:algstat:coarse} hold for lower-semicomputable products (\cref{q:algstat:lsc})?
\item \emph{The teacher's mistakes.} Other model classes (we expect none from majority-like functions); a junta window at level at most $2$ for $p_1\le p<\frac14$; near-population constants far below $10^{11}$ samples; unequal cell multiplicities; schedules that leave the window (\cref{q:teacher:open}); non-uniform input laws (separable case only, \cref{prop:limits:inputlaw}).
\item \emph{Structured error rules.} Envelopes whose cheap region has error density below one, what is selected above $c_{\rm env}$, and a choice of $c$ that does not use the imitation data (\cref{q:limits:open}).
\item \emph{Shared hypotheses.} Is every lower-semicomputable law of a random partial function dominated by $\MF$ up to a constant (\cref{q:absorb:shared})?
\item \emph{Resource bounds.} Does a time-bounded shared class contain a short member that absorbs everything at $\lambda>1$? Is there a computable map from data sets to $\lambda$-MAPs (\cref{q:related:open})?
\item \emph{Imitation} (\cref{sec:imit}). A near-imitation theorem when the coin combines $\beta(w)$ with a private residual coin, or when the cells have unequal masses; \cref{thm:imit:main} for $cn$-MAPs at each finite $n$ with probability $1-\delta$, for every response function; whether a coupling that is short to describe but slow to compute is private randomness for a time-bounded class; and whether data other than imitation data, from several environments or from interventions, identify which structure belongs to the person.
\end{enumerate}
