### Solomonoff (2008), "Three Kinds of Probabilistic Induction", The Computer Journal 51(5):566–570 (`solomonoff2008three`)

* **The problem.** Section 4 ("Operator induction") states the *operator induction problem*: "we are given an unordered set of n strings and/or number pairs, [Q_i, A_i]. Given a new Q_{n+1}, what is the probability distribution over all possible A_{n+1}?" Here **"operator induction" names the problem.** Solomonoff gives two solutions.
* **First solution, eq. (9).**
  * Treat each pair as one string D_i = (Q_i, A_i) and use the set-induction mixture of eq. (6): P_M([D_i]) = Σ_j a_j ∏_i P_j(D_i), a mixture of i.i.d. laws on strings with a_j = 2^{−|a_j|}.
  * Then P(A_{n+1}) = P(Q_{n+1}, A_{n+1}) / Σ_A P(Q_{n+1}, A).
  * This is a *joint* solution: it also models the questions. Solomonoff remarks that it "includes regularities in the set [Q_i]".
* **Second solution, eq. (10).**
  * The prior on answers is Σ_j a_0^j ∏_{i=1}^{n+1} O^j(A_i | Q_i).
  * The O^j range over conditional probability distributions computed by partial recursive functions. He writes: "We would like to sum over all total recursive functions, but since this set of functions is not effectively enumerable, we will instead sum over all partial recursive functions".
  * The weights satisfy a_0^j ≈ 2^{−l(O^j)}.
  * Eq. (11) is the posterior-weighted form.
  * **This is our per-query mixture M_pq** of Paper 1, Definition 4.1 (`def:versions:variants`): Σ_i m(i) ∏_t P_i(y_t | x_t) over the lsc conditional semimeasures. A repeated question gets an independent factor, so fresh randomness. On distinct inputs it equals M_prod.
* **Convergence theorem, Section 4.3, eq. (12).**
  * Suppose the answers are generated by a probabilistic algorithm μ(A_i | Q_i) describable in k bits, for the given sequence of questions.
  * Then the μ-expected total squared error of solution (10) is less than k ln 2. The total is summed over all symbols of all answers, with each answer written over the alphabet {0, 1, s}, where s is a separator.
  * The proof applies Hutter's generalisation of the sequence-prediction convergence theorem to arbitrary alphabets.
  * The question sequence is arbitrary: μ(Z_l) is "the probability that μ assigns to Z_l in view of the sequence of Qs".
  * In Section 2 he notes that the proofs also give the same convergence for Kullback–Leibler loss.
* **Section 4.4.** Set induction, eq. (6), is the special case Q_i = empty, so the theorem covers it.
* **Further remarks** (usable as motivation, with attribution):
  * Switching to a new domain of questions raises k.
  * A priori information can be put into the reference machine.

### Solomonoff (1999), "Two Kinds of Probabilistic Induction", The Computer Journal 42(4):256–259 (`solomonoff1999two`)

* It treats prediction of unordered sets of strings and gives two solutions:
  * Section 3.1: a universal distribution over bags, a universal machine printing a punctuated string, summed over orderings;
  * Section 3.3: the mixture Σ_j 2^{−|a_j|} ∏ P_j(D_n).
* It describes supervised categorisation and question–answer pairs as examples of "**stochastic operator induction**": we want a stochastic function that, given a question, outputs a probability distribution on answers.
* It gives no formula specific to operators and no convergence theorem for unordered data. It says "It is likely that a similar error bound will be found for unordered data".

### Consequences for our papers

1. **Solomonoff's own solutions.** His solution (10) is M_pq, which equals M_prod on distinct inputs. His solution (9) is a joint version that also models the inputs; we have no numbered object for it.
2. **Our versions are not in his papers.** These are:
   * the one-tape law M_F, one fair-coin tape shared by all questions, giving a random partial function;
   * the coin-free version W;
   * the Kolmogorov version K_F;
   * the history-aware M_H;
   * all their comparisons.
3. **Credit his theorem.** Eq. (12) is the expected squared-error form of the dominance of (10) over every k-bit μ, for an arbitrary question sequence; KL is mentioned in his Section 2.
   * Paper 1's pathwise log-loss bound for M_pq (`prop:learn:perquery`(b)) is the standard dominance form of the same fact. Its i.i.d. KL bound, part (c), is a standard consequence. Credit Solomonoff (2008, eq. (12)) there, in prose next to the statement.
   * The dominance and regret statements for M_F (`thm:learn:dominance` and relatives) are ours in this form, because the randomness is shared. They follow by the same kind of dominance argument; say so where they are stated, without overclaiming.
4. **Update every place that calls operator induction "unverified" or "in this spirit":**

## 3. Naming (binding)

* **Solomonoff operator induction (SOI)** is the family of universal-prior Bayesian solutions to Solomonoff's operator-induction problem, as "Solomonoff induction" is for sequence prediction. Use the acronym SOI. "SFI" must not appear in printed text.
* **The versions,** with how to refer to them:

  | object | how to refer to it |
  |---|---|
  | M_F | **the one-tape version**: the law of a universal machine that reads one fair-coin tape shared by all questions, conditioned on the data. "SOI" without qualification means this version. |
  | M_pq | **the per-query version**, Solomonoff's solution (10), or "Solomonoff's per-query solution". |
  | M_prod | the product mixture: private randomness per input, on data sets. |
  | W | the coin-free (deterministic) version, also "the program mixture". |
  | K_F | the Kolmogorov version. |
  | M_H | the history-aware version, written SOI^hist (macro `\SFIhist`, which now prints SOI^hist; likewise `\SFIset`, `\SFIcount`, `\SFIpairs`, `\LSFI` → L_SOI). |
  | eq. (9) | Solomonoff's joint solution. Mention it in `rem:versions:operator` only. |

* **The default convention is stated once,** in `setting.tex` where M_F is defined: "When we say SOI without qualification, we mean the one-tape version $\MF$." Give a one-sentence reason:
  * it treats the labelling as one random function, so labels of repeated inputs agree;
  * it is the law of a single universal machine and dominates every function machine;
  * on distinct inputs it agrees with the other versions up to K(dom D) + O(1) bits (Theorem 4.4, `thm:versions:chain`).
* **Where the distinction matters, name the version explicitly.** This covers:
  * repeated inputs and fresh noise;
  * shared versus private randomness (`prop:versions:shared`, `rem:versions:randomness`);
  * the per-query proposition;
  * Paper 2's private-randomness class;
  * absorption.

  Every statement that said "SFI" and meant M_F must still mean M_F.
* **"Function induction" disappears from printed text,** with two exceptions:
  * one footnote, merged into the existing credit footnote near the definition in `setting.tex`: "The author's working notes call this setting function induction \citep{hanni2026notes}.";
  * the `note` field of `hanni2026notes` in `core.bib`, which names the note as it is called in the notes repository. Leave it.
* **"Function machine"** (a machine reading one tape, queried at each input) stays: it names the class of machines, not the induction.
* **Titles** (already changed in `main.tex` and in `core.bib`, which must stay identical in both papers):
