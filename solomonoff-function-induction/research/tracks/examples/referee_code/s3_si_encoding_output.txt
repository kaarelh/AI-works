Reading: with delimiter-free blocks the proxy pays about 1-9 bits of label loss, varying with the
permutation: it must infer where the blocks end, and hypotheses with other block lengths survive for
a while.  With the prefix code it reads n from the first header, before any label, and pays < 0.1 bits
(the residual weight of the null model) for every n.  The proxy prior is not universal, so the raw
column illustrates the mechanism only; it is not evidence about the growth rate K(n).
