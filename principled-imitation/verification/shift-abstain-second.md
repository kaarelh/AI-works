### 1.1 Corollary 3.6 (N7), as restated by the editor: CORRECT

(a) Reduction. For 0 ≤ i ≤ h and 1 ≤ x ≤ h, h_i(x) = 1[x ≤ i]; the members h_0, …, h_h restricted to {1, …, h} are exactly the threshold class of Theorem 3.3 with N replaced by h + 1 (h_h is the all-ones labelling, as h_{N−1} is in Theorem 3.3). Members of H outside these h + 1, and the members h_{h+1}, …, h_{N−1}, only enlarge the class, so a learner for H on the inputs 1, …, h is a learner for the class of Theorem 3.3 with N = h + 1, and the uniform average over those h + 1 members bounds the worst of them. Hypotheses: Theorem 3.3 needs N ≥ 2, here h + 1 ≥ 2 since h ≥ 1. The consequence: Qu ≤ Q on every run; if Q + 1 > (h + 1)/2 then Q ≥ (h + 1)/2 − 1 since Q is an integer greater than (h − 1)/2; otherwise Q + 1 ≥ 3(h + 1)/(16s). So Q ≥ min{(h + 1)/2, 3(h + 1)/(16s)} − 1. With N = 2^K, h = N − 1 this is 2^K·min{1/2, 3/(16s)} − 1. All correct.

(b) (i) is Proposition 4.3(a) with Theorem 4.1 (the asked rounds are the abstention rounds; count ≤ log(W/w(f))/log(1/(1 − η)) ≤ K/log(1/(1 − η)) ≤ K ln 2/η since −ln(1 − η) ≥ η). (ii) Enumeration: f ∈ V always because w(f) = 2^(−K) ≥ 2^(−k) and f is consistent; |{g : w(g) ≥ 2^(−k)}| ≤ W·2^k ≤ 2^k; each question is put where two members of V differ, the answer refutes at least one member other than f, and refuted members never return; so at most 2^k − 1 questions; where no two members differ the common answer is f's. Correct, and indeed (P2) is not used.

(c) The reading is consistent with (a) and (b): upper bound 2^k − 1 with no silent error; lower bound 2^(K−1) − 1 even for s → 0, so within a factor 2 at s = 0 for k = K.

Numerical check (`shift-abstain_second_thresholds.py`). ### 1.2 Example 4.5a: CORRECT

(1) For a rare cell c, the human systems of f₀ and f_c differ exactly on runs that call c, of probability p_π = 1 − (1 − π)^L = 4σ. If c is not asked (probability 1 − π_c under f₀), the transcripts under f₀ and f_c coincide, the deployed system is the same, and on runs that call c its outcome (in {0, 1}) is wrong for one of the two; so Fail(f₀) + Fail(f_c) ≥ (1 − π_c)·4σ (this is LB Lemma 1.10(1) with one patch; I checked the argument directly, not the lemma's text). Both ≤ σ forces π_c ≥ 1/2; the patches {c} are disjoint, so the expected number of questions under f₀ is at least Σ_c π_c ≥ N₁/2. (2) If the answer at c₀ is 1 the human is f_{c₀} (the only member with value 1 at c₀) and the deployed system is f_{c₀}: no abort, no error. If it is 0 the human is f₀ or a rare f_c; the system answers 0 at c₀ (right for all of them) and abstains at the first rare call; a run without a rare call has outcome 0, which is the human system's outcome. Abort probability 1 − (1 − N₁π)^L = a. (3) N₁π = 1 − (1 − a)^(1/L) ≥ a/L because (1 − a/L)^L ≥ 1 − a; π = 1 − (1 − 4σ)^(1/L) ≤ ln(1/(1 − 4σ))/L ≤ 4σ/((1 − 4σ)L); so N₁ ≥ a(1 − 4σ)/(4σ) ≥ a/(4σ) − 1 and N₁/2 ≥ a/(8σ) − 1/2. Edge cases: σ = p_π/4 < 1/4 for π < 1, so 1 − 4σ > 0; N₁π < 1 since a < 1.

Numerical check (`shift-abstain_second_ex45a.py`): the quoted numbers for L = 10 (π from σ = 10⁻³, 10⁻⁴, 10⁻⁵; N₁ = 55, 551, 5516 give a = 0.1998, 0.1998, 0.2000; N₁ = 167, 1673, 16741 give a = 0.4998, 0.4998, 0.5000) agree with the proof file; the inequality of (3) holds in all 2891 grid cases (L from 1 to 100, N₁ from 1 to 2000, π on a grid); item 2 was confirmed by exact enumeration of all runs for four small settings (silent failure 0 for every member, abort probability a, 0 for f_{c₀}). ### 1.3 Theorem 5.3(b), rewritten: CORRECT

Let g′ ∈ 𝒞 = 𝒞^rat_α(D) with g′(x) ≠ f(x). g′ has positive posterior weight, so it is consistent with D, which f produced; hence g′ = f on A. For functions consistent with D, w_D(ν) = w(ν)/ξ(D), so w_D(g′) ≥ α·w_max(D) gives w(g′) ≥ α·max{w(ν) : ν consistent} = α·2^(−K_D). The set {g′ ≠ f} is decidable, contains x, misses A, and by (P2) has complexity at most log(1/w(g′)) + log(1/w(f)) + c₂ ≤ K_D + log(1/α) + K + c₂. The case θ_𝒞(x) > 0: for functions S_𝒞(·|x) is 1 at a common value and 0 otherwise, so θ_𝒞(x) > 0 means two members differ at x, and one differs from f. The ratio set is nonempty (it contains a heaviest hypothesis) and finite, so "all members answer f(x)" makes the rule answer f(x). The argument nowhere uses f ∈ 𝒞, which is the case the prover's proof missed. Numerical check (`shift-abstain_second_coverage.py`, part 1): in a finite model of (P2) with c₂ = 0 (tests are the difference sets with complexity log(1/w(g)) + log(1/w(g′)), plus random extra tests), 40 random classes, every human, every asked set, five values of α: 86181 cases in which a member of the ratio set differs from f, no violation; 18285 of the (f, A, α) triples have f outside the ratio set, so the repaired case is exercised.

### 1.4 Proposition 6.2(4): CORRECT

First bound. Under Protocol R[Nov_s] the asked inputs form a sequence as in Setting 1.0. On every path, an asked round with sep(x_t; A(D_{<t})) < s uses up a test Q with K(Q) < s, x_t ∈ Q, Q ∩ A(D_{<t}) = ∅; after the round x_t ∈ A, so Q is never used again; there are at most 2^s − 1 programs of length below s, hence at most 2^s − 1 such rounds. The frozen abstain variant is deterministic and abstains exactly where sep < s, and the run halts there, so Σ_{j≤ℓ_t} 1[sep(x_{t,j}; A(D_{<t})) < s] = 1[Halt_t] (the aborting call is counted in ℓ_t and can be asked, as Protocol R[𝔯] says). Lemma 1.2 gives Pr[asked round t is of this kind] = Pr[Halt_t]/L; summing, Σ_t Pr[Halt_t] ≤ L·(2^s − 1). Second bound. A wrong answer of the round-t run is a call with sep ≥ s and g_{D_{<t}}(x) ≠ f(x); the aborting call has sep < s and is not counted; so Σ_j φ = Wr_t for φ(D, x) = 1[sep(x; A(D)) ≥ s, g_D(x) ≠ f(x)]. An asked round of that kind refutes g_{D_{<t}}, whose weight is at least w(f) (f is consistent and g_D is a heaviest consistent member; a heaviest one exists because only finitely many members have weight above w(f)); refuted members never return, f is never refuted, and at most W/w(f) ≤ 2^K members have weight at least w(f); so at most 2^K − 1 such rounds (at most ⌊2^K⌋ − 1 when K is not an integer). Lemma 1.2 and the last sentence of Lemma 1.2 give the statements for round T. Numerical check (`shift-abstain_second_nov.py`): a finite stand-in (finite family of tests with integer complexities, 12 weighted functions, random adaptive scaffolds with horizon 4, n = 60 rounds, s = 2 and 3, 12 settings, 4000 rehearsals each): on every simulated path the two counts hold (number of asked rounds of the first kind at most the number of tests of complexity below s; of the second kind at most the number of members at least as heavy as f, minus one); the Monte Carlo sums Σ_t Pr[Halt_t] and Σ_t E[Wr_t] agree with L times the expected counts (the identity of Lemma 1.2) and are below the bounds; in one setting the first bound is nearly attained (estimate 8.038 ± 0.024 against the bound 8, the exact expectation being just below 8), so the factor L is not loose.
