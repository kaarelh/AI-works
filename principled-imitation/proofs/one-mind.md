**In brief.** (1) R4 is correct. The constant improves to 2L²/(L+1), and for K > 1 this is the exact constant up to a factor (1 − 1/L)(1 − 1/K). The hypotheses may be stochastic; what the proof needs is a deterministic human. (2) For a human who is not deterministic R4 has no version: with K = 1 bit a posterior draw per run stays at a fixed total-variation distance from the human system for any prescribed number of rounds (the class is built for that number), because single answers at fresh inputs cannot refute hypotheses whose answers within one run are dependent, and a posterior draw per run reproduces that dependence. The per-call mixture is exact in the same example. Recorded runs of the human system support a posterior draw per run (Theorem A); rehearsal data do not, even when all calls of the driver's runs are put to the human; data in between are open. One member kept for good is a different matter. A draw from the final posterior fails (the same example); the member of largest posterior weight fails (the codebook class, a known counterexample); a member selected with the weights squared has a run law with H² < L·(28·K ln 2 + 40·ln(1/δ))/n from the human system's (Theorem 3.8, added in editing and verified by the second check). ## 1. Setting

**Definition 1.1 (class, posterior, mixture).** X and Y are countable sets. A *hypothesis* ν assigns to every x ∈ X numbers ν(y|x) ≥ 0, y ∈ Y, with Σ_y ν(y|x) ≤ 1; it is identified with the probability kernel on Y_⊥ that gives ⊥ the missing mass. A *sampler* is a hypothesis with no missing mass; a function g: X → Y_⊥ is the hypothesis δ_{g(x)}. H is a countable set of hypotheses with weights w(ν) > 0 and W := Σ_ν w(ν) ≤ 1. The human is a sampler P ∈ H (assumptions A1 and A2); when P is a function it is written f. For a list D of pairs (x_i, y_i): ν(D) := Π_i ν(y_i|x_i), ξ(D) := Σ_ν w(ν)ν(D), the posterior is w_D(ν) := w(ν)ν(D)/ξ(D) when ξ(D) > 0, and the mixture is M_D(y|x) := Σ_ν w_D(ν)ν(y|x). For a class of functions, w_D is w restricted to the *version space* V_D := {g ∈ H : g(x_i) = y_i for all i} and normalised.

**Definition 1.2 (scaffold, runs).** A scaffold Π of horizon L ≥ 1 has top-level inputs z ~ D₀ on a countable set, internal randomness ρ ~ λ, and maps next_j(z, ρ, y_1, …, y_{j−1}) ∈ X ∪ {STOP}, j ∈ [L] (next_{L+1} := STOP). The run answered by an answerer A on (z, ρ) is the sequence (z, ρ, y_1, …, y_T): x_j := next_j(z, ρ, y_<j), the run ends at the first STOP, T ≤ L is its number of calls, and y_j is A's answer at call j. A hypothesis ν answers call j by an independent draw from ν(·|x_j). Q_A is the law of the run. For a function g the run on (z, ρ) is determined; it is written τ^g(z, ρ), with inputs x^g_j(z, ρ) and length T^g(z, ρ). The *human system* is Q_P; for a deterministic human its run on (z, ρ) is τ^f(z, ρ).

**Definition 1.3 (three drivers).** A *rehearsal with driver 𝔡* runs for rounds t = 1, 2, …. In round t, with D_{t−1} the pairs collected so far and w_t := w_{D_{t−1}}:
1. the driver produces an answerer A_t from D_{t−1} (and fresh randomness);
2. (z_t, ρ_t) ~ D₀ ⊗ λ is drawn and Π is run with A_t; this uses compute only;
3. J_t is drawn uniformly from [L], independently of everything else; if the run made at least J_t calls, the input x_t := x_{t,J_t} of call J_t is put to the human, the answer y_t ~ P(·|x_t) is drawn independently of the past given x_t (A1, A3), and (x_t, y_t) is appended.

The drivers are:
* **mixture** (Protocol R of the candidate theory): A_t answers every call by a fresh draw from M^(t) := M_{D_{t−1}}; equivalently, a new hypothesis is drawn from w_t at every call;
* **posterior draw** (variant R′ of the candidate theory, "one mind per run"): one ν_t ~ w_t is drawn and answers every call of the run;
* **first consistent** (for a class of functions with a fixed enumeration g_1, g_2, …): A_t is the first g_i in V_{D_{t−1}}. If the enumeration is by non-increasing weight this is the "current simplest consistent hypothesis" (the highest-weight member of the version space).

For a deterministic human a run on (z, ρ) is called *unfaithful* if it differs from τ^f(z, ρ), and a call is *unfaithful* if its answer differs from f at its input. These are the notions of the outline: for a deterministic human the shadow answer at input x is f(x).

**Lemma 1.4 (first deviation). PROVED.** Let f be a function, fix (z, ρ), and let (y_1, …, y_T) be the answers of any run on (z, ρ), with inputs x_1, …, x_T. Let σ := min{j ≤ T : y_j ≠ f(x_j)} (σ := ∞ if there is no such j). Then:
(a) for every j ≤ min(σ, T): j ≤ T^f and x_j = x^f_j;
(b) the run equals τ^f(z, ρ) if and only if σ = ∞; so a run is unfaithful if and only if it has an unfaithful call, and its first unfaithful call is made at an input of the human system's run;
(c) if the run is answered by a hypothesis ν, and e_ν(x) := 1 − ν(f(x)|x), then for j ≤ T^f: Pr[σ ≥ j] = Π_{i<j}(1 − e_ν(x^f_i)) and Pr[σ = j] = e_ν(x^f_j)·Π_{i<j}(1 − e_ν(x^f_i)); and Pr[σ = ∞] = Π_{i≤T^f}(1 − e_ν(x^f_i)).

*Proof.* (a) By induction on j. For j = 1, x_1 = next_1(z, ρ) = x^f_1 (if T ≥ 1 then next_1 ≠ STOP, so T^f ≥ 1). If j ≤ min(σ, T) and j ≥ 2, then y_i = f(x_i) = f(x^f_i) for i < j by the induction hypothesis and the definition of σ, so the history before call j is that of the f-run; hence next_j has the same value in both runs, it is not STOP because j ≤ T, so j ≤ T^f and x_j = x^f_j. (b) If σ = ∞, the same induction shows that both runs have the same histories and stop at the same call. If σ < ∞, call σ exists in both runs by (a), with the same input, and the answers differ. (c) By (a), as long as no wrong answer has been given the inputs are those of the f-run, and the answer at x^f_i is f(x^f_i) with probability 1 − e_ν(x^f_i), independently of the earlier answers. ∎

**Lemma 1.5 (potential). PROVED (standard; it is Lemma 4.2 of `proofs/rehearsal-core.md`).** Let the human be a function f ∈ H, and let questions x_1, x_2, … be put to the human in any way, D_k the first k pairs. Put m_k := 1 − M_{D_{k−1}}(f(x_k)|x_k), the posterior mass that the k-th answer removes (for a class of functions: m_k = w_{D_{k−1}}{g : g(x_k) ≠ f(x_k)}). Then on every path, for every n,

  Π_{k≤n} (1 − m_k) = ξ(D_n)/W ≥ w(f)/W, hence Σ_{k≤n} m_k ≤ Σ_{k≤n} −ln(1 − m_k) ≤ ln(W/w(f)) ≤ K ln 2.

*Proof.* f(D_n) = 1 for every list of answers of f, so ξ(D_n) ≥ w(f) > 0 and the posterior is defined. M_{D_{k−1}}(f(x_k)|x_k) = ξ(D_k)/ξ(D_{k−1}), the product telescopes, ξ(∅) = W; then (E2). ∎

**Lemma 1.6 (the same for a human who is not deterministic; standard). ADDED in editing** (it is needed in Section 3; parts (a) and (b) are Lemma 4.1 of `proofs/rehearsal-core.md`, the regret bound for Bayes mixtures on adaptively chosen questions, where the integrability is shown in full). Let the human be a sampler P ∈ H. Let questions x_1, x_2, … be put to the human in any way: each question is a function of the earlier pairs and of randomness independent of the human's coins, and the answer y_k is drawn from P(·|x_k) given the past and x_k (A1, A3). D_k is the list of the first k pairs. Then:

(a) almost surely, for every n: P(D_n) > 0 and Π_{k≤n} M_{D_{k−1}}(y_k|x_k)/P(y_k|x_k) = ξ(D_n)/(W·P(D_n)) ≥ w(P)/W;

(b) Σ_{k≥1} E[KL(P(·|x_k) ‖ M_{D_{k−1}}(·|x_k))] ≤ ln(W/w(P)) ≤ K ln 2;

(c) for every hypothesis ν and every input x: E_{y ~ P(·|x)}[√(ν(y|x)/P(y|x))] = 1 − H²(ν, P)(x).

*Proof.* (a) An answer of probability 0 under P occurs with probability 0, so P(D_n) > 0 almost surely, and ξ(D_n) ≥ w(P)·P(D_n). The product of the factors M_{D_{k−1}}(y_k|x_k) = ξ(D_k)/ξ(D_{k−1}) telescopes to ξ(D_n)/W. (b) By (a), Σ_{k≤n} ln(P(y_k|x_k)/M_{D_{k−1}}(y_k|x_k)) ≤ ln(W/w(P)) on almost every path. Given the past and x_k, the k-th summand has the conditional mean KL(P ‖ M_{D_{k−1}})(x_k) ≥ 0, which is finite because M_{D_{k−1}} ≥ w_{D_{k−1}}(P)·P. Take expectations and let n grow. (c) The left side is Σ_{y: P(y|x)>0} √(ν(y|x)·P(y|x)), and the terms with P(y|x) = 0 contribute nothing to Σ_y √(ν(y|x)P(y|x)) = 1 − H²(ν, P)(x). ∎

## 2. R4: one posterior draw per run, deterministic human

Throughout this section the human is a function f ∈ H; the other members of H may be samplers or semimeasures. The rehearsal has the posterior-draw driver. For a round t and a pair (z, ρ) let

  u_t(z, ρ) := Pr[ the run of ν_t on (z, ρ) is unfaithful | D_{t−1} ],

the probability being over ν_t ~ w_t and over the answers of ν_t. The probability that the run of round t is unfaithful, given D_{t−1}, is ū_t := E[u_t(z_t, ρ_t) | D_{t−1}]. Put

  ψ_L(u) := u − u²·(L − 1)/(2L) for u ∈ [0, 1].

ψ_L is increasing and concave on [0, 1], ψ_1(u) = u, and u·(L + 1)/(2L) ≤ ψ_L(u) ≤ u.

**Theorem 2.1 (R4). PROVED; the constant and the generality are MODIFIED.** Assume A1 to A3 and a deterministic human f ∈ H. For the rehearsal with the posterior-draw driver,

  Σ_{t≥1} E[ ψ_L(u_t(z_t, ρ_t)) ] ≤ L·ln(W/w(f)) ≤ L·K ln 2.  (2.1)

Consequently

  Σ_{t≥1} Pr[ the run of round t differs from the human system's run on (z_t, ρ_t) ] = Σ_t E[ū_t] ≤ (2L²/(L + 1))·K ln 2 < 2L·K ln 2.  (2.2)

*Proof.* Fix t, condition on D_{t−1}, and fix (z, ρ); write x^f_j, T^f for the human system's run on (z, ρ). For ν ∈ H let σ_ν be the index of the first unfaithful call of the run of ν on (z, ρ) (Lemma 1.4), and put, for j ∈ [T^f],

  p_j := Σ_ν w_t(ν)·Pr[σ_ν = j],  so that u := u_t(z, ρ) = Σ_{j≤T^f} p_j

by Lemma 1.4(b). Let ē(x) := 1 − M^(t)(f(x)|x) = Σ_ν w_t(ν)e_ν(x).

*Step 1: ē(x^f_j) ≥ p_j.* By Lemma 1.4(c), Pr[σ_ν = j] ≤ e_ν(x^f_j); average over ν ~ w_t.

*Step 2: the removed mass.* Let m_t be the posterior mass removed in round t (m_t := 0 if no question is asked); m_t = ē(x_t) if a question is asked. Let ν_t be the driver and σ := σ_{ν_t}. If J_t ≤ min(σ, T^f), then by Lemma 1.4(a) and (b) the run has at least J_t calls (if σ = ∞ the run is the f-run; if σ < ∞ the run has at least σ calls) and its J_t-th input is x^f_{J_t}; so a question is asked and m_t = ē(x^f_{J_t}) ≥ p_{J_t}. Since m_t ≥ 0 always, and J_t is uniform on [L] and independent of the run,

  E[m_t | D_{t−1}, z, ρ] ≥ (1/L)·Σ_{j≤T^f} Pr[σ ≥ j]·p_j, where Pr[σ ≥ j] = 1 − Σ_{i<j} p_i

(the probability is over ν_t ~ w_t and its answers; σ ≥ j means that the first unfaithful call is not among the calls before j).

*Step 3: algebra.* Σ_j p_j·(1 − Σ_{i<j} p_i) = u − Σ_{i<j} p_i p_j = u − ½(u² − Σ_j p_j²) ≥ u − ½u² + u²/(2L) = ψ_L(u), because Σ_j p_j² ≥ (Σ_j p_j)²/T^f ≥ u²/L by the Cauchy–Schwarz inequality. So E[m_t | D_{t−1}, z, ρ] ≥ ψ_L(u_t(z, ρ))/L.

*Step 4: summation.* (z_t, ρ_t) is independent of D_{t−1}, so E[m_t] ≥ E[ψ_L(u_t(z_t, ρ_t))]/L. By Lemma 1.5, Σ_t m_t ≤ ln(W/w(f)) on every path. This gives (2.1). For (2.2) use ψ_L(u) ≥ u·(L + 1)/(2L). ∎

*What is used.* The human's answers remove hypotheses for certain: a wrong answer at the asked input costs a hypothesis the factor ν(f(x)|x). The freshness of J_t and of (z_t, ρ_t) (A3). Nothing about the class, the prior or the scaffold. *What it does not say.* Nothing about the number of unfaithful calls within an unfaithful run (Section 4), and nothing for a stochastic human (Section 3).

**Corollary 2.2 (deployment). PROVED.** After n rounds draw U uniformly from [n] and ν ~ w_U.
(a) *A fresh draw for each run.* A deployed run differs from the human system's run on the same (z, ρ) with probability at most 2L²·K ln 2/((L + 1)·n).
(b) *One draw kept for good.* With u(ν) := Pr_{z,ρ}[the run of ν is unfaithful]: E[u(ν)] ≤ 2L²·K ln 2/((L + 1)·n), so for every δ ∈ (0, 1), with probability at least 1 − δ over the rehearsal, U and the draw, u(ν) ≤ 2L²·K ln 2/((L + 1)·n·δ).

*Proof.* E[u(ν)] = (1/n)Σ_{t≤n} E[ū_t]; then (2.2), and Markov's inequality for (b). ∎

**Remark 2.3 (the candidate's proof, line by line).** The candidate takes two independent draws g, g′ ~ w_t and the event {j*(g′) ≤ j*(g), j*(g′) < ∞, J = j*(g′)}, where j*(h) is the first index of the f-run at which h differs from f. **Example 2.4 (the scaffold used in Proposition 2.5 and Example 5.2).** Let N_z ≥ 1 and L ≥ 1. Inputs: X := ([N_z] × [L]) ∪ {⋆}; answers {0, 1}. The scaffold Π^path_{N_z,L} draws z uniformly from [N_z] and has no internal randomness; next_j(z, y_<j) := (z, j) if y_i = 0 for all i < j, and := ⋆ otherwise. Every run has exactly L calls. The human is f ≡ 0, so the human system asks (z, 1), …, (z, L). A hypothesis that answers 1 at (z, j) and 0 at ⋆ sends the run to ⋆ for all later calls.

**Proposition 2.5 (the constant of Theorem 2.1 is sharp, and the order L·K is attained). NEW.** Let L ≥ 2, let K > 0 with ε := 2^(−K), and η > 0. There are N_z and n such that for the scaffold Π^path_{N_z,L}, the human f ≡ 0 with weight w(f) = ε, and the class H := {f} ∪ {g_a : a ∈ [L]^[N_z]}, where g_a(z, j) := 1[a(z) = j] and g_a(⋆) := 0, with weights w(g_a) := (1 − ε)/L^(N_z), the rehearsal with the posterior-draw driver has

  Σ_{t≤n} Pr[the run of round t is unfaithful] ≥ S(L, K) − η,  S(L, K) := Σ_{k≥0} u_k/(1 − u_k(L − 1)/(2L)),  u_k := R_k/(1 + R_k),  R_k := (2^K − 1)(1 − 1/L)^k,

and S(L, K) ≥ (2L/(L + 1))·ln(1 + (L + 1)(2^K − 1)/(2L))/ln(L/(L − 1)) ≥ (2L(L − 1)/(L + 1))·(K − 1) ln 2.

So for K > 1 the bound (2.2) cannot be improved by more than the factor (1 − 1/L)(1 − 1/K). For K ≤ 1 the last lower bound is empty, and the comparison is between the series and (2.2) directly: for example S(3, 1) = 2.202 against 3.119 (Section 7.6). The class of the example is large: it has L^(N_z) + 1 members, and the proof takes N_z ≥ n³/η top-level inputs for n rounds; K does not grow with it, because the weight of f is fixed.

*Proof.* Every g_a deviates on every z, at position a(z): its run is unfaithful for every z. So given the data, u_t(z) is the posterior mass of H ∖ {f}, whatever z is.

*The posterior.* The prior on a is uniform, hence a product over z of uniform laws on [L]. A question at ⋆ removes nothing. A question at (z, j) is answered 0 and removes exactly the g_a with a(z) = j. So the posterior on a is again a product: a(z) is uniform on the set of positions j such that (z, j) has not been asked. If z is *fresh* (no (z, ·) asked before), a question at (z, j) removes the fraction 1/L of the mass of H ∖ {f}.

*One round at a fresh z.* Let R be the ratio of the posterior mass of H ∖ {f} to that of f, so u = R/(1 + R). With probability 1 − u the driver is f; the question is (z, J) and R is multiplied by 1 − 1/L. With probability u the driver is some g_a, and a(z) is uniform on [L]; if J ≤ a(z) the question is (z, J) and R is multiplied by 1 − 1/L; if J > a(z) the question is ⋆ and R does not change. Pr[J ≤ a(z)] = (L + 1)/(2L). So, as long as the top-level inputs are fresh, R moves from R_k to R_{k+1} with probability s_k := 1 − u_k(L − 1)/(2L) and stays otherwise, and each round spent at level k is unfaithful with probability u_k. The expected number of rounds at level k is 1/s_k, so the expected number of unfaithful rounds at level k is u_k/s_k, and the total over all levels is S(L, K), a convergent series (u_k ≤ R_k decays geometrically).

*Finitely many top-level inputs.* Choose n with Σ_{t≤n} E[u^∞_t] ≥ S(L, K) − η/2 for the chain just described (monotone convergence), then N_z ≥ n³/η. With probability at least 1 − n²/(2N_z) the first n top-level inputs are distinct, and on that event the rehearsal coincides with the chain (driven by the same coins); so Σ_{t≤n} E[u_t] ≥ Σ_{t≤n} E[u^∞_t] − n·n²/(2N_z) ≥ S(L, K) − η.

*The lower bound for S.* With c := (L + 1)/(2L) and φ(R) := u/(1 − u(L − 1)/(2L)) = R/(1 + cR), which is increasing in R: the terms φ(R_k) decrease in k, so S ≥ ∫_0^∞ φ(R_0 e^(−λx)) dx with λ := ln(L/(L − 1)) and R_0 := 2^K − 1. Substituting R = R_0 e^(−λx): the integral is (1/λ)∫_0^{R_0} dR/(1 + cR) = ln(1 + cR_0)/(cλ). Finally c ≥ ½ gives 1 + cR_0 ≥ (2^K + 1)/2 ≥ 2^(K−1), and λ ≤ 1/(L − 1). ∎

The script `one-mind_r4.py` evaluates S(L, K) (for L = 100 and K = 100 bits it is 1.951·L·K ln 2, between the two bounds 13452 and 13726), checks (2.1) and (2.2) by simulation on eight random classes and scaffolds with runs of variable length, and simulates this example directly (Section 7.1).

**Remark 2.6 (comparison with the mixture on the same example).** With the mixture driver the round at a fresh z asks on the main path with probability (1/L)Σ_J (1 − u/L)^(J−1), which is about 1 − 1/e = 0.63 when u is near 1, against (L + 1)/(2L), about ½, for the posterior draw. So the posterior draw learns more slowly here by a factor of about 1.26, and its count of unfaithful runs is about twice the mixture's count of unfaithful calls. Exactly (added from the check report, and re-derived): at level k the mixture's run has an unfaithful call with probability 1 − (1 − u_k/L)^L, and at most one, and the level is left with probability (1 − (1 − u_k/L)^L)/u_k per round; so the mixture's expected number of unfaithful calls at level k is u_k, and its total is Σ_k u_k, against Σ_k u_k/(1 − u_k(L − 1)/(2L)) for the posterior draw (6897.3 against 13523.3 for L = K = 100). This is the whole difference for a deterministic human as long as the object of interest is the probability of a fully faithful run.

## 3. A human who is not deterministic: R4 has no version; what one program can still have

**3.0 What an unfaithful run is when the human is stochastic.** Under the posterior-draw driver the run of round t has, given D_{t−1}, the law

  Q̄_t := Σ_ν w_t(ν)·Q_ν.

In every coupling of this run with a run of the human system the two differ with probability at least TV(Q̄_t, Q_P), with equality for the best coupling. So TV(Q̄_t, Q_P) is the least possible probability of an unfaithful run. For a deterministic human it equals ū_t of Section 2 (both laws have the same marginal on (z, ρ), and given (z, ρ) the human system's run is the single point τ^f(z, ρ)). The larger quantity Σ_ν w_t(ν)·TV(Q_ν, Q_P) is not the right one. For a hypothesis that is a function g it equals 1 − E_{(z,ρ)}[Q_P(τ^g(z, ρ) | z, ρ)], the probability that the human system does not produce the run of g; this is close to 1 when the human system's runs are spread out, even if Q̄_t = Q_P (and it is small for a nearly deterministic human and g = its most likely answers). The examples below refute a bound for the smaller quantity, hence for both.

**Example 3.1 (one question asked three times). REFUTED: R4 for a human who is not deterministic (one posterior draw per run).** Let ε ∈ (0, ½] and N_z ≥ 1. X := [N_z], Y := {0, 1}. The human answers every input z with 1 ("right") with probability 1 − ε and with 0 with probability ε, independently each time it is asked: P(1|z) = 1 − ε. The class is H := {P} ∪ F, where F is the set of all functions s: [N_z] → {0, 1}, with weights w(P) := ½ and w(s) := ½·Π_z P(s(z)|z). The weights add up to 1 and K = 1 bit. The scaffold draws z uniformly from [N_z] and makes three calls, each with the input z (its outcome may be the majority of the three answers). So L = 3.

Consider a rehearsal with any driver and one question per round; the question of round t is z_t whichever call is chosen. Let 𝒟_t be the event that z_1, …, z_{t−1} are distinct; Pr[𝒟_t] ≥ 1 − (t − 1)²/(2N_z). Call z *fresh* in round t if it is none of z_1, …, z_{t−1}. On 𝒟_t:

(a) w_t(P) = ½, and under the posterior the members of F have s(z_i) = y_i at the asked inputs and independent values with law P(·|z) at the fresh inputs.

(b) *Posterior draw per run.* For fresh z, TV(Q̄_t(·|z), Q_P(·|z)) = (3/2)·ε(1 − ε). Hence TV(Q̄_t, Q_P) ≥ (3/2)·ε(1 − ε)·(1 − (t − 1)/N_z). The majority of the three answers is 0 with probability ½·ε + ½·(3ε² − 2ε³) at a fresh z, against 3ε² − 2ε³ in the human system.

(c) *Per-call mixture.* For fresh z, Q_{M^(t)}(·|z) = Q_P(·|z); this part holds on every path, also outside 𝒟_t. Hence TV(Q_{M^(t)}, Q_P) ≤ (t − 1)/N_z on every path.

Consequently, for every n and η ∈ (0, 1), with N_z ≥ n²/η: Σ_{t≤n} E[TV(Q̄_t, Q_P)] ≥ (1 − 2η)·n·(3/2)·ε(1 − ε), which is 0.375·(1 − 2η)·n for ε = ½, with K = 1 and L = 3. So no bound on Σ_{t≤n} TV(Q̄_t, Q_P) that holds for all classes and scaffolds and depends on L, K and n only can be of the form C·L·K, or C·√(n·L·K), or b(L, K, n) with b/n → 0, for the posterior-draw driver and a human who is not deterministic. (The class depends on n through N_z; K and L do not.) In the same rounds the per-call mixture has total variation at most (t − 1)/N_z ≤ η/n from the human system, on every path and whoever drove the rehearsal.

*Proof.* (a) For distinct asked inputs the likelihood of the data under the prior on F is Σ_s w(s)·Π_i 1[s(z_i) = y_i] = ½·Π_i P(y_i|z_i), because the prior on F is a product over z; this is w(P) times the likelihood under P. So the posterior odds are 1. The second statement is the product form again. (b) At a fresh z the driver is P with probability ½, and then the three answers are independent draws from P(·|z); with probability ½ it is a function s, and the answers are (c, c, c) with c = s(z) of law P(·|z). The law of three independent draws gives the six non-constant triples the mass 1 − (1 − ε)³ − ε³ = 3ε(1 − ε), the law of (c, c, c) gives them 0 and is larger on the two constant triples; so their total variation distance is 3ε(1 − ε), and that of the half-and-half mixture from Q_P(·|z) is half of it. The two run laws have the same marginal on z, so TV(Q̄_t, Q_P) is the mean over z of the conditional distances. The majority is 0 under (c, c, c) with probability ε. (c) The prior on F is a product over the inputs, and the data concern other inputs than a fresh z; so, whatever the data are (also if some input was asked twice), the posterior law of s(z) given s ∈ F is P(·|z). A fresh posterior draw therefore answers 1 at a fresh z with probability w_t(P)·(1 − ε) + w_t(F)·(1 − ε) = 1 − ε, and the draws at the three calls are independent. At most t − 1 of the N_z inputs are not fresh. (Checked for all data lists of length at most 3 on three inputs, with repetitions: `one-mind_editor_checks.py`, part E1.) ∎

*Reading.* F consists of the human "with the coins filled in" by a function of the input. Single answers at fresh inputs cannot tell F from P: every single-call likelihood is the same. The difference shows only in the joint law of several answers of one run: the human's three answers are independent, a function's are equal. A posterior draw per run reproduces the dependence. A fresh draw at every call destroys it, which is correct because the human is stateless (A1). In scaffold terms: asking three times and taking the majority lowers the human system's error from ε to about 3ε²; with one mind per run the error stays at ε on the runs driven by a function. If two calls of each run were put to the human, F would be refuted in this example (two different answers to one input). The next proposition shows that this repair is not general. In a class of programs the role of F is played by the human's program with its coins replaced by a keyed function of the input (the "sampler with some bits specified" of the researcher's notes, item F15 in `research/understand/notes.md`). The posterior weight of that family in a universal class is not computed here. For the product class of the repository's Paper 2, the digest `research/understand/repo.md` reports (items E11 and E5(c), marked there as read in the source; not opened by me) that at the prior's own weights the sampler and its fill-ins have comparable posterior weight on distinct inputs, and that with steeper weights the posterior mass of the fill-ins is exponentially small. Theorem 3.8 below is the counterpart of the second fact for rehearsal data.

**Proposition 3.2 (all calls of the run put to the human; no repeated input). NEW.** Let R ≥ 2 and N_z ≥ 1. Inputs: X := [N_z] ∪ ([N_z] × [R] × {2, 3}). The human: P(·|z) is uniform on [R]; P(·|(z, r, j)) is uniform on {0, 1}. F is the set of all functions s on X with s(z) ∈ [R], s(z, r, j) ∈ {0, 1}, and

  s(z, s(z), 2) = s(z, s(z), 3) for every z.

H := {P} ∪ F with w(P) := ½ and w(s) := 1/(2|F|); K = 1 bit. The scaffold draws z uniformly, and asks x_1 := z, x_2 := (z, y_1, 2), x_3 := (z, y_1, 3); L = 3, and no input occurs twice in a run. For data whose top-level inputs are distinct, let ϱ be the posterior odds of F against P. Then:

(a) *One call of a run put to the human* (any driver): ϱ does not change.

(b) *All three calls of the driver's run put to the human.* Let r_d be the driver's first answer and r′, b, b′ the human's answers to x_1 = z, x_2 = (z, r_d, 2), x_3 = (z, r_d, 3). If r′ ≠ r_d, ϱ does not change. If r′ = r_d, ϱ is multiplied by 2 when b = b′ and by 0 when b ≠ b′.

(c) *A recorded run of the human system* (the human's own first answer r′ is fed forward, and the human then answers (z, r′, 2) and (z, r′, 3)): ϱ is multiplied by 2 when b = b′ and by 0 when b ≠ b′. So F survives N recorded runs with probability 2^(−N).

(d) At a fresh z, the run law of a uniformly drawn member of F is at total variation ½ from Q_P(·|z), and the per-call mixture has Q_{M^(t)}(·|z) = Q_P(·|z).

Consequently, for the posterior-draw driver with all calls of every rehearsal run put to the human (3n answers in n rounds): with probability at least 1 − n/(2R) − n²/(2N_z), every round t ≤ n has TV(Q̄_t, Q_P) ≥ ¼·(1 − n/N_z); in the same rounds the per-call mixture of the same posterior has TV(Q_{M^(t)}, Q_P) ≤ n/N_z.

*Proof.* F is a product over z of sets F_z; a member of F_z is given by r* := s(z) ∈ [R], a common bit for the two inputs (z, r*, 2), (z, r*, 3), and two free bits for each r ≠ r*; |F_z| = R·2·4^(R−1). The uniform law on F_z is invariant under relabelling of [R] and under flipping all bits. So under it s(z) is uniform on [R] and each single bit s(z, r, j) is uniform: (a). For (b), the members of F_z consistent with the three answers have r* = r′ (a fraction 1/R). If r_d ≠ r′ the bits at (z, r_d, ·) are free and must equal (b, b′): a further fraction ¼; the total 1/(4R) equals the likelihood under P. If r_d = r′ the common bit must equal both b and b′: the fraction is 0 if b ≠ b′ and ½ if b = b′, total 1/(2R), twice the likelihood under P. (c) is the case r_d = r′ of (b). (d) A uniform member of F_z produces the run (r, c, c) with r and c uniform, the human system (r, b, b′) with independent uniform entries; the distance is ½. For the mixture the three calls are answered by independent draws, and each single answer is uniform by (a). For the consequence: by (b), ϱ stays at least 1 unless some round has r′ = r_d and b ≠ b′, which has probability 1/(2R) per round because the human's answers are independent of r_d; the top-level inputs of n rounds are distinct with probability at least 1 − n²/(2N_z); and on these events the posterior on F at a fresh z is uniform on F_z, so TV(Q̄_t(·|z), Q_P(·|z)) = w_t(F)/2 ≥ ¼. ∎

*Reading.* The human's answers at calls 2 and 3 are answers at the driver's inputs, which lie on the human's own path only if the human's first answer happens to equal the driver's. The dependence between a hypothesis's first answer and its later answers is tested only by a run that the human carries out itself. This is why Theorem A (H1 in the note), which deploys a posterior draw per run, uses recorded runs of the human system, and why a rehearsal, which never records one, must not deploy a posterior draw: it deploys the per-call mixture, or one member selected with the weights squared (Theorem 3.8).

**Remark 3.3 (what remains true for a stochastic human).** (i) Theorem 2.1 allows stochastic hypotheses; only the human must be deterministic. (ii) With N recorded runs of the human system, one posterior draw per run is sound: Theorem 4.2 of `proofs/hellinger-runs.md` (Theorem A; H1 in the note) states E KL(Q_P ‖ Q̂) ≤ K ln 2/N and E TV(Q̂, Q_P) ≤ √(K ln 2/(2N)) for the draw from the posterior of a uniformly random time (quoted from that file; not re-proved here; both verification reports of that part confirm it). Since the human is stateless, a recorded run is L single questions put in sequence with the human's own answers fed forward, so this costs N·L answers; what it adds to rehearsal is that the questions lie on the human's own path. (iii) For the posterior-draw driver the regret bound still holds for the *per-call mixture* at the inputs of the driver's runs: Σ_t E[E_{Q̄_t} Σ_j KL(P ‖ M^(t))(x_j)] ≤ L·K ln 2 (Lemma 1.6(b) applied to the asked inputs; the asked term of round t has the conditional mean 1/L times the inner expectation). It does not bound TV(Q̄_t, Q_P): in Example 3.1 all its terms vanish at fresh inputs. For the mixture's own run law it gives a bound with the factor 1/w_t(P), which can be 2^K and cannot be removed (Proposition 3.5). (iv) For one member selected at the end of a mixture-driven rehearsal and kept: a draw from the posterior, and the member of largest posterior weight, have no guarantee in terms of K alone (Example 3.1, Example 3.6; for a class with Σ_ν √w(ν) < ∞ they have the guarantee of Remark 3.9); a member selected with the weights squared has a guarantee of the same order as the mixture's (Theorem 3.8).

**Remark 3.4 (the mechanism suggested by the lead; a heuristic, not a theorem; nothing in this file or in the note rests on it).** Consider one hypothesis ν that marks its own runs by a tilt at the first call, ν(S|x_1) = η > p₀ = P(S|x_1) for a set S of answers, and deviates only after an answer in S. It adds at most η·w_t(ν) to TV(Q̄_t, Q_P). Every question at x_1 multiplies its odds against P by a factor whose logarithm has mean −KL(P(·|x_1) ‖ ν(·|x_1)) ≤ −[p₀ ln(p₀/η) + (1 − p₀) ln((1 − p₀)/(1 − η))], about −η when p₀ is much smaller than η; and x_1 is asked with probability 1/L in every round, whoever drives. So on a typical path the log-odds of ν fall by about η/L per round. (This is a statement about the mean of the logarithm. The odds themselves are a martingale under the human's answers; a rigorous version would go through E[min(1, odds)] ≤ √(odds₀)·(1 − h/L)^t with h the squared Hellinger distance of the two first-call laws. It is not written out.) With odds o₀·e^(−ηt/L), where o₀ := w(ν)/w(P) ≤ 2^K, the sum over the rounds of η·min(1, odds) is about L·(1 + max(0, ln o₀)): the order of (2.2). A tilt with small divergence (η close to p₀) does not make the marked runs the hypothesis's own: the other drivers visit them as often. So one hypothesis that marks its runs by a tilt, or a family whose tilts point the same way, is paid for at the linear rate. A family whose tilts cancel in the mixture is not, and Example 3.1 is the extreme case: each s ∈ F is the human tilted all the way to the point mass at s(z), the tilts average to P under the prior, and each member marks its own run by the triple (c, c, c). So the lead's mechanism and the dependence mechanism are the same thing, seen for one member and for the family. What breaks R4 is the dependence, under the posterior, between the answers of the drawn hypothesis at different calls, which costs nothing in any single-call likelihood.

**Proposition 3.5 (a rehearsal driven by posterior draws trains the per-call mixture only at the price 2^K). ADDED in editing** (statement and example from the check report, Section B; re-derived by the editor, and checked by enumeration in `one-mind_check_stochastic.py`, part C, and `one-mind_editor_checks.py`, part E2). Let the human be a sampler P ∈ H, and run the rehearsal with the posterior-draw driver.

(a) Σ_{t≥1} E[ w_t(P)·KL(Q_P ‖ Q_{M^(t)}) ] ≤ L·K ln 2. The process 1/w_t(P) is a nonnegative supermartingale that starts at W/w(P) ≤ 2^K; so for every δ ∈ (0, 1), with probability at least 1 − δ, w_t(P) ≥ δ·2^(−K) in all rounds.

(b) The factor 1/w_t(P) cannot be removed. Let K ≥ 1 and R ≥ 2 be integers. Take the inputs, the human and the scaffold of Proposition 3.2 and add a fourth call with the input x_4 := (z, y_1, y_2, y_3, 4), which the human answers by a uniform bit; so L = 4. Let ★ be an answer that the human never gives. F′ is the set of all functions s such that s restricted to the first three kinds of input is a member of the class F of Proposition 3.2, and s(z, r, b, b′, 4) = ★ if b ≠ b′, while s(z, r, b, b, 4) ∈ {0, 1} is free. H := {P} ∪ F′ with w(P) := 2^(−K) and w(s) := (1 − 2^(−K))/|F′|. Call z *fresh* if no input with the first coordinate z has been asked. Then, in a round whose top-level input z is fresh:

 (i) a question at x_1, x_2, x_3, or at x_4 when y_2 = y_3, leaves the posterior odds of F′ against P unchanged, whatever the human answers;
 (ii) a question at x_4 when y_2 ≠ y_3 removes all of F′ (the human answers a bit, every member of F′ answers ★);
 (iii) the run of a member of F′ has y_2 = y_3, the run of P has y_2 ≠ y_3 with probability ½, and so has the run of the per-call mixture;
 (iv) if F′ has the posterior mass w_F, then TV(Q_{M^(t)}(·|z), Q_P(·|z)) = w_F/2 and KL(Q_P(·|z) ‖ Q_{M^(t)}(·|z)) = ½·ln(1/(1 − w_F)).

Consequently, for n rounds, N_z top-level inputs and every t ≤ n: with the posterior-draw driver,

 E[TV(Q_{M^(t)}, Q_P)] ≥ ½·(1 − 2^(−K))·(1 − n/N_z)·[(1 − 2^(−K)/8)^(t−1) − n²/(2N_z)],

which is at least 0.07 for all t ≤ 5·2^K when N_z ≥ 10·n² and n ≥ 5·2^K; and with the mixture driver E[TV(Q_{M^(t)}, Q_P)] ≤ ½·(7/8)^(t−1) + n/N_z + n²/(2N_z). So F′ is removed after 8·2^K rounds in expectation by the first driver and after 8 rounds by the second. In the limit N_z → ∞ the inequality of (a) holds with equality in this example: (8·2^K)·2^(−K)·½·K ln 2 = 4·K ln 2 = L·K ln 2.

*Proof.* (a) Given D_{t−1}, the run of round t has the law Q̄_t = Σ_ν w_t(ν)Q_ν ≥ w_t(P)·Q_P. J_t is uniform and independent of the run, so the asked term of round t has the conditional mean

 E[1{J_t ≤ T}·KL(P ‖ M^(t))(x_{J_t}) | D_{t−1}] = (1/L)·E_{Q̄_t}[Σ_{j≤T} KL(P ‖ M^(t))(x_j)] ≥ (w_t(P)/L)·E_{Q_P}[Σ_{j≤T} KL(P ‖ M^(t))(x_j)] = (w_t(P)/L)·KL(Q_P ‖ Q_{M^(t)}).

The last step is the chain rule: a run (z, ρ, y_1, …, y_T) has, under a sampler S, the probability of (z, ρ) times Π_j S(y_j|x_j), so ln(Q_P(τ)/Q_{M^(t)}(τ)) = Σ_j ln(P(y_j|x_j)/M^(t)(y_j|x_j)), and under Q_P the j-th term has the conditional mean KL(P ‖ M^(t))(x_j) given the run before call j (Lemma 2.1 of `proofs/rehearsal-core.md`). By Lemma 1.6(b) the asked terms have total expectation at most K ln 2. For the second statement, 1/w_t(P) = ξ(D_{t−1})/(w(P)·P(D_{t−1})), and for a question x answered by y ~ P(·|x): E[ν(y|x)/P(y|x)] = Σ_{y: P(y|x)>0} ν(y|x) ≤ 1 for every ν, so E[ξ(D + (x, y))/P(D + (x, y))] ≤ ξ(D)/P(D). The maximal inequality for nonnegative supermartingales gives Pr[sup_t 1/w_t(P) ≥ 2^K/δ] ≤ (W/w(P))·δ·2^(−K) ≤ δ.

(b) F′ is a product over z of sets F′_z, and the uniform law on F′_z is the uniform law on F_z of Proposition 3.2 together with independent uniform bits s(z, r, b, b, 4). By Proposition 3.2(a) every single answer at x_1, x_2, x_3 has the human's law under the uniform law on F′_z; so has the answer at an input (z, r, b, b, 4). This is (i). (ii) is the definition of F′. (iii) For a member of F′ the second and third answers are the common bit s(z, s(z), 2) = s(z, s(z), 3). The per-call mixture answers each call by a fresh posterior draw, and by (i) each of its first three answers has the human's law whatever the earlier answers were; so its second and third answers are two independent uniform bits. (iv) By (i) the first three answers of the mixture's run have the human's law. If y_2 ≠ y_3 (probability ½), the fourth answer is ★ with probability w_F and a uniform bit otherwise; if y_2 = y_3 it is a uniform bit. So the two run laws differ by the mass w_F/2 moved to ★, and KL(Q_P(·|z) ‖ Q_{M^(t)}(·|z)) = ½·ln(1/(1 − w_F)).

*The consequence.* Let 𝒟 be the event that the n top-level inputs are distinct, Pr[𝒟] ≥ 1 − n²/(2N_z). Couple the rehearsal with the chain in which every top-level input is fresh, driven by the same coins; on 𝒟 the two coincide. In the chain with the posterior-draw driver the odds of F′ against P stay at their prior value until F′ is removed, by (i); so while F′ is alive, the driver is P with probability 2^(−K), and by (ii) and (iii) the round then removes F′ with probability ½·¼ (the fourth call must be the asked one). So F′ is alive at the start of round t with probability (1 − 2^(−K)/8)^(t−1), and then the mixture's run is at distance (1 − 2^(−K))/2 from the human system's at each of the at least N_z − n fresh inputs, by (iv). For t − 1 ≤ 5·2^K, (1 − 2^(−K)/8)^(t−1) ≥ 1 − 5/8, and ½·½·(1 − 1/10)·(3/8 − 1/20) ≥ 0.07. In the chain with the mixture driver every round removes F′ with probability ½·¼ by (ii) and (iii), and the posterior mass of F′ is at most 1; off 𝒟, and at inputs that are not fresh, the distance is at most 1. The expected lifetimes are those of geometric variables. For the equality: while F′ is alive, w_t(P) = 2^(−K) and KL(Q_P ‖ Q_{M^(t)}) = ½·K ln 2 by (iv). ∎

*Reading.* A driver drawn from the posterior goes where its own hypothesis goes. The members of F′ never visit the inputs at which F′ is wrong; only the human's own program does, and it drives a share w_t(P) of the rounds. The per-call mixture, used as the driver, visits those inputs half of the time, because it does not reproduce the dependence between the second and the third answer. So for a human who is not deterministic the rehearsal should be driven by the mixture and not by posterior draws, also when the mixture is what is deployed. (The example compares these two drivers only; it says nothing about other drivers, and nothing about a member selected with the weights squared: Theorem 3.8, "What is used".)

**Example 3.6 (the member of largest posterior weight: the codebook class). ADDED in editing** (construction from the check report, Section F; re-derived by the editor; simulated in `one-mind_check_codebook.py` and in `one-mind_editor_checks.py`, part E3. It is the known counterexample to selection by posterior weight at the prior's own weights, in the present setting: see Section 9, Zhang 2006.) Let n ≥ 1 and K ≥ 1 be integers, m := n + K − 2 ≥ 0, and N_z ≥ 1. The human is a fair coin at every input: P(·|z) is uniform on {0, 1} for z ∈ [N_z]. The scaffold is that of Example 3.1: three calls at the top-level input z, which is uniform on [N_z]; L = 3. The class consists of P with w(P) := 2^(−K) and of 2^m functions s_1, …, s_{2^m}: [N_z] → {0, 1} (a *codebook*) with the weights (1 − 2^(−K))·2^(−m) each. A member's *posterior weight* is w(ν)·ν(D) up to the common normalisation; for a class of functions the member of largest posterior weight is the highest-weight consistent member. Then:

(a) there is a codebook for which, with probability at least 1 − exp(−2^(K−2)) − n²/(2N_z) over a rehearsal of n rounds (with any driver), the member of largest posterior weight is a function, and every function s has TV(Q_s, Q_P) = 7/8. For K = 4 the first term is 1 − e^(−4) ≥ 0.98.

(b) With the weights squared, in the same class and for n ≥ 5, the member that maximises w(ν)²·ν(D_n) is P, on every path.

*Proof.* (a) Every call of a run has the input z, so the question of round t is z_t whatever the driver does, and the data are n pairs (z_t, y_t) with independent uniform z_t and independent fair bits y_t. Draw the values s_i(z) of the codebook as independent fair bits; the codebook is then independent of the data. On the event that z_1, …, z_n are distinct, of probability at least 1 − n²/(2N_z), each function is consistent with the data with probability 2^(−n), independently of the others, so some function is consistent with probability 1 − (1 − 2^(−n))^(2^m) ≥ 1 − exp(−2^(m−n)) = 1 − exp(−2^(K−2)). A consistent function has the posterior weight (1 − 2^(−K))·2^(−m) = 4·(1 − 2^(−K))·2^(−K−n) ≥ 2·2^(−K−n), and P has 2^(−K)·2^(−n). So whenever some function is consistent, the member of largest posterior weight is a function. The probability of the event in (a), averaged over the codebooks, is therefore at least the stated bound, and some codebook is at least as good as the average. For every function s and every z, Q_s(·|z) is the point mass at (s(z), s(z), s(z)), which has the probability 1/8 under Q_P(·|z); so TV(Q_s, Q_P) = 7/8. (b) P(D_n) = 2^(−n) on every path, and a function has the likelihood at most 1; (1 − 2^(−K))²·2^(−2m) < 2^(−2n−2K+4) = 2^(4−n)·2^(−2K−n), which is less than w(P)²·P(D_n) = 2^(−2K−n) for n ≥ 5. (The same line gives it for n = 4, since the first inequality is strict; for n = 3 and K ≥ 2 a function that fits beats P also with the weights squared. Noted by the second check; `one-mind_editor_second.py`, part T3.) ∎

The class is built for the number n of questions, as in Example 3.1: the codebook has 2^(n+K−2) members. What stays fixed is K.

**Theorem 3.8 (one program for a human who is not deterministic: select with the weights squared). ADDED in editing; proved by the editor; verified line by line by the second check (Section 10.4).** (Origin: the adversarial report, finding F1, asks whether a single member selected by penalised likelihood works; the script of the first referee, `one-mind_check_stochastic.py`, part D, states and tests a proposition of this kind with other constants, without a written proof. Part (a) is the standard bound for selection by description length with the weights squared, in a form for adaptively chosen questions; see Section 9.) Assume A1 to A3 and let the human be a sampler P in a countable class H of hypotheses (Definition 1.1). Run the rehearsal with the mixture driver for n rounds (the mixture is the usual one, with the weights w). For ν ∈ H and a round t put

 h_t(ν) := (1/L)·E_{Q_{M^(t)}}[Σ_{j≤T} H²(ν, P)(x_j)],  κ_t := E_{Q_{M^(t)}}[Σ_{j≤T} H²(P, M^(t))(x_j)],

both functions of D_{t−1}. Let Π₂(ν) := w(ν)²·ν(D_n)/Σ_ν′ w(ν′)²·ν′(D_n), and let ν̂ be either one draw from Π₂, or any member with w(ν̂)²·ν̂(D_n) ≥ w(P)²·P(D_n), for instance a maximiser of w(ν)²·ν(D_n). Let δ ∈ (0, 1). Then:

(a) with probability at least 1 − δ: Σ_{t≤n} h_t(ν̂) < K ln 2 + ln(1/δ);

(b) with probability at least 1 − δ: Σ_{t≤n} κ_t < L·(½·K ln 2 + ln(1/δ));

(c) with probability at least 1 − 2δ:

 H²(Q_ν̂, Q_P) < L·(28·K ln 2 + 40·ln(1/δ))/n, hence TV(Q_ν̂, Q_P) < √( L·(56·K ln 2 + 80·ln(1/δ))/n ).

So ν̂, used alone for every call of every later run, produces runs whose law is within this distance of the human system's.

*Proof.* A maximiser of w(ν)²ν(D_n) exists: P(D_n) > 0 almost surely, and only finitely many ν have w(ν) ≥ w(P)·√P(D_n).

*Step 1 (a supermartingale for each member).* Fix ν. Let ρ_t := √(ν(y_t|x_t)/P(y_t|x_t)) if a question is asked in round t, and ρ_t := 1 otherwise. Given D_{t−1}, the question is the input of a uniformly chosen call of a run of M^(t), if that call exists, and the answer is drawn from P; so by Lemma 1.6(c), E[ρ_t | D_{t−1}] = 1 − E[1{J_t ≤ T}·H²(ν, P)(x_{J_t}) | D_{t−1}] = 1 − h_t(ν). By (E3), E[ρ_t·e^(h_t(ν)) | D_{t−1}] ≤ 1. So N_s(ν) := Π_{t≤s} ρ_t·e^(h_t(ν)) is a nonnegative supermartingale with N_0 = 1, and E[N_n(ν)] ≤ 1. Note that Π_{t≤n} ρ_t = √(ν(D_n)/P(D_n)).

*Step 2 (proof of (a)).* Let a := K ln 2 + ln(1/δ) and A := {ν ∈ H : Σ_{t≤n} h_t(ν) ≥ a}, a random set. Put s_ν := (w(ν)/w(P))·√(ν(D_n)/P(D_n)) and S := Σ_{ν∈A} s_ν. For ν ∈ A, √(ν(D_n)/P(D_n)) = N_n(ν)·exp(−Σ_t h_t(ν)) ≤ N_n(ν)·e^(−a). Hence E[S] ≤ e^(−a)·Σ_ν (w(ν)/w(P))·E[N_n(ν)] ≤ e^(−a)·W/w(P) ≤ δ. Now Π₂(A) ≤ Σ_{ν∈A} w(ν)²ν(D_n)/(w(P)²P(D_n)) = Σ_{ν∈A} s_ν² ≤ S², and Π₂(A) ≤ 1; so Π₂(A) ≤ min(1, S²) ≤ S and E[Π₂(A)] ≤ δ: a draw from Π₂ lies in A with probability at most δ. And if some ν ∈ A has w(ν)²ν(D_n) ≥ w(P)²P(D_n), then s_ν ≥ 1 and S ≥ 1, which has probability at most E[S] ≤ δ.

*Step 3 (proof of (b); it is Lemma 4.3(b) of `proofs/rehearsal-core.md`).* Let ρ′_t := √(M^(t)(y_t|x_t)/P(y_t|x_t)) if a question is asked in round t, and ρ′_t := 1 otherwise. As in Step 1, E[ρ′_t | D_{t−1}] = 1 − κ_t/L, so N′_s := Π_{t≤s} ρ′_t·e^(κ_t/L) is a nonnegative supermartingale with mean at most 1. By Lemma 1.6(a), Π_{t≤n} ρ′_t ≥ √(w(P)/W) ≥ 2^(−K/2). So N′_n ≥ 2^(−K/2)·exp(Σ_{t≤n} κ_t/L), and by Markov's inequality N′_n < 1/δ with probability at least 1 − δ.

*Step 4 (from single calls on the mixture's runs to the run law of ν; no probability is involved).* Fix ν, a round t and the data D_{t−1}, and write M := M^(t). By (E4) at each input, H²(ν, M)(x) ≤ 2H²(ν, P)(x) + 2H²(P, M)(x). By Corollary 2.3 of `proofs/hellinger-runs.md` (for samplers S, S′: H²(Q_S, Q_S′) ≤ 4·E_{Q_S} Σ_j H²(S, S′)(x_j)), applied with the mixture in the first place,

 H²(Q_M, Q_ν) ≤ 4·E_{Q_M} Σ_j H²(ν, M)(x_j) ≤ 8L·h_t(ν) + 8κ_t  and  H²(Q_M, Q_P) ≤ 4κ_t.

By (E4) for laws of runs, H²(Q_ν, Q_P) ≤ 2H²(Q_ν, Q_M) + 2H²(Q_M, Q_P) ≤ 16L·h_t(ν) + 24κ_t.

*Step 5.* Average Step 4 over t ≤ n: H²(Q_ν, Q_P) ≤ (16L/n)·Σ_t h_t(ν) + (24/n)·Σ_t κ_t for every ν. On the events of (a) and (b), for ν = ν̂, the right side is less than [16L·(K ln 2 + ln(1/δ)) + 24L·(½K ln 2 + ln(1/δ))]/n = L·(28·K ln 2 + 40·ln(1/δ))/n. Finally TV ≤ √(2H²). ∎

*What is used, and what it does not say.* The expectations in h_t and κ_t are over the mixture's own runs, which is where the rehearsal asks; that the mixture's runs are close to the human system's enters through κ_t. The human must be in the class. The theorem is proved for a rehearsal driven by the mixture: Step 4 uses that the questions are asked along the mixture's own runs. For a rehearsal driven by posterior draws the mixture's own runs are controlled only up to the factor 1/w_t(P), which can be 2^K (Proposition 3.5); whether the member selected with the weights squared then has a bound without that factor is not decided here. (The example of Proposition 3.5 does not decide it: there the member selected with the weights squared is P as soon as N_z ≥ n ≥ K, because |F′| = (R·2^(4R−1))^(N_z), so that the squared weight of a member of F′ is below (R·2^(4R−1))^(−2N_z), while w(P)²·P(D_n) ≥ 2^(−2K)·R^(−n). This sentence and the two before it replace, in the second round, the words "the rehearsal must be driven by the mixture"; they are the editor's and no one else has checked them.) The constants are not optimised (with the constant c* < 2.9642 of Theorem 2.7 of `proofs/hellinger-runs.md` in place of 4 they become 7c* < 21 and 10c* < 30). The bound for the mixture itself is E H²(Q_{M^(U)}, Q_P) ≤ 2L·K ln 2/n (Theorem R2, `proofs/hellinger-runs.md`, Theorem 3.1), so the price of one program is a constant factor and a confidence parameter, as for a deterministic human (Theorem 5.5). The theorem selects with the weights w² and rehearses with the weights w. It says nothing for the weights w themselves (Example 3.6 refutes a bound in terms of K alone for them; Remark 3.9 says what holds), nothing about which member is selected beyond its run law, and nothing when the human is outside the class. On the random instances tried, the inequality of Step 4 is loose by a factor of at least 9, and the final bound by much more (Section 7.6).

## 4. R5: when stakes are low, a committee per call beats one member per run

**Definition 4.1 (trap scaffold, trap functions).** Let N ≥ 2 and L ≥ 1. Inputs X := [N] × ({0} ∪ [N]), answers {0, 1}. The scaffold Π^trap_{N,L} draws z = (a_1, …, a_L) uniformly from [N]^L and keeps a *flag* s_j ∈ {0} ∪ [N]: s_1 := 0; the input of call j is x_j := (a_j, s_j); s_{j+1} := a_j if s_j = 0 and y_j = 1, and s_{j+1} := s_j otherwise. Every run has L calls. The flag records the first input at which the answer 1 was given. Functions: g_0 :≡ 0, and for a ∈ [N],

  g_a(b, s) := 1 if (s = 0 and b = a) or s = a, and := 0 otherwise.

g_a answers 1 at its *trigger* (a, 0) and on its *region* [N] × {a}. **Class A:** H_A := {g_0, g_1, …, g_N} with w(g_0) := ½ and w(g_a) := 1/(2N); the human is g_0, K = 1 bit. **Class B:** H_B := {g_1, …, g_N} with weights 1/N; the human is some g_{a*}, K = log₂ N.

*What a question does.* Let c ∈ {0} ∪ [N] be the human's index. A question at (b, 0) with b ≠ c, or at (b, a) with a ≠ c, is answered 0 and removes at most one member: g_b, respectively g_a, if it has not been removed before. A question at the human's trigger or in the human's region (c ≠ 0) is answered 1 and removes every member but g_c.

**Proposition 4.2 (class A: posterior draw against mixture, K = 1). PROVED.** In class A with human g_0, let U be the set of traps that the data have not removed, k := |U|. The posterior gives g_0 the mass N/(N + k) and each trap in U the mass 1/(N + k). Let C be the number of unfaithful calls of a run.

(a) *One posterior draw for the run.* Pr[C = L − i + 1] = (k/(N + k))·(1 − 1/N)^(i−1)/N for i ∈ [L], and C = 0 otherwise. So for c ∈ [L]

  Pr[C ≥ c] = (k/(N + k))·(1 − (1 − 1/N)^(L−c+1)).

(b) *The mixture.* For every m ≥ 0, Pr[C ≥ m + 1] ≤ (L choose m+1)·N^(−(m+1)) ≤ (L/N)^(m+1)/(m + 1)!. Exactly: C = 0 if no call sets the flag; otherwise C = 1 + B, where the first flag-setting call τ is geometric with parameter k/(N(N + k)) and B is binomial with parameters L − τ and 1/(N + k).

(c) *After n rounds of rehearsal with either driver,* E[k] ≥ N·(1 − 1/N − L/N²)^n. In particular for n = N ≥ 100 and L ≤ √N, a posterior draw per run has

  Pr[C ≥ L/4] ≥ 0.11·L/n,

while the mixture has Pr[C ≥ 2] ≤ (L/n)²/2 and Pr[C ≥ L/4] ≤ (L/n)^⌈L/4⌉/⌈L/4⌉!.

*Proof.* (a) The run of g_0 is faithful. The run of g_a answers 0 until a first occurs in z, at position i say, and 1 at that call and at every later call, since the flag is then a; the human answers 0 everywhere. So C = L − i + 1 if a first occurs at position i, an event of probability (1 − 1/N)^(i−1)/N, and the driver is a trap with probability k/(N + k). (b) At a call with flag 0 and input (b, 0) the fresh draw answers 1 if and only if it is g_b, which has probability at most 1/(N + k); at a call with flag a it answers 1 if and only if it is g_a. So every call is unfaithful with conditional probability at most 1/N given the earlier calls. For a fixed set of m + 1 calls the probability that all are unfaithful is at most N^(−(m+1)); sum over the sets. The exact law: a call with flag 0 sets the flag with probability (k/N)·(1/(N + k)) (the input must be the trigger of a surviving trap and the draw that trap), and after the flag is set to a each call is unfaithful with probability 1/(N + k). (c) A trap a ∈ U is removed in a round only if the asked input is (a, 0) or lies in the region of a. The first has probability at most 1/N (the J-th top-level symbol is a). The second needs the flag a at the asked call: for the posterior-draw driver the driver must be g_a and a must occur in z, probability at most (1/(N + k))·(L/N); for the mixture some call must have the input (a, 0) and the draw g_a, probability at most L·(1/N)·(1/(N + k)). So each trap survives a round with conditional probability at least 1 − 1/N − L/N², and E[k] is the sum of the survival probabilities. For the numbers: k/(N + k) ≥ k/(2N), so E[k/(N + k)] ≥ ½(1 − 1.1/N)^N ≥ ½·0.989^100 ≥ 0.165 (the function N ↦ (1 − 1.1/N)^N increases); with c := ⌈L/4⌉ we have L − c + 1 ≥ 3L/4 and 1 − (1 − 1/N)^(L−c+1) ≥ (3L/(4N))·(1 − L/(2N)) ≥ 0.95·(3L/(4N)) by the Bonferroni inequality; the product is at least 0.117·L/N. The bounds for the mixture are (b). ∎

In class A, with the weights as given, the highest-weight consistent hypothesis is g_0 itself, so the failure of (a) belongs to the random draw. With traps slightly heavier than the human it belongs to the highest-weight consistent member as well (Proposition 4.6). That every way of choosing a member fails for some human is the next statement.

**Proposition 4.3 (class B: every rule that deploys a member of the class). PROVED; the candidate's statement is MODIFIED (see Remark 4.5).** Let n ≥ 16, N := 2n and L ≤ n; class B on Π^trap_{N,L}.

(a) Let a protocol put at most n questions of its choice to the human (adaptively, with its own randomness) and then answer every call of a run by one member of H_B. The member is chosen in any way from the data and the protocol's randomness, possibly afresh for each run, but without looking at the top-level input of the run. Then for some human g_{a*} ∈ H_B, a deployed run has at least L/4 unfaithful calls with probability at least L/(8n).

(b) For the rehearsal with the mixture driver, for every human g_{a*}, every round t ≤ n + 1 and every m ≥ 0, the run of M^(t) has more than m unfaithful calls with probability at most L/(2n²) + (3L/(2n))^(m+1)/(m + 1)!.

*Proof.* (a) Let a* be uniform on [N], independent of the protocol's randomness ω. Each question tests one index: (b, 0) tests b and (b, a) tests a; the answer is 1 if and only if the tested index is a*. Let A(ω) be the set of at most n indices tested when all answers are 0, and â(ω) the index of the member deployed in that case. If a* ∉ A(ω), all answers are 0 and the protocol deploys g_â(ω). For every ω, Pr[a* ∉ A(ω) and a* ≠ â(ω)] ≥ 1 − (n + 1)/N. On this event the deployed member g_â is not the human: on a run in which â first occurs at position j it answers 0 before call j (so the flag stays 0), answers 1 at (â, 0), where the human answers 0, and answers 1 at each later input (·, â), where the human answers 0 because â ≠ a*. So the run has at least L − j + 1 unfaithful calls, and at least ⌈L/4⌉ of them if j ≤ m₀ := L − ⌈L/4⌉ + 1, where m₀ ≥ 3L/4. The top-level input of the run is independent of (ω, a*), and therefore of â, because the member is chosen without looking at it; so the probability is at least (1 − (n + 1)/N)·(1 − (1 − 1/N)^m₀) ≥ ((n − 1)/(2n))·(3L/(8n))·(1 − L/(4n)) ≥ (15/32)·(9/32)·L/n ≥ L/(8n). The bound holds on average over a*, hence for some a*.

(b) If some question so far was answered 1, the posterior is the point mass at the human and the run is faithful. Otherwise the posterior is uniform on a set S of at least N − (t − 1) ≥ n members, and a* ∈ S. Let Dm be the event that some call with flag 0 has the input (a*, 0) and the draw g_{a*}; Pr[Dm] ≤ L·(1/N)·(1/n) = L/(2n²). For a call j let E_j be the event that its input is (a*, 0), or that its draw is the one member that answers 1 at its input (g_b at (b, 0), g_s at flag s). Given the run before call j, the first has probability at most 1/N (the j-th symbol of z is uniform and independent of the earlier calls) and the second at most 1/n; so E_j has conditional probability at most 3/(2n). Outside Dm the flag is never a*, and then every unfaithful call is a call at which E_j occurs. So the run has more than m unfaithful calls with probability at most Pr[Dm] plus the probability that E_j occurs at more than m calls, which is at most (L choose m+1)·(3/(2n))^(m+1) as in Proposition 4.2(b). ∎

The condition in (a) that the member is chosen before the top-level input is seen is needed: a rule that sees z can deploy a member whose trigger does not occur in z, and on that run this member answers 0 everywhere, like the vote of Remark 4.5. Such a rule is a way of computing the committee's vote, not a single program.

On the event Dm the mixture has answered the human's trigger correctly and then stands in the human's own region, where the posterior still gives the human's answer little weight: the human of class B is a trap from the committee's point of view. This costs the term L/(2n²), a factor n/4 below the bound of (a).

The proof of (b) uses of the rehearsal only that at most n questions have been put to the human before the run: after any at most n questions, however they were chosen, the posterior is the point mass at the human or the uniform law on a set of at least n members that contains the human. So (b) holds for the per-call mixture after any at most n questions, which is the form in which the note states it. (Noted by the second check; computed exactly for sets of several sizes from n to N, n from 16 to 64 and L ≤ n, in `one-mind_editor_second.py`, part T5: the largest ratio of the probability to the bound is 0.71.)

**Remark 4.5 (a member of the class, or the committee; not: deterministic or random).** The candidate's R5 says "every rule that deploys a single hypothesis per run". **Proposition 4.6 (class A with traps slightly heavier than the human: the highest-weight consistent member). ADDED in editing** (from the check report, Section C; re-derived by the editor; exact values and a simulation in `one-mind_editor_checks.py`, part E4). Let n ≥ 1, N := 2n, L ≤ n and ι > 0. (a) the deployed member is a trap, and its run has at least L/4 answers equal to 1 with probability 1 − (1 − 1/N)^m₀ ≥ (9/32)·L/n, where m₀ := L − ⌈L/4⌉ + 1;

(b) for the per-call mixture after the same questions, every call is unfaithful with conditional probability less than 1/n given the earlier calls, so its run has more than m unfaithful calls (which are its answers 1) with probability at most (L/n)^(m+1)/(m + 1)!.

*Proof.* The human answers 0 to every question, and a question removes at most one trap (Definition 4.1). So at least N − n = n traps are consistent. Each is heavier than g_0, so the deployed member is a trap g_a, and a is a function of the data and of the protocol's randomness, hence independent of the top-level input z of the deployed run. In class A′ the human is fixed and simple to state, but its weight is 1/(2n) of the total, as in class B: K grows like log₂ n. With K = 1 (class A) the highest-weight consistent member is the human.

## 5. R6: which single hypothesis, and when it is chosen

In this section H is a class of functions and the human is a function f ∈ H. For g ∈ H put

  u(g) := Pr_{(z,ρ)}[ τ^g(z, ρ) ≠ τ^f(z, ρ) ],

the probability that a run answered by g alone is unfaithful.

### 5.1 The simplest consistent hypothesis as driver

**Proposition 5.1 (R6(a), upper bound). PROVED.** Let g_1, g_2, … be an enumeration of H and f = g_i₀. For the rehearsal with the first-consistent driver,

  Σ_{t≥1} Pr[the run of round t is unfaithful] ≤ L·(i₀ − 1).

If the enumeration is by non-increasing weight, i₀ − 1 ≤ W/w(f) − 1 ≤ 2^K − 1.

*Proof.* f is never removed, so the driver always has an index at most i₀, and a removed function never drives again. Fix i < i₀ and consider the rounds in which g_i drives and its run is unfaithful. In such a round the first deviation index j* of g_i on (z_t, ρ_t) is finite, and J_t = j* with probability 1/L, independently of the past and of (z_t, ρ_t); in that case the question is x^f_{j*} (Lemma 1.4), g_i is wrong there and is removed. So the number of such rounds exceeds k with probability at most (1 − 1/L)^k, and its expectation is at most L. Sum over i < i₀. For the count: (i₀ − 1)·w(f) ≤ Σ_{i<i₀} w(g_i) ≤ W − w(f). ∎

**Example 5.2 (R6(a): the bound is attained when 2^K ≤ L + 1). PROVED.** Let 1 ≤ M ≤ L. Take the scaffold Π^path_{1,L} of Example 2.4 (one top-level input; write j for the input (1, j)), f ≡ 0, and g_i(j) := 1[j = i], g_i(⋆) := 0 for i ∈ [M]. H := {g_1, …, g_M, f} in this order, with weights 1/(M + 1), so K = log₂(M + 1). (With weights proportional to 1 + ι·(M − i), ι > 0 small, the order is strictly by weight and K changes by less than log₂(1 + ιM).) Then, with the first-consistent driver:

(a) the number of unfaithful rounds is G_1 + … + G_M with independent G_i, each geometric with parameter 1/L (the number of trials up to the first success); its expectation is exactly L·M = L·(2^K − 1);

(b) the unfaithful rounds are exactly the rounds 1, …, G_1 + … + G_M; so for M ≥ 40 and every n ≤ L·M/2, the driver of round n produces an unfaithful run with probability at least 0.9.

With the posterior-draw driver the expected number of unfaithful rounds is at most (2L²/(L + 1))·ln(M + 1) (Theorem 2.1), and with the mixture driver at most L·ln(M + 1) (Theorem R1; in this scaffold a run has at most one unfaithful call).

*Proof.* While g_d drives, the functions g_i with i < d have been removed. The run of g_d answers 0 at the inputs 1, …, d − 1, answers 1 at d and then stands at ⋆. If J < d the question is the input J; every surviving function answers 0 there, nothing is removed. If J = d the question is d and exactly g_d is removed. If J > d the question is ⋆ and nothing is removed. So each round with driver g_d is unfaithful, ends the reign of g_d with probability 1/L independently of the past, and removes nothing else; after g_M is removed f drives and all runs are faithful. This is (a) and the first half of (b). The sum has mean L·M and variance at most L²·M, so it is below L·M/2 with probability at most 4/M by Chebyshev's inequality. ∎

So for M = L the simplest consistent hypothesis as driver spends about L² rounds, all of them unfaithful, where the mixture and the posterior draw have at most L·ln(L + 1) and 2L·ln(L + 1) unfaithful rounds in total. The reason is the one named in the candidate theory: a deterministic driver that deviates early hides the later deviations of all the other hypotheses, so each hypothesis is refuted only during its own reign.

**Example 5.3 (large K: the bound is approached, slowly). PROVED.** Let M ≥ 1 and ε ∈ (0, ¼]. The scaffold draws z ∈ {0, 1, …, M} with Pr[z = i] = ε^i for i ≥ 1, and is otherwise that of Example 2.4: next_j := (z, j) if all earlier answers are 0, and := ⋆ otherwise; L ≥ 1 calls. f ≡ 0; g_i := 1 at the single input (i, 1) and 0 elsewhere, for i ∈ [M]; H := {g_1, …, g_M, f} in this order with weights 1/(M + 1). With the first-consistent driver:

(a) the expected total number of unfaithful rounds lies between L·M·(1 − 2ε) and L·M = L·(2^K − 1);

(b) the expected number of unfaithful rounds among the first n is at most Σ_i min(L, n·ε^i) ≤ L·(log(n/L)/log(1/ε) + 3) for n ≥ L; and g_M is removed only after L·ε^(−M) rounds in expectation.

*Proof.* A question removes g_i if and only if it is (i, 1), that is, if and only if z_t = i and J_t = 1, whoever drives (a driver other than g_i answers 0 at (i, 1); the driver g_i answers 1 there, and the question of call 1 is still (i, 1)). So the removal time D_i of g_i is the first round with (z_t, J_t) = (i, 1), and for d ≠ i, Pr[D_i < D_d] = ε^i/(ε^i + ε^d). The reign of g_i is the set of rounds t with max_{d<i} D_d < t ≤ D_i; a round of this reign is unfaithful if and only if z_t = i, and each such round ends the reign with probability 1/L. So, given that the reign is not empty, it contains a geometric number of unfaithful rounds with mean L (whether the reign is empty, and the round max_{d<i} D_d after which it begins, are determined by the rounds up to that one, and the later rounds are independent of them: the strong Markov property); and it is empty with probability at most Σ_{d<i} ε^(i−d) ≤ ε/(1 − ε) ≤ 2ε. This gives (a). For (b), the reign of g_i contributes at most L in expectation and at most the expected number n·ε^i of rounds t ≤ n with z_t = i; the indices with ε^i ≥ L/n number at most log(n/L)/log(1/ε) + 1, and the others contribute at most n·Σ_{i: ε^i<L/n} ε^i ≤ L/(1 − ε) ≤ 2L. E[D_M] = L·ε^(−M). ∎

**Remark 5.4 (why I have no fast example for 2^K > L + 1; OPEN).** For g_i to cost about L unfaithful rounds it must be removed almost only in rounds that it drives. In a round driven by g_d the question lies on the human system's run up to the first deviation of g_d (Lemma 1.4) or beyond it, off that run; it removes g_i when it is a position at or before the first deviation of g_d at which g_i is wrong. So g_i is safe on (z, ρ) only if every earlier driver deviates on (z, ρ) strictly before g_i does. On one (z, ρ) such a chain of drivers has strictly increasing first-deviation positions, hence at most L members; Example 5.2 is such a chain. Further hypotheses must deviate on rarer runs than their predecessors, which lengthens their own reigns as in Example 5.3. Whether the number of unfaithful rounds among the first n can exceed the order L²·log n for some class, and the exact worst case as a function of n, L and K, are open.

### 5.2 One consistent hypothesis selected at the end of mixture-driven rehearsal

For the rehearsal with the mixture driver let, for g ∈ H and a round t,

  d_t(g) := E[ #{ j ≤ T : g(x_j) ≠ f(x_j) } | D_{t−1} ]  for a run of M^(t),

the expected number of calls of the round-t run at whose inputs g is wrong. d_t(g)/L is the probability, given D_{t−1}, that the question of round t removes g.

**Theorem 5.5 (R6(b): an Occam bound on the rehearsal's own visit distribution, and the selected hypothesis's own run). PROVED.** Let H be a class of functions, f ∈ H the human, and run the rehearsal with the mixture driver for n rounds. Let δ ∈ (0, 1).

(a) With probability at least 1 − δ, every g in the final version space V_{D_n} satisfies

  (1/n)·Σ_{t≤n} d_t(g) < L·(ln(1/w(g)) + ln(1/δ))/n.

(b) With probability at least 1 − 2δ, every g ∈ V_{D_n} satisfies

  u(g) < L·(ln(1/w(g)) + K ln 2 + 2 ln(1/δ))/n.

In particular every consistent g with w(g) ≥ w(f), for instance the highest-weight member of V_{D_n}, has u(g) < 2L·(K ln 2 + ln(1/δ))/n: used alone for every call of every later run, it produces a run that differs from the human system's with less than this probability.

*Proof.* *Step 1 (Occam martingale).* Fix g. Let B_t := 1[a question is asked in round t and g(x_t) ≠ f(x_t)], so g ∈ V_{D_n} if and only if B_t = 0 for all t ≤ n. Since J_t is uniform and independent of the run, E[B_t | D_{t−1}] = d_t(g)/L =: r_t, and r_t is a function of D_{t−1}. Put N_s := Π_{t≤s} (1 − B_t)·e^(r_t). By (E3), E[(1 − B_t)e^(r_t) | D_{t−1}] = (1 − r_t)e^(r_t) ≤ 1, so (N_s) is a nonnegative supermartingale with N_0 = 1 and E[N_n] ≤ 1. On the event {g ∈ V_{D_n}, Σ_{t≤n} r_t ≥ c} we have N_n ≥ e^c; so this event has probability at most e^(−c) by Markov's inequality. Take c := ln(1/(w(g)δ)) and sum over g: the probability that some consistent g has Σ_t d_t(g) ≥ L·ln(1/(w(g)δ)) is at most Σ_g w(g)·δ ≤ δ. This is (a).

*Step 2 (the mixture's runs are mostly faithful, with high probability).* Let β_t := E[number of unfaithful calls of the run of M^(t) | D_{t−1}], and m_t the mass removed in round t. A call at input x is unfaithful with probability ē_t(x) = 1 − M^(t)(f(x)|x) given the run so far, and m_t = ē_t(x_t) when a question is asked, so E[m_t | D_{t−1}] = β_t/L, and β_t/L ≤ 1 − w_t(f) < 1. The process Π_{t≤s} (1 − m_t)/(1 − β_t/L) is a positive martingale with mean 1. By Markov's inequality, with probability at least 1 − δ it is below 1/δ at s = n, and then, by Lemma 1.5 and (E2), Σ_{t≤n} β_t/L ≤ Σ_{t≤n} −ln(1 − β_t/L) < ln(1/δ) + Σ_{t≤n} −ln(1 − m_t) ≤ ln(1/δ) + K ln 2. (This is Lemma 4.3(a) of `proofs/rehearsal-core.md`.)

*Step 3 (from the visit distribution of the mixture to the hypothesis's own run).* Fix g and t. Given D_{t−1}, consider the run of M^(t) on (z, ρ). If g's own run on (z, ρ) is unfaithful, g is wrong at the input x^f_{j*} of the human system's run, j* its first deviation index (Lemma 1.4); and if the run of M^(t) is faithful, it is the human system's run and visits x^f_{j*}. So the number of calls of the mixture's run at whose inputs g is wrong is at least 1 on the intersection of the two events, and

  d_t(g) ≥ u(g) − Pr[the run of M^(t) is unfaithful | D_{t−1}] ≥ u(g) − β_t.

*Step 4.* Average Step 3 over t ≤ n: u(g) ≤ (1/n)Σ_t d_t(g) + (1/n)Σ_t β_t. On the intersection of the events of Steps 1 and 2, which has probability at least 1 − 2δ, the first term is below L·ln(1/(w(g)δ))/n for every consistent g and the second is below L·(K ln 2 + ln(1/δ))/n. ∎

*What it says and does not say.* The selection may be any rule that returns a consistent hypothesis: the bound is uniform over the version space, with the weight of the selected hypothesis in it. The first term is the price of selecting; the second is the price of having measured g on the mixture's runs instead of its own. The statement is for a deterministic human and deterministic hypotheses. For a human who is not deterministic the corresponding rules have no guarantee in terms of K alone: not the member of largest posterior weight (Example 3.6) and not a draw from the final posterior (Example 3.1); see Remark 3.9 for what they have in a finite class. A member selected with the weights squared has a guarantee in terms of K (Theorem 3.8). The driver matters: with the first-consistent driver in place of the mixture the same selection rule is the driver itself, and Example 5.2 applies. For a rehearsal driven by posterior draws see Proposition 5.7.

**Corollary 5.6 (one posterior draw at the end, kept for good). NEW.** In the setting of Theorem 5.5 draw ĝ from the final posterior w_{D_n}. With probability at least 1 − 2δ over the rehearsal and the draw, u(ĝ) < 2L·(K ln 2 + ln(1/δ))/n.

*Proof.* For c > 0 let Bad_c := {g ∈ V_{D_n} : Σ_{t≤n} d_t(g) ≥ L·c}. The posterior mass of Bad_c is w(Bad_c)/w(V_{D_n}) ≤ w(Bad_c)/w(f), and E[w(Bad_c)] = Σ_g w(g)·Pr[g ∈ Bad_c] ≤ e^(−c) by Step 1. With c := K ln 2 + ln(1/δ) the expected posterior mass of Bad_c is at most δ, so ĝ ∉ Bad_c with probability at least 1 − δ. Combine with Steps 2 to 4. ∎

**Proposition 5.7 (the same when the rehearsal is driven by posterior draws). ADDED in editing** (the statement is in the first referee's script `one-mind_check_exact.py`, check 8, which verifies the identities used below on 786 version spaces and the bounds (a) and (b) by exact enumeration of all paths on eight classes; the two reports of the first round contain no proof; the proof below is the editor's, and the second check verified it line by line, Section 10.4). ## 6. One program or a committee: what the results imply

The researcher would like the imitator to be one program, like the human, and not a mixture. The table says which guarantees a single member of the class can carry. "Member per run" is a posterior draw for each run; "member for good" is one member selected once and kept. Every entry is a statement of this file or a quotation from another proof file; the comparisons between columns are comparisons of upper bounds unless a lower bound is named. Every upper bound that contains K = log₂(1/w(P)) says something only when the number of questions exceeds a multiple of K (editor, referee round; the sentence read "All bounds are linear in K", see "In brief", item (5)). For a person under a prior that does not already contain the person, the note uses K of the order of 10⁹ bits (its Section 9; the figure is an order of magnitude taken from the literature on human memory, see the proof file of part assumptions, Section 6.3 of `research/prove-c/assumptions.md`); then none of the bounds is below 1 unless n is of the order of 10⁹ or more, and what remains is the comparison between the columns.

Five conclusions.

1. **For a deterministic human a single program is available at the same order of cost** as the committee, as long as every call matters: a fresh draw per run costs the factor 2L/(L + 1), a program fixed for good costs the factor 2 and a confidence parameter (ratios of upper bounds). The program must be chosen by a posterior draw, or selected after a rehearsal driven by the mixture or by posterior draws; it must not drive the rehearsal as the current simplest consistent hypothesis.

2. **Under low stakes one member of the class is not enough; the committee is, and in the examples so is one program computed from the committee.** A member of the class that is wrong at a rare input is the same wrong member at the next call; a committee that errs once is corrected by its other members at the next call. Tolerance of faults is used by the committee (R3). In the trap class it is also used by the committee's plurality vote, which is one deterministic program and not a member (Remark 4.5); whether this holds in general is open. It is not used by a posterior draw (Proposition 4.2), nor by the highest-weight consistent member when the traps are heavier than the human (Proposition 4.6), nor by any rule that deploys a member chosen before the run's input is seen, for some human of class B, who may depend on the rule (Proposition 4.3; there the count is of answers that differ from the human's).

3. **For a human who is not deterministic, rehearsal data do not support, with a bound in terms of K alone, a member drawn from the posterior or the member of largest posterior weight; they support a member selected with the weights squared.** Under A1 the human's answers at different calls are independent given the inputs. A fresh draw per call has this property by construction, and so has any single member kept for good. The posterior over members need not: it can keep, for as long as the asked inputs do not recur, members whose answers at the calls of one run are jointly unlike the human's while each single answer is distributed correctly, because single answers do not test joint behaviour. A posterior draw per run reproduces that dependence (Example 3.1), and putting all calls of the driver's runs to the human does not help in general (Proposition 3.2; in Example 3.1 itself, where a run repeats its input, it would). Recorded runs of the human system support the posterior draw per run (Theorem A); whether fewer answers on the human's own path suffice is open. Selection by posterior weight fails for another, known, reason: members that are more definite than the human fit the answers better (Example 3.6). Squaring the weights removes them, and the selected member's run law is then as close to the human system's as the mixture's, up to a constant and a confidence parameter (Theorem 3.8, verified by the second check). In a finite class the prior's own weights give a bound that contains the logarithm of the class's size (Remark 3.9); what fails at the prior's own weights is a bound in terms of K alone. The rehearsal should be driven by the mixture: driven by posterior draws it controls the mixture's own runs only up to the factor 2^K (Proposition 3.5), and Theorem 3.8 is proved for the mixture as the driver only. The per-call mixture is itself one stateless sampler, a single program in the sense of the model; it is not a member of the class, and its description is the data and the class, not a program of K bits.

4. **Nothing here separates the human's own program from another member that behaves like it on the closed system.** Theorems 2.1, 5.5 and 3.8 bound how often, or how far in law, the selected member's run differs from the human system's; they say nothing about which member it is (the copy test). For a human who is not deterministic the candidates that survive rehearsal at the prior's own weights include the human "with coins filled in" (Examples 3.1 and 3.6); the difference is behavioural, visible in runs and invisible in single calls, and with the weights squared these candidates lose their weight.

5. **The absolute bounds are empty for a person.** Every upper bound that contains K needs a number of questions above a multiple of K before it says anything (editor, referee round; the sentence read "Every bound is linear in K", see "In brief", item (5)). With K of the order of 10⁹ bits, the figure the note uses for a person under a generic prior, none of them is below 1 unless the number of questions is of the order of 10⁹ or more. The comparative statements do not depend on K being small: the factors between the committee, a member per run and a member for good; the failure of the simplest-consistent driver; the failure of members under low stakes; the failure of posterior draws and of the largest posterior weight for a human who is not deterministic.

## 8. Open questions, and remarks on other files

### 8.1 Open in this part

1. **The exact constant of R4** for given L and K lies between S(L, K) and (2L²/(L + 1))·K ln 2; for K > 1 these differ by the factor (1 − 1/L)(1 − 1/K) at most. A version of Theorem 2.1 for the last round in place of a random round is not written. (A version with high probability over the rehearsal is Proposition 5.7(a).)
2. **A nearly deterministic human** (P(f(x)|x) ≥ 1 − ε for all x). In Example 3.1 the damage is of order ε per run. Whether the posterior-draw driver satisfies a bound of the form (R4 bound) + O(L·ε) in general is not treated.
3. **A human who is not deterministic, a posterior draw per run, and single-call data.** Proposition 3.2 refutes the posterior draw per run for rehearsal data, including all calls of the rehearsal runs. Recorded runs of the human system cost L answers each. Whether fewer answers on the human's own path suffice (for example a random prefix of a human run) is open.
4. **R6(a) for 2^K > L + 1** (Remark 5.4): the worst case of the number of unfaithful rounds among the first n for the first-consistent driver.
5. **Theorem 5.5** with one confidence parameter (a single martingale for Steps 1 and 2).
6. **The vote.** Remark 4.5 uses the plurality function in class B only. A general statement that the plurality vote of the posterior inherits the committee's use of fault tolerance is not proved here; Protocol AB of `proofs/lower-bounds.md` bounds the probability of a fully faithful run, not the number of unfaithful calls.
7. **Theorem 3.8 and Remark 3.9.** They were proved by the editor and verified by the second check (Section 10.4); no adversarial reader has tried to break them. Open: the constants 28 and 40 are not optimised, and it is open whether one program can match the mixture's bound 2L·K ln 2/n up to a factor 1 + o(1); the weights w^λ for 1 < λ < 2 are not treated (for recorded runs Theorem B covers every λ > 1); a human outside the class is not treated; a rehearsal driven otherwise than by the mixture is not treated. For a rehearsal driven by posterior draws Proposition 3.5 shows that the mixture's own runs are controlled only up to the factor 2^K; whether the member selected with the weights squared then has a bound without that factor is open, and the example of Proposition 3.5 does not decide it (the paragraph after Theorem 3.8).
8. **A general lower bound for members under low stakes.** Propositions 4.2, 4.3 and 4.6 are examples. A statement of the form "in every class closed under such and such patches, a rule that deploys a member cannot use fault tolerance" is not formulated.

## 9. Literature, and what is used from where

**What the proofs use.** No result from the literature is used as a black box. The proofs use Markov's and Chebyshev's inequalities, the Cauchy–Schwarz inequality, the Bonferroni inequality 1 − (1 − x)^m ≥ mx − (m choose 2)x², nonnegative supermartingales with Markov's inequality, and once (Proposition 3.5(a)) the maximal inequality for nonnegative supermartingales.
