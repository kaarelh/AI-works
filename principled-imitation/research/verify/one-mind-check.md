## A. Sections 0 to 2 (conventions, setting, R4)

**Section 0 (conventions). CORRECT.** (E2) and (E3) are the standard inequalities. The change of notation (T for the length of a run, U for the round of deployment) is announced and used consistently.

**Definitions 1.1 to 1.3. CORRECT.** Checked: with W < 1 the prior is normalised by ξ(∅) = W, so the posterior weights add up to 1 and M_D is a probability kernel on Y_⊥ whenever ξ(D) > 0; for a function f ∈ H every data list that can arise has ξ(D) ≥ w(f) > 0. The three drivers are well defined; the first-consistent driver always exists because f is never removed.

**Lemma 1.4 (first deviation). CORRECT.** (a) The induction is complete: for j ≤ min(σ, T) the answers before call j are f's answers at f's inputs, so the two histories agree, next_j has the same value in both runs, and it is not STOP because the run has a j-th call. (b) If σ = ∞, part (a) gives T ≤ T^f and equal histories after T calls, so both runs stop at the same call; if σ < ∞ the two runs have call σ at the same input with different answers. (c) The event {σ ≥ j} is the event that the first j − 1 answers are f's answers at x^f_1, …, x^f_{j−1} (if they are, the run has these calls, by (a)); the answers are independent draws. Edge cases: T^f = 0 gives σ = ∞ with probability 1 (empty product); a semimeasure's missing mass counts as the wrong answer ⊥, and f(x) ≠ ⊥ because the human is a sampler. Confirmed by brute-force enumeration of run trees (Section H.1, check 1).

**Lemma 1.5 (potential). CORRECT.** M_{D_{k−1}}(y_k|x_k) = ξ(D_k)/ξ(D_{k−1}), the product telescopes to ξ(D_n)/W, and ξ(D_n) ≥ w(f)·f(D_n) = w(f). (E2) applies because 1 − m_k ≥ w_{D_{k−1}}(f) > 0. The statement holds on every path and for any way of choosing the questions, which is what Theorem 2.1 and Theorem 5.5 need.

**Theorem 2.1 (R4). CORRECT**, including the two extensions claimed (stochastic hypotheses; runs of variable length). Line by line:
* *The function ψ_L.* ψ_L′(u) = 1 − u(L − 1)/L ≥ 1/L > 0, ψ_L″ < 0, and ψ_L(u) = u·(1 − u(L − 1)/(2L)) ≥ u·(L + 1)/(2L).

J_t is independent of (ν_t, its answers), so the event {J_t = j, σ ≥ j} has probability (1/L)·Pr[σ ≥ j], and Pr[σ ≥ j] = 1 − Σ_{i<j} p_i because Pr[σ = i] = p_i under ν_t ~ w_t. The removed mass on this event is ē(x^f_j) ≥ p_j; elsewhere it is ≥ 0.
* *Step 3.* Σ_j p_j(1 − Σ_{i<j} p_i) = u − ½(u² − Σ_j p_j²) and Σ_j p_j² ≥ u²/T^f ≥ u²/L. (If T^f = 0 then u = 0 and there is nothing to prove.)

* *Numerical confirmation.* The per-round inequality E[m_t | D_{t−1}, z, ρ] ≥ ψ_L(u_t(z, ρ))/L holds in 4000 of 4000 random instances with stochastic hypotheses, semimeasures and runs of variable length, computed exactly by enumeration of run trees; and the totals Σ_t E[ψ_L(u_t)] and Σ_t E[u_t] over an infinite rehearsal, computed exactly as an absorbing Markov chain on version spaces, are below L·ln(W/w(f)) and (2L²/(L + 1))·ln(W/w(f)) in all 300 random classes tried (Section H.1, checks 2 and 3).

## D. Section 5.1 (R6(a): the simplest consistent hypothesis as driver)

**Proposition 5.1 (R6(a), upper bound). CORRECT.** Line by line:
* f is never removed, so the first consistent index is at most i₀, and a removed function is never consistent again; so only g_1, …, g_{i₀−1} can drive an unfaithful run.
* In a round driven by g_i whose run is unfaithful, the first deviation σ of g_i's run from f is finite and the run has a σ-th call at x^f_σ (Lemma 1.4(a),(b)). J_t is uniform on [L] and independent of (z_t, ρ_t) and the past, so J_t = σ with probability exactly 1/L; then the question is x^f_σ, the human answers f(x^f_σ) ≠ g_i(x^f_σ), and g_i is removed. So, round by round, each unfaithful round of g_i's reign ends the reign with conditional probability at least 1/L, and the number of such rounds is stochastically dominated by a geometric variable with mean L. Summing over i < i₀ gives L·(i₀ − 1).
* The count: if the enumeration is by non-increasing weight, w(g_i) ≥ w(f) for i < i₀, so (i₀ − 1)·w(f) ≤ W − w(f) and i₀ − 1 ≤ W/w(f) − 1 ≤ 2^K − 1 (K := log₂(1/w(f)), W ≤ 1). Ties in weight may be ordered arbitrarily; the bound still holds because only w(g_i) ≥ w(f) is used.
* Edge cases: L = 1 gives i₀ − 1 (each wrong driver is removed in its first unfaithful round); runs with no call are faithful and ask nothing; i₀ = 1 gives 0.
* Numerical: the exact totals over 300 random classes (Section H.1, check 3) reach the bound with ratio 1.0000 at the maximum, as Example 5.2 predicts.

**Example 5.2 (the bound is attained when 2^K ≤ L + 1). CORRECT.** Recomputed:
* with driver g_d (g_1, …, g_{d−1} already removed) the run answers 0 at inputs 1, …, d − 1, 1 at d, and then stands at ⋆; d ≤ M ≤ L, so the run has a d-th call and is unfaithful;
* J < d asks j < d, where all surviving functions answer 0; J = d asks d, where exactly g_d answers 1; J > d asks ⋆, where all answer 0. So each round of g_d's reign is unfaithful and ends the reign with probability exactly 1/L, and removes nothing else;
* (a) the total is a sum of M independent geometric variables with mean L: exactly L·M, with K = log₂(M + 1) (W = 1, w(f) = 1/(M + 1));
* (b) Var ≤ M(L² − L) ≤ ML²; Chebyshev gives Pr[S < LM/2] ≤ 4/M ≤ 0.1 for M ≥ 40, and round n is unfaithful iff n ≤ S. The exact negative-binomial value at n = ⌊LM/2⌋ is at least 0.99995 on a grid of M ∈ {40, …, 400}, L ∈ {M, …, 10M} (Section H.5), so the stated 0.9 is very conservative.
* The comparison sentences: ln(W/w(f)) = ln(M + 1); in this scaffold every call after the first answer 1 is at ⋆, where every hypothesis agrees with f, so a run has at most one unfaithful call and Theorem R1 bounds the number of unfaithful rounds of the mixture by L ln(M + 1). **Example 5.3 (large K: the bound is approached, slowly). CORRECT.** Recomputed:
* the only input at which g_i differs from f is (i, 1), and it is the input of call 1 exactly when z = i; later calls are at (z, j), j ≥ 2, or ⋆. So a question removes g_i iff z_t = i and J_t = 1, whoever drives, an event of probability ε^i/L per round; the removal times D_i are first occurrences of disjoint events in i.i.d. rounds, so Pr[D_i < D_d] = ε^i/(ε^i + ε^d);

* given that the reign is not empty, the number of its rounds with z_t = i is geometric with mean exactly L: the event {D_i > max_{d<i} D_d} and the time max_{d<i} D_d are determined by the rounds up to that time, and the later rounds are fresh (strong Markov property). The proof states this step as "each such round ends the reign with probability 1/L"; the conditioning on a non-empty reign is legitimate for the reason just given, which the proof could state;

## E. Section 5.2 (R6(b): one hypothesis selected at the end)

**Definition of d_t(g). CORRECT.** Since J_t is uniform on [L] and independent of the run, the probability given D_{t−1} that a question is asked and removes g is (1/L)·Σ_j Pr[j ≤ T, g(x_j) ≠ f(x_j)] = d_t(g)/L.

**Theorem 5.5 (R6(b)). CORRECT.** Line by line:
* *Step 1.* r_t = d_t(g)/L is predictable; (1 − r)e^r ≤ 1 holds for every real r (E3), so N_s is a nonnegative supermartingale with E N_n ≤ 1. On {g ∈ V_{D_n}, Σ_t r_t ≥ c} all B_t vanish and N_n = e^{Σ r_t} ≥ e^c, so the event has probability ≤ e^{−c} (Markov). With c = ln(1/(w(g)δ)) the union over the countable class costs Σ_g w(g)δ = Wδ ≤ δ. The complement gives the strict inequality of (a). Rounds without a question have B_t = 0 and are covered.
* *Step 2.* A call at input x is unfaithful with conditional probability ē_t(x) given the run so far, so β_t = E Σ_{j≤T} ē_t(x_j) and E[m_t | D_{t−1}] = β_t/L; m_t ≤ 1 − w_t(f), so β_t/L < 1. Π_t (1 − m_t)/(1 − β_t/L) is a positive martingale with mean 1; on the event that it is < 1/δ at n, Σ_t β_t/L ≤ Σ_t −ln(1 − β_t/L) < ln(1/δ) + Σ_t −ln(1 − m_t) ≤ ln(1/δ) + ln(W/w(f)) ≤ ln(1/δ) + K ln 2, by (E2) and Lemma 1.5.
* *Step 3.* If g's own run on (z, ρ) is unfaithful, Lemma 1.4 applied to g's run against f gives a first deviation σ < ∞ with g wrong at x^f_σ, σ ≤ T^f. If the mixture's run on (z, ρ) is faithful it is τ^f(z, ρ) and visits x^f_σ. Hence u(g) − Pr[mixture run unfaithful] ≤ Pr[mixture run visits an input where g is wrong] ≤ d_t(g); and Pr[mixture run unfaithful] ≤ Pr[≥ 1 unfaithful call] ≤ β_t (Lemma 1.4(b) applied to the mixture's run: a run with no unfaithful call is τ^f).
* *Step 4.* Adding the two bounds gives L(ln(1/w(g)) + K ln 2 + 2 ln(1/δ))/n on an event of probability ≥ 1 − 2δ. The "in particular": for w(g) ≥ w(f), ln(1/w(g)) ≤ ln(1/w(f)) = K ln 2 by the convention of Section 0, giving 2L(K ln 2 + ln(1/δ))/n; the highest-weight member of V_{D_n} qualifies because f ∈ V_{D_n}.
* *Hypotheses.* Deterministic human and a class of functions are both used (Step 3 needs functions so that "g's own run" is a point given (z, ρ) and Lemma 1.4 applies; Lemma 1.5 needs f(D) = 1). The mixture driver is used in Step 2 (β_t is the mixture's quantity) and Step 3. None is missing.
* *Numerical.* Exact enumeration of all paths of version spaces on seven small classes (Section H.1, check 6): the two martingales have mean exactly 1 and neither (a) nor (b) fails with probability above δ; on a nearly tight instance with L = 1 (check 7) the failure probability of (a) is 0.048 for δ = 0.1, so the factor ln(1/δ) cannot be much improved.
*"What it says and does not say."* Correct, with one qualification: "for a stochastic human no version holds (Section 3)" is shown in Section 3 for a posterior draw kept for good; for the highest-weight member it needs another example, given in F below (the codebook class).

**Corollary 5.6. CORRECT.** For a class of functions the posterior is w restricted to V_{D_n} and normalised by w(V_{D_n}) ≥ w(f), so the posterior mass of Bad_c is ≤ w(Bad_c)/w(f); E w(Bad_c) ≤ W e^{−c} by Step 1; with c = K ln 2 + ln(1/δ), W e^{−c}/w(f) = Wδ ≤ δ.
