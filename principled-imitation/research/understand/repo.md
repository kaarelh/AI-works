## 1. Notation and the versions of SOI

**Data and the versions (P1).** Inputs X are binary strings; labels Y form a countable set (finite in P2). A *data set* D is a finite partial function X ⇀ Y; D_n is the set of the first n pairs; a sequence is *consistent* if no input reappears with another label. K is prefix complexity on a fixed universal prefix machine V; c, O(1) and (in P2) κ are machine constants; m(i) ≥ 2^(−K(i)) is the universal discrete semimeasure. A *function machine* T reads, on each query x, a prefix of **one** random tape ω shared by all queries and outputs a label or diverges; its *machine law* is ν_T(D) = Prob_ω[f^T_ω ⊇ D]. The **one-tape version** (the default "SOI") is the law M_F of the universal function machine: M_F(D) = Σ_i m(i)·ν_{T_i}(D) for D ≠ ∅, conditioned on the data; its loss L_SOI(D) = −log M_F(D) is the cumulative log loss in the *semimeasure convention* (raw conditionals; the missing mass is the posterior probability of "undefined"), and does not depend on the order of the data; the *normalised convention* divides each conditional by its sum and never increases the loss. The **coin-free version** is the program mixture W(D) = Σ_p 2^(−|p|)·1[φ_{V(p)} ⊇ D] over deterministic programs, and the **Kolmogorov version** is K_F(D), the length of a shortest program consistent with D. The **product version** is M_prod(D) = Σ_i m(i)·Π_{(x,y)∈D} P_i(y|x), a mixture over all lower-semicomputable (lsc) conditional semimeasures P_i, each drawing private coins at each *input*; the **per-query version** M_pq(y_{1:n}‖x_{1:n}) = Σ_i m(i)·Π_{t≤n} P_i(y_t|x_t) is the same mixture scored on sequences, with fresh coins at each *query*. M_pq is Solomonoff's own solution (2008, eq. (10)); it equals M_prod on sequences with distinct inputs, and it alone gives positive probability to an input that reappears with another label. The **history-aware version** SOI^hist has law M_H, the one-tape law over input *lists*: its hypotheses see the earlier inputs (not the earlier labels, which they can recompute), and M_H is a universal lsc chronological semimeasure. The versions satisfy 2^(−K_F(D)) ≤ W(D) ≤ O(1)·M_prod(D) ≤ O(1)·M_F(D) ≤ O(1)·M_w(D) ≤ 2^(K(dom D)+O(1))·2^(−K_F(D)) (M_w a universal lsc weak function semimeasure), and no two of K_F, W, M_F agree up to a constant [read in source: P1 `setting.tex` def:setting:data, def:setting:machine, thm:setting:universal, def:setting:sfi; `versions.tex` def:versions:variants, thm:versions:chain (Thm 4.4), thm:versions:nocoding (Thm 4.9); `hist.tex` def:hist:sfihist, cor:hist:H4].

**Steeper priors, samplers and the population objective (P2).** A *product hypothesis* is an lsc conditional semimeasure ν(y|x); the class H_× consists of the programs π ∈ dom V for such kernels ν_π, of length ℓ(π), "two programs for the same law are different hypotheses". Three data objects: **DS** (one data set, no probability model), **FR** (frozen labels: one label per distinct input, drawn once) and **PQ** (per-query: pairs i.i.d. from μ⊗ν, the label redrawn at every query, the sample being h_n); FQ is a frozen table counted per query. The *fit* is L(π;o) = −log P_π(o); the *steeper objective* is J_λ(π;o) = λ·ℓ(π) + L(π;o) with *complexity weight* λ ≥ 1, a minimiser is a **λ-MAP**; the *power-prior posterior* is Π_λ(π|o) ∝ 2^(−λℓ(π))·P_π(o) with normaliser ξ_λ (the *steeper mixture*; ξ_1 in H_× is M_prod, respectively M_pq). With n data points and c := λ/n, J_λ/n = c·ℓ(π) + empirical risk, whose population version is J_c(π) = c·ℓ(π) + R(π), R the expected log loss, and Φ(c) = inf_π J_c(π); statements with λ = cn are batch statements. A *sampler* is a probability kernel ν; 𝓔 is the set of programs whose kernel equals ν at μ-almost every input, ℓ_0 its least length, 𝓔_0 the shortest ones; a *fill-in* is a deterministic program consistent with the data; the *Hellinger gap* is Hel_μ(π) = E_{x∼μ}[1 − Σ_y √(ν(y|x)ν_π(y|x))], and γ_L̄ is the least gap among programs outside 𝓔 of length ≤ L̄ (a *margin*); L_n(ν) = −log ν(o_n) is the *sampled randomness*. The **Ville deficiency** is δ* = sup_n log(ξ_𝒞(o_n)/ν(o_n)) for the class mixture ξ_𝒞 = Σ_π 2^(−ℓ(π))ν_π, and Prob[δ* ≥ j] ≤ 2^(−j). A class has **(Dom)** if one member U satisfies P_π ≤ 2^(ℓ(π)+κ_0)·U for all π (true of the one-tape, weak, sequence and history-aware classes, which contain their own mixture; false in H_×). In the plane (length, fit), a reference point has a *left kink* of steepness σ if every shorter program fits worse by at least σ bits per bit saved, and a set of programs has a *right line* (τ, g) if no program gains more than τ bits of fit per extra bit, up to an offset g. For out-of-distribution statements: a decidable Q ⊆ X *separates* x from a set A of inputs if x ∈ Q and Q ∩ A = ∅; sep(x;A) is the least K(Q) over such Q; K(Q,b) is the complexity of a decider of Q paired with a program for a behaviour b [read in source: P2 `setup.tex` def:setup:data, def:setup:product, def:setup:class, def:setup:objectives, rem:setup:persample; `recovery.tex` def:split:setting, lem:split:ville; `absorb.tex` eq. (Dom); `kinks.tex` def:kink:kinks; P1 `ood.tex` conventions, prop:ood:budget].

### A. Learning and regret bounds that hold on every input sequence

**A1. Universal function machine** [thm:setting:universal, P1 Thm 3.8, `setting.tex`; prop:setting:includes, Prop 3.9]. M_F(∅) = 1 and, for every D ≠ ∅, M_F(D) = Σ_i m(i)ν_{T_i}(D); hence M_F ≥ 2^(−K(ν))·ν for every machine law ν. Machine laws include: (a) the product law ν_P(D) = Π_{(x,y)∈D} P(y|x) of every lsc conditional semimeasure P, with K(ν_P) ≤ K(P) + O(1), and "probabilistic machines that read x and output y (halting or not) define exactly these P"; (b) every deterministic partial computable φ; (c) computable laws of random partial functions; (d) lsc mixtures of machine laws. [read in source]

**A2. Dominance** [thm:learn:dominance, P1 Thm 5.1, `learn.tex`]. For every machine law ν and every consistent sequence, "however its inputs are chosen (in advance, adversarially, adaptively, non-computably)": L_SOI(D_n) ≤ −log ν(D_n) + K(ν). In particular (a) for every lsc conditional semimeasure P, L_SOI(D_n) ≤ Σ_{t≤n} −log P(y_t|x_t) + K(P) + c (the right side counts a repeated input each time, the left side once); (b) if y_t = φ(x_t) for a partial computable φ, L_SOI(D_n) ≤ K(φ) + c; (c) against an lsc weak semimeasure ν the bound has an extra K(dom D_n), which cannot be replaced by a constant. [read in source]

**A3. Order independence; normalisation** [prop:setting:order, P1 Prop 3.16; prop:setting:normalise, Prop 3.17; `setting.tex`]. For every weak semimeasure ν and consistent sequence, Σ_{t≤n} −log ν(y_t|D_{t−1},x_t) = −log ν(D_n) + log ν(∅), which depends only on the set D_n; on an inconsistent sequence it is infinite. The normalised loss is at most the semimeasure loss. [read in source]

**A4. Invariance** [thm:setting:invariance, P1 Thm 3.20, `setting.tex`]. Two universal machines change log M_F(D) by at most a constant; computable injective re-encodings α, β of inputs and labels change it by at most K(α,β) + O(1), uniformly over data sets. The same holds for W, M_prod, M_w. [read in source]

**A5. The one-tape version cannot model fresh label noise** [prop:learn:freshnoise, P1 Prop 5.6, `learn.tex`]. Let μ(x_0) = α > 0 and P(·|x_0) give positive probability to two labels; draw pairs i.i.d. from μ×P with a fresh label at every draw, and predict with any weak semimeasure (M_F, W, M_prod, M_w) under the repeated-input convention. Then for every n ≥ 2 the data are inconsistent with positive probability, so the expected cumulative log loss is infinite in both conventions, and Prob[D_n consistent] → 0. The repairs are time-stamped inputs, frozen noise, or M_pq. [read in source]

**A6. Solomonoff's per-query solution** [prop:learn:perquery, P1 Prop 5.7, `learn.tex`]. (a) M_pq is an lsc chronological semimeasure that depends only on the multiset of pairs. (b) **On every sequence, consistent or not**: −log M_pq(y_{1:n}‖x_{1:n}) ≤ Σ_{t≤n} −log P(y_t|x_t) + K(P) for every lsc conditional semimeasure P. (c) If (x_t,y_t) are i.i.d. from μ×P (μ arbitrary, P any conditional probability), q_t the predictive of M_pq and q̄_n the average of q_1..q_n, then for every lsc P′: Σ_{t≤n} E E_μ KL(P‖q_t) ≤ K(P′) + n·E_μ KL(P‖P′), so E E_μ KL(P‖q̄_n) ≤ K(P′)/n + E_μ KL(P‖P′). (d) With stamped inputs, M_F ≥ 2^(−c)·M_pq. P1 adds that Solomonoff (2008, eq. (12)) proves the expected squared-error form "for labels drawn from P(y|x) computed by a probabilistic algorithm describable in k bits, and any given sequence of inputs": the expected summed squared error of the predicted symbol probabilities is less than k·ln 2. [read in source]

**A7. Merging for the one-tape version** [thm:learn:merging, P1 Thm 5.3, `learn.tex`]. Let ν be a machine law of a random total function (equivalently a computable one), F ∼ ν, and let the inputs follow any measurable rule x_t = s_t(h_{t−1}, ξ_t) with (ξ_t) independent of F and s_t arbitrary (possibly non-computable). With d_t = KL(ν(·|D_{t−1},x_t) ‖ M_F(·|D_{t−1},x_t)): Σ_{t≥1} E d_t ≤ K(ν), d_t → 0 almost surely, and Σ_t E‖ν(·|D_{t−1},x_t) − M_F(·|D_{t−1},x_t)‖_1² ≤ 2 ln 2·K(ν). If the rule may see F the expected bound can fail (a finite analogue with bound 1 bit has summed KL 12.5 bits); the pathwise bound A2 still holds. Frozen noise is the special case of a product law: thm:learn:batch(c) (Thm 5.5(c)). [read in source]

**A8. History-aware prediction** [`hist.tex`]. (i) [cor:hist:H4, P1 Cor 6.17] M_H ≥ 2^(−K(ρ)−c)·ρ for every lsc chronological semimeasure ρ; for every lsc history-aware predictor P and **every** sequence, consistent or not, L_H ≤ L_P + K(P) + c; and L_H ≤ L_SOI(D_n) + c in every order. (ii) [thm:hist:chain, Thm 6.3; thm:hist:skipped, Thm 6.4; prop:hist:orderfree, Prop 6.5] there are deterministic O(1)-complexity predictors that see the history and have loss 0 on sequences on which SOI, and every order-independent predictor that sees the past as a set, pays quadratically many bits (Ω(n²) in the chain example). (iii) [thm:hist:shared, Thm 6.8] for computable samplers Δ (of inputs) and P (of labels), on every consistent sequence L_SOI(D_n) ≤ L_P + L_Δ + K(Δ) + K(P) + c. (iv) [thm:hist:bayes, Thm 6.9; thm:hist:directed, Thm 6.10] if f ∼ ν is a computable random function and the inputs see f only through revealed labels, then L_SOI(D_n) ≤ −log ν(D_n) + K(ν) + c on every path and E L_SOI ≤ E L_P + K(ν) + c for every predictor P; if the inputs have any joint law with f, the excess is at most the directed information I(f → x_{1:n}) + K(ν) + c, and this can be quadratic (thm:hist:randchain, Thm 6.11). (v) [prop:hist:operator, Prop D.15] M_pq ignores the history: M_H dominates it, and on distinct inputs it pays the lower bounds of (ii). [read in source]

**A9. Computable relatives** [`comp.tex`, `app-comp.tex`]. (i) [prop:comp:round, P1 Prop 9.4; cor:comp:poly, Cor 9.5] a round-activated Bayes mixture of clocked programs has, on every stream (repeats and conflicting labels allowed), regret at most log(1/w_i) + (J_A − 1)·log|Y| against every predictor A = A_i running in time c_A·t(|x|); with clocks (|x|+2)^(g(k)) one learner has constant regret against every polynomial-time x-only predictor. (ii) [prop:comp:samplers, Prop G.4] the same against time-bounded *samplers*, at a cost per round exponential in the clock; polynomial time per round is open (q:comp:samplers). (iii) [prop:comp:history, Prop 9.6] constant regret against time-bounded history-aware predictors. (iv) SOI itself: M_F is lsc and not computable; its conditionals are computable relative to the halting problem and not computable [prop:setting:computability, Prop A.10]. [read in source]

**A10. The steeper mixture as a predictor** [P2 `absorb.tex`, `app-absorb.tex`, `setup.tex`, `teacher.tex`]. For fixed λ, ξ_λ is one Bayesian predictor with a telescoping loss; in H_× it dominates a sampler ν with a program of length k, ξ_λ^× ≥ 2^(−λk)·ν, so "their summed expected KL divergences to ν's predictions are at most λk" (sentence after the proof of thm:split:shared, by the argument of A7). With λ = cn the prior changes with n: there is no sequential regret, only the batch excess −log ξ_λ(D_n) ≤ n·(c·ℓ(π) + empirical risk of π) for every π [rem:limits:schedule, Rem 8.4], and in H_× no fixed prior with full support gives the cn-MAPs on every sample [prop:teacher:nofixedprior, Prop F.6]. [read in source]

### B. On-distribution risk (i.i.d. inputs)

**B1. Online-to-batch, deterministic labels** [thm:learn:batch(a), P1 Thm 5.5, `learn.tex`]. Let x_1, x_2, … be i.i.d. from **any** distribution μ (computable or not), φ partial computable with μ(dom φ) = 1, y_t = φ(x_t), Q_t = M_F(·|D_t, ·), Q̄_n the average of Q_0..Q_{n−1}, R(Q) = E_{x∼μ}[−log Q(φ(x)|x)]. Then Σ_{t<n} E R(Q_t) ≤ K(φ) + c; E R(Q̄_n) ≤ (K(φ)+c)/n; and the expected 0–1 risk of argmax_y Q̄_n(y|x) is at most (K(φ)+c)/n. The bounds are for the Cesàro average, not the last iterate (open: rem:learn:lastiterate, Rem C.2). [read in source]

**B2. Noisy labels** [thm:learn:batch(b), P1 Thm 5.5; prop:learn:perquery(c), Prop 5.7]. For y_t ∼ P(·|x_t) with any conditional probability P (possibly non-computable), SOI on stamped inputs ⟨x_t,t⟩, or M_pq without stamps, has E E_{x∼μ} KL(P(·|x) ‖ q̄_n(·|x)) ≤ (K(P′)+c)/n + E_μ KL(P‖P′) for every lsc P′; for computable P this is (K(P)+c)/n. The expected excess 0–1 risk over the Bayes classifier is at most √(2 ln 2) times the square root of the right side. [read in source]

**B3. Per-step error in distribution** [cor:learn:perstep, P1 Cor 5.10, `learn.tex`]. For any μ, partial computable f with μ(dom f) = 1, i.i.d. x_1..x_n, x*, ν ∈ {W, M_F}, and e(x*) = 1 − ν(f(x*)|D_n, x*): (a) E e(x*) ≤ ε + 2^(K(f)+c)·exp(−εn) for every ε, hence E e(x*) ≤ ((K(f)+c)·ln 2 + ln n + 1)/n; with probability ≥ 1−δ over the sample, E_{x*}[e(x*)|D_n] ≤ ε + 2^(K(f)+c)·exp(−εn)/δ; the posterior-majority predictor has expected 0–1 risk ≤ 2·E e(x*). (b) E e(x*) ≤ 2^(K(f)+c)/(n+1). [read in source]

**B4. Occam bound** [prop:learn:occam, P1 Prop 5.11, `learn.tex`; standard, after Blumer, Ehrenfeucht, Haussler and Warmuth, "Occam's Razor", *Information Processing Letters* 24(6):377–380, 1987, as cited there]. With x_t i.i.d. from μ and y_t = φ(x_t): with probability ≥ 1−δ, **every** program p consistent with D_n has μ{x : φ_{V(p)}(x) ≠ φ(x)} ≤ (|p|·ln 2 + ln(1/δ))/n. [read in source]

**B5. A lower bound even in distribution** [prop:learn:typical, P1 Prop 5.9, `learn.tex`]. For f ≡ 0 on {0,1}^d, n i.i.d. uniform training inputs and an independent uniform test input x*, d ≥ ⌈log n⌉ + 1: a prefix set of complexity ≤ log n + 2 log log n + c separates x* from the training inputs with probability ≥ 1/2, so E e^wr(x*) ≥ 2^(−c)/(8n(log n + 3)²) for ν ∈ {W, M_F}, in both conventions; for computable binary f, ≥ 2^(−K(f)−c)/(8n(log n+3)²). So the per-step error is Θ(1/n) up to log² n: it does not decay faster than polynomially. [read in source]

**B6. Splits, leave-one-out, learning curves** [prop:learn:splits, P1 Prop 5.8; prop:learn:loo, Prop C.3; conj:learn:loo, Conj C.4; prop:learn:curve, Prop C.1]. A uniformly random train/test split of any finite input set B (possibly adversarial) has expected test loss ≤ L_ν(f|_B)/|B|. Σ_{x∈B} e_LOO(x) < 2^(L_ν(f|_B)); whether the average leave-one-out error is O(K_F(f|_B)/|B|) is a conjecture. The expected risk of a Bayes predictor with a fixed target need not decrease with the sample size (explicit three-hypothesis example). [read in source]

### C. Adversarial input sequences and mistake bounds

**C1. Mistake bound** [cor:learn:mistakes, P1 Cor 5.4, `learn.tex`]. Let φ be partial computable, x_1, x_2, … ∈ dom φ **any** inputs, y_t = φ(x_t). At most K(φ) + c steps have M_F(φ(x_t)|D_{t−1}, x_t) ≤ 1/2; so the argmax predictor makes at most K(φ) + c mistakes on every input sequence. (The label is revealed after each prediction.) [read in source]

**C2. Cumulative error bound** [thm:ood:cumulative, P1 Thm 8.4, `ood.tex`]. Let f be computable and x_1, x_2, … any distinct inputs (adversarial, adaptive or non-computable), ν ∈ {W, M_F}, e_k = 1 − ν(f(x_k)|D_{k−1}, x_k). For every n: Σ_{k≤n} −log(1−e_k) ≤ K(f) + c; Σ_{k≤n} e_k ≤ (ln 2)(K(f)+c); #{k ≤ n : e_k ≥ δ} ≤ (ln 2)(K(f)+c)/δ. The same holds normalised, and with K(f)+c replaced by L_ν(f|_B) ≤ K_F(f|_B) + c for B = {x_1..x_n}. [read in source]

**C3. Choosing the order is worthless for log loss; small loss is not identification** [prop:learn:active, P1 Prop C.5, `app-learn.tex`]. (1) For every weak ν and every query set A, chosen adaptively or not, the total semimeasure log loss on the labels of A is −log(ν(f|_A)/ν(∅)) in every order. (2) For the point functions f_a(x) = 1[x = a] on {0,1}^d, the total loss of M_F on any query sequence is at most d + 2 log d + c, "yet every query strategy, adaptive or randomised, needs at least (2^d − 1)/2 queries in expectation over a uniform a to identify a". [read in source]

**C4. Selection rule matters out of distribution** [thm:comp:circuitbayes, P1 Thm 9.8; rem:comp:majority, Rem 9.9; thm:comp:ladder, Thm 9.10; `comp.tex`]. For Bayes over Boolean circuits with a size prior, on every ordering of every input set B: the expected number 𝓔 of mistakes of posterior sampling satisfies 𝓔 ≤ (ln 2)·L_B and L_B ≤ 16·𝓔·(d+1)·log(2(𝓔+1)(d+2)); the posterior-majority predictor makes at most L_B mistakes. But **Occam (simplest-consistent, i.e. MAP-hypothesis) learning** of the conjunction x_1∧…∧x_d makes at least 2^d − 2 (formulas) or 2^d − d − 2 (circuits) mistakes on a simply described ordering, for every tie rule: 2^(Ω(ℓ/log ℓ)) in the description length ℓ. With the same prior the posterior-majority predictor makes at most ℓ(f) mistakes on every ordering, "so it is the selection rule, not the prior, that fails". Whether a steeper posterior over a universal machine can fail exponentially on some ordering is open (q:comp:open(d)). [read in source]

**C5. Mistake bounds for steeper mixtures in shared classes** [thm:absorb:absorption(c), P2 Thm 4.2, `absorb.tex`]. In a class with (Dom), fixed λ > 1, a total computable teacher t with a program of length ℓ_t, distinct inputs: Σ_{i≤n} −log ξ_λ(t(x_i)|x_i, D_{i−1}) ≤ min{λℓ_t, λℓ_U + κ_0 + ℓ_t} for every n; every λ-MAP for D_n lies, from some n_0 on, in a fixed finite set, and at only finitely many n does a λ-MAP give t(x_{n+1}) probability below 1/2 (no explicit rate; "explicit online bounds for two-part MDL are in general exponentially worse than for Bayes mixtures", citing Poland and Hutter, "Asymptotics of Discrete MDL for Online Prediction", *IEEE Transactions on Information Theory* 51(11):3780–3795, 2005; I did not read that paper). With λ = cn these are not available. [read in source]

### D. Out-of-distribution floors and machine dependence

**D1. Unseen simple properties (the floor)** [prop:ood:hanni, P1 Prop 8.1, `ood.tex`]. Let Q be decidable, b partial computable, dom D ∩ Q = ∅, S ⊆ Q ∩ dom b finite, ν ∈ {W, M_F}. Then ν(D ∪ b|_S) ≥ 2^(−K(Q,b)−c)·ν(D), and the hypotheses consistent with D that agree with b on **all** of Q ∩ dom b have mass at least 2^(−K(Q,b)−c)·ν(D); also K_F(D ∪ b|_S) ≤ K_F(D) + K(Q,b) + c. "However large D is, SOI behaves like b on all unseen Q-inputs with posterior probability at least 2^(−K(Q,b)−c)"; no logarithmic term arises (rem:ood:logterm). A version for properties simple *given a program p that fits the training data* has floor 2^(−K(q,r|p)−c) times the posterior weight of p [prop:ood:relative, Prop F.2]. [read in source]

**D2. Dependence on the universal machine** [prop:ood:machine, P1 Prop 8.2, `ood.tex`; cf. Leike and Hutter, "Bad Universal Priors and Notions of Optimality", COLT 2015, PMLR 40:1244–1259, as cited there]. For every decidable Q and partial computable b there is a universal machine, at distance K(Q,b) + c from the reference one, which gives the same weights to all data sets disjoint from Q and under which the posterior probability of behaving like b on all of Q ∩ dom b is at least 1/2, for every nonempty D disjoint from Q. [read in source]

**D3. Two-sided bound on property-abiding generalisation** [thm:ood:twosided, P1 Thm 8.3, `ood.tex`]. Let P ⊆ X×Y be a property of pairs, Q decidable with dom D ∩ Q = ∅, S ⊆ Q finite nonempty. (a) If P is c.e. and every x ∈ Q has an abiding y, then ν(every x ∈ S gets a P-abiding output | D) ≥ 2^(−K(P,Q)−c). (b) If the complement of P is c.e. and every x ∈ Q has a violating y, then ν(some x ∈ S gets a P-violating output | D) ≥ 2^(−K(P,Q)−c). (c) For x ∈ Q and (x,z) ∉ P: M_F(D+(x,z)) ≥ 2^(−K(Q)−K(z|x)−c)·M_F(D). These hold "in both conventions and for every amount of data". Two natural pointwise sharpenings fail [prop:ood:draftfalse, Prop F.3]. [read in source]

**D4. Novelty budget** [prop:ood:budget, P1 Prop 8.5; rem:ood:lopsided, Rem 8.6]. With binary labels and sep_k the least K(Q) over decidable Q containing x_k and none of x_1..x_{k−1}: e_k ≥ e_k^wr ≥ 2^(−sep_k−c) for every k, and Σ_k 2^(−sep_k) ≤ 1. So separation forces constant error at single steps but only O(1) in total: "each simple property surprises only once" (when labels are revealed). [read in source]

**D5. Converses** [prop:ood:converse, P1 Prop 8.7; prop:ood:labelled, Prop 8.8; prop:ood:sandwich, Prop F.4]. (i) "No simple separating property ⇒ small error" fails for complex targets: for a uniformly random f every learner has expected normalised error ≥ 1/2 off the sample, while a property of conditional complexity ≤ s separates the test point with probability ≤ 2^(s+1)/(n+1). (ii) **Given the labelled sample** it holds with a factor depending on the target: for a labelling f of a finite B, x* ∈ B, A = B∖{x*}: e^wr(x*) ≤ e_norm(x*) ≤ 2^(L_ν(f) − K(x*|f) + c) ≤ 2^(K_F(f) − K(x*|f) + c′), with |K(x*|f) − sep(x*;A|f)| ≤ c; and e^wr(x*) ≥ 2^(−sep(x*;A) − K(y) − c) for every y ≠ f(x*). (iii) Whether a positive statement holds for properties simple given a program fitted to the training data only is open (Question 8.10). [read in source]

**D6. The intended answer; easy-to-hard** [prop:ood:intended, P1 Prop 8.11; ex:ood:hanniexamples, Ex 8.12; ex:ood:easyhard, Ex F.5]. If the labels follow a partial computable g and x ∈ dom g is new, SOI gives g(x) predictive probability at least 2^(L_SOI(D) − K(g) − c), in both conventions. For provability labels in a theory 𝒯: if every training sentence has a proof or refutation of length ≤ L and the test sentence, decided by 𝒯, has none of length ≤ L′ := 2^⌈log L⌉ (so L ≤ L′ ≤ 2L), its wrong label keeps probability ≥ 2^(−K(𝒯) − 2 log log L − c) "however many training sentences were seen". Whether some natural universal machine gives the intended answers probability near 1 is open (Question 8.13). [read in source]

**D7. Steeper priors off the support** [prop:limits:ood, P2 Prop G.5, `app-limits.tex`]. In H_×, for decidable Q with dom D ∩ Q = ∅ and λ ≥ 1: the programs that answer b on Q and run an arbitrary program elsewhere carry power-posterior mass at least 2^(−λ(K(Q,b)+κ)), and ξ_λ(D ∪ b|_Z) ≥ 2^(−λ(K(Q,b)+κ))·ξ_λ(D); two programs with equal likelihood on D have posterior odds exactly 2^(−λ(ℓ(π_1)−ℓ(π_2))). With λ = cn the floor is 2^(−cn(K(Q,b)+κ)). "With a steeper prior the per-query solution extrapolates more reliably than the one-tape version if [the shortest hypotheses that fit the data] extrapolate well, and is more confidently wrong if they do not." [read in source]

### E. Recovery of the sampler itself: the model–randomness split, steeper priors, λ ∝ n

*What counts as one hypothesis*

**E1. Absorption** [thm:absorb:absorption, P2 Thm 4.2; thm:split:shared, Thm 4.4; prop:kink:universal, Prop 5.7; `absorb.tex`, `kinks.tex`]. In a class with (Dom) (SI; the one-tape version of SOI; the weak class; the history-aware class) and λ > 1: for every observation o with U(o) > 0, every λ-MAP has length at most ℓ*_λ = (λℓ_U + κ_0)/(λ−1) and fits almost as well as U. If a sampler has a program π_ν of length k with (λ−1)k > λℓ_U + κ_0, then J_λ(π_U;o) < J_λ(π_ν;o) for every such o: "the sampler program is never a λ-MAP", and the power posterior puts at most 2^(−(λ−1)L̄ + λℓ_U + κ_1) on all programs of length ≥ L̄. A universal member also flattens every left kink far beyond its own length. So in these classes the selected hypothesis is "a short universal learner that contains no model of ν", whatever the data. [read in source]

**E2. No private-randomness hypothesis is universal** [cor:absorb:nouniversal, P2 Cor 4.5; prop:absorb:pricing, Prop B.2; rem:absorb:condsemi, Rem B.3]. For every product hypothesis ν_U and every d ≥ 1 there are a data set D on {0,1}^d∖{0^d} and a parity f ⊇ D with a program of length ≤ d + 2 log d + κ such that ν_U(D) ≤ 2^(−(2^d − 1)); so (Dom) fails in H_×. A product hypothesis "pays its likelihood term at every input": on some parity it pays at least n bits on n nonzero inputs, where the shared Bayes mixture over parities pays at most d. The universal lsc conditional semimeasure pays a constant at every input and its prediction does not depend on the data. [read in source]

**E3. The price and the boundary of private randomness** [prop:absorb:price, P2 Prop B.5; prop:absorb:history, Prop B.6; prop:absorb:inputs, Prop B.7; `app-absorb.tex`]. (i) Randomness shared by several inputs costs a product class a factor: on data D_β showing each of s fair coins on two inputs, every π ∈ H_× has J_λ(π;D_β) ≥ min(λ,2)·(K(β|s) − κ), while −log M_F(D_β) ≤ s + κ. ("Persistent latent causes, such as a per-batch coin, are of this kind.") (ii) If a hypothesis's input contains the block's earlier **labelled** pairs, an in-context Bayes mixture over a computable family is a single product hypothesis that pays log(1/w_θ) once per block: absorption returns. (iii) If inputs contain only the earlier *inputs*, per-input pricing persists. [read in source]

*Samplers with private coins: exact recovery*

**E4. Ville deficiency** [lem:split:ville, P2 Lemma 6.2, `recovery.tex`]. Let the inputs follow **any rule that fixes x_{n+1} before y_{n+1} is drawn** (adaptive, randomised, non-computable), labels frozen on distinct inputs or drawn per query, ξ a shared hypothesis or the class mixture ξ_𝒞. Then δ_n = log(ξ(o_n)/ν(o_n)) and δ* = sup_n δ_n satisfy Prob[δ* ≥ j] ≤ 2^(−j), "whether or not ν has a program in 𝒞"; and for every π ∈ 𝒞 and every n: L_n(π) ≥ L_n(ν) − ℓ(π) − δ_n ≥ L_n(ν) − ℓ(π) − δ*. (No program's cumulative likelihood gain over the sampler exceeds its length plus δ*.) [read in source]

**E5. Exact model recovery** [thm:recovery:main, P2 Thm 6.3, `recovery.tex`; proofs `app-recovery.tex`]. Setting: 𝒞 any countable class of programs with Kraft weights and sub-probability kernels (H_×, a time-bounded or circuit subclass, a finite class); PQ data with inputs i.i.d. from **any** law μ; 𝓔 ≠ ∅.
* (a) For every schedule λ_n ≥ 1 with λ_n/n → 0 (fixed λ ≥ 1 included), almost surely the set of λ_n-MAPs equals 𝓔_0 for all large n.
* (b) For fixed λ ≥ 1, almost surely Π_λ(𝓔|h_n) → 1 with Π_λ(π|h_n) → 2^(−λℓ(π))/W_λ on 𝓔 (W_λ = Σ_𝓔 2^(−λℓ)); the tempered posterior concentrates on 𝓔 too. Concentration on 𝓔_0 fails (rem:recovery:posterior): "only the MAP singles out 𝓔_0".
* (c) Fixed λ > 1, every n: every λ-MAP has length ≤ (λℓ_0 + δ_n)/(λ−1) ≤ ℓ_0 + (ℓ_0 + δ*)/(λ−1); every fill-in has length ≥ L_n(ν) − δ*; the fill-ins' total mass is ≤ 2^(λℓ_0 + λδ* − (λ−1)L_n(ν)) under Π_λ; L_n(ν)/n → H_μ(ν) almost surely.
* (d) For every n and λ > 0: Prob[set of λ-MAPs ≠ 𝓔_0] ≤ Σ_{π∉𝓔} inf_{0<s≤1} 2^(−sλ(ℓ(π)−ℓ_0))·C_s(π)^n (C_s the Chernoff coefficient). If λ > 1, ε ∈ (0,1), L̄_ε = ⌈(λℓ_0 + log(2/ε))/(λ−1)⌉ and 0 < γ ≤ γ_{L̄_ε}, this probability is ≤ ε for every n ≥ ⌈λ(ℓ_0 + log(2/ε))·ln 2 / (2·min(1,λ−1)·γ)⌉.

Parts (a), (b) are "the standard argument from Ville's inequality and the strong law", no novelty claimed; what needs λ > 1 is (c) and the margin form of (d) (rem:recovery:method). [read in source]

**E6. What λ > 1 buys; what is necessary** [prop:recovery:lambda1, P2 Prop 6.6; prop:recovery:necessity, Prop D.2]. In a class of a fair coin of length k and parities (uniform margin > 0.29): at λ = 1 no function of (ℓ_0, γ, ε) bounds the recovery time, and in the class 𝒞_k it is Θ(2^(ℓ_0/2)); for fixed λ > 1, Prob[λ-MAPs ≠ {coin}] ≤ 2^(k−2−(1−1/λ)n) for every n, so the recovery time is ≤ ⌈λ(k + log(1/(4ε)))/(λ−1)⌉. Necessity, in separate classes: a margin is needed; the factor 1/γ is needed (for λ ≥ 2, up to constants); the factor 1/(λ−1) is needed up to logarithms; and in H_×, for binary labels and a computable ν bounded away from 0 and 1, the margin γ_L̄ is eventually below every computable function of L̄, "so (d) gives no computable sample size". [read in source]

**E7. A sample has a kink at the shortest equivalent program** [thm:recovery:kink, P2 Thm 6.7]. In the per-query setting, for fixed n and ε: (i) with probability ≥ 1−ε, **simultaneously for all π ∈ 𝒞**: L_n(π) − L_n(ν) > 2 log e·n·Hel_μ(π) − 2ℓ(π) − 2 log(1/ε); (iii) with probability ≥ 1−ε, L_n(π) > L_n(ν) − (ℓ(π) − ℓ_0) − (ℓ_0 + log(1/ε)) for every π; (v) almost surely the left steepness at (ℓ_0, L_n(ν)) grows linearly in n and λ = 1 eventually lies strictly inside the kink. [read in source]

**E8. Noisy computable functions** [cor:recovery:noisy, P2 Cor 6.8]. For ν_{f,p}(y|x) = 1−p if y = f(x), p otherwise (f total computable, p < 1/2 computable), PQ data from i.i.d. inputs: for every 1 ≤ λ_n = o(n), almost surely every λ_n-MAP is eventually a shortest program whose kernel is f (up to μ-null sets) with flips at rate exactly p; for fixed λ > 1 the fill-ins ("f plus the list of flipped queries" among them) have posterior mass ≤ 2^(λℓ_0 + λδ* − (λ−1)L_n(ν)) with L_n(ν)/n → H(p). [read in source]

**E9. Any input rule; frozen labels** [thm:split:private, P2 Thm 6.9; prop:recovery:frozen, Prop 6.10; rem:recovery:frozentable, Rem D.4; `recovery.tex`, `app-recovery.tex`]. Let the inputs follow any rule (as in E4), labels frozen or per query, and π_ν ∈ 𝒞 of length k with ν_{π_ν}(o_n) = ν(o_n). For fixed λ > 1, simultaneously for all n: (i) every λ-MAP π̂ has ℓ(π̂) ≤ (λk + δ*)/(λ−1) and L_n(ν) − ℓ(π̂) − δ* ≤ L_n(π̂) ≤ L_n(ν) + λk; (ii) Π_λ(ℓ > L̄ | o_n) ≤ 2^(λk + δ* − (λ−1)L̄); (iii) fill-ins have length ≥ L_n(ν) − δ* and Π_λ-mass ≤ 2^(λk + λδ* − (λ−1)L_n(ν)). (iv) For every fixed λ ≥ 1, if infinitely many queries are made, almost surely from some n on every λ-MAP is **ν-equivalent on the run**: Σ_i Hel(ν(·|x_i), ν_π(·|x_i)) < ∞ along the queried inputs, and Π_λ(ν-equivalent on the run | o_n) → 1. "Equivalence on the run says nothing about unseen inputs and is vacuous on a finite domain" (rem:split:reading).
With **frozen labels** and i.i.d. inputs: (a) if ν, ν′ differ only at one input of positive mass (mutually absolutely continuous there), every estimator that is almost surely eventually in 𝓔_ν under ν is almost surely not eventually in 𝓔_ν′ under ν′: "no procedure, the λ-MAP for any λ included, recovers every computable sampler with noise on the support of μ"; (c) an explicit 10-input class where for every λ < 1.5 the λ-MAP is eventually a program with one memorised noise label with probability exactly 1 − (63/64)^10. Record only [SP `iid/notes-final.md` Remark 7.7]: with frozen labels on a large uniform finite domain, identification holds with high probability "while the table is far from exhausted". [read in source]

**E10. Adaptive inputs, misspecification, λ = cn** [prop:recovery:beyond, P2 Prop D.5, `app-recovery.tex`]. (a) With the fixed non-i.i.d. inputs x_j = 0^j and ν(1|0^j) = 1/2 + 2^(−j/2−2), in the class {truth, a shorter fair coin}: the coin differs from ν at every query, is ν-equivalent on the run, and for every fixed λ > 0 is, with positive probability, the λ-MAP for all large n. (b) If the class consists of deterministic programs and one fair coin while the truth is f with flips at rate p ∈ (0, 1/2), per query the coin (the unique KL-minimiser) is almost surely eventually the unique λ-MAP for every λ > 0: no fill-ins per query. (c) With λ = cn, per query: A_c = argmin (c·ℓ + R_ν) is nonempty and finite and almost surely every cn-MAP is in A_c for all large n; if 𝓔 ≠ ∅ and c* := min{KL_μ(π)/(ℓ_0 − ℓ(π)) : ℓ(π) < ℓ_0}, the cn-MAPs are eventually 𝓔_0 for c < c* and eventually contain no program of 𝓔_0 for c > c*.
Record only [SP `iid/notes-final.md` Prop 7.3, Conj 7.4]: under misspecification (𝓔 = ∅), "the λ-MAP is eventually a shortest KL-projection" is **refuted** for fixed λ (per query, two projections with different kernels are each the unique MAP infinitely often; with frozen labels on distinct inputs, in a class of deterministic programs plus one fair coin and truth f ⊕ Bern(p), every λ-MAP is eventually a fill-in when λ·H(p) < 1 and the coin when λ·H(p) > 1), and **proved** in finite classes for λ_n/√(n log log n) → ∞, λ_n = o(n), a sharp rate; open in countable classes. [read in source]

**E11. λ = 1 on one data set; SI** [thm:split:lambda1, P2 Thm 6.11; lem:split:stream, Lemma D.6; prop:split:si, Prop D.7; rem:split:siprograms, Rem D.8]. In H_× with frozen labels on distinct inputs, simultaneously for all n: Π_1(π_ν|D_n) ≥ 2^(−k−δ*), and the posterior odds of **all fill-ins** against the sampler program lie in [2^(−2 log(t_n+1) − κ), 2^(k+δ*)], with 2 log(t_n+1) doubly logarithmic in the input length and triply logarithmic in the number of inputs: at λ = 1 sampler and fill-ins get similar posterior weight. In Solomonoff's M, a mixture over deterministic programs, "no complexity weight separates a sampler from its fill-ins": "the split needs a representation in which the randomness is not part of the program: a product hypothesis with private coins". [read in source]

*One geometry: hull, kinks, the kink lemma*

**E12. Hull lemma and coding bound** [lem:setup:hull, P2 Lemma 3.8; lem:setup:coding, Lemma 3.9; `setup.tex`]. The minimisers of c·ℓ + L over a countable family of points (length, fit) lie on the lower convex hull; a point is the unique minimiser on an open interval of c iff it is a vertex; MAP length is nonincreasing in c; every penalised minimiser solves a length-bounded problem but not conversely. In every data-set class, ℓ(π) + L(π;D) ≥ K(y_D | dom D) − κ: "one bit of description pays for at most one bit of fit". [read in source]

**E13. The kink lemma and its corollaries** [lem:kink:main, P2 Lemma 5.3; cor:kink:split, Cor 5.5; thm:kink:converse, Thm 5.6; `kinks.tex`]. Let a reference point (α_r, L_r) be bounded by a program, programs split as 𝓜 ⊔ 𝓝, 𝓜 have a right line (τ, g) with length floor ℓ_𝓜, and c > τ. If every π ∈ 𝓝 has J′_c(π) > J_r(c) + ε, then every π with J_c(π) ≤ Φ(c) + ε lies in 𝓜, has ℓ(π) ≤ α_r + (g+ε)/(c−τ) and L′(π) ≥ L_r − (cg + τε)/(c−τ); and Φ(c) ≥ J_r(c) − [g + (c−τ)(α_r − ℓ_𝓜)] when 𝓝's margin is nonnegative. On one data set: if π_s is b-sufficient and has a left kink (σ, w), then for every λ ∈ (1, σ) every λ-MAP is within [−w, (b+κ)/(λ−1)] bits of its length, fits within [−λ(b+κ)/(λ−1), λw] bits of its fit, and is (b + (λ−1)w)-sufficient. Conversely, MAP lengths that stay in an interval for all λ in an interval occur only at kinks. [read in source]

*A fixed error rule (the teacher): λ must grow like n*

**E14. The reuse factor and the schedules** [lem:teacher:reuse, P2 Lemma 8.2; prop:teacher:schedules, Prop 8.3; prop:limits:plain, Prop F.2; prop:teacher:frozen, Prop F.1]. Counting every term of a data set r times multiplies every λ-threshold by r. In the parity instance of E15 with per-query data from the deterministic teacher y*: (a) if λ_n/n → 0, almost surely for all large n every λ_n-MAP reproduces y* everywhere (it learns the errors); (b) if λ_n/n → ∞ the MAPs collapse to the shortest finite-risk programs; (c) for λ_n/n in a compact subset of the window, with probability ≥ 1−δ every λ_n-MAP satisfies the identification of E15 with an explicit ε̄_n → 0. Plain Bayes (M_prod, M_F) predicts the teacher's erroneous labels after at most d + ⌈L_S⌉ + κ_b + κ mistakes. A frozen table counted per query (FQ) behaves like an error rule: if the class contains a program that agrees with ν off a finite set A and memorises the table on A (where some label had probability < 1), then for every λ_n = o(n) almost surely each program whose kernel equals ν on supp μ is a λ_n-MAP for only finitely many n. [read in source]

**E15. The teacher's-mistakes theorem** [def:teacher:instance, P2 Def 7.1, `parity.tex`; thm:teacher:main, Thm 8.7; prop:teacher:kinks, Prop 8.6; `teacher.tex`]. Instance: inputs uniform on {0,1}^d; simple model the parity f_a with K(a) ≥ d; error rule S ⊆ {0,1}^m of size s_0 = p·2^m (p ≤ 1/4), error set E = S×{0,1}^(d−m); teacher y* = f_a ⊕ 1_E; deficiency δ_S = log C(2^m, s_0) − K(S | a, K(a)); population objective J_c = c·ℓ + R over **all** programs of H_×. Results: every program of level 1 (agreement u(π) > 3/4 with f_a) has ℓ(π) ≥ d − 4 − Λ_1 and R_B(π) ≥ H(p) − Λ_2/2^m − 2^(−m)(ℓ(π) − d − κ_g) (a right line of slope 2^(−m)); every program of level ≥ 2 has J_c ≥ Φ_2(c) (list decoding of parities). **Identification:** if c·2^m > 1 and J_g(c) + ε < Φ_2(c) (true on (2^(−m), c_hi), which requires p < p_0 = 0.05596…), every π with J_c(π) ≤ Φ(c) + ε has level 1, knows the parity (u(π) ≥ max{3/4, 2^(−R_max) − p − 2^(−B)}), fits no better than noise (R_B(π) ≥ H(p) − (cΛ_2 + ε)/(c2^m − 1)), is short (ℓ(π) ≤ d + Δ_ℓ), holds little information about S (I(π) ≤ Δ_ℓ + Λ_3), and gives the erroneous labels average probability e(π) ≤ 1 − u(π) + γ_g + 2^(−g). **Memoriser regime:** for c·2^m < 1 near-optimal programs reproduce the errors; the lower end 2^(−m) is sharp. At d = 100, m = 20, p = 2^(−10): window (9.54·10^(−7), 8.06·10^(−3)] at κ = 0 (an illustration), e ≤ 0.200 at c = 10^(−4) against 1 for the memoriser. The theorem controls the near-optimal set, not the minimiser (rem:teacher:selected); it relies on a list-decodable model class, the product form of E, uniform inputs, a margin and a small deficiency (rem:teacher:hypotheses). From samples: uniform convergence over all programs with Kraft weights [lem:teacher:finite, Lemma F.3; cor:teacher:sampled, Cor 8.12], near-population constants needing about 10^11 samples at these sizes; asymptotically windows exist for flip rates up to 0.1233 [prop:teacher:rates, Prop 8.13]. [read in source]

**E16. Where the second reason fails** [prop:limits:envelope, P2 Prop 9.1; prop:limits:rateblind, Prop 9.2; prop:limits:separable, Prop 9.3; prop:limits:guard, Prop G.2; prop:limits:noident, Prop G.3; prop:limits:inputlaw, Prop G.4; `limits.tex`, `app-limits.tex`]. (i) An error rule with a cheap dense part has a kink of its own: below an explicit c_env no hypothesis that fits no better than the good model is near-optimal, and near-optimal hypotheses reproduce the cheap errors; in the computed instance (128 cheap and 896 random error cells, same density and description length as the running example) this is about a third of the window's logarithmic width at κ = 0, an illustration. (ii) *Rate blindness:* once the simple model is long enough, a cheap frequent rule defeats every c. (iii) *Rate, not validity:* with separable components, component j is selected iff its risk reduction per bit r_j/k_j exceeds c; "two worlds with the same teacher channel and input law, one where a component is an error and one where it is a rare valid rule, get the same selection at every c". (iv) *Guard erosion:* a guard with a lower rate than its rule is dropped on an interval of c, and the rule is applied where the teacher never applied it. (v) **c cannot be chosen from imitation data**: every strictly proper score is maximised by the teacher's channel, errors included (Gneiting and Raftery, *JASA* 102(477):359–378, 2007, as cited); log-loss validation picks the smallest c; in the twin worlds every rule choosing c from imitation data alone is wrong in one. (vi) The window moves with the input law (separable case). [read in source]

**E17. Computable classes** [prop:related:computable, P2 Prop 11.1; prop:related:computability, Prop I.1; q:related:open, Question 11.4]. E5 and E7 "hold in every countable product class with Kraft weights that contains a program whose kernel equals ν at μ-almost every input, for example a time-bounded, circuit or finite class; ℓ_0, 𝓔_0 and the margins are then those of the class, in its own code"; E9 holds in every countable product class with Kraft weights that contains a program for the sampler; the lower-bound parts of E15 hold in every product hypothesis class with a class-dependent constant. Absorption does not transfer to time-bounded classes ("a mixture of all time-t programs is not a time-t program"). In H_× the steeper mixture ξ_λ is lsc and its conditionals are limit-computable but not computable; whether there is a computable map from data sets to λ-MAPs is open. [read in source]

### F. The imitation section: results and stated limits

**F1. Private coins: robust against every predictor** [rem:imit:private, P2 Rem H.1, `app-imit.tex`; IM `robust/notes-final.md` Lemma 2.1, Thm 2.2, Prop 2.3]. Let 𝒜_1 ⊆ 𝒜_2 ⊆ … be σ-algebras containing whatever a hypothesis may use to predict y_i (earlier data, any environment variables, earlier or later), and let the coins be private: Prob[y_i = y | 𝒜_i] = ν_H(y|x_i). Then for every countable family of predictors with Kraft weights, δ* := sup_n log Σ_π 2^(−ℓ(π) + L_n(ν_H) − L_n(π)) has Prob[δ* ≥ j] ≤ 2^(−j), and L_n(π) ≥ L_n(ν_H) − ℓ(π) − δ* for all π and n: "no predictor, however it models the environment, gains over the person more than its length plus a Ville deficiency". For product hypotheses that also see a countable environment variable, with i.i.d. pairs, none predicts better in population and E5 returns the person. Record only (Prop 2.3, the privacy dichotomy): for a calibrated person, if I(Y;Z|X) > 0 and the class contains the kernel P(y|x,z), then for every λ_n = o(n) almost surely every copy of the person is a λ_n-MAP for only finitely many n. [read in source]

**F2. The setting with environment-driven coins** [def:imit:setting, P2 Def 10.1, `imit.tex`]. Finite Y and coin set Σ; cells W = {0,1}^m; a channel μ(·|w) of finitely supported input laws, input law μ̄ = 2^(−m) Σ_w μ(·|w) (*feature case*: the input shows w as its first m bits). The **person**: a coin law ρ on Σ with every ρ(b)·2^m a positive integer, a response function h(x,b) injective in b, kernel ν_H(y|x) = ρ(b) if y = h(x,b), model h_0 = (h,ρ). A **copy** is a program of H_× whose kernel equals ν_H on supp μ; ℓ_0 the length of a shortest copy π_H. A **coupling** β: W → Σ of exact type ρ drives the coins: w_i uniform, x_i ∼ μ(·|w_i), y_i = h(x_i, β(w_i)); the learner sees (x_i, y_i), i.i.d. from μ̄ ⊗ P*, with P* the data kernel. δ_β = L_β − K(β | h_0, μ) (L_β the log-size of the type class); I_β(π) the information of π about β; D_{1/2}(P‖Q) = −2 log Σ_y √(P(y)Q(y)). The teacher of E15 is the feature case with h(x,b) = f_a(x) ⊕ b. "The data identify P*; … hypotheses that model β predict better than the person, by up to H(ρ) bits per sample in the feature case." Hence a fixed λ, or any λ_n = o(n), eventually returns a shortest program for P*, not a copy when P* ≠ ν_H. [read in source]

**F3. Coding and closeness lemmas** [lem:imit:coding, P2 Lemma H.2; lem:imit:closeness, Lemma H.3; `app-imit.tex`]. For every π ∈ H_×: K(β | h_0, π, μ) ≤ 2^m·R(π) + κ. For every π ∈ H_× with R(π) < ∞: E_{x∼μ̄} D_{1/2}(ν_H(·|x) ‖ ν_π(·|x)) ≤ R(π) − H(ρ) + 2·(I_β(π) + δ_β + |Σ|·log(2^m + 1) + E(π) + κ)/2^m, with E(π) = 2 log(2^(m−1)(H(ρ) + R(π)) + 1). (The final referee verified the lemma and found the factor 2 tight: IM `referee-final.md` §1.) [read in source]

**F4. Robust near-imitation** [thm:imit:main, P2 Thm 10.2, `imit.tex`]. In the setting of F2 let c = a·2^(−m) with a > 1, ε ≥ 0, G := ℓ_0 + δ_β + |Σ|·log(2^m+1) + κ. **Every π ∈ H_× with J_c(π) ≤ Φ(c) + ε, "whatever its internal structure"**, satisfies: (i) ℓ(π) ≤ ℓ_0 + (G + 2^m ε)/(a−1); (ii) −(aG + 2^m ε)/((a−1)2^m) ≤ R(π) − H(ρ) ≤ c·ℓ_0 + ε; (iii) I_β(π) ≤ ℓ_0 + (G + 2^m ε)/(a−1) + κ; (iv) E_{x∼μ̄} D_{1/2}(ν_H(·|x) ‖ ν_π(·|x)) ≤ c·ℓ_0 + (2a/(a−1))·(G + E + κ)/2^m + ((a+1)/(a−1))·ε, with E ≤ 2m + 2 log(2H(ρ) + cℓ_0 + ε + 1); the Hellinger gap from the person is at most (ln 2)/2 times this. Moreover J_c(π_H) ≤ Φ(c) + G/2^m + c·ℓ_0. In the feature case with distinct values of ρ, a program of length ≤ ℓ_0 + ⌈L_β⌉ + a_ρ + κ has kernel P* and risk 0 and beats every copy for c < H(ρ)/(⌈L_β⌉ + a_ρ + κ) ≈ 2^(−m).
Reading given there: informative when the coupling is incompressible (δ_β ≪ 2^m·H(ρ)), the person much simpler than it (ℓ_0 + |Σ|m ≪ 2^m·H(ρ)), and c between the reuse factor 2^(−m) and well below H(ρ)/ℓ_0. "The theorem gives near-copies, not copies"; "the hypotheses that predict better gain only by storing an incompressible table". From samples: by E10(c) with the sampler P*, almost surely every cn-MAP satisfies (i)–(iv) with ε = 0 for all large n (each fixed c; no finite-sample bound for general h). Numbers (κ = 0, an illustration): at m = 20, c = 2^(−19), the bound (iv) is 6.2·10^(−4) bits against H(ρ) = 1 for a fair-coin person. [read in source]

**F5. What no procedure can do** [prop:imit:limits, P2 Prop 10.3, `imit.tex`, `app-imit.tex`]. (a) *One data law, at most one copy.* If worlds 𝒲_1..𝒲_N have one law of the data pairs and persons whose kernels differ pairwise on sets of positive μ̄-mass, every procedure Ψ (a measurable map from samples and independent randomness to programs) has Σ_i Prob_{𝒲_i}[Ψ(h_n) ∈ 𝓔(ν_i)] ≤ 1 at every n. In the feature case with |Σ| ≥ 2 one such world has the person P*, "who responds to the cell". (b) *A person entangled with its coupling.* X = W, Y = Σ = {0,1}, ρ = Bern(s_0/2^m), person H_f answers f(w) ⊕ b for a table f; draw f uniformly and β uniformly from its type class, independently. Then Prob[δ_β > j] < 2^(−j), "yet every procedure copies the person with probability at most 2^(−L_β), at every n"; and with high probability no c gives a window (the table or the fair coin beats every copy at every c). [read in source]

**F6. Cheap couplings; a window needs many cells** [prop:imit:cheap, P2 Prop H.4, `app-imit.tex`]. Feature case, |Σ| ≥ 2, distinct values of ρ, π_u a program for the uniform kernel shorter than ℓ_0. (i) If H(ρ)/(K(β|π_H) + κ) ≥ (log|Y| − H(ρ))/(ℓ_0 − ℓ(π_u)), then at every c > 0 some program that is not a copy has J_c at most that of every copy ("a pseudo-random generator with a short seed … no c returns the person with fresh coins"). (ii) If some c makes the copies the only minimisers, then 2^m > (ℓ_0 − ℓ(π_u))/(log|Y| − H(ρ)) − (a_ρ + 1 + κ)/H(ρ), whatever the coupling: "a person of 10^6 bits with H(ρ) ≈ 1/2 and |Y| = 2 needs more than 1.99·10^6 cells". [read in source]

**F7. Hypotheses that learn in context** [P2 `app-imit.tex`, paragraph after the proof in app:imit:private; IM `robust/notes-final.md` Prop 5.2]. In a class whose hypotheses carry information across queries, a Bayes mixture P_U over persons giving the person weight w has P_U ≥ w·P_H on every data set, "private coins or not", so J_λ(π_U) − J_λ(π_H) ≤ λ(ℓ_U − ℓ_H) + log(1/w): once λ times the length it saves exceeds log(1/w) the person's program is never a λ-MAP. "The private-randomness class excludes such hypotheses by construction, not because of anything in the data, and a person with memory is not a product sampler." [read in source]

**F8. Results that stayed in the research record** [IM `robust/notes-final.md`; not in P2 unless noted]. All [read in source]:
* *Prop 3.1, Ex 3.2 (behaviour, not mechanism).* Programs with equal kernels μ-a.e. have equal fits at every n, so every schedule and every prior depending only on length orders them by length alone; no procedure separates two worlds with the same input law and μ-a.e. equal kernels, "with any mechanisms and any behaviour off the support of μ".
* *Prop 3.3 (what separates a copy from an equivalent program).* (a) more observed per query (a report, a recorded internal signal τ_i jointly drawn with y_i): E5 applies with label set Y×T; (b) more varied inputs, including manipulations of the person's situation taken as part of the input; (c) "the data identify the kernel of whatever is observed, under whatever is varied", and the selected program is a shortest program for that enlarged kernel; (d) a class restricted so that every equivalent program is longer than the person's (an assumption "no data can check"); (e) more data from the same μ, any schedule λ_n, or any length-based prior do not help.
* *Thm 4.7(L) (left condition).* If every program that does not know the person's model up to t bits is worse than π_H by more than ε at c, the offsets shrink from ℓ_0 to t + D_0 and near-optimal programs know the model; proved for the parity person via list decoding, open for other model classes.
* *Prop 4.10(a3) (a refuted slogan).* "The set of aliens a procedure is robust against is the set of humans it cannot copy" is **refuted** for general procedures: a non-likelihood procedure Ψ_var copies the person with probability 0.985 in one world and a partial memoriser with probability 0.995 in another. Only data-law twins obstruct a general procedure; the advantage per bit is the right quantity only for penalised likelihood.
* *Prop 4.10(b4), (b5) (schedules).* The shortest copies are almost surely eventually the unique MAPs only if s_+ < λ_n/n < s_− eventually; in finite classes a margin ≫ √(log log n / n) from both ends suffices.
* *Remark 4.13 (partially private coins).* If the coin is β(w) ⊕ b′ with a private residual b′, the coding lemma survives but the right line is anchored too low to be useful; in explicit classes the window's lower end falls below 2^(−m); a conjecture only.
* *Remark 4.14 (several environments; a sketch, not proved).* With E environments each with its own incompressible coupling, every outside predictor's advantage per bit is at most about 2^(−m)/E, while a coupling the person carries across environments has rate about 2^(−m): for c between them the c-procedure attributes "what is the same across environments" to the person. The twin world (a person carrying all E couplings) has the same data law.
* *Prop 5.1, 5.3, Remark 5.4 (a person with latent state).* Ville's bound survives for every chronological class with the person's predictive law given the observable history. With i.i.d. **episodes** and a class of predictors that restart at episode boundaries, E5 holds per episode (n = number of episodes); a restarted in-context learner has positive per-episode regret and is eventually rejected. Without episodes: product hypotheses cannot represent the person; chronological classes with a dominating member absorb it; single-trajectory recovery in a class without a dominating member is open.

**F9. The limits the paper states** [P2 `discussion.tex`, "What the toy cases leave open" and open problem (7); `intro.tex`, "Scope"]. "We do not claim to solve the problems that motivate the two reasons, imitating a person and learning what a teacher means rather than what the teacher says." Six gaps: (1) data identify behaviour, not mechanism; the selected program "extrapolates off the support of the inputs as that program does"; (2) which structure belongs to the person and which to the environment, and with it the complexity weight, "are conventions that imitation data cannot settle"; (3) realistic errors and realistic randomness have structure: cheap couplings defeat every c, and no procedure reliably copies an entangled person; (4) "exact copies need the same question answered afresh; with frozen labels no procedure recovers every sampler"; (5) people have memory, and excluding in-context learners is a choice of class; (6) the steeper predictors are not computable, the margin form gives no computable sample size in H_×, and every window depends on the class and the reference machine. Open: partly private coins, cells of unequal mass, finite-sample versions, couplings short to describe but slow to compute, and "whether data other than imitation data, from several environments or from interventions, identify which structure belongs to the person". Related work cited there for the same kind of limit [bib data read in source, content at abstract level per the paper]: Armstrong and Mindermann, "Occam's Razor Is Insufficient to Infer the Preferences of Irrational Agents", NeurIPS 2018, arXiv:1712.05812; de Haan, Jayaraman and Levine, "Causal Confusion in Imitation Learning", NeurIPS 2019, arXiv:1905.11979; Cohen, Hutter and Nanda, "Fully General Online Imitation Learning", *JMLR* 23(334):1–30, 2022 (described there only as "a Bayesian imitation learner for environments that never reset"). [read in source]

### G. The ultranatural notes (properties; isolation; the equational inductor) and axiom induction

*`note.md`: total computable hypotheses g: X → Y; K_tot(D) the least K(g) over total g ⊇ D; W_tot(D) = Σ_{g ⊇ D} 2^(−K(g)); sep(x;A|f) the least K(Q|f).*

**G1. The floor for total functions** [UN `note.md` §1]. If Q separates x from A and f ⊇ D is total, then for y ∈ {0,1}: K_tot(D+(x,y)) ≤ K(f) + sep(x;A|f) + c and W_tot(D+(x,y)) ≥ 2^(−K(f) − sep(x;A|f) − c). (For W and M_F the stronger relative form D1 holds.) [read in source]

**G2. The consensus window (the "property idea", formalised)** [UN `note.md` Theorem 1]. A *property* is a decidable P ⊆ X×Y, *true so far* if D ⊆ P; excl(x,y) is the least K(P) over properties true so far that do not contain (x,y); S_k(x) = {y : excl(x,y) > k}. For every D, x ∉ A and total computable f ⊇ D: (1) excl(x,y) ≤ K(f) + c for every y ≠ f(x); (2) sep(x;A|f) − c ≤ excl(x, f(x)), and excl(x,y) ≤ sep(x;A) + c for **every** label y, f(x) included; (3) S_k(x) = {f(x)} whenever K(f) + c ≤ k < sep(x;A|f) − c, and S_k(x) = ∅ whenever k ≥ sep(x;A) + c. "The window is SOI's margin": the property that always excludes the right label at level sep(x;A) is "no input in Q occurs". [read in source]

**G3. A tally of broken properties adds nothing** [UN `note.md` Proposition 2]. With v(y) the total weight 2^(−K(P)) of properties true so far that (x,y) would break: v(y′) ≥ 2^(−K(f)−c) for y′ ≠ f(x); v(y) ≥ 2^(−sep(x;A)−c) for binary y, the right one included; if A is n independent samples from μ and x a further one, E v(f(x)) ≤ 1/(n+1). So the tally agrees with SOI at typical new inputs, is dominated by untested guard properties when sep(x;A) is small, and "in no regime does it pin the right label beyond the floor". [read in source]

**G4. The grue theorem** [UN `note.md` Lemma A, Theorem 3]. A scheme S (machine, data, input ↦ label or distribution) is *relabelling-equivariant* if S_{V^ρ}(ρD, x) = ρ_x(S_V(D,x)) for every computable relabelling ρ of labels input by input. Equivariant: the Kolmogorov version, every mixture with length-based weights (W, W_tot, the steeper priors of P2), the one-tape and per-query versions, any tally of properties, patch-free induction. **Theorem:** for S equivariant, V universal, D a data set, x ∉ A, Q decidable separating x from A, labels y ≠ y′, ρ the exchange of y and y′ on Q, V′ = V^ρ: (1) S_{V′}(D,x) is S_V(D,x) with y and y′ exchanged; (2) dist(V,V′) ≤ K(Q) + K(y) + K(y′) + c, which is sep(x;A) + c for binary labels; (3) S_{V′}(E,x′) = S_V(E,x′) for every E with dom E ∩ Q = ∅ and x′ ∉ Q. So "no scheme that takes its bias from the machine is stable at x beyond sep(x;A) + O(1) bits of machine change". The Kolmogorov version is stable under machine changes of up to half its margin and not beyond (Proposition 4); whether any equivariant scheme is stable beyond sep(x;A)/2 is open. [read in source]

**G5. The price of pinning** [UN `note.md` Theorem 5]. pin_π(x,y;D) = −log π(D+(x,y)) + log π(D) is the log loss π suffers at x if (x,y) is the next datum. If π has regret ≤ λ·K + b on every data set, then pin_π(x,y;D) ≤ λ·(K(f) + K(Q|f) + K(y) + c) + b for every separating Q; and every π with regret ≤ K + b has pin_π − pin_{W_tot} ≤ L(D) + b ≤ K(f) + b. "Pinning is a bet": universal learners have at most K(f) + b bits of room over SOI; steeper priors lower the floor to 2^(−λ·sep(x;A)) at regret slope λ. [read in source]

**G6. Most new inputs; far and near alternatives** [UN `note.md` Propositions 6, 7, §4]. With A = n independent μ-samples: with probability ≥ 1−η, μ{x : sep(x;A|f) ≤ a} ≤ 2^a·(a·ln 2 + ln(1/η))/n; but "if one simple Q separates a whole test set from A, Theorem 3 flips all of it at once". *Far* alternatives (distance ≥ δ from f under μ) of complexity ≤ k survive n samples with probability ≤ 2^k(1−δ)^n; *near* alternatives (patches behind a guard of measure ≈ 1/n) cost only K(f) + log n + 2 log log n + c bits. In a δ-*rigid* class (any two members at distance ≥ δ: translations, additive maps over GF(2), low-degree polynomials) "a wrong label at one input cannot come alone". [read in source]

**G7. Isolated functions and patch-free induction** [UN `note.md` Proposition 8, Theorem 9, §5]. f is *δ-isolated* if K(g) > K(f) for every total computable g ≠ f with μ{f ≠ g} < δ; equivalently, erasing f on any set of measure < δ, f is the unique simplest function agreeing with the rest. Two distinct δ-isolated functions are at distance ≥ δ. *Patch-free induction* puts prior 2^(−K(g)) on the δ-isolated g only. **Theorem 9:** if f is δ-isolated and D_n is n independent μ-samples labelled by f, the expected posterior mass off f is ≤ 2^(K(f))(1−δ)^n; so with probability ≥ 1 − 2^(K(f))(1−δ)^n/η the predictive probability of a wrong label is below η "at every input x ∈ X simultaneously, whatever its separation complexity". Costs: it cannot learn small exceptions (it predicts f on an unseen patch "with growing confidence and is wrong there"); a fallback mixture (1−ε)·patch-free + ε·W_tot restores the floor at ε times SOI's; and "its confidence is as machine-relative as SOI's prediction" (G4: a machine sep(x;A) + O(1) bits away regards the patch as the isolated function). In one concrete language of bounded primitive recursion (86,265 functions on a 6×6 grid), successor and addition are isolated at scales 5/6 and 2/3; after 16 random examples of addition the posterior probability of a wrong label falls from 2·10^(−3) (all hypotheses) to about 10^(−6) (isolated ones). Open: a noise version ("the analogue of isolation for hypotheses with private randomness at each query"), standard machines, non-equivariant principled schemes. [read in source]

*`equational.md`: hypotheses are finite sets T of identities in the vocabulary {0, S, f}; T fits D if it is consistent and proves every datum; prior weight a^(−(|T|+1)); Bel(y|D,x) = M_E(D+(x,y))/M_E(D); beliefs sum to at most 1, the rest is "undetermined".*

**G8. The inductor is a sub-mixture of SOI with three-valued predictions** [UN `equational.md` §1]. M_E(D) ≤ 2^c·W(D) for every D, so SOI's cumulative loss never exceeds the inductor's by more than c bits. M_E is a difference of two lower-approximable numbers; consistency is undecidable. [read in source]

**G9. Data up to the test radius pin the target at every input** [UN `equational.md` Lemma 1, Theorem 2]. A fitting set contains no identity refuted by D. The *test radius* τ_g(m) is the largest reach of an identity false of g with sides of ≤ m symbols. If D contains g on the box [0, τ_g(m))^k and T fits D, then every identity of T with sides of ≤ m symbols is true of g; and for **every** input x outside D and every y ≠ g(x): M_E(D+(x,y)) ≤ ε(m) (the prior weight of sets containing a term of more than m symbols), so Bel(y|D,x) ≤ ε(m)/w(T_g) if some set T_g fits all data from g. [read in source]

**G10. Addition and successor are pinned linearly; what is not bounded** [UN `equational.md` Theorem 3, Corollary 4, Proposition 4b]. τ(m) ≤ m − 1 for addition and ≤ m for successor (exactly so). If D contains x + y for all x, y < n (half the square suffices), then for every input x and every wrong y: Bel(y|D,x) ≤ 7^13·ε(n+1) ≤ 2^(36.5 − 0.485·n) (the exact bound is below 1 from n = 59, the closed form from n = 76; it is 2^(−71) at n = 200); for successor ≤ 2^(13 − 1.58·n). SOI on the same data keeps probability ≥ about 2^(−K(n)) for a wrong sum just outside the square. "The theorems bound the belief in wrong values; they do not show that the rest is on the right value and not on 'undetermined', though in the runs it is." [read in source]

**G11. The price, and what cannot be learned** [UN `equational.md` Propositions 5, 6, 7]. Law complexity C_E(g) = least size of a fitting set for all of g: ≤ 12 for plus; ≥ N + 3 for quus with threshold N; ∞ for squaring (no finite set of identities), on which the inductor's loss is unbounded while SOI's stays below K(g) + c. If C_E(g) < ∞ the total −log Bel(true label) along any sequence of distinct inputs is ≤ (C_E(g)+1)·log a. If the truth agrees with plus on [0,n)² and then deviates, the inductor loses at least 0.485·n − 36.5 bits at the first exception, where SOI loses about log n. [read in source]

**G12. The vocabulary is the bias (why the grue theorem does not apply)** [UN `equational.md` §5, Propositions 8, 9, 10]. The inductor has no reference machine and relabelling is not a symmetry of its hypotheses. With auxiliary function symbols, quus with threshold 2^j has a fitting set of 79 + 2j symbols ("auxiliary symbols bring the guards back", pinning logarithmic again); with a background doubling function an exception at 2^j costs about j² symbols; a fast-growing target names large numbers itself (doubling is pinned only polylogarithmically). "An exception at x costs at least what it costs to name x in the vocabulary." [read in source]

**G13. Axiom induction** [SAI README, "Answers in brief"]. SAI's prior is the probability that a random theory emitted by a universal machine is consistent and proves every datum; at a new sentence "the posterior splits three ways: the random theory proves it, refutes it or leaves it open", a belief function. Loss ≤ K_≡(T) + c for every r.e. theory T consistent with the background that proves every datum (Theorem 3.7 there). Version by version SAI agrees with SOI over consistent labellers up to constants (Theorems 4.2–4.4), so on two-valued data "the idealised formalism cannot see the difference between a theory and a program"; a purpose loss can replace log loss with regret K(G)·ln 2/η against every theory machine G (Proposition G.51); "the best system is the same for every balance of simplicity against strength in an interval exactly when the hull of length against fit has a kink there" (Proposition 9.3). Only the README was read. [read in source]

## 3. What each group gives, and does not give, for the problem

The four desiderata: **(S)** guarantees under distribution shift between training and deployment; **(O)** failures only of an obvious kind; **(U)** P′ is a copy ("mind upload"), not an outside predictor; **(Q)** a bounded number of queries to P, with the human not in the loop forever.

### 3.2 Immediate consequences that the sources do not state

All of X1–X8 are **[my own derivation]** from statements read in the sources; each proof is a few lines and none has been refereed. ν ∈ {W, M_F} in X1–X3.

**X1. The loss budget applies to the queried subsequence.** Let f be computable. A protocol is shown inputs x_1, x_2, … chosen by any rule and at each step either queries f(x_t), adding the pair to its data D, or does not. Then the sum, over the query steps at new inputs, of −log ν(f(x_t)|D_{t−1}, x_t) is at most K(f) + c; so at most (ln 2)(K(f)+c)/δ query steps have posterior error e_t ≥ δ. *Proof.* C2 for the sequence of queried inputs; which inputs are queried may depend on anything (C3(1)). ∎

**X2. A never-wrong rule with an exponential query bound.** Suppose a number k ≥ K(f) + c is known (c the constant of A2(b)). Rule: at a new input x, if some label y has ν(y|D,x) > 1 − 2^(−k), output y without querying; otherwise query. Then (i) every output equals f(x); (ii) at most (ln 2)·k·2^k queries are made, on every input sequence. *Proof.* (i) ν(f(x)|D,x) = ν(D+(x,f(x)))/ν(D) ≥ 2^(−K(f)−c) ≥ 2^(−k) (D6, with ν(D) ≤ 1), and the conditionals sum to at most 1. (ii) At a query step e_t ≥ 2^(−k); apply X1. ∎ *Remarks.* The exponential cannot be avoided for a rule that is never wrong on every sequence: on the point functions of C3(2), until a is found the rule must query every new input (answering 0 unqueried at x is wrong when a = x), so up to 2^d − 1 queries at K(f_a) ≤ d + 2 log d + c. The rule uses the uncomputable conditionals of ν and a numerical bound on a machine-dependent quantity.

**X3. Random audits.** Suppose that at every step, after x_t is fixed, the protocol queries with probability at least p by a coin independent of the past and of x_t. Let N be the number of steps with x_t new and ν(f(x_t)|D_{t−1}, x_t) ≤ 1/2 (the only steps at which the argmax prediction can be wrong). Then E N ≤ (K(f)+c)/p for every input rule, adaptive ones included. *Proof.* Each such step that is audited adds at least one bit to the loss of X1, so the audited ones number at most K(f)+c; and their expected number is at least p·E N, because whether a step is of this kind is settled before its coin. ∎ With an audit rate that decreases to p_T by time T, E N_T ≤ (K(f)+c)/p_T. (A rule that audits and never queries otherwise makes about (1−p)/p mistakes in expectation already against two hypotheses, when the wrong one has the larger prior and the inputs lie where they differ.) So the three regimes for a deterministic target on arbitrary input sequences are: labels at every step, at most K(f)+c mistakes (C1); audits at rate p, at most (K(f)+c)/p expected mistakes; the threshold rule X2, no mistakes and about k·2^k queries.

**X4. A stochastic sampler, any input rule, audits.** Let P be a computable probability kernel answering every query with fresh coins. Inputs follow any rule that fixes x_t before y_t is drawn and before the audit coin. The protocol predicts with q_t, the conditional of M_pq given the pairs queried so far (or of ξ_λ for a fixed λ ≥ 1, in a class with Kraft weights that contains a program for P of length k), and audits at rate at least p as in X3. Then, summing over **all** steps, audited or not: Σ_t E KL(P(·|x_t) ‖ q_t(·|x_t)) ≤ K(P)/p (respectively λk/p), hence Σ_t E TV(P(·|x_t), q_t(·|x_t))² ≤ (ln 2/2)·K(P)/p. *Proof.* A6(b) on the subsequence of queried pairs gives Σ_{queried t} log(P(y_t|x_t)/q_t(y_t|x_t)) ≤ K(P) on every path (for ξ_λ use ξ_λ ≥ 2^(−λk)·ν_π). Given the past, x_t and the decision to query, y_t ∼ P(·|x_t), so the summand has conditional mean KL_t ≥ 0 (integrability as in the proof of A7). KL_t is settled before the coin, so E[1{audited at t}·KL_t] ≥ p·E KL_t. The last step is Pinsker's inequality in the form of P1 `app-learn.tex`, eq. (learn:pinsker). ∎ Note that q_t is a posterior mixture, not one program.

**X5. The true program stays in every credible set.** Let the inputs follow any rule as in E4 and let the class contain π_ν of length k with ν_{π_ν}(o_n) = ν(o_n). For every λ ≥ 1, simultaneously for all n: Π_λ(π_ν|o_n) ≥ 2^(−λk−δ*), with Prob[δ* ≥ j] ≤ 2^(−j). *Proof.* Π_λ(π_ν|o_n) = 2^(−λk)ν(o_n)/ξ_λ(o_n), and ξ_λ ≤ ξ_1 = ξ_𝒞 ≤ 2^(δ*)·ν(o_n) by E4. ∎ So with probability ≥ 1 − 2^(−j) the set of programs with posterior at least α contains the truth at all times whenever α ≤ 2^(−λk−j): a rule "answer where all programs of posterior ≥ α agree, query otherwise" would be sound for such α. The sources prove nothing about such a rule; α is exponentially small in k, and by X2's remark its query count cannot be polynomial in k on arbitrary sequences. (P2 cites Cohen, Hutter and Nanda 2022 as "a Bayesian imitation learner"; I did not check how their learner relates to this.)

**X6. Closeness of the λ-MAP in distribution without a margin.** Per-query data, inputs i.i.d. from μ, 𝓔 ≠ ∅, λ > 1, n and ε fixed. With probability at least 1 − ε (if λ ≥ 2) or 1 − 2ε (if 1 < λ < 2), every λ-MAP π̂ has
Hel_μ(π̂) < [λℓ_0 + (2−λ)^+·L̄ + 2 log(1/ε)] / (2 log e · n), with L̄ := (λℓ_0 + log(1/ε))/(λ−1).
*Proof.* E7(i) for π̂, and J_λ(π̂) ≤ J_λ(π_0) = λℓ_0 + L_n(ν) for π_0 ∈ 𝓔_0, give 2 log e·n·Hel_μ(π̂) < λℓ_0 + (2−λ)·ℓ(π̂) + 2 log(1/ε); for λ < 2 bound ℓ(π̂) by E5(c) on the event δ* ≤ log(1/ε). ∎ So a margin is needed for *exact* recovery (E6) but not for behavioural closeness on the training law: the average Hellinger gap is O(λℓ_0/n), hence the average total variation O(√(λℓ_0/n)) (by E_x TV ≤ √(2·Hel_μ), IM `robust/notes-final.md` Setting 4.1).

**X7. Shifts that stay on the training support.** (a) If ν_π = ν μ-almost everywhere and μ′ ≪ μ, then ν_π = ν μ′-almost everywhere: exact recovery (E5) is exact under every such shift, with no density-ratio factor. (b) For every π, Hel_{μ′}(π) ≤ ‖dμ′/dμ‖_∞·Hel_μ(π). (c) If each training input is drawn from the deployment law μ′ with probability p and from μ otherwise, the training law μ_mix has dμ′/dμ_mix ≤ 1/p, so X6 gives Hel_{μ′}(π̂) < (1/p)·[…]/(2 log e·n). Immediate. This is the sense in which "requery on the deployment distribution with some probability" already works when the deployment inputs are i.i.d. from a fixed law.

**X8. From per-step closeness to closeness of a whole decomposition.** Let a process produce x_1, y_1, x_2, y_2, … with x_t a function of the earlier inputs and outputs and of independent randomness, and each y_t drawn from P(·|x_t) in one run and from P′_t(·|x_t) in the other. Then the total variation distance between the laws of the two T-step transcripts is at most Σ_{t≤T} E TV(P(·|x_t), P′_t(·|x_t)), with the expectation under either run. (Standard hybrid argument.) With X3, for a deterministic target the expected number of steps at which an audited imitator deviates is bounded uniformly in T. With X4, for a stochastic P only the sum of *squared* distances is bounded, so the right side is at most √(T·(ln 2/2)·K(P)/p), which grows like √T.

### 3.3 Theorem-shaped statements available today

1. **The toy model as posed (P a probabilistic program of x alone, fresh coins per query), training inputs i.i.d. from μ.** E5 with F1: every λ_n-MAP in H_× (1 ≤ λ_n = o(n)) is eventually a shortest program whose kernel equals P's μ-a.e. [read in source]; for fixed λ > 1 it is O(λℓ_0/n)-close in average Hellinger gap at every n with high probability (X6) and exact on shifts within supp μ (X7) [my own derivation]. Nothing off the support.
2. **Any input sequence, the human audited at rate p.** Bounded total KL divergence of the mixture predictor from P, K(P)/p (X4); for deterministic P, at most (K(f)+c)/p expected mistakes (X3) [my own derivation]. The human stays in the loop at rate p.
3. **Deterministic target with a known complexity bound, any input sequence.** Never wrong, at most (ln 2)·k·2^k queries, after which the human is out of the loop (X2) [my own derivation]; the exponential is forced (C3(2)).
4. **A law-governed deterministic target in a fixed vocabulary.** After the finite box of queries up to the test radius, the belief in a wrong value at *every* input is at most ε(m)/w(T_g); the alternative to the right value is "undetermined" (G9, G10) [read in source]. Shown for addition, successor, max, min; fails to be strong for fast-growing targets; cannot learn squaring.

### 3.4 The researcher's three suggestions against the record

* **"Properties of (x, y) pairs that have held so far keep holding."** For decidable properties of single pairs this is formalised and settled in UN `note.md`: the properties of complexity ≤ k leave exactly the label f(x) for K(f) + c ≤ k < sep(x;A|f) − c and no label at all for k ≥ sep(x;A) + c; "the window is SOI's margin" (G2); a weighted tally adds nothing (G3); and no scheme that is equivariant under relabelling can be stable beyond sep(x;A) + O(1) bits of machine change (G4). P1's two-sided bound (D3) says the same from SOI's side. What does go beyond SOI in the record is (i) laws relating several pairs, which make alternatives far (rigid classes, G6), (ii) a prior restricted to isolated functions (G7), and (iii) a prior over laws in a fixed vocabulary with no guards (G8–G12). Each is a choice of bias with a stated price (G5, G11), and each is for deterministic functions. [read in source]
* **"SOI isn't quite good enough."** The record's reasons: the floor and its machine dependence (D1, D2, G4); error only polynomially small even in distribution (B5); at λ = 1 the posterior does not single out the sampler from its fill-ins (E11), and in the one-tape, sequence and history-aware classes any steeper selection returns a short universal learner (E1); the one-tape version cannot represent fresh noise (A5); nothing is computable (A9(iv)). The floor remains (on the power posterior it is 2^(−λ(K(Q,b)+κ)), and a single selected program behaves off the support as the shortest fitting program does: D7), and so do the machine dependence and the non-computability. [read in source]
* **"Task decomposition, and requerying the human with some probability on the induced deployment distribution."** The repository has no result on task decomposition. For requerying it has the statements that hold for every input rule (A2, A6(b), A7, C1, C2, E4, E9), from which X1–X5 and X8 follow, and the lower bound C3(2). ## 4. Gaps: statements a protocol theorem would still need

1. **A definition of success under shift.** The record measures closeness by equality μ-a.e. (E5), an average Hellinger gap or D_{1/2} under the training input law (F4, X6), posterior error at a point (C2, D5), or belief in a wrong value (G9). None is stated for a deployment process different from the training law beyond the transfer X7. A theorem needs the deployment process (in particular the one induced by a decomposition) and the event "non-obvious failure" defined.
2. **An abstention channel with a soundness theorem for samplers.** Available: X2 for deterministic targets with a known complexity bound; "undetermined" in the equational inductor and in SAI with G9's bound on wrong beliefs; SOI's semimeasure defect, about which nothing useful is proved (D1 bounds defined-and-wrong mass from below). Missing: for a stochastic P in H_×, a statistic of the posterior and a theorem of the form "where P′ answers, its output law is within ε of P(·|x), with probability ≥ 1 − δ". X5 is one ingredient.
3. **A query bound that is not exponential in the complexity of P.** By C3(2) and X2's remark this needs a hypothesis on the shift or on P. Candidates: deployment inputs i.i.d. from a fixed unknown law (then X7(c)); a structural hypothesis on P (rigidity or isolation, G6–G7; laws in a vocabulary, G9); or accepting a bounded number of undetected errors (X3). A matching lower bound under the chosen hypothesis is also missing.
4. **Quantitative statements for one selected program on non-i.i.d. inputs.** E9(iv) gives only "eventually equivalent on the run", with no rate; C5 records that online bounds for two-part selection are in general exponentially worse than for mixtures; C4 exhibits exponential failure of single-hypothesis selection on an adversarial order (circuits and formulas), and the same question for a steeper posterior over a universal machine is open (P1 q:comp:open(d)); E10(a) shows a wrong program winning forever on a fixed non-i.i.d. sequence. So either a bound on Σ_t Hel(ν(·|x_t), ν_{π̂_t}(·|x_t)) for adaptive inputs in terms of (λ, k, δ*) must be proved, or the protocol must answer with the posterior mixture (X4), and "upload" must then be defined for a mixture.
5. **Off-support behaviour needs an explicit hypothesis on P, and its stochastic version.** By D1, D2, D7 and G4 no guarantee at an input separated from the data by a simple test can come from a universal prior. The record's two hypotheses that do pin unseen inputs (isolation; laws in a fixed vocabulary) are proved for deterministic functions, with data that are random samples under the isolation scale or a full box. Missing: versions for samplers with private coins (`note.md` open question 4; `equational.md` open question 7); for sparse data (`equational.md` open question 1); a control of the "undetermined" mass (`equational.md` open question 3); any argument that a person's behaviour satisfies such a hypothesis; and the accounting of G5 for the protocol: what is lost when the hypothesis is false, and whether that loss is an obvious failure.
6. **Which laws the "property idea" needs.** Properties of single pairs give exactly SOI's margin (G2); what pins unseen inputs is relational structure (G6, G9). There is no general theorem of the form "if P satisfies laws with small test radius, or lies in a rigid class, then after the tests are covered every fitting hypothesis of class 𝓗 is close to P at all inputs" beyond the worked cases, and none for properties that hold of sampled pairs with probability one (for example "y is a correct solution of x"), for which D3 gives only constant floors on both sides.
7. **The data model.** Real imitation data give one answer per question on inputs that rarely repeat. E5 is a per-query statement with i.i.d. inputs (on a countable input set inputs repeat, and repeats must be answered afresh); with frozen answers no procedure recovers every sampler (E9), and the finite-sample statement for frozen answers on a large domain is only in the record (SP `iid/notes-final.md` Remark 7.7, uniform finite domains). X6 is per-query. A finite-sample closeness statement for distinct inputs from a general μ is missing.
8. **Mechanism.** No theorem from (x, y) pairs can go beyond the kernel on the support (F5(a), F8 Prop 3.1). A claim of upload-likeness needs either a richer observable (intermediate work, reactions to interventions; then E5 applies to the enlarged kernel if the data are i.i.d.), or a restricted class (an assumption no data can check), or agreement off the support, which is gap 5. The researcher's footnote (the person changes while working; the notebook and environment take part) meets F7 and F8: a product class cannot represent a person with memory, and only an episodic version of E5 is proved, in the record.
9. **Person against environment.** If the person's coins depend on context visible in the input, every schedule λ_n = o(n) learns the data kernel P*, and how much context-dependence belongs to the person is among the "conventions that imitation data cannot settle" (E16(v), F5(a), F9). The toy model as posed avoids this by assuming private coins; a protocol theorem should state that assumption as F1's privacy condition.
10. **Computability and constants.** Every SOI-based statement uses objects that are not computable (A9(iv), E17); whether λ-MAPs in H_× are computable from data is open; the computable mixtures have regret constants described as "triple exponential in the index" (P1 `comp.tex`, proof idea of the time-bounded theorem) and, against samplers, exponential time per round (A9(ii)). All constants c, κ are machine-dependent and unknown, and X2 needs a numerical bound on K(f) + c.
11. **Task decomposition.** Nothing in the record. At least: the composition inequality X8 as a lemma; a model of who generates the subtask inputs; and a treatment of the dependence between the current P′_t and the input law it induces, for which only the any-input-rule statements apply. For a stochastic P the bound of X8 grows like √T, so closeness of long decompositions needs either a structure that bounds the summed error (as Σ e_t is bounded for deterministic targets, C2) or a different criterion of success.
