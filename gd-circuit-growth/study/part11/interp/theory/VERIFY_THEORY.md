## Verdict

Every numerical claim I recomputed reproduces exactly, through my own code and my own refits. That covers the P1 null simulation (280/280, 16/4800, 43/4800, 46/300) and the null full fits, the P2 parity cells (250/250, the n = 16 forced-variant mechanism, all 11 n*, the borderline probabilities), the P3 round-0 agreement and calibration (8681/8409/104/168), the first-appearance and route counts, the mod-3 Walsh weights (exact rationals equal to the table), and the P5 budget tables and FLOP decomposition (228 + 4 + 43). 7 of the 54 claims need correcting. They fix wording that overstates what is proved or measured, and one count; none changes a proof or a measured value. (1) 'A k-parity is admitted exactly when ...' should be 'passes round 0's test exactly when ...'. Admission also needs the cap and room, and the forced variant admits χ_S without the criterion. (2) 'n_thr ≈ 2k ln d' is a growth rate. The value is 2k ln d + 2 ln(4K/δ) - 2 ln k!, and 2k ln d alone is 9-44% below it on the tabulated range. (3) The '263 of 263' cells for the 1e-9 term include 16 unsearched cells; the real count is 247/247. (4) P2' bounds passing a test, not admission (forced guesses, linear block). (5) The union-bound factor 'at most 1.7' is a class median. Per character it reaches 3.3 (degree ≤ 6, local), and 44% of local entries exceed 1.7. (6) P3a's 'k ≤ 4 at every grid n' fails at n = 16. (7) The P1 headline should say the character and linear tests, since the spectral test does admit under skewed nulls.

**2. [confirmed]** P1a (Proved): under the null, in round 0 of any fit call, P(max_{|S|=k} z_S ≥ u) ≤ 2N_k(δ/(4KN_k))^{u²c²}. This is δ/(2K) = 0.0125 per degree at u = c = 1, for any d and n, and in total δ/2 (degrees 1-4) or 3δ/4 (with degrees 5-6).
- Evidence: I checked each step. (i) At round 0 the only feature is the constant, so w0, r, s and rms(r[:m]) are functions of y alone (589-595). (ii) For a fixed nonempty S the χ_S(x_t) are iid fair signs independent of y. This also holds on fold rows and permuted columns, because the folds and the permutation come from the fit rng, which is independent of the data. (iii) The threshold is c σ √(2L/m), with σ = s ≥ rms(r) on all rows. On a subsample σ = rms(r[:m]) exactly, since the clamp on s cancels in thr_m. (iv) Two-sided Hoeffding for Rademacher sums, P(|Σ r_t ε_t| ≥ λ) ≤ 2exp(-λ²/(2Σr_t²)), at λ = u c σ √(2mL) gives 2e^{-u²c²L}. (v) Each size-k set is one event: degrees 3-4 score each set once, and the degree-5/6 splits T1 ∪ T2 compute the same mean_m(r χ_S), offered only if |T1 ∪ T2| = k (line 662). So a union over C(d, k) events is valid, and then over degrees. The arithmetic δ/(2K) = 0.0125, 4·0.0125 = δ/2 and 6·0.0125 = 3δ/4 is right. The parenthetical case r[:m] = 0 cannot occur (|w0| < 1 makes every r_t nonzero) but does no harm. The statement is for exact arithmetic, as the report says.

**3. [confirmed]** P1b (Proved): in round 0, P(T1 over all d inputs > d + 2√(dx) + 2x) ≤ e^{-x}. At x = ln(1/δ) the linear test with lin = all inputs passes with probability ≤ δ, and P(a false linear block in round 0) ≤ δ + δ/(2K).
- Evidence: n s² ≥ ‖r‖², so T1 ≤ Σ Z_i² with Z_i = Σ_t a_t x_ti and Σ a_t² = 1. Given y the Z_i depend on disjoint columns, so they are independent. E exp(λZ²) = E_g Π_t cosh(√(2λ) g a_t) ≤ E_g exp(λg²) = (1 - 2λ)^{-1/2} (Tonelli, cosh u ≤ e^{u²/2}). So log E e^{λ(ΣZ² - d)} ≤ -λd - (d/2)ln(1 - 2λ) ≤ dλ²/(1 - 2λ). This is a sub-gamma bound with v = 2d and scale 2, whose Chernoff tail is 2√(dx) + 2x (Laurent-Massart Lemma 1). In round 0 lin = all d unless a degree-1 character is a candidate, and only the global degree-1 class can offer one there. Wording nit: the short answer's 'the linear block's test passes with probability at most δ' is for lin = all inputs. For a false linear block the proved bound is δ + δ/(2K) = 0.1125.
