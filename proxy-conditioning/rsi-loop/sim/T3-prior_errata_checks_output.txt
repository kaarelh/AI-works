
========================================================================
E1. Protection bought by dK bits of prior: tilt (ln O) versus plain PG on mixture logits (O)
========================================================================
matched rates: eta = 2/beta, so both operators move L at the same speed at L = 0
ratio n*_PG / n*_tilt = F(ln O) / (4 ln O)
dK =   5 bits (ln O =   3.47 nats): ratio = 2.81;  tilt-equivalent protection = 9.73 nats instead of 3.47
dK =  10 bits (ln O =   6.93 nats): ratio = 37.4;  tilt-equivalent protection = 259 nats instead of 6.93
dK =  20 bits (ln O =  13.86 nats): ratio = 1.89e+04;  tilt-equivalent protection = 2.62e+05 nats instead of 13.86
dK =  40 bits (ln O =  27.73 nats): ratio = 9.91e+09;  tilt-equivalent protection = 2.75e+11 nats instead of 27.73
P1 of train_sim, eta = 0.25, Dr = 0.0145: dK = 10 bits -> n*_PG = 1.43e+05, n*_tilt(beta = 2/eta) = 3.82e+03 episodes
P1 of train_sim, eta = 0.25, Dr = 0.0145: dK = 20 bits -> n*_PG = 1.45e+08, n*_tilt(beta = 2/eta) = 7.65e+03 episodes
